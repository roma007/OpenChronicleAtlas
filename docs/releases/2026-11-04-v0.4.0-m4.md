## 1. 里程碑目标回顾

把 Web 已验证的能力搬到 Android/iOS：同一套 shared 逻辑与 `/data/atlases` 数据，
完成地图、时间轴、详情、搜索、筛选、分享，并产出可安装的 APK/AAB 与 iOS 构建。

## 2. 交付内容

### 2.1 移动端功能

- React Navigation native-stack：专题列表 / 专题地图 / 搜索。
- 高德地图（`expo-gaode-map`）：分色路线、事件 Marker、当前事件高亮。
- 时间轴：拖动、播放/暂停、0.5/1/2/4x、日期输入、刻度自适应。
- 详情底部抽屉：Markdown、图片、来源、关联事件、分享。
- 搜索：复用 shared 索引/查询，专题筛选 chips。
- 筛选：实体、事件类型、时间段；与时间轴叠加。
- 分享：`Share.share` + `expo-linking` 深链（scheme `atlas`）。
- 隐私同意：首次启动展示高德 SDK 隐私说明，同意后初始化地图。
- Android 不申请定位权限（`blockedPermissions`）。

### 2.2 构建产物

- Android：release APK（已用 `~/.openchronicle/atlas-release.keystore` 签名）。
- iOS：模拟器 Debug 构建（`CODE_SIGNING_ALLOWED=NO`）。
- 构建脚本：`apps/mobile/scripts/configure-android-release.mjs`（签名与 ProGuard 配置）。

### 2.3 数据

- 移动端读取同一套 `/data/atlases`，未打包副本。
- 封面由 SVG 增加 JPEG 版本（RN 不支持 SVG），Web 同步使用 JPEG。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| Gradle 版本 | wrapper 自动下载 9.4.1 | 使用华为镜像下载并本地运行 | services.gradle.org/GitHub 下载超时 |
| iOS Pods | 直接 `pod install` | 设置 `HERMES_ENGINE_TARBALL_PATH` 绕过中文路径编码问题 | React Native hermes podspec 在中文路径下编码报错 |
| 开发数据 | 远端 URL | Android 开启 `usesCleartextTraffic`；iOS 允许本地网络 | 开发期 HTTP 数据服务 |
| 数据封面 | SVG | 增加 JPEG 版本 | RN Image 不支持 SVG |
| 日期显示 | `Intl` | shared 中文日期手动格式化 | Hermes 缺少中文 locale 数据 |
| R8 混淆 | 开启 | **关闭 minify** | 系统内存不足导致 R8 进程被杀；M5 在 CI/更高内存环境恢复 |
| iOS IPA | 计划可选 | 无 Apple 账号，仅模拟器构建 | 待账号就绪 |

## 5. 已知问题与限制

1. **iOS 阻塞**：高德 iOS SDK 仅提供 x86_64 模拟器 + arm64 真机切片，当前 arm64 Mac 的 iOS 模拟器无法安装 x86_64 构建；需真机 + Apple Developer 账号出 IPA，或 Intel Mac 验证。
2. Android 详情已改为全屏 Modal，TV 模拟器文字换行正常；手机真机仍建议复验。
3. 移动端未实现独立时间轴缩放控件。
4. 未做 Marker 聚合；低缩放级别可能重叠。
5. 移动端未做离线数据；依赖网络访问 `/data/atlases`。
6. 分享深链未配置 Universal Links / App Links。
7. 数据仍为示意初稿，待史料校订。

## 6. 升级 / 迁移说明

- 数据契约不变（v1.0.0）。
- 新增移动端依赖：`expo-gaode-map`、React Navigation、`expo-linking`、`react-native-markdown-display`、`expo-build-properties`、`zustand`。
- 新增环境变量：`EXPO_PUBLIC_DATA_BASE_URL`（默认 Android 模拟器 `http://10.0.2.2:5180/data/atlases`）。
