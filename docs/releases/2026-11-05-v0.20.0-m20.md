## 1. 本批次目标

用 3 个后台子代理并行推进：

1. M21：搜索拼音 chunk 懒加载；
2. M20：商店英文元数据与发布检查清单；
3. M22：第四专题「抗日战争」数据草稿。

## 2. 交付内容

### 2.1 M21 搜索拼音懒加载

- `pinyin-pro` 改为 `import()` 动态加载；
- 新增 `loadPinyinProvider()`；
- `buildSearchIndex` 支持可选拼音 provider；
- Web / 移动端搜索页先显示基础索引，拼音加载完成后自动增强；
- 移除 Vite `manualChunks` 中的 pinyin 配置；
- 拼音 chunk 不再进入首屏加载路径。

### 2.2 M20 商店英文元数据与检查清单

- `docs/releases/store-metadata-en.md`：英文名称、副标题、短/长描述、关键词、权限、AMap 披露、截图建议、审核备注；
- `docs/releases/release-checklist.md`：iOS / Android / Web / 合规 / 文档 / 回滚检查清单；
- 明确列出 5 项外部阻塞：iOS 账号、真机、商店账号、正式域名、高德商用许可。

### 2.3 M22 抗日战争数据草稿

- `data/atlases/anti-japanese-war`：29 个事件 / 9 段路线 / 3 个实体；
- 中英字段与 sources 齐全；
- 10 个政治/外交事件标记为 `routeEvent = false`；
- **未加入 `index.json`，应用内不显示**；
- 事件-路线抽查仍有 13 个实体级偏差/缺失，详见 QA 报告。
