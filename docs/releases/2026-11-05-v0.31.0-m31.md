## 1. 里程碑目标回顾

把 M23–M30 期间临时使用的事件-路线距离检查脚本产品化：逻辑进入 shared 层，提供统一命令、参数与测试。

## 2. 交付内容

### 2.1 共享 QA 模块

新增 `packages/shared/src/qa/routes.ts`：

- `distancePointToSegmentKm`：点到线段距离；
- `distancePointToRouteKm`：点到折线路线距离；
- `isRouteActiveForEvent`：事件与路线日期区间重叠判断；
- `checkDatasetRoutes` / `checkDatasetsRoutes`：专题级/多专题检查；
- 默认阈值 30km，支持覆盖；
- 跳过 `extensions.routeEvent = false` 的政治/外交事件。

### 2.2 命令入口

```bash
pnpm check:routes
pnpm check:routes --atlas anti-japanese-war
pnpm check:routes --threshold 20
pnpm check:routes --json
```

- 输出每个专题的事件数、路线段数、问题数；
- 问题详情包含事件 id、名称、实体、日期区间、距离/阈值；
- 有问题时退出码为 1。

### 2.3 测试

- 新增 `packages/shared/src/__tests__/route-qa.test.ts`；
- 覆盖点在线上、端点距离、折线最短距离、无活动路线、超阈值、`routeEvent: false`、多日事件重叠、阈值覆盖。
