## 1. 里程碑目标回顾

把 M41 标注的 `segmentType` 接入地图线型与图例，让进攻、反击、防御、撤退、航行在视觉上可区分。

## 2. 交付内容

### 2.1 共享样式与标签

新增 `packages/shared/src/route-style.ts`：

- `routeStyleForSegmentType(type)`：
  - `advance`：线宽 4，实线；
  - `counterattack`：线宽 5，实线；
  - `defense`：线宽 3，点线；
  - `retreat`：线宽 3，虚线；
  - `naval`：线宽 4，虚线；
  - `supply`：线宽 3，点线；
  - `other`：线宽 3，实线。
- `segmentTypeLabel(type, locale)`：中英文标签。

### 2.2 Web

- `MapCanvas` 按 `segmentType` 设置 `strokeWeight`、`strokeOpacity`、`strokeStyle` 与 `strokeDasharray`；
- `Legend` 新增「路线样式」区块，只列出当前专题存在的类型；
- 浏览器实测：抗日战争专题显示「进攻 / 前进、防御 / 驻守、反击 / 反攻、撤退 / 突围」四项。

### 2.3 移动端

- `AtlasMap` 按类型设置线宽与 `dotted`；
- `FilterSheet` 新增「路线样式」图例；
- iOS 不支持 `dotted`，以线宽区分。

### 2.4 文案

- 新增 `legend.routeStyles`：路线样式 / Route styles。
