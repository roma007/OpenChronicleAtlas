## 1. 里程碑目标回顾

在时间轴上显示事件点，让用户看到事件分布、直接点击跳转，并让当前事件高亮。

## 2. 交付内容

### 2.1 共享事件标记

- 新增 `timelineEventMarkers(events, timeline)`：
  - 返回事件起点/终点比例；
  - 无 `endDate` 时终点等于起点；
  - 保留越界比例，供组件过滤；
  - 按起点升序。

### 2.2 Web 时间轴

- 轨道上方增加 16px 事件点区域；
- 每个事件点 8px 圆点；
- 当前事件点朱红放大 + 外圈；
- 已发生事件朱红半透明，未来事件灰色；
- 点击事件点：暂停播放、跳到事件日期、打开详情；
- 事件点带 `aria-label` 与 `title`。

### 2.3 移动端时间轴

- 轨道上方增加 14px 事件点区域；
- 使用 `Pressable`，点击区域 12px；
- 点击同样暂停、跳转、打开详情；
- 当前事件点朱红 + 赭石外圈；
- 事件点不参与拖动 PanResponder。

### 2.4 联动

- 事件点随图层开关、类型/时间段筛选变化；
- 缩放后只渲染视口内事件；
- 拖动/播放时当前事件点自动高亮。

4. 事件点没有聚合，缩放很小的时候可能拥挤。
