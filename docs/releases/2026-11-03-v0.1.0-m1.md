## 1. 里程碑目标回顾

搭好可运行、可校验、可扩展的 monorepo 骨架，并用「长征」示例专题验证
**数据包 → shared 加载与校验 → 高德地图渲染路线与节点** 主链路。

## 2. 交付内容

### 2.1 功能

- pnpm workspaces monorepo：`apps/web`、`apps/mobile`、`packages/shared`。
- `@atlas/shared`：
  - 数据契约类型 + zod schema（v1.0.0）；
  - `loadAtlas()` / `loadAtlasIndex()` 加载器与跨文件一致性校验；
  - UTC 日粒度时间函数；
  - WGS84 ↔ GCJ-02 坐标转换；
  - 多语言字段解析。
- Web（React 19 + Vite + Tailwind + Zustand + 高德 JS API 2.0）：
  - 首页专题卡片墙；
  - 专题地图页：高德底图、按实体分色的路线 Polyline、28 个事件 Marker；
  - 点击 Marker 打开只读详情（时间、地点、主体、类型、摘要、描述、史料来源）；
  - 图例显示/隐藏实体图层；
  - 底部时间轴占位（M2 替换）。
- 移动端空壳：Expo SDK 58 + RN 0.88，包名/Bundle ID 已配置，`expo prebuild` 验证通过。
- 数据校验脚本 `pnpm validate:data`。
- 高德 Key 通过本地 `.env.local` 注入，不入库。

### 2.2 数据

- `data/atlases/long-march`：
  - 6 个实体；
  - 9 段路线（中央红军 6 段 + 红二十五军 1 段 + 红二/红四方面军 2 段）；
  - 28 个事件，均带 `sources`；
  - 封面 SVG（自制）。
- 数据标注为「示意初稿，待史料校订」；路线为简化折线，坐标为示意级别。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| Web React 版本 | React 18 | **React 19.3** | Expo SDK 58 使用 React 19，统一版本避免 `@types/react` 双版本冲突 |
| 数据规模 | 6 实体 / 6 段 / 24 事件 | **6 实体 / 9 段 / 28 事件** | 增加红二、红四、红二十五军路线，更好验证多主体 |
| 移动端 | Expo 空壳 | Expo SDK 58 + RN 0.88 空壳，prebuild 通过 | 锁定当前稳定版本 |
| 原生目录 | 计划含 android/ios | **由 prebuild 生成并 gitignore** | 采用 Expo CNG，避免提交生成代码 |
| 地图最小缩放 | 无 | fitView 后最小 4.5 | 移动端窄屏避免缩到洲际尺度 |
| 加载器 | 设计稿直接 fetch | 绑定 `globalThis` + 相对 URL 补全 | 修复浏览器 `Illegal invocation` 与相对路径解析 |

## 5. 已知问题与限制

1. 时间轴仅为占位，拖动/播放/刻度自适应在 M2。
2. 路线生长动画未实现（M2）。
3. Marker 在低缩放级别会重叠，未做聚合（M3/M2 视数据量处理）。
4. 移动端图例隐藏，暂不支持实体筛选（M4）。
5. 自定义高德地图样式未配置，当前为默认样式；`VITE_AMAP_STYLE_ID` 已预留。
6. 数据为示意初稿，日期、地点、路线需史料校订。
7. 高德 Key 曾在对话中明文传递，**上线前建议重置 Web 安全密钥**。
8. React Router 6 的 v7 future flag 警告，不影响运行；升级 v7 时处理。

## 6. 升级 / 迁移说明

- 新增环境变量：`VITE_AMAP_KEY`、`VITE_AMAP_SECURITY_CODE`、`VITE_AMAP_STYLE_ID`（可选）。
- 移动端：`EXPO_PUBLIC_AMAP_ANDROID_KEY`、`EXPO_PUBLIC_AMAP_IOS_KEY`。
- 数据契约仍为 `1.0.0`，无迁移。
