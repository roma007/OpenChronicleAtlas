## 1. 里程碑目标回顾

让专题从「可回放的地图」升级为「可查、可筛、可分享的历史工具」：
事件详情支持 Markdown/图片/关联事件/史料来源；支持跨专题搜索与专题内筛选；分享链接可恢复时间点、事件与地图视野。

## 2. 交付内容

### 2.1 shared 检索与分享

- `buildSearchIndex(datasets)`：索引事件名、地名、摘要、描述、类型、实体与日期，中英文变体全部纳入。
- `searchEvents(query, index, options)`：归一化子串匹配 + 字段评分 + 片段；支持 atlas/category/entity/时间范围/limit 过滤。
- `applyEventFilters` / `collectCategories`：类型多选 + 时间段。
- `encodeShareState` / `decodeShareState` / `buildShareUrl`：URL 参数校验与生成。
- 新增 18 个单测，shared 共 **57 个测试通过**。

### 2.2 事件详情

- Markdown 渲染（`react-markdown` + `remark-gfm` + `rehype-sanitize`），禁止原始 HTML。
- 图片懒加载、图注、作者、许可；相对路径自动拼到专题数据包。
- 关联事件跳转、史料来源展示。
- 分享按钮：优先 Web Share，1.5 秒未响应降级复制；剪贴板失败再用 `execCommand` 兜底。
- Markdown 组件按需加载，主包体积保持可控。

### 2.3 检索与筛选

- 新增 `/search` 页面：搜索框、专题筛选、结果列表、关键词高亮、空状态、错误重试。
- 首页与专题页增加「搜索」入口。
- 专题侧栏增加「筛选」：事件类型 chips、开始/结束日期、命中数量、重置；实体沿用图例开关。
- 筛选与时间轴叠加：只显示已发生且符合条件的事件；Marker、气泡、当前事件均使用过滤后集合。
- 移动端筛选改为底部浮层，390px 无横向溢出。

### 2.4 分享与深链

- 分享链接：`/atlas/<id>?t=YYYY-MM-DD&event=<id>&view=lng,lat,zoom`。
- 打开链接后恢复时间轴、选中事件与地图视野；带 `view` 时视野优先于事件定位。
- 非法日期/事件/视野参数忽略，不崩溃。
- 视野使用 GCJ-02（高德底图坐标）。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| Markdown 加载 | 直接引入 | **React.lazy 按需加载** | 避免主包超过 500KB |
| Web Share | 直接调用 | **1.5 秒超时降级复制** | 部分环境（含无头浏览器）Share 不 resolve，避免卡住 |
| 剪贴板 | `navigator.clipboard` | **失败再用 `execCommand` 兜底** | 权限受限环境仍可复制 |
| 深链视野 | 事件定位与视野同时应用 | **带 view 时视野优先** | 分享链接应精确恢复发送者看到的视野 |
| 搜索匹配 | 子串 | 子串（未做拼音/分词） | 按 Q2 约定延后到 M5 |

## 5. 已知问题与限制

1. 搜索仅子串匹配，不支持拼音、分词、错别字纠正。
2. 跨专题搜索需在首次进入 `/search` 时加载全部专题；专题多时首屏会变慢（ADR-0006 已记录迁移条件）。
3. 分享链接较长；未做短链与访问统计。
4. Markdown 图片未做 lightbox，点击在新标签打开原图。
5. 关联事件仅支持本专题。
6. 移动端筛选为浮层，M4 再统一为抽屉式。
7. 数据仍为示意初稿，待史料校订。

## 6. 升级 / 迁移说明

- 数据契约不变（v1.0.0）。
- 新增 shared 导出：`search/*`、`filters`、`share/state`。
- 新增 Web 依赖：`react-markdown`、`remark-gfm`、`rehype-sanitize`。
- 无新增环境变量。
