继续精修抗战路线，减少「示意简化」范围。第二批覆盖南京保卫战、百团大战、豫湘桂战役。

## 2. 交付内容

### 2.1 南京保卫战

- 新增 `china-resistance` 段：1937-12-01 → 1937-12-13；
- 节点：汤山 → 淳化 → 牛首山 → 雨花台 → 中华门 → 南京。

### 2.2 百团大战

- 新增 `china-resistance` 段：1940-08-20 → 1941-01-24；
- 节点：阳泉 → 娘子关 → 石家庄 → 榆次。

### 2.3 豫湘桂战役

- `japanese-advance` 段 6 加密节点：
  - 郑州 → 许昌 → 驻马店 → 信阳 → 武汉 → 岳阳 → 长沙 → 衡阳 → 桂林 → 柳州 → 南宁。

### 2.4 精度分层

- 精修段描述：`战役路线（据常见战史地图整理，待页码核对）`；
- 其余段保留：`示意简化路线，待史料校订`；
- manifest 说明同步更新。
