## 1. 里程碑目标回顾

用户提出：在地图上增加当时代的地理分布半透明遮罩。本轮把「时代疆域」做成可选数据层，地图上的多边形随时间轴与实体开关显隐，为路线与事件提供时代背景。

## 2. 交付内容

### 2.1 数据契约

- `manifest.territories?: string[]`；
- `AtlasTerritoryFeature` 支持 `Polygon` / `MultiPolygon`；
- 字段：`entityId`、`startDate`、`endDate`、`name`、`description`、`opacity`、`extensions`；
- `opacity` 限制 0—0.6，默认 0.16；
- 跨文件校验：实体存在、日期顺序、时间范围警告。

### 2.2 共享层

- 类型、schema、loader 与校验接入 `territories`；
- 搜索索引指纹纳入疆域数据，数据变化会刷新 `dataVersion`；
- 新增 `territory.test.ts`：Polygon / MultiPolygon、透明度上限、未知实体、有效数据。

### 2.3 Web 地图

- `AMap.Polygon` 半透明疆域层，位于路线与标记之下；
- 时间过滤：仅在 `startDate—endDate` 内显示；
- 实体过滤：与图例实体开关联动；
- 总开关：图例新增「时代疆域遮罩 / Period territories」按钮，默认显示；
- MultiPolygon 自动拆分为多个面。
