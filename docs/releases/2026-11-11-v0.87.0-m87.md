## 1. 里程碑目标回顾

用户在三国的 223 年发现「魏」标识位于疆域之外。原因是标识落点取外环顶点平均值，而 Cliopatria 的魏面在黄河河套一带呈凹形，平均值落在面外。本轮改为面内离边界最远的点，并重算全部 116 个标识点。

## 2. 问题与原因

| 项 | 说明 |
| --- | --- |
| 现象 | 223 年魏标识在疆域外 |
| 旧算法 | 外环所有顶点经纬度平均值 |
| 原因 | 魏面为凹多边形，平均值落在凹口/面外 |
| 影响范围 | 所有凹形或多部分疆域面 |

## 3. 修正内容

### 3.1 新算法

- 取外环包围盒，48×48 网格采样；
- 射线法判断点是否在面内（排除孔洞）；
- 计算点到所有边界的最近距离；
- 取距离最大的点；
- 在最优点附近做 11×11 局部细化；
- MultiPolygon 先选面积最大的部分。

## 7. 已知问题与限制

1. 标识点只保证在面内，不保证避开路线与事件标记；
2. 极窄或极碎的面仍可能回退到首个顶点；
3. 疆域边界仍为 Cliopatria 学术估算，不是精确国界；
4. Android 0.87.0 APK 未重建；
