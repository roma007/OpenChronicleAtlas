## 2. 交付内容

### 2.1 第二次长沙会战

- 新增事件 `changsha-1941-09`：
  - 日期：1941-09-07 → 1941-10-08；
  - 地点：湖南岳阳新墙河一线；
  - 实体：`japanese-invasion`、`china-resistance`；
  - 类型：战役；
  - 中英摘要、描述、来源齐全。
- 日军路线：新墙河 → 汨罗 → 长沙；
- 中国军队路线：长沙 → 汨罗 → 新墙河（反击方向）。

### 2.2 第三次长沙会战

- 新增事件 `changsha-1941-12`：
  - 日期：1941-12-24 → 1942-01-15；
  - 地点：湖南长沙；
  - 实体：`japanese-invasion`、`china-resistance`；
  - 类型：战役；
  - 中英摘要、描述、来源齐全。
- 日军路线：新墙河 → 汨罗 → 长沙 → 汨罗 → 新墙河（进攻与撤退）；
- 中国军队路线：长沙 → 浏阳方向 → 平江方向 → 新墙河（外围反击）。
