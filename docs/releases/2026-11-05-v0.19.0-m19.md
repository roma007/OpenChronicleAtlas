## 1. 里程碑目标回顾

搜索页此前只有关键词 + 专题筛选。本轮把 `searchEvents` 已支持的 `category/from/to` 暴露到 Web 与移动端。

## 2. 交付内容

### 2.1 Web 搜索筛选

- 类型 chips：全部类型 + `collectCategories`；
- 开始/结束日期输入；
- 「重置筛选」按钮；
- 类型、时间段、专题、关键词可叠加；
- 非法日期自动忽略；
- 重置只清筛选，不清关键词。

### 2.2 移动端搜索筛选

- 专题 chips 下方增加类型 chips 横向滚动；
- 开始/结束日期输入；
- 「重置筛选」按钮；
- 使用同一 `searchEvents` 参数；
- 中英文分类名。

### 2.3 文案

新增：

- `search.filters`
- `search.allCategories`
- `search.resetFilters`

## 6. 已知问题与限制

1. 搜索仍为子串匹配，不支持分词与纠错；
2. 时间段按事件起点过滤；
3. 移动端未重新打包 APK；
4. 类型 chips 来自全部专题，跨专题筛选时可能看到无关类型。
