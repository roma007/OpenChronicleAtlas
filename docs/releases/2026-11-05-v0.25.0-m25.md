## 1. 里程碑目标回顾

把搜索索引从运行时构建改为构建期生成，搜索页只加载一个索引文件，降低网络与计算开销。

## 2. 交付内容

### 2.1 构建期索引

- 新增 `scripts/build-search-index.ts`；
- 扫描 4 个专题，加载全部事件；
- 构建期写入拼音/首字母；
- 生成 `data/atlases/search-index.json`：
  - 4 个专题 / 103 条事件 / 270.2 KB；
  - `atlasTitle` 为多语言对象；
  - 包含完整事件对象与搜索字段。

### 2.2 搜索页改造

- Web / 移动端搜索页只请求 `search-index.json`；
- 不再加载全部专题 manifest / routes / events；
- 不再运行时构建索引；
- 不再运行时加载 `pinyin-pro`；
- 专题筛选与分类从索引 entries 派生；
- 英文界面显示英文专题名。

### 2.3 构建集成

- `package.json` 新增 `build:search-index`；
- `build` 先构建索引再构建 Web；
- `vercel.json` buildCommand 同步；
- 索引文件提交到仓库，静态部署可直接使用。
