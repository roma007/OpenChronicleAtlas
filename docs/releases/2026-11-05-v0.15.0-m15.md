## 1. 里程碑目标回顾

补齐 PWA 更新体验与 Web 缓存管理：新版本可用时提示用户，提供关于页与缓存清理入口。

## 2. 交付内容

### 2.1 PWA 更新提示

- `registerType` 从 `autoUpdate` 改为 `prompt`；
- 移除 Workbox `skipWaiting` / `clientsClaim`，让新 SW 等待用户确认；
- 使用 `virtual:pwa-register/react` 的 `useRegisterSW`；
- 新版本可用时顶部显示提示：
  - 「新版本可用」
  - 「刷新」/「稍后」
- 点击刷新调用 `updateServiceWorker(true)` 并重载。

### 2.2 关于页

新增 `/about`：

- 版本号（构建时注入 `__APP_VERSION__`）；
- 数据契约 v1.0.0；
- 地图服务 AMap；
- 离线缓存占用与条目数；
- 清除离线缓存按钮；
- GitHub / Gitee / 隐私政策链接；
- 中英文切换。

### 2.3 Web 缓存管理

- `useCacheInfo()` 读取 `caches.keys()` 与 `navigator.storage.estimate()`；
- 显示已用空间与缓存条目数；
- `clearAppCaches()` 删除所有 Cache Storage；
- 清除后自动刷新；
- 不影响 localStorage（语言等）。

### 2.4 入口与路由

- 首页页脚增加「关于」链接；
- `vercel.json` 增加 `/about` SPA rewrite；
- 新增依赖 `workbox-window`（`virtual:pwa-register/react` 需要）。

## 6. 已知问题与限制

1. 更新提示只在浏览器检测到新 SW 时出现；
2. 清除缓存后刷新，Service Worker 会重新缓存应用壳；
3. 缓存占用为浏览器存储估算值，不等于纯 Cache Storage 大小；
4. 移动端未重新打包 APK。
