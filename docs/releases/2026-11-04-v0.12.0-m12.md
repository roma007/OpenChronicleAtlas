## 1. 里程碑目标回顾

让分享链接不仅保留时间点与地图视野，还保留语言、图层与筛选状态，接收者打开后看到与分享者一致的视图。

## 2. 交付内容

### 2.1 分享状态扩展

新增字段：

| 字段 | URL 参数 | 说明 |
| --- | --- | --- |
| `locale` | `lang` | `zh` / `en` |
| `entities` | `entities` | 逗号分隔的实体 ID |
| `categories` | `categories` | 逗号分隔的事件类型 |
| `from` | `from` | 筛选开始日期 |
| `to` | `to` | 筛选结束日期 |

- 旧链接（只有 `t/event/view`）仍可解析；
- 非法语言、实体、类型、日期被忽略；
- `to < from` 时忽略 `to`；
- 实体/类型去重并限制 50 项。

### 2.2 Web

- `useShare` 分享时附加语言、图层、类型、时间段；
- `AtlasPage` 打开链接后恢复上述状态；
- 恢复实体时与专题实际实体取交集，避免空白地图。

### 2.3 移动端

- `EventSheet` 分享链接附加同样字段；
- `App.parseDeepLink` 复用 `decodeShareState`；
- `AtlasScreen` 恢复语言、图层与筛选；
- store 新增 `setActiveEntities`。

## 6. 已知问题与限制

1. 移动端未重新打包 APK，深链恢复需真机验收；
2. 分享链接为明文参数，超长筛选可能被部分平台截断；
3. 不包含服务端短链、二维码与分享统计；
4. 旧链接不会恢复语言/图层/筛选，仍按默认状态打开。
