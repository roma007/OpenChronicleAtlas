## 1. 里程碑目标回顾

把 M35 定义的 `segmentType` 真正用到数据中，并为全部路线补结构化精度标注，替代只写在描述文案里的精度信息。

## 2. 交付内容

### 2.1 全量分段类型

127 段路线全部补 `segmentType`：

| 类型 | 数量 |
| --- | --- |
| `advance` | 83 |
| `counterattack` | 20 |
| `defense` | 3 |
| `retreat` | 1 |
| `naval` | 20 |

判定规则：

- 船队实体 → `naval`；
- 日军路线 → `advance`，名称含「防御」→ `defense`；
- 盟军路线 → `advance`，松山/滇西反攻 → `counterattack`；
- 其他实体：突围/撤退 → `retreat`；保卫/城防 → `defense`；反击/反攻 → `counterattack`；其余 → `advance`。

### 2.2 全量精度标注

127 段路线全部补 `extensions.precision`：

| 精度 | 数量 |
| --- | --- |
| `campaign` | 40 |
| `schematic` | 87 |

- 描述含「战役路线」→ `campaign`；
- 否则 → `schematic`；
- 保留原有 `extensions` 键。

### 2.3 Schema 文档

`docs/schema/atlas-schema-v1.1.0.md` 新增「推荐扩展字段：precision」：

- `extensions.precision?: 'campaign' | 'schematic'`；
- 说明该字段只表达精度层级，不改变几何、日期或名称；
- 旧客户端忽略。
