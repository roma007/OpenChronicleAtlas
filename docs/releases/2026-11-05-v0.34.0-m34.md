## 1. 里程碑目标回顾

搜索索引此前同时保存完整事件对象与搜索字段，体积 323.7 KB。本轮把索引事件收敛为搜索与结果展示所需的摘要，减少重复数据与网络传输。

## 2. 交付内容

### 2.1 SearchEvent 摘要

新增 `SearchEvent` 类型，仅保留：

- id、name、date、endDate；
- location、entityIds、category、summary；
- importance。

不再写入 `description`、`sources`、`images`、`relatedIds`、`extensions`。

### 2.2 构建改造

- `buildSearchIndex` 使用 `toSearchEvent` 生成摘要；
- `SearchEntry.event` / `SearchHit.event` 改为 `SearchEvent`；
- `fields.description` 保留，描述文本仍可被搜索命中。

### 2.3 类型收敛

- `eventStart` 接受 `{ date: string }`；
- `eventEnd` 接受 `{ date: string; endDate?: string }`；
- `collectCategories` 接受 `Array<{ category: string }>`。

### 2.4 测试

- 新增「索引事件只保留搜索与展示所需字段」；
- 新增「描述文本仍保留在搜索字段中」；
- 既有搜索、拼音、分类、日期用例全部通过。
