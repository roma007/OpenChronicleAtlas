## 1. 里程碑目标回顾

用户提出：时代疆域遮罩能否增加文字标识，例如三国的魏、汉、吴。本轮为疆域面加入数据驱动的文字标识，支持中英文切换，并与遮罩同步显隐。

## 2. 交付内容

### 2.1 数据契约

- `AtlasTerritoryProperties` 新增可选 `label` 与 `labelPoint`；
- `label` 缺省回退到 `name`，再回退到实体 `name`；
- `labelPoint` 缺省取外环顶点平均值；
- `labelPoint` 经纬度范围与坐标一致。

### 2.2 地图文字层

- 使用 `AMap.Text` 渲染，`zIndex: 20`；
- 实体色文字 + 半透明羊皮纸底 + 圆角胶囊；
- `pointer-events: none`，不拦截地图与标记点击；
- 与疆域面共用时间、实体、总开关条件；
- 语言切换时重建文字层，标识同步切换；
- 修复语言切换后疆域层重建导致全部隐藏的问题。

### 2.3 标识数据（15 个）

| 专题 | 标识 |
| --- | --- |
| 隋唐 | 隋、唐（前期）、唐（后期）、吐蕃、安史 |
| 宋元 | 北宋、辽、金、南宋、蒙古、元 |
| 三国 | 魏、汉、吴、晋 |

## 6. 已知问题与限制

1. 标识为示意落点，复杂形状可能仍需人工微调 `labelPoint`；
2. 疆域与标识均为示意简化，不作为边界依据；
3. 其余 6 个专题暂无疆域面与标识；
4. Android 0.84.0 APK 未重建；
5. iOS 真机、商店账号、域名、高德许可仍未解决。
