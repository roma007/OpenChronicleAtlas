## 1. 里程碑目标回顾

用户观察到地图上不同政权的疆域遮罩互相重叠。经排查，原因是各政权面独立绘制、未共用边界，部分时间区间也存在重叠。本轮重绘三国、宋元、隋唐的示意疆域，使同期政权边界相接而不重叠。

## 2. 重叠原因

| 原因 | 说明 |
| --- | --- |
| 独立绘制 | 魏、汉、吴在荆州一带的多边形互相侵入 |
| 时间重叠 | 金从 1115 年显示，但北宋到 1127 年才结束 |
| 最大版图提前 | 金面直接用了后期华北范围 |
| 唐蕃未对齐 | 唐前期西南界切入青藏高原东缘 |
| 有意叠加 | 安史叛军控制区位于唐境内 |

## 3. 修正内容

### 3.1 三国

- 魏、汉、吴、晋改用共享边界节点；
- 魏与汉以 `103,35 → 108,34 → 111,33` 为界；
- 汉与吴以 `111,33 → 109,30 → 107,28` 为界；
- 魏与吴以 `120,34 → 117,33 → 114,33 → 111,33` 为界；
- 西晋接替魏、汉，与吴仍共享边界；
- 魏结束时间改为 266-01-31，晋从 266-02-01 开始，避免交接日重叠。

### 3.2 宋元

- 北宋北界 38—40°N，辽南界与其共享；
- 金从 1127-04 开始，接在北宋结束后；
- 金南界淮水 33—34°N，南宋北界与其共享；
- 蒙古南界与金北界共享；
- 元从 1271-12 开始，南界仍止于淮水，不覆盖南宋；
- 蒙古结束时间改为 1271-11-30，与元交接。

### 3.3 隋唐

- 唐前期西南界东移至 104°E，避开吐蕃东缘；
- 唐后期西南界退至 103°E 以东；
- 唐与吐蕃不再重叠；
- 安史控制区仍保留为唐境内占领区叠加。

### 3.4 渲染

- 疆域描边不透明度 0.4 → 0.55；
- 描边宽度 1 → 1.2，相邻政权更易分辨。
