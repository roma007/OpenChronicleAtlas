## 1. 里程碑目标回顾

补齐原始需求中尚未实现的「节点 Marker/聚合」与「时间轴缩放」，并保持三端共享逻辑一致。

## 2. 交付内容

### 2.1 事件聚合

- 新增共享聚合算法 `clusterEvents(events, zoom)`：
  - 按缩放级别计算经纬网格；
  - 同格事件合并，中心取平均坐标；
  - 网格锚点固定，平移地图时聚合结果稳定；
  - 缩放增大后自然拆分为单点。
- Web：聚合点显示事件数量，点击放大 2 级；单点点击打开详情。
- 移动端：复用同一算法，聚合点显示数量，点击放大。
- 聚合只影响 Marker，不影响路线、时间轴、搜索、筛选与详情。

### 2.2 时间轴缩放

- Web / 移动端时间轴支持 **0—8 级**缩放；
- 每级跨度减半，最小视口 1 天；
- 缩放后刻度自动从年细化到月/日；
- 拖动、日期输入、播放跟随、键盘操作均按视口换算；
- 新增共享视口工具 `createViewport` / `centerViewportStart` / `timelineSpan`。

### 2.3 共享层与测试

- `packages/shared/src/geo/cluster.ts`：事件聚合；
- `packages/shared/src/timeline/viewport.ts`：时间轴视口；
- 新增 `cluster.test.ts`（5 项）与 `viewport.test.ts`（4 项）；
- 共享测试共 **13 个文件 / 66 项**通过。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| 聚合实现 | 各端自行调用地图聚合 API | 共享网格算法 | 移动端 SDK 无统一聚合 API，共享算法保证三端一致 |
| 移动端验收 | 安装 APK 验收 | 仅 typecheck | 本轮未重建 APK；逻辑与 Web 共用并有单测 |
| 时间轴缩放 | 0—8 级 | 0—8 级 | 与计划一致 |

## 6. 已知问题与限制

1. 网格聚合在网格边界可能把相邻点分到两个聚合点；
2. 聚合点位置为成员平均坐标，不代表单个事件精确位置；
3. 移动端本轮未重建 APK，需下次打包验证真机交互；
4. 离线缓存、i18n、iOS 真机、商店提审仍不在本轮范围。
