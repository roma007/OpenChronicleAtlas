## 1. 里程碑目标回顾

按原始需求 §6.6 完成中英双语：界面可切换、数据带英文、日期与分类按语言显示、英文检索可用。

## 2. 交付内容

### 2.1 界面双语

- Web / 移动端新增 `中文 / EN` 切换；
- Web 语言写入 `localStorage`，刷新后保持；
- 首页、专题页、搜索页、详情、筛选、时间轴、隐私页、移动端隐私同意页全部双语化；
- 英文缺失时回退中文，不出现空白。

### 2.2 数据英文

- 两个专题共 **54 个事件**全部补齐：
  - 英文名称；
  - 英文摘要；
  - 英文描述；
  - 英文地点。
- 郑和专题补齐英文标题、副标题、描述与实体名称/描述；
- 长征实体补齐英文描述；
- 专题索引 `index.json` 同步英文标题与副标题。

### 2.3 语言相关逻辑

- 新增共享模块：
  - `i18n/locale.ts`：语言归一化、语言标签、切换；
  - `i18n/messages.ts`：中英文 UI 字典与占位符替换；
  - `i18n/categories.ts`：事件分类中英映射；
  - `i18n/tags.ts`：专题标签中英映射。
- 日期在英文下使用 `en-US`（如 `October 22, 1936`）；
- 分类在英文下显示 `March / Battle / Key meeting / Link-up / Voyage / Diplomacy / Policy`；
- 搜索索引的分类字段同时包含中英文，英文关键词可命中。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| 移动端语言持久化 | 可后续加 | 本轮会话内切换 | 避免新增原生存储依赖 |
| 地图底图标签 | 不要求 | 仍为中文 | 高德底图自带标签，暂不替换 |
| 史料来源标题 | 不要求翻译 | 保留中文 | 书目为中文文献，避免误译 |
