## 1. 里程碑目标回顾

为 Web 端增加渲染错误边界与基础可观测性：异常时显示可恢复的兜底页，生成错误编号，并在本地记录错误上下文。

## 2. 交付内容

### 2.1 错误记录模块

新增 `apps/web/src/lib/observability.ts`：

- 生成错误编号 `ERR-<base36 时间>-<4 位 base36 随机>`；
- 序列化 Error / 字符串 / 对象；
- `console.error` 输出带编号的结构化信息；
- 写入 `sessionStorage['atlas:error-log']`，最多 20 条；
- sessionStorage 不可用时静默降级；
- 全局监听 `error` 与 `unhandledrejection`；
- 不发送网络请求，不采集个人信息。

### 2.2 ErrorBoundary

新增 `apps/web/src/components/system/ErrorBoundary.tsx`：

- 捕获 React 渲染异常；
- 显示兜底页，不白屏；
- 展示错误编号；
- 提供「重新加载」与「返回专题」；
- 中英文文案完整。

### 2.3 入口接入

- `main.tsx` 安装全局错误监听；
- `<App />` 包裹在 `<ErrorBoundary>` 内。

### 2.4 测试

- 新增 `apps/web/src/lib/__tests__/observability.test.ts`；
- 覆盖错误编号格式、Error 序列化、非 Error 值序列化。

## 6. 已知问题与限制

1. 错误记录只保存在当前标签页的 sessionStorage，关闭标签页后清空；
2. 不提供错误上报后端，用户需手动复制错误编号反馈；
3. 移动端未增加同类错误边界；
4. Android 0.33.0 APK 未重建；
5. iOS、真机、商店账号、域名、高德许可仍未解决。
