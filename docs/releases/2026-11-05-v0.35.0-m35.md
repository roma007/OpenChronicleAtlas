## 1. 里程碑目标回顾

评估并落地数据契约 v1.1：新增事件别名与路线分段类型两个向后兼容字段；公元前日期暂缓到 v2.0。

## 2. 交付内容

### 2.1 Schema v1.1

- 新增 [ADR-0009](../decisions/ADR-0009-Schema-v1.1演进.md)；
- 新增 [Atlas Schema v1.1.0](../schema/atlas-schema-v1.1.0.md)；
- 4 个 manifest 与 `data/atlases/index.json` 的 `schemaVersion` 升为 `1.1.0`。

### 2.2 事件别名

- `AtlasEvent.aliases?: LocalizedString[]`；
- zod 校验别名数组；
- 别名进入搜索索引 `fields.name`，与正式名同权重；
- 为 6 个事件补充别名：
  - 九一八事变 → 沈阳事变；
  - 卢沟桥事变 → 七七事变；
  - 平型关大捷 → 平型关战斗；
  - 台儿庄战役 → 台儿庄大捷；
  - 百团大战 → 百团战役；
  - 第一次长沙会战 → 长沙会战。

### 2.3 路线分段类型

- 新增 `RouteSegmentType`：
  - `advance`、`retreat`、`defense`、`counterattack`、`naval`、`supply`、`other`；
- `AtlasRouteProperties.segmentType?: RouteSegmentType`；
- zod 校验枚举；
- 本轮只定义契约，不接入 UI 样式。

### 2.4 公元前日期

- 评估三种方案后暂缓到 v2.0；
- 原因：日期解析、时间轴、格式化、分享参数与全量数据迁移风险过高。

- Android `versionCode` 升为 32；
- iOS build 32；
