## 1. 里程碑目标回顾

解决 M5 审计遗留 A7 中的「离线/弱网」问题：Web 应用壳与数据可离线使用，移动端断网可加载已缓存专题。

## 2. 交付内容

### 2.1 Web 离线

- 接入 `vite-plugin-pwa` / Workbox：
  - 应用壳（JS/CSS/HTML/图标）预缓存；
  - 专题 JSON/GeoJSON 使用 `StaleWhileRevalidate`；
  - 封面图片 `CacheFirst`；
  - 高德 JS、矢量瓦片、样式与图标运行时缓存；
- SPA 深链离线回退到 `index.html`；
- `autoUpdate` + `cleanupOutdatedCaches`；
- 新增 PWA manifest（中文名称、主题色、192/512/1024 图标）。

### 2.2 离线提示

- 新增 `useOnlineStatus` 与 `OfflineBanner`；
- 断网时顶部显示胶囊提示：
  - 中文：`当前离线，已缓存内容仍可浏览。`
  - 英文：`You are offline. Cached content is still available.`

### 2.3 移动端缓存

- 新增 `CachedHttpDataSource`：
  - 网络成功时把原始 JSON 写入 AsyncStorage；
  - 网络失败时读取缓存；
  - 缓存读写失败不阻塞主流程。
- `fetchAtlasIndex` / `fetchAtlas` 全部走缓存数据源；
- 使用 Expo 兼容的 `@react-native-async-storage/async-storage@2.2.0`。

### 2.4 部署配置

- `vercel.json` 为 `/sw.js`、`/manifest.webmanifest` 增加 `no-cache` 头，确保更新及时生效。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| 离线地图瓦片 | 已浏览区域可看 | 缓存已命中，但 WebGL 地图离线仍可能空白 | 高德 WebGL 渲染依赖额外配置请求 |
| 移动端离线提示 | 不做 | 未做 | 避免再引入网络状态原生依赖 |
| 移动端缓存测试 | 可选单测 | 仅 typecheck + 逻辑审查 | 无 RN 测试环境 |

## 6. 已知问题与限制

1. 离线时高德 WebGL 地图可能空白，但路线、Marker、时间轴与详情仍可用；
2. 移动端未重新打包 APK；AsyncStorage 为新增原生依赖，下次打包需重新 prebuild；
3. 移动端缓存没有过期与容量上限，后续可加版本清理；
4. Service Worker 首次访问后才会接管，首次离线不可用。
