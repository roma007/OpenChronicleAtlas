## 1. 里程碑目标回顾

补齐键盘与屏幕阅读器体验：Skip Link、详情焦点管理、时间轴 ARIA、移动端可访问标签。

## 2. 交付内容

### 2.1 Skip Link

- 新增 `SkipLink`，Tab 首次聚焦时显示「跳到主要内容」；
- 激活后焦点进入 `#main-content`；
- 首页、搜索、隐私、关于、专题页均增加主内容 landmark。

### 2.2 详情焦点管理

- 打开事件详情时，焦点进入「关闭详情」按钮；
- 关闭详情或按 Escape 后，焦点恢复到打开前的元素（通常是事件点）；
- `<aside>` 增加 `role="dialog"`、`aria-modal="false"`、`aria-labelledby`；
- 不做完整焦点陷阱，保持侧栏语义。

### 2.3 时间轴 ARIA

- 当前事件名容器增加 `aria-live="polite"` 与 `aria-atomic="true"`；
- 当前事件点增加 `aria-current="true"`；
- 只播报事件名，不逐帧播报日期。

### 2.4 移动端

- 首页专题卡片增加 `accessibilityRole="button"` 与 `accessibilityLabel`；
- 时间轴当前事件增加 `accessibilityLiveRegion="polite"`；
- 事件点增加 `accessibilityState={{ selected }}`。

### 2.5 更新提示

- PWA 更新提示增加 `role="status"` 与 `aria-live="polite"`。
