## 1. 里程碑目标回顾

在事件详情内提供「上一事件 / 下一事件」，让用户不必关闭详情再重新找事件。

## 2. 交付内容

### 2.1 共享邻居计算

- 新增 `neighborEvents(events, eventId)`：
  - 按日期升序，日期相同按 ID 升序；
  - 返回前后各一个事件；
  - 不存在当前事件时返回空对象；
  - 不修改输入数组。

### 2.2 Web

- 详情底部增加「← 上一事件 / 下一事件 →」；
- 使用当前筛选与图层后的集合；
- 当前事件不在筛选集合时回退全量；
- 点击后暂停、跳到事件日期、更新详情；
- 首尾按钮禁用；
- 快捷键 `Alt+←` / `Alt+→`；
- 按钮 `title` 显示目标事件名与快捷键。

### 2.3 移动端

- 详情底部增加上一/下一事件按钮；
- 复用同一 `neighborEvents`；
- 点击后暂停、跳转、更新详情；
- 首尾按钮禁用。

## 6. 已知问题与限制

1. 导航基于当前筛选集合，切换筛选后前后关系会变化；
2. 日期相同的事件按 ID 排序，可能与视觉顺序不完全一致；
3. 移动端未重新打包 APK；
4. 不支持循环导航（首尾不回到另一端）。
