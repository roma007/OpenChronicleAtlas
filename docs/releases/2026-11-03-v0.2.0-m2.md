## 1. 里程碑目标回顾

在 Web 端实现通用时间轴：拖动/播放/倍速/刻度自适应，路线按时间生长，事件按时间显隐，当前事件高亮并弹出气泡。

## 2. 交付内容

### 2.1 shared 时间轴引擎

- `createTimeline / timeToRatio / ratioToTime / snapToDay / stepDays / clampToTimeline`。
- `generateTicks`：按时间跨度与可用宽度自适应选择年/月/日，目标 2–12 个刻度。
- `buildRouteGeometry / partialPathAt`：haversine 累计长度 + 二分插值截断路线。
- `eventStart / eventEnd / visibleEventsAt / latestEventAt / isEventActive`。
- `advancePlayback`：真实时间 → 专题时间，支持 0.5/1/2/4x，到达终点自动结束。
- 新增 23 个时间轴单测，shared 共 39 个测试全部通过。

### 2.2 Web 时间轴 UI

- 底部时间轴面板：主/次刻度、拖动手柄、进度填充。
- 播放/暂停、倍速 0.5/1/2/4x、日期输入跳转。
- 键盘：←/→ ±1 天，Shift+←/→ ±7 天，PageUp/PageDown ±30 天，Home/End，空格播放/暂停。
- ARIA：`role="slider"`、`aria-valuemin/max/now/valuetext`。
- 390px 移动视口下压缩刻度与倍速控件，无横向溢出。

### 2.3 地图联动

- 路线按 `currentTime` 截断生长（`Polyline.setPath`），分段独立计算。
- 事件 Marker 按日期显隐；当前事件 Marker 脉冲高亮。
- 播放跨过事件时弹出轻量气泡（事件名、日期、查看详情、关闭），4 秒自动消失；点击查看详情暂停并打开详情面板。
- 图例开关与时间轴联动。

## 4. 与计划的偏差

| 项 | 计划 | 实际 | 原因 |
| --- | --- | --- | --- |
| 事件气泡 | 高德 `InfoWindow` | **固定 UI 气泡（时间轴上方）** | InfoWindow 在标记靠近视口顶部时被裁切，`autoMove` 也无法稳定解决；固定气泡更可控、移动端更友好 |
| 播放时间精度 | 每帧 `snapToDay` | **保留亚日精度** | 每帧推进不足 1 天时会被 snap 回原点，导致播放不前进；改为连续时间，UI 显示仍按日 |
| 刻度选择 | 单纯数量优先 | 数量 + 单位权重 | 90 天步长的日刻度会压过月刻度，产生难读标签 |
| 独立缩放控件 | 待确认 | **M2 未做** | 跳转日期 + 自适应刻度已覆盖；留到后续 |

## 5. 已知问题与限制

1. 低缩放级别 Marker 仍会重叠，未做聚合。
2. 气泡展示「时间点之前最近的事件」，在事件稀疏区间可能长时间显示同一事件。
3. 播放速度固定为 60 秒走完整条时间轴（1x），未做用户自定义时长。
4. 独立时间轴缩放控件未实现。
5. 移动端时间轴仍为底部面板，M4 改为抽屉式。
6. 数据仍为示意初稿，待史料校订。
7. 大数据量（>500 事件 / >50 段）未做性能压测。
