## 1. 里程碑目标回顾

回答「抗战路线为什么仍是示意简化」后，先精修 4 个重点战役，区分「战役路线」与「示意简化」两种精度层级。

## 2. 交付内容

### 2.1 淞沪会战

- 新增 `china-resistance` 段：1937-08-13 → 1937-11-12；
- 节点：上海 → 宝山 → 罗店 → 大场 → 苏州河 → 上海。

### 2.2 台儿庄战役

- `南京—台儿庄`：南京 → 蚌埠 → 徐州 → 滕县 → 台儿庄；
- `台儿庄—武汉`：台儿庄 → 徐州 → 郑州 → 信阳 → 武汉。

### 2.3 武汉会战

- `japanese-advance` 段 5：安庆 → 九江 → 瑞昌 → 阳新 → 武汉；
- 起始日期改为 1938-06-12。

### 2.4 中国远征军/缅北反攻

- `云南—印度`：云南 → 瑞丽 → 曼德勒 → 印度；
- `缅北反攻`：缅北 → 密支那 → 八莫 → 腊戍 → 曼德勒。

### 2.5 精度分层

- 精修段描述：`战役路线（据常见战史地图整理，待页码核对）`；
- 其余段保留：`示意简化路线，待史料校订`；
- manifest 说明同步区分两类路线。
