## 1. 背景

M293、M294 补完汉末、称帝、江淮荆州与姜维北伐后，仍缺三块：
238 年司马懿平辽东、251 年淮南一叛、279—280 年晋六路灭吴。
本批按三个历史簇补齐，并首次对三国专题执行 `check:land`。

## 2. 目标

1. 补辽东、淮南一叛、晋灭吴三个簇；
2. 每条事件至少两条独立出处；无行军事件标 `routeEvent = false`；
3. 新增路线端点接既有路线或本实体事件；
4. 内河航段按规则登记例外，不调阈值；
5. 校验全绿，生成物与数据同一次提交。
