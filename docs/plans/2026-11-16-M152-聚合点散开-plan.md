## 1. 背景

同一坐标上的多个事件在任何缩放级别都被聚合成一个数字圈，点不开单个事件。用户要求放大后看到安顺场那个「5」变成 5 个单点。

## 2. 目标

1. 12 级以上把约 100m 内的共址事件散成环；
2. 位置本就分开的事件保持原位；
3. 每个散开的点直接打开事件详情；
4. 12 级以下保持数字圈与点击放大逻辑；
5. 不加新依赖、不改数据结构。

## 3. 范围

- `apps/web/src/components/map/MapCanvas.tsx`
- 本轮 docs 与 CHANGELOG

不包含：地图瓦片、聚合算法本身的网格尺寸、事件数据。
