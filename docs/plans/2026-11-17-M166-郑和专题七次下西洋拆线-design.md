## 1. 需求

M165 上线后，图例是「明朝宝船队（20 段）」「分䑸（2 段）」「明朝海防线（2 段）」。用户提出三点：

1. 把明朝宝船队线拆分为 7 次下西洋，每一次一条线路；
2. 去掉明朝海防线这条线路，但保留在地图上的划线，因为它不是线路，而是防线；
3. 分䑸不单独成一条线路，而是融入那 7 次下西洋线路中。

## 2. 设计

### 2.1 七次下西洋各一条线

原来 `ming-fleet` 的 20 段路线按航次合并为 7 条完整往返航线，每条航线一个实体：

| 实体 | 名称 | 颜色 | 起止 |
| --- | --- | --- | --- |
| `voyage-1` | 第一次下西洋 | `#123f5e` | 1405-07-11 → 1407-10-02 |
| `voyage-2` | 第二次下西洋 | `#17506f` | 1408-10-01 → 1409-08-15 |
| `voyage-3` | 第三次下西洋 | `#1f5f8b` | 1410-01-01 → 1411-07-06 |
| `voyage-4` | 第四次下西洋 | `#2a6f9b` | 1413-12-01 → 1415-08-12 |
| `voyage-5` | 第五次下西洋 | `#357fa7` | 1417-12-01 → 1419-08-15 |
| `voyage-6` | 第六次下西洋 | `#418fb2` | 1421-03-01 → 1422-09-03 |
| `voyage-7` | 第七次下西洋 | `#4d9fbd` | 1431-01-01 → 1433-07-22 |

每条航线的几何是把原有去程、返程与支线首尾相接，去掉重复端点，形成一条完整 `LineString`：

- 第一次：太仓 → 占城 → 满剌加 → 爪哇（往返）→ 锡兰山 → 古里 → 返航；
- 第二次：太仓 → 满剌加 → 锡兰山 → 返航；
- 第三次：太仓 → 满剌加 → 返航；
- 第四次：太仓 → 锡兰山 → 古里 → 忽鲁谟斯 → 麻林地 → 返航；
- 第五次：太仓 → 锡兰山 → 古里 → 阿丹 → 返航；
- 第六次：太仓 → 满剌加 → 榜葛剌（分䑸往返）→ 返航；
- 第七次：太仓 → 锡兰山 → 古里 → 阿丹 → 天方（分䑸往返）→ 返航。

### 2.2 分䑸并入航次

删除 `detached-squadron` 实体，把原「满剌加—榜葛剌（分䑸）」与返航段并入第六次航线；原「分䑸访问榜葛剌」事件改挂 `voyage-6`。第七次的「阿丹—天方」支线也并入 `voyage-7`，不再单独成段。

### 2.3 海防线降为背景

保留 `ming-coastal-defense` 实体与两段 `defense` 路线，但给实体加：

```json
"extensions": {
  "legend": false,
  "role": "defense-line"
}
```

- 图例与移动端图层列表过滤 `legend: false` 的实体；
- 地图渲染不按 `activeEntityIds` 过滤这类实体，独显某次航次时海防线仍作为背景显示；
- 路线样式区只统计图例内的路线，因此不再出现「防御 / 驻守」一行；
- 图例「说明」增加一条「沿海红色点线为明朝海防示意线，不是航线」。

### 2.4 事件归属

41 个事件按日期归入对应航次（1405—1407 → 第一次，1408—1409 → 第二次，……，1431—1433 → 第七次）。1424 年「仁宗停止下西洋」归入第六次，作为该航次之后的政策收束。
