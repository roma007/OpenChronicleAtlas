## 1. 背景

长征、郑和、玄奘三个专题已有基础时间轴，但部分关键时段仍缺事件；部分路线节点跨度较大，事件地点与路线距离偏远。

## 2. 目标

1. 长征补强渡乌江、包座战役、榜罗镇会议；
2. 郑和补旧港、苏门答剌、木骨都束；
3. 玄奘补健陀罗、波罗奈、拘尸那迦；
4. 在现有路线中插入对应节点；
5. 重新生成搜索索引。

## 3. 范围

- 三个专题的 `events.json`；
- 三个专题的 route GeoJSON；
- `data/atlases/search-index.json`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | 长征事件与节点 | data |
| S3 | 郑和事件与节点 | data |
| S4 | 玄奘事件与节点 | data |
| S5 | 索引、校验、构建、部署、tag | `v0.43.0-m43` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 事件日期存在不同说法 | 准确性 | 采用通行说法并标注待校订 |
| 路线绕行变大 | 可读性 | 只加关键节点，不重绘全线 |
| 事件地点偏离路线 | 校验失败 | 先加节点再跑 `check:routes` |

## 6. 验收

- 9 个事件字段完整；
- 事件-路线 0 个 >30km；
- 全项目 127 事件 / 127 路线段；
- 搜索索引 127 事件；
- 双仓 tag 一致。
