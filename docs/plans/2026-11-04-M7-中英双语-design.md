## 1. 总体设计

```
packages/shared/src/i18n/
├── localized.ts      # 已有 resolveLocalized(value, locale)
├── locale.ts         # Locale 类型、归一化、语言标签
├── messages.ts       # UI 文案字典 zh/en
└── categories.ts     # 事件分类 zh/en 映射
```

Web / 移动端各自维护当前语言：

- Web：`useAtlasStore.locale`，写入 `localStorage`；
- 移动端：`useAtlasStore.locale`，会话内保持（后续可持久化）。

所有展示层统一调用：

```ts
resolveLocalized(value, locale);
formatDate(time, locale === 'en' ? 'en-US' : 'zh-CN');
t(locale, 'nav.search');
categoryLabel(event.category, locale);
```

## 2. 语言与回退

| 场景 | 行为 |
| --- | --- |
| 语言为 `zh` | 优先中文，缺失回退英文 |
| 语言为 `en` | 优先英文，缺失回退中文 |
| 数据无 `en` | 回退中文，不显示空字符串 |
| 未知语言 | 归一化为 `zh` |

`Locale` 只支持 `'zh' | 'en'`，避免引入未翻译语言。

## 3. 文案字典

`messages.ts` 使用扁平 key：

```ts
export const messages = {
  zh: {
    'app.title': '史迹 · 时空地图',
    'nav.search': '搜索',
    ...
  },
  en: {
    'app.title': 'Chronicles Atlas',
    'nav.search': 'Search',
    ...
  },
} as const;
```

`t(locale, key, params?)` 支持 `{count}` 等占位符替换；缺失 key 时返回 key 本身，便于开发期发现遗漏。

## 4. 分类映射

数据中的 `category` 保持稳定中文键（`行军`、`战斗`、`重要会议`、`会师`、`航行`、`外交`、`政策`），展示与检索时映射：

| 中文 | English |
| --- | --- |
| 行军 | March |
| 战斗 | Battle |
| 重要会议 | Key meeting |
| 会师 | Link-up |
| 航行 | Voyage |
| 外交 | Diplomacy |
| 政策 | Policy |

搜索索引的 `category` 字段写入「中文 + 英文」，保证两种语言都能命中。

## 5. 数据翻译

### 5.1 事件

为每个事件补：

```json
{
  "name": { "zh": "...", "en": "..." },
  "summary": { "zh": "...", "en": "..." },
  "description": { "zh": "...", "en": "..." },
  "location": { "place": { "zh": "...", "en": "..." } }
}
```

译名原则：

- 地名使用常见英文通名（如 Zunyi, Luding Bridge, Malacca）；
- 历史专名使用通行译名（如 Long March, Zheng He）；
- 不做逐字直译，保持事件摘要可读。

### 5.2 专题与实体

- 长征 manifest 已有英文，补实体描述英文；
- 郑和 manifest 补标题、副标题、描述英文；
- 郑和实体补名称与描述英文。

## 6. Web 实现

### 6.1 状态

`useAtlasStore` 增加：

```ts
locale: Locale;
setLocale(locale: Locale): void;
```

初始化时从 `localStorage.getItem('atlas-locale')` 读取，切换时写回。

### 6.2 组件

- 新增 `useI18n()` hook：返回 `locale`、`t`、`formatDate` 包装；
- 页头增加 `中 / EN` 切换按钮；
- 所有页面与组件用 `t()` 替换硬编码文案；
- `resolveLocalized(value, locale)` 传入当前语言；
- 日期用 `formatDate(time, locale === 'en' ? 'en-US' : 'zh-CN')`；
- 隐私页按语言渲染两套段落。

## 7. 移动端实现

- `useAtlasStore` 增加 `locale` 与 `setLocale`；
- Gallery / Atlas / Search 页头增加 `中 / EN` 切换；
- 组件文案用 `t()`；
- 日期与 `resolveLocalized` 传 locale；
- 隐私同意页按语言显示；
- 不新增原生依赖，避免 prebuild。

## 8. 搜索

- `buildSearchIndex` 的 category 字段改为 `categoryLabel(category, 'zh') + ' ' + categoryLabel(category, 'en')`；
- 名称、地点、摘要、描述已经合并所有语言；
- 搜索输入英文可命中；
- 搜索结果标题、地点、摘要按当前语言解析。
