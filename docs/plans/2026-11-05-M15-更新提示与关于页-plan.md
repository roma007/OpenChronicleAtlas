# M15 更新提示与关于页 — 计划

- **日期**：2026-11-05
- **里程碑**：M15（v0.15.0-m15）
- **状态**：待确认 / 执行中
- **关联**：
  - [对话档案](../conversations/2026-11-05-M15启动与更新提示关于页方案.md)
  - [M15 方案](2026-11-05-M15-更新提示与关于页-design.md)

## 1. 背景

M8 的 PWA 使用 `autoUpdate`，新版本静默接管；用户不知道何时更新。Web 端也没有缓存管理入口，无法查看或清除离线数据。

## 2. 目标

1. 新版本可用时显示提示；
2. 用户可手动刷新激活新版本；
3. 新增 `/about` 关于页；
4. 显示缓存占用与条目数；
5. 支持清除 Web 离线缓存；
6. 中英文案。

## 3. 范围

### 3.1 包含

- PWA `registerType: 'prompt'` 与 React 更新提示；
- `/about` 页面；
- `useCacheInfo` 与 `clearAppCaches`；
- 首页页脚「关于」入口；
- 文案、版本、发布说明、tag。

### 3.2 不包含

- 服务端版本检查；
- 强制更新；
- 移动端缓存管理（M11 已有）；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | PWA prompt 与更新提示 | `vite.config.ts`、`PwaUpdatePrompt` |
| S3 | 关于页与缓存管理 | `AboutPage.tsx`、`useCacheInfo` |
| S4 | 路由、页脚入口、文案 | `App.tsx`、`AtlasGalleryPage.tsx` |
| S5 | 测试、构建、部署、tag | `v0.15.0-m15` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| SW 更新提示不出现 | 用户仍用旧版 | 构建两次验证；提供 `/about` 手动刷新入口 |
| 清除缓存后 SW 立即回填 | 用户以为没清掉 | 清除后刷新页面，让 SW 重新初始化 |
| storage.estimate 不支持 | 无法显示占用 | 显示条目数，占用显示未知 |
| 新增页面路由 | 刷新 404 | `vercel.json` 增加 `/about` rewrite |

## 6. 验收标准

- 新版本提示可见并可刷新；
- `/about` 显示版本、数据契约、地图服务、仓库链接；
- 缓存条目与占用可见；
- 清除缓存后缓存为空；
- 中英文案正确；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.15.0-m15` 一致。
