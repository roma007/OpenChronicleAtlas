# M152 聚合点散开：高缩放下共址事件逐个显示 — 方案

- **日期**：2026-11-16
- **里程碑**：M152（Web 交互批次）
- **状态**：内容已实施并通过校验
- **关联**：[M149 路线图层显示控制](2026-11-15-M149-路线图层显示控制-design.md)

## 1. 问题

事件聚合按经纬网格分组，最小格 0.05°（约 5km）。同一坐标上的多个事件——例如安顺场的「大渡河战役」「强渡大渡河」「安顺场渡口」「国民党军大渡河防线」——永远落在同一格，放大到任何级别都不会拆开。点击数字圈只会继续放大，用户无法打开其中单个事件。

## 2. 方案

高缩放级别下把**共址事件**散开成环：

- 阈值：`MARKER_SPIDERFY_ZOOM = 12`；
- 环半径：`MARKER_SPIDERFY_RADIUS_PX = 22px`；
- 分桶：同一聚合格内，坐标四舍五入到小数点后 3 位（约 100m）相同的才进入同一桶；
- 桶内 ≥2 个事件：按等角分布在环上，每个事件一个圆点；
- 桶内 1 个事件：保持原坐标，不加偏移（位置本来就分开的事件不应被挪动）；
- 每个散开的圆点直接打开对应事件详情，不再有「点不开」的聚合点。

低于 12 级仍按原逻辑显示数字圈；点击数字圈放大 2 级（上限 12 级），到达 12 级后自动散开。

## 3. 安顺场例子

5 个事件：

| 事件 | 坐标 | 显示 |
| --- | --- | --- |
| 大渡河战役 | 102.283, 29.276 | 环上 |
| 强渡大渡河 | 102.283, 29.276 | 环上（当前事件，放大态） |
| 安顺场渡口 | 102.283, 29.276 | 环上 |
| 国民党军大渡河防线 | 102.283, 29.276 | 环上 |
| 川军安顺场北岸防线 | 102.287, 29.280 | 原位（约 500m 外，不加偏移） |

12 级以上看到 4 个环形圆点 + 1 个原位圆点，共 5 个。

## 4. 实现

- `MarkerEntry` 由持有整个 cluster 改为持有事件数组；
- 新增 `MarkerGroup`，把「聚合点」与「散开的单点」统一成同一种 marker 条目；
- AMap Marker 用 `offset: new AMap.Pixel(x, y)` 做像素偏移，`anchor` 在散开时为 `center`；
- 时间轴可见性、当前事件高亮、数字圈计数逻辑不变。

## 5. 验证

- `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过；
- 浏览器 DOM 实测（1935-05-25，zoom 13）：安顺场 5 个 marker 中 4 个带环偏移（`transform-origin` 为 10px 32px / -12px 10px / 10px -12px / 32px 10px），川军北岸防线保持默认原点；
- 截图确认 5 个圆点可见。
