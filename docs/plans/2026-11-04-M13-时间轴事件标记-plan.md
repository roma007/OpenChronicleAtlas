## 1. 背景

时间轴目前只有刻度和当前事件文字，用户无法看到事件分布，也无法直接点击事件跳转。地图 Marker 已有聚合，但时间轴缺少对应的事件入口。

## 2. 目标

1. 在时间轴上显示事件点；
2. 当前事件点高亮；
3. 点击事件点跳转并打开详情；
4. 缩放后只显示视口内事件；
5. 与图层/筛选联动；
6. 共享计算逻辑与单测。

## 3. 范围

### 3.1 包含

- shared `timelineEventMarkers`；
- Web Timeline 事件点；
- 移动端 Timeline 事件点；
- 测试、版本、发布说明、tag。

### 3.2 不包含

- 事件持续时间条；
- 时间轴事件聚合；
- 新增事件数据；
- APK/IPA 打包。

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 事件点过多 | 视觉拥挤 | 只渲染视口内事件；点大小 8—10px |
| 点击区域过小 | 移动端难点 | 移动端使用 12px 点击区域 |
| 与拖动手势冲突 | 误触 | 事件点放在轨道上方独立区域 |
| 缩放后位置错误 | 跳转偏差 | 使用视口 `timeToRatio` 计算 |

## 6. 验收标准

- 时间轴出现事件点；
- 当前事件点高亮；
- 点击事件点跳到对应时间并打开详情；
- 缩放后只显示视口内事件；
- 图层/筛选变化后事件点同步；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.13.0-m13` 一致。
