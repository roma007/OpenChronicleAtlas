## 1. 背景

M86 接入 Cliopatria 后，疆域面形状比手绘面复杂得多。标识落点仍沿用「外环顶点平均值」，在凹形面上会落到面外。用户在三国的 223 年观察到「魏」标识位于疆域之外。

## 2. 目标

1. 用面内离边界最远的点替换顶点平均值；
2. 支持 Polygon 孔洞与 MultiPolygon；
3. 重新计算全部 116 个疆域面的 `labelPoint`；
4. 增加「标识点在面内」校验；
5. 保持数据契约 `1.1.0`。

## 3. 范围

- `scripts/import-cliopatria-territories.py`；
- `data/atlases/{three-kingdoms,sui-tang,song-yuan}/territories/territories.geojson`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | 实现面内最远点算法 | script |
| S3 | 重算 116 个标识点 | data |
| S4 | 校验、构建、部署、双仓 tag | `v0.87.0-m87` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 极窄或极碎的面找不到内点 | 回退到首个顶点 | 保留回退并打印警告 |
| 网格搜索较慢 | 导入时间增加 | 48×48 粗网格 + 局部细化 |
| 标识点仍靠近边界 | 视觉不佳 | 取离边界最远的点 |
| 孔洞内误判 | 标识落在湖/空白区 | 点在面内时排除孔洞 |

## 6. 验收

- 223 年魏标识在魏面内；
- 116 个标识点全部通过「点在面内」校验；
- 地图显示正常；
- 双仓 tag 一致。
