## 1. 背景

M201 删掉「辽县—沂水」「沂水—黎城」后，用户要求「查清楚其他连线有没有类似的情况，
仔细核对，不偏不倚」。因此本轮不再只盯八路军一层，而是对 11 个专题的全部 723 段路线
做统一筛查，再逐条人工判定。

## 2. 判据

一条线同时满足以下三条，才按「假连线」处理：

1. 名称是纯 `A—B`，描述只有「示意简化路线，待史料校订」这类套话；
2. 时间跨度 > 90 天，且两端不是同一次行军/战役的起止；
3. 端点分别落在**不同性质**的事件上（「某部成立」「某根据地形成」等），
   读起来像「从 A 走到 B，就地成立某事」，但史实没有这次行动。

明确**不删**的四类：防线（跨年驻守）、战役/行军（跨度即战役周期）、
水陆通道（跨朝代即使用期）、机构点位标记（1km 级，地图上是一个点）。

## 3. 筛查结果

启发式命中 145 段。逐条核对后：

- 抗日战争 45 段：删除 3 段、改写 9 段为「活动区域 / 转战区域」、13 段真实行军线补名称与收紧日期；
- 明清 36 段：删除 2 段跨事件叙事线（北京—福州、成都—武昌），其余为机构点位标记，暂不动；
- 其余专题（grand-canal、long-march、song-yuan、sui-tang、three-kingdoms、xu-xiake、
  xuanzang、zheng-he、xi-lu-jun）命中项均为真实战役、防线、游历或航次分段，不改。

详见 `docs/research/units/anti-japanese-war-route-audit.md`。

## 4. 具体改动

### 4.1 删除（5 段）

| 专题 | 路线 | 理由 |
| --- | --- | --- |
| 抗日 / 华南游击队 | 琼山—五指山（1938-12 → 1942-05） | 五指山根据地 1943—1944 才开辟，等于提前五年「到达」 |
| 抗日 / 新四军 | 云岭—黄桥（1937-10 → 1940-10） | 黄桥战役由苏北指挥部自苏南渡江发起，非军部自云岭行军 |
| 抗日 / 新四军 | 盐城—车桥（1941-01 → 1944-03） | 车桥战役由第一师在苏中发起，与军部驻地无关 |
| 明清 / 清 | 北京—福州（1661） | 迁界禁海是北京决策，福州端无对应事件 |
| 明清 / 清 | 成都—武昌（1911-06 → 10） | 保路运动与辛亥革命被连成一条线，方向还与史实相反 |

### 4.2 改写为「活动区域 / 转战区域」（9 段）

华南游击队 7 段（宝安—惠阳、琼山—六连岭、中山—五桂山、西贡—九龙、五桂山—珠江口、
潮汕—韩江、遂溪—雷州）→ `segmentType: other`，名称加「活动区域」，描述写明
「示意活动区域，非单次行军路线」。

国民党军 2 段（第58军、新3军跨 1938—1945 的转战线）→ `other` + 「转战区域」。

### 4.3 真实行军线补名称、收紧日期（抗日战争 13 段）

宝安—大岭山、琼山—美合、惠阳—香港、琼山—白沙、惠阳—东江（终点改罗浮山）、
白沙—五指山、白沙—昌感、惠阳—海陆丰、儋州—临高、东江—粤北（起点改罗浮山）、
中山—新会、中山—云雾山、云雾山—高要、白沙—尖峰岭、南雄—和平；
八路军「黎城—辽县」补黄崖洞—十字岭说明。

### 4.4 事件口径

- 「黄桥战役」「车桥战役」标 `extensions.routeEvent = false`，正文写明是战役点、不绘行军线；
- 「琼崖抗日根据地」由五指山改到琼山、文昌一带（1941 年根据地实际在琼文），
  正文写明五指山根据地 1943—1944 才开辟，并标 `routeEvent: false`；
- 「琼崖抗日独立队成立」标 `routeEvent: false`（建军建制）；
- 明清「迁界禁海」「保路运动」标 `routeEvent: false`。

### 4.5 端点与顺序

- 删除后按时间重排 `order`（华南游击队 23 → 22，新四军 5 → 3）；
- 「东江纵队挺进粤北」起点改罗浮山，接上「移驻罗浮山」；「移驻罗浮山」终点改罗浮山
  `114.1, 23.1`，两条线共用锚点；
- `route-endpoints.allow.json` 的 order 从 12/14/15 改为 11/13/14，与新编号一致，
  `reason` 改为「活动区域线，无单一行军记录」。
