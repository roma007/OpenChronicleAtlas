# M211 技术方案：地区浏览增量（as-built）

- **任务名**：地区浏览增量与范围对账
- **日期**：2026-11-20
- **里程碑**：M211
- **关联 plan**：[M211 plan](2026-11-20-M211-地区浏览增量-plan.md)
- **关联**：[M209 design](2026-11-20-M209-抗战按地区浏览-design.md) / [M210 design](2026-11-20-M210-地区标注与定位-design.md)
- **状态**：已实施

## 1. 背景

M209/M210 之后，用户连续要求“继续”，逐步追加了地区树、本区事件/路线、搜索页地区筛选、路线详情、分享状态等。功能已上线，但原计划没有这些条目。本方案把增量集中记录，明确范围。

## 2. 增量清单

### 2.1 地区树

- `RegionFilter` 从扁平列表改为 `ActiveFirst → County → Place` 树；
- 县默认收起，选中/搜索时自动展开；
- 县名加 `◎`/`≈` 前缀，与地图标注一致。

### 2.2 本区事件 / 本区路线

- 事件：按日期排序，默认 12 条，可展开；点击设置时间并选中事件；
- 路线：按开始日期排序，显示实体颜色、名称、分段类型；点击跳到结束日、缩放到路线、选中高亮；
- 移动端点击后关闭筛选面板。

### 2.3 搜索页“仅搜本区”

- 地区筛选“搜本区” → `/search?atlas=...&regions=...&regionLabel=...`；
- `SearchOptions.regionIds` 用事件已有 `location.regionIds` 过滤；
- 打开搜索结果时把 `regions` 带回专题页；
- 原 M209 将此项列为不包含，本方案正式追加为已接受范围。

### 2.4 路线选中

- `selectedRoute` 状态；
- 地图叠加光晕 + 朱砂高亮线；
- Web 随时间进度截断，移动端显示整条；
- 路线详情面板/弹层显示名称、类型、日期、主体、描述、起终点附近事件、经过地区；
- 路线与事件选中互斥。

### 2.5 分享状态

`ShareState` 扩展为：

```ts
{
  time?, eventId?, view?, locale?,
  entities?, categories?, regions?, route?,
  regionLabels?, adminBoundaries?, territories?,
  from?, to?
}
```

- `route` 使用 `entityId:order`；
- 开关使用 `1/0`；
- 旧链接只含 `t/event/view` 仍可解析。

### 2.6 省级标签

- Web 省界标签可点击筛选、悬停显示省名/今地名/来源；
- 移动端从省界 `labelPoint` 生成省名标签，4.5 级以上显示；
- 标签点击监听 DOM `click`，避免 AMap.Text 事件不触发。

## 3. 取舍

| 选项 | 结论 | 原因 |
| --- | --- | --- |
| 把增量悄悄塞进 M209 | 不采纳 | 范围不可追溯 |
| 为每个小改动开新里程碑 | 不采纳 | 文档碎片化 |
| 用一个 M211 收编增量 | **采纳** | 保持可追溯，文档不过度膨胀 |
| 搜索页地区筛选直接删掉 | 不采纳 | 已上线且有用；记录为接受扩展 |
| 县界顺手画了 | 不采纳 | 数据许可与精度不允许 |

## 4. 验收

- 地区树、本区事件/路线、搜索页仅搜本区、路线详情、分享恢复均可用；
- 旧分享链接兼容；
- `pnpm validate:data`、`typecheck`、`lint`、`test`、`build` 通过；
- 移动端真机验收仍待补。
