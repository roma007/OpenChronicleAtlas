## 1. 背景

M23–M30 期间，事件-路线距离检查一直使用临时脚本。该脚本未入库、无测试、无统一命令入口，无法在后续数据扩展中稳定复用。

## 2. 目标

1. 把检查逻辑放入 shared 层；
2. 提供 `pnpm check:routes` 命令；
3. 支持按专题过滤与阈值覆盖；
4. 补充单元测试；
5. 在完整计划中勾选该待办。

## 3. 范围

- `packages/shared/src/qa/routes.ts`（新建）；
- `packages/shared/src/index.ts`；
- `packages/shared/src/__tests__/route-qa.test.ts`（新建）；
- `scripts/check-event-routes.ts`（新建）；
- `package.json`；
- `README.md`、文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | shared QA 模块 | `qa/routes.ts` |
| S3 | 单测 | `route-qa.test.ts` |
| S4 | CLI 脚本与命令入口 | `pnpm check:routes` |
| S5 | 文档、版本、部署、tag | `v0.31.0-m31` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 距离算法误差 | 误报/漏报 | 30km 阈值下使用局部切平面，误差可忽略 |
| 多日事件匹配过严 | 误报无路线 | 使用日期区间重叠而非完全覆盖 |
| 政治事件被误报 | 噪声 | 跳过 `routeEvent: false` |
