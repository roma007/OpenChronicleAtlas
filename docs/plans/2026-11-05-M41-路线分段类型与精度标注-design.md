## 1. segmentType 规则

按以下优先级判定：

1. `entityId` 为 `ming-fleet` / `detached-squadron` → `naval`；
2. `entityId` 为 `japanese-invasion`：
   - 名称含「防御」→ `defense`；
   - 其他 → `advance`；
3. `entityId` 为 `allied-forces`：
   - 名称含「松山」或「滇西反攻」→ `counterattack`；
   - 其他 → `advance`；
4. 其他实体：
   - 名称含「突围」/「撤退」→ `retreat`；
   - 名称含「保卫」/「城防」→ `defense`；
   - 名称含「反击」/「反攻」→ `counterattack`；
   - 名称含「平型关」/「百团」→ `counterattack`；
   - 其他 → `advance`。

## 2. precision 规则

- 路线描述含「战役路线」→ `campaign`；
- 否则 → `schematic`；
- 写入 `properties.extensions.precision`；
- 保留已有 `extensions` 键。

- 说明该字段只表达精度层级，不改变几何；
- 旧客户端忽略该字段。
