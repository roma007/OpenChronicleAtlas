## 1. SearchEvent

在 `packages/shared/src/search/types.ts` 新增：

```ts
export interface SearchEvent {
  id: string;
  name: LocalizedString;
  date: string;
  endDate?: string;
  location: { lng: number; lat: number; place?: LocalizedString };
  entityIds: string[];
  category: string;
  summary: LocalizedString;
  importance?: 1 | 2 | 3;
}
```

- `SearchEntry.event` 与 `SearchHit.event` 改为 `SearchEvent`；
- 不再包含 `description`、`sources`、`images`、`relatedIds`、`extensions`。

## 2. 构建改造

`buildSearchIndex` 中：

```ts
event: {
  id: event.id,
  name: event.name,
  date: event.date,
  endDate: event.endDate,
  location: event.location,
  entityIds: event.entityIds,
  category: event.category,
  summary: event.summary,
  importance: event.importance,
}
```

- `fields` 保持现状，包括完整 `description` 文本用于搜索；
- 因此描述关键词仍可命中，但索引不再重复存完整事件对象。

## 3. 类型收敛

- `eventStart(event: { date: string })`；
- `eventEnd(event: { date: string; endDate?: string })`；
- `collectCategories(events: Array<{ category: string }>)`。

这样搜索页把 `SearchEvent[]` 传给分类收集时无需强制类型转换。

## 4. 兼容性

- `searchEvents` 入参与返回字段不变；
- 搜索结果页只使用 id/name/date/category/location/summary；
- 跳转仍通过 `atlasId + t + event`，由专题页加载完整数据。

## 5. 测试

在 `search.test.ts` 增加：

- 索引事件不包含 `description` / `sources` / `images` / `relatedIds`；
- 索引事件仍包含 id/name/date/category/location/summary；
- 既有搜索用例全部通过。
