## 1. 背景

路线只有“按日期截断的折线”，缺乏出发预告与推进感；用户要求更生动的表现形式。

## 2. 目标

1. 在矢量覆盖物上实现预告线、线头、尾迹、抵达涟漪、悬停浮签；
2. 播放时聚焦当前路线，已走完的压暗；
3. 用临时开关与画布方案做同机位对比，由用户选型；
4. 定稿后移除画布原型与开关，只保留矢量增强版。

## 3. 范围

- `apps/web/src/components/map/MapCanvas.tsx`
- `apps/web/src/components/map/RouteTooltip.tsx`（新增）
- `apps/web/src/map/route-visuals.ts`（新增，进度与弧长采样）
- `apps/web/src/styles/globals.css`（线头 / 涟漪动画）
- `apps/web/src/pages/AtlasPage.tsx`、`apps/web/src/stores/useAtlasStore.ts`（仅清理临时开关与开发钩子）
- 本轮 docs 与 CHANGELOG

不包含：节点军标符号、镜头跟随、stroke-in 动画、数据变更。
