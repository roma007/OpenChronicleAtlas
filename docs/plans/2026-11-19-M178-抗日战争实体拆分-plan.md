## 1. 缘起

用户指出地图上有一条线从阳泉直接走到昆明，要求「不是删除了事，而是弄清楚这些战役的部队都是什么部队，从哪里来，然后又去了哪里，一路上都经过了哪些地方，发生了什么事件」。

核查确认：

- 该线是 `china-resistance`（「中国抗战力量」）order 19「华北—云南（远征军）」，
  坐标 `阳泉 → 重庆 → 昆明`，日期 `1940-08-21 → 1942-02-01`，全长 1765 km；
- 它不是部队行军线，而是 2026-11-05 M21 首发时为把该层画成一条贯穿十四年的
  连续叙事线而加的转场连接线；
- 同类的跨战区转场线共 10 段（北平—上海、上海—平型关、平型关—南京、南京—台儿庄、
  台儿庄—武汉、武汉—华北、华北—云南、云南—河南、河南—松山、松山—桂林）。

## 2. 方案

用户选择「方案 A：彻底拆分实体」。

1. `china-resistance` 收缩为「中国政府与民众」层，只保留政治、外交、民众运动与
   察哈尔民众抗日同盟军（1 段路线）；
2. 删除 10 段跨战区叙事转场线；
3. 军事事件按参战部队改挂：
   - 国民党军正面战场 → `kmt-forces`；
   - 集团军 → `kmt-group-armies`；
   - 八路军 → `eighth-route-army`；
   - 远征军/盟军 → `allied-forces`；
4. 新增部队战史线：第74军、第5军、第10军、第33集团军、第18军、第1战区、第6战区、第4战区、新6军空运。
