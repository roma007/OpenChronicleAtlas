## 1. 需求修正

M162 为郑和专题新增了 13 个疆域实体，图例中因此出现「沿途邦国」以及每个政权一行。用户澄清：

- 删除「沿途邦国」这条线；
- 删除各国家的图例线；
- 图例只保留「明朝宝船队」与「分䑸」两条航线；
- 已新增的各国家边界保留在地图上。

## 2. 问题

图例目前直接遍历 `manifest.entities`。疆域实体没有路线与事件，却占了一行；「沿途邦国」也只是一个疆域分组，不是航线。

同时，疆域可见性依赖 `activeEntityIds`。如果只在图例里隐藏这些实体，用户独显某条航线时，`activeEntityIds` 只剩一个 id，所有疆域会被一起隐藏，与「边界保留」冲突。

## 3. 修法

### 3.1 图例

Web `Legend` 与移动端 `FilterSheet` 只列出**有路线或事件**的实体：

```ts
const entitiesWithData = new Set([
  ...dataset.routes.map((route) => route.properties.entityId),
  ...dataset.events.flatMap((event) => event.entityIds),
]);
```

郑和专题因此只剩「明朝宝船队」「分䑸」两行；三国等专题所有实体都有路线，行为不变。

### 3.2 疆域可见性

`MapCanvas` 对纯疆域实体（没有路线与事件）不再检查 `activeEntityIds`：

```ts
const visible =
  showTerritories &&
  (entitiesWithData.has(entityId) ? activeEntityIds.has(entityId) : true) &&
  currentTime >= start &&
  currentTime <= end;
```

这样：

- 独显某条航线时，疆域仍然显示；
- 关闭「时代疆域遮罩」仍然可以统一隐藏疆域；
- 有路线或事件的实体（如三国各政权）仍按原有图例开关控制疆域。

### 3.3 数据

不删除任何疆域面。`port-states` 与 13 个政权实体仍保留在 manifest 中，只作为疆域颜色与标识的载体，不再出现在图例。

## 4. 效果

- 图例：2 行航线 + 路线样式 + 筛选；
- 地图：27 个疆域面、边界与地名标识全部保留；
- 独显「明朝宝船队」时，沿途邦国边界不消失；
- 移动端筛选面板同样只显示两条航线。

## 5. 验证

- 图例只出现「明朝宝船队」「分䑸」；
- 默认视图与独显状态下疆域、标识均可见；
- `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过。
