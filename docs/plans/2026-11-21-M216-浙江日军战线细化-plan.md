# M216 浙江日军战线细化计划

- **日期**：2026-11-21
- **专题**：`anti-japanese-war`
- **前置**：[M213—M233 总体计划](2026-11-21-M213-日军进攻分省补全总体计划.md)、M213 江苏、M214 安徽、M215 山东
- **触发**：浙江日军事件只有杭州、宁波、温州、衢州等 14 条战役级节点，
  缺杭州湾登陆后的嘉湖、钱塘江、宁绍、温台、金衢丽的县城时序。
- **目标**：按「杭州湾登陆 → 嘉湖 → 杭州 → 宁绍 → 温台 → 浙赣战役 → 受降」补齐浙江。
- **史料核对表**：[anti-japanese-war-zhejiang.md](../research/units/anti-japanese-war-zhejiang.md)

## 1. 史实骨架

### 1.1 1937-11 ～ 1937-12：杭州湾—嘉湖—杭州

- 11/5 日军在杭州湾金山卫、全公亭登陆（既有事件）。
- 11/19 嘉兴；11/24 吴兴（湖州）；11/25 长兴；12/24 杭州。
- 1938-02-18 乔司惨案；03-04 富阳午朝庙惨案；03-26 龙溪惨案。

### 1.2 1940-01 ～ 1941-05：钱塘江—宁绍

- 1940-01-22 萧山；1940-07-17 镇海；1940-10-27 宁波细菌战。
- 1941-04-17 绍兴；04-18 瑞安；04-19 温州、镇海；04-20 宁波；04-22 慈溪；04-23 奉化、余姚。
- 1941-05-30 鄞西大皎惨案；1941-05 象山茅洋砩矿。

### 1.3 1942-05 ～ 1944-08：浙赣战役

- 1942-05-15 浙赣战役开始；05-17 诸暨；05-20 东阳；05-21 义乌；05-28 金华、兰溪；
  06-08 衢州；06-24 丽水；07-11 温州第二次沦陷；07-14 嵊县、新昌。
- 1944-08-26 丽水第二次沦陷。

### 1.4 1938 / 1945：伪政权与受降

- 1938-06-19 伪浙江省暨杭州市政府成立。
- 1945-09-04 富阳宋殿洽降；09-18 杭州日军全部缴械。
