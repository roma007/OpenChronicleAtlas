## 1. 背景与问题

M2 已经能按时间回放，但用户仍缺少三件事：

1. **看得全**：详情只有纯文本摘要，图片、关联事件、史料来源没有充分呈现；
2. **找得到**：事件多了以后，只能在地图上点 Marker，无法按名称/地点/时间搜索，也无法按类型筛选；
3. **传得走**：无法把「某个时间点 + 某个事件 + 当前视野」发给别人。

M3 的目标是用**纯前端**方案补齐这三件事，不引入后端。

## 4. 检索设计

### 4.1 索引结构

```ts
export interface SearchEntry {
  atlasId: string;
  atlasTitle: string;
  event: AtlasEvent;
  fields: {
    name: string;
    place: string;
    summary: string;
    description: string;
    category: string;
    entities: string;
    date: string;
  };
}

export interface SearchIndex {
  entries: SearchEntry[];
}

export function buildSearchIndex(datasets: AtlasDataset[], locale = 'zh'): SearchIndex;
```

- 用 `resolveLocalized` 展开多语言字段；
- 归一化：`trim`、转小写、连续空白折叠；中文不做额外处理；
- `description` 去掉 Markdown 标记后再索引（`#`、`*`、链接语法）；
- 索引在内存中构建，1–2 个专题（几十条）成本可忽略。

### 4.2 查询与评分

```ts
export interface SearchOptions {
  atlasId?: string;
  category?: string;
  entityId?: string;
  from?: AtlasTime;
  to?: AtlasTime;
  limit?: number;
}

export interface SearchHit {
  atlasId: string;
  atlasTitle: string;
  event: AtlasEvent;
  score: number;
  field: keyof SearchEntry['fields'];
  snippet: string;
}

export function searchEvents(
  query: string,
  index: SearchIndex,
  options?: SearchOptions,
): SearchHit[];
```

评分：

| 字段 | 命中方式 | 分数 |
| --- | --- | --- |
| name | 完全相等 | 100 |
| name | 包含 | 80 |
| place | 包含 | 60 |
| category | 包含 | 40 |
| entities | 包含 | 30 |
| summary | 包含 | 25 |
| description | 包含 | 15 |
| date | 包含（如 1935 / 1935-01） | 20 |

- 同一事件取最高分字段；
- 排序：分数降序 → 日期降序 → 事件 id；
- `snippet`：在命中字段中截取查询词前后各 30 字，保留省略号；
- 空查询返回空数组（搜索页显示热门/全部事件入口）；
- 所有筛选条件在查询前应用（专题、类型、实体、时间范围）。

### 4.3 搜索页

`/search`：

- 顶部搜索框（`autoFocus`），输入防抖 200ms；
- 结果列表：专题名、事件名、日期、地点、类型、摘要片段；
- 结果项键盘可聚焦，Enter 跳转；
- 空状态：「没有找到匹配事件」+ 清空按钮；
- 加载状态：骨架；
- 错误状态：重试。

跳转 URL：

```
/atlas/<atlasId>?t=<event.date>&event=<event.id>
```

## 5. 筛选设计

### 5.1 数据结构

```ts
export interface AtlasFilters {
  categories: string[];
  from?: DateString;
  to?: DateString;
}

export const EMPTY_FILTERS: AtlasFilters = { categories: [] };

export function applyEventFilters(events: AtlasEvent[], filters: AtlasFilters): AtlasEvent[];
```

- 实体筛选继续用 `activeEntityIds`（图例开关），与类型/时间段叠加；
- 时间段按事件 `date` 判断，包含边界；
- 与时间轴叠加：事件必须 `date <= currentTime` 且满足筛选。

### 5.2 筛选面板

桌面：左侧图例面板下方增加「筛选」区块：

- 事件类型 chips（从当前专题事件中收集 `category`，去重排序）；
- 开始/结束日期输入；
- 命中数量：`N / 总数`；
- 「重置筛选」按钮。

移动端：图例区域改为底部抽屉，M4 再统一；M3 用顶部「筛选」按钮打开浮层。

### 5.3 与地图/时间轴的关系

```
全部事件
  → applyEventFilters(filters)        // 类型/时间段
  → filter by activeEntityIds         // 实体
  → filter by date <= currentTime     // 时间轴
  → Marker / 气泡 / 当前事件
```

`latestEventAt` 与气泡只使用过滤后的事件，避免筛选后仍高亮被隐藏事件。

## 6. 分享与深链

### 6.1 状态编码

```ts
export interface ShareState {
  atlasId: string;
  time?: DateString;
  eventId?: string;
  view?: { lng: number; lat: number; zoom: number };
}

export function encodeShareState(state: ShareState): URLSearchParams;
export function decodeShareState(params: URLSearchParams): ShareState | null;
export function buildShareUrl(baseUrl: string, state: ShareState): string;
```

URL 示例：

```
https://atlas.example.com/atlas/long-march?t=1935-01-15&event=zunyi-1935-01&view=106.92,27.72,7
```

- `t`：`YYYY-MM-DD`，解析失败则忽略；
- `event`：`^[a-z0-9][a-z0-9-]*$`，不存在则忽略；
- `view`：`lng,lat,zoom`，范围校验失败则忽略；
- 所有字段独立校验，非法字段不影响其他字段；
- `decodeShareState` 返回 `null` 表示没有任何有效字段。

### 6.2 分享动作

```ts
export function useShare(): {
  share(state: ShareState): Promise<'shared' | 'copied' | 'failed'>;
  lastResult: 'shared' | 'copied' | 'failed' | null;
};
```

- 优先 `navigator.share({ title, url })`；
- 不支持或用户取消 → 复制到剪贴板（`navigator.clipboard.writeText`）；
- 剪贴板不可用 → 显示可选中文本；
- 成功后显示轻提示「链接已复制」。

### 6.3 深链恢复

`AtlasPage`：

```ts
const [params] = useSearchParams();
const dataset = ...;

useEffect(() => {
  if (!dataset || appliedRef.current) return;
  const state = decodeShareState(params);
  if (!state) return;
  if (state.time) setCurrentTime(parseDateString(state.time));
  if (state.eventId && dataset.eventsById.has(state.eventId)) selectEvent(state.eventId);
  if (state.view) setMapView(state.view);
  appliedRef.current = true;
}, [dataset, params]);
```

- 只在数据集首次加载后应用一次；
- `eventId` 不属于当前专题则忽略；
- 时间越界由 `setCurrentTime` clamp；
- 视野恢复由 `MapCanvas` 监听 `mapView` 变化，调用 `setZoomAndCenter`。

### 6.4 地图视野同步

- `MapCanvas` 监听 `moveend` / `zoomend`，把 `{ lng, lat, zoom }` 写入 store（GCJ-02 坐标）；
- 分享时把 `mapView` 原样写入 URL；
- 深链恢复时设置 `mapView`，`MapCanvas` 应用一次；
- 注意：URL 中的 view 是 GCJ-02（高德坐标），与数据 WGS84 不同；分享链接只用于高德底图，文档需注明。

## 7. 事件详情增强

### 7.1 Markdown

```tsx
<Markdown>{resolveLocalized(event.description)}</Markdown>
```

- `react-markdown` + `remark-gfm` + `rehype-sanitize`；
- 禁止原始 HTML（不启用 `rehype-raw`）；
- 链接：`target="_blank"` + `rel="noreferrer noopener"`；
- 图片：`loading="lazy"`、`referrerPolicy="no-referrer"`、最大宽度 100%；
- 代码块、表格、引用样式与专题视觉一致。

### 7.2 图片

- 使用 `event.images`，渲染为网格；
- 图注、作者、许可；
- 加载失败显示占位；
- 点击可放大（M3 可用原生 `dialog` 或简单 lightbox，非必需）。

### 7.3 关联事件

- `relatedIds` 解析为事件名 + 日期；
- 点击后：暂停播放、选中事件、地图定位；
- 跨专题关联（M5）暂不支持。

### 7.4 分享按钮

- 详情面板顶部/底部放「分享」按钮；
- 分享状态：当前专题 + 当前时间 + 当前事件 + 当前视野；
- 分享成功后按钮短暂显示「已复制」。

## 8. 技术取舍（Trade-offs）

| 议题 | 选项 | 结论与理由 |
| --- | --- | --- |
| 搜索实现 | A. 后端 API / B. 构建期索引 / C. 运行时内存索引 | **C**。M3 专题少、纯静态；实现最快；后续可平滑切 B |
| 搜索匹配 | A. 子串 / B. 分词 / C. 拼音 | **A**。中文分词/拼音成本高，M5 再评估 |
| Markdown | A. 自研 / B. react-markdown | **B**。生态成熟，配合 sanitize 安全 |
| 分享状态 | A. 短链后端 / B. URL query | **B**。无后端依赖，可离线生成 |
| 视野坐标 | A. WGS84 / B. GCJ-02 | **B**。分享链接直接用于高德地图，避免再转换误差 |
| 筛选位置 | A. 搜索页 / B. 专题页 | **B**。筛选是专题内操作；全局搜索是独立页面 |

## 9. 兼容性、性能与安全

### 9.1 兼容性

- `navigator.share` 不支持时降级剪贴板；
- `navigator.clipboard` 需要 HTTPS/localhost；
- 日期输入 `type="date"` 不支持时降级文本 + 校验；
- Markdown 组件按需加载，避免首屏体积。

### 9.2 性能

- 搜索索引在首次进入 `/search` 时构建，缓存在 store；
- 输入防抖 200ms；
- 结果最多渲染 50 条，超出显示「缩小范围」；
- Markdown 仅在详情打开时加载。

### 9.3 安全

- `rehype-sanitize` 消毒，禁止 `script`/`iframe`/事件属性；
- 外链 `rel="noreferrer noopener"`；
- URL 参数严格校验，避免注入与崩溃；
- 不在 URL 中放任何密钥。

## 10. 关键代码骨架

### 10.1 `search/query.ts`

```ts
export function searchEvents(query: string, index: SearchIndex, options: SearchOptions = {}): SearchHit[] {
  const normalized = normalize(query);
  if (!normalized) return [];

  const hits: SearchHit[] = [];

  for (const entry of index.entries) {
    if (options.atlasId && entry.atlasId !== options.atlasId) continue;
    if (options.category && entry.event.category !== options.category) continue;
    if (options.entityId && !entry.event.entityIds.includes(options.entityId)) continue;
    if (options.from && eventStart(entry.event) < options.from) continue;
    if (options.to && eventStart(entry.event) > options.to) continue;

    const match = bestMatch(entry, normalized);
    if (!match) continue;

    hits.push({
      atlasId: entry.atlasId,
      atlasTitle: entry.atlasTitle,
      event: entry.event,
      score: match.score,
      field: match.field,
      snippet: makeSnippet(entry.fields[match.field], normalized),
    });
  }

  return hits
    .sort((a, b) => b.score - a.score || b.event.date.localeCompare(a.event.date))
    .slice(0, options.limit ?? 50);
}
```

### 10.2 `share/state.ts`

```ts
export function encodeShareState(state: ShareState): URLSearchParams {
  const params = new URLSearchParams();
  if (state.time) params.set('t', state.time);
  if (state.eventId) params.set('event', state.eventId);
  if (state.view) {
    const { lng, lat, zoom } = state.view;
    params.set('view', `${lng.toFixed(6)},${lat.toFixed(6)},${zoom.toFixed(2)}`);
  }
  return params;
}

export function decodeShareState(params: URLSearchParams): ShareState | null {
  const time = params.get('t');
  const eventId = params.get('event');
  const viewRaw = params.get('view');

  const validTime = time && /^\d{4}-\d{2}-\d{2}$/.test(time) ? time : undefined;
  const validEvent = eventId && /^[a-z0-9][a-z0-9-]*$/.test(eventId) ? eventId : undefined;

  let view: ShareState['view'];
  if (viewRaw) {
    const [lng, lat, zoom] = viewRaw.split(',').map(Number);
    if (
      Number.isFinite(lng) && Math.abs(lng) <= 180 &&
      Number.isFinite(lat) && Math.abs(lat) <= 85 &&
      Number.isFinite(zoom) && zoom >= 0 && zoom <= 22
    ) {
      view = { lng, lat, zoom };
    }
  }

  if (!validTime && !validEvent && !view) return null;
  return { atlasId: '', time: validTime, eventId: validEvent, view };
}
```

### 10.3 `useShare.ts`

```ts
export function useShare() {
  const [lastResult, setLastResult] = useState<'shared' | 'copied' | 'failed' | null>(null);

  const share = async (state: ShareState) => {
    const url = buildShareUrl(window.location.origin, state);
    if (navigator.share) {
      try {
        await navigator.share({ title: '史迹 · 时空地图', url });
        setLastResult('shared');
        return 'shared' as const;
      } catch {
        // 用户取消或失败，降级复制
      }
    }
    try {
      await navigator.clipboard.writeText(url);
      setLastResult('copied');
      return 'copied' as const;
    } catch {
      setLastResult('failed');
      return 'failed' as const;
    }
  };

  return { share, lastResult };
}
```
