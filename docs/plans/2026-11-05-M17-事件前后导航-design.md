## 1. 共享邻居计算

```ts
export interface EventNeighbors {
  previous?: AtlasEvent;
  next?: AtlasEvent;
}

export function neighborEvents(
  events: AtlasEvent[],
  eventId: string,
): EventNeighbors;
```

- 按 `date` 升序，日期相同按 `id` 升序；
- 找到当前事件后返回前后各一个；
- 当前事件不存在时返回空对象；
- 不修改输入数组。

## 2. Web

### 2.1 导航集合

```ts
const filtered = applyEventFilters(dataset.events, filters).filter((event) =>
  event.entityIds.some((id) => activeEntityIds.has(id)),
);
const pool = filtered.some((candidate) => candidate.id === event.id)
  ? filtered
  : dataset.events;
const neighbors = neighborEvents(pool, event.id);
```

### 2.2 UI

在详情底部增加：

```tsx
<div className="flex items-center justify-between gap-2">
  <button disabled={!neighbors.previous}>← 上一事件</button>
  <button disabled={!neighbors.next}>下一事件 →</button>
</div>
```

- 显示目标事件名作为 `title`；
- 点击：`pause()` → `setCurrentTime(eventStart(target))` → `selectEvent(target.id)`；
- 首尾按钮 `disabled`。

### 2.3 快捷键

在现有 `keydown` effect 中：

```ts
if (keyboardEvent.altKey && keyboardEvent.key === 'ArrowLeft') { ... }
if (keyboardEvent.altKey && keyboardEvent.key === 'ArrowRight') { ... }
```

- 阻止默认行为；
- 没有上一/下一事件时忽略。

## 3. 移动端

`EventSheet` 底部增加两个按钮：

- 上一事件 / 下一事件；
- 使用同一 `neighborEvents`；
- 点击后暂停、跳转、更新详情；
- 首尾禁用。

## 5. 测试

- `neighborEvents` 返回正确前后事件；
- 首尾返回 undefined；
- 日期相同按 ID 排序；
- 不存在的 ID 返回空对象；
- Playwright：详情显示上一/下一，点击切换，Alt+方向键切换。
