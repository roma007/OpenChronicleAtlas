## 2. 质量标准（每省验收线）

达到「海南/广东标准」= 同时满足以下 5 条：

1. **登陆/出发**：沿海、沿江省份必须有登陆点或渡江点事件，写清出发地、登陆地、日期。
2. **县城时序**：主要县城/城市逐个有沦陷事件；日期有异说的写明异说，考不实的标「待考」。
3. **进攻路线**：每次主要进攻至少一段线；路线端点必须落在同一实体的事件上，禁止直线硬连。
4. **暴行/资源/统治**：至少覆盖该省最重大的惨案、资源掠夺、伪政权/据点/清乡之一。
5. **受降/光复**：该省有受降仪式的必须补；没有单独仪式的，写进战区受降事件并在正文说明。

数量参考（不是硬指标，准确优先）：

- 小省/日军仅局部入侵：≥ 12 事件、≥ 5 段路线；
- 中等省：≥ 20 事件、≥ 8 段路线；
- 主战场省（苏、皖、鲁、冀、晋、豫、鄂、湘、赣、浙）：≥ 30 事件、≥ 12 段路线；
- 广东（含海南）已经是 89 / 55，后续只做校订，不再追求数量。

## 4. 每批固定流程（不可跳步）

1. **建研究笔记**：`docs/research/units/anti-japanese-war-<省>.md`，先列史料中的日期、地点、主体、异说。
2. **列事件清单**：城市/登陆点/暴行/资源/受降，逐条写「日期 + 出处 + 是否画线」。
3. **列路线清单**：出发地 → 经过地 → 终点，每段写日期区间与史料依据。
4. **写数据**：事件追加到 `events/events.json`，路线追加到 `routes/japanese-advance.geojson`，
   路线 `order` 全专题唯一且递增。
5. **补地区字典**：在 `scripts/build-region-data.py` 的 `COUNTY_HINTS` 增加当时县名，
   让事件落到「省 → 县 → 地点」；然后运行 `python3 scripts/build-region-data.py`。
6. **校验**：第 5 节命令全部通过；`check:heads` 必须 0 个无来由端点。
7. **文档**：专题 README、manifest 描述、CHANGELOG、研究笔记、对话档案同一次提交。
8. **提交 + 发布**：按 `AGENTS.md` 第 2、7 节执行 `pnpm release`，确认线上自检四条全过。

## 5. 验收命令

```bash
pnpm validate:data
pnpm check:routes --atlas anti-japanese-war
pnpm check:heads --atlas anti-japanese-war
pnpm check:land --atlas anti-japanese-war   # 涉及海路/江路时
pnpm typecheck
pnpm lint
pnpm test
pnpm build:search-index
pnpm build:mobile-data --check
```

补充人工检查：

- 抽 5 个事件，逐个在来源中能查到日期与地点；
- 抽 3 段路线，起终点均能在同实体事件中找到锚点；
- 检查 `region-index.json` 中每个新增事件都有省 + 县/地点归属；
- 检查没有把中国军队的路线挂到 `japanese-invasion`，反之亦然。

## 6. 风险与停线条件

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 网络史料互相抄错、日期冲突 | 史实错误，政治风险 | 至少两条独立来源；冲突写异说；宁标待考 |
| 把不同部队/不同时间拼成一条线 | 主体错乱 | 一条路线只挂一个实体；端点必须有同实体事件 |
| 为凑数量补「某县沦陷」但无日期 | 假精确 | `routeEvent:false` + 「月份待考」，不画线 |
| 省界/县治归属用今名 | 地区筛选错 | 用 1937 年县名，今名写进 `modernName` |
| 一次改太多无法回溯 | 出错难定位 | 一批一提交；研究笔记逐条对应 |

**停线条件**：任何一条新增事件无法给出两条来源，或任何一条路线端点找不到史实锚点，
该条不得进入本次提交；先写进研究笔记的「待考」区。
