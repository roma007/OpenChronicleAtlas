## 1. 背景

平台已有路线、事件、时间轴与实体图层，但地图缺少「当时代地理分布」的背景层。用户希望在地图上增加半透明疆域遮罩，让路线与事件落在时代背景中，而不是悬空于现代底图。

## 2. 目标

1. 数据契约新增可选 `territories`，支持 Polygon / MultiPolygon；
2. 共享层完成类型、schema、loader、跨文件校验与测试；
3. Web 地图渲染半透明疆域面，随时间轴与实体开关显隐；
4. 图例新增「时代疆域遮罩」显示开关；
5. 为隋唐、宋元、三国补充示意疆域数据；
6. 保持数据契约 `1.1.0`。

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 历史边界争议 | 误导用户 | 全部标注「示意简化疆域」，只作背景 |
| 面遮挡路线 | 可读性下降 | 默认 0.14—0.2 透明度 + 一键关闭 |
| 多边形跨 180° 经线 | 渲染异常 | 本期专题均在中国及周边，不跨经线 |
| 旧客户端不识别新字段 | 兼容性 | 字段可选，旧客户端直接忽略 |
| 数据指纹未覆盖疆域 | 版本不更新 | 将 territories 纳入索引指纹 |

## 6. 验收

- 地图出现半透明疆域面；
- 时间轴移动时疆域随时间切换；
- 实体关闭时对应疆域隐藏；
- 「时代疆域遮罩」开关可整体显隐；
- 9 专题 / 531 事件 / 443 路线段通过校验；
- 双仓 tag 一致。
