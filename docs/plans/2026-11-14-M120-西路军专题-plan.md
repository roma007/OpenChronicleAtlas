## 1. 背景

西路军（1936-10 渡黄河—1937-03 石窝分兵）与长征尾段紧密相关，但超出 `long-march` 专题 1936-10-22 的时间范围。继续放入长征专题会破坏「长征结束」的时间边界，因此单开「西路军」专题。

## 2. 目标

1. 新建 `data/atlases/xi-lu-jun/` 专题：manifest、6 个事件、2 段路线、1 个实体；
2. 将新专题加入 `data/atlases/index.json`；
3. 重新生成搜索索引与移动端内置数据映射；
4. 不改版本号、不部署、不打 tag。

## 3. 范围

### 3.1 包含

- `data/atlases/xi-lu-jun/manifest.json`
- `data/atlases/xi-lu-jun/events/events.json`
- `data/atlases/xi-lu-jun/routes/xi-lu-jun.geojson`
- `data/atlases/index.json`
- `data/atlases/search-index.json`
- `apps/mobile/src/generated/atlasData.ts`
- 本轮 docs 与 CHANGELOG

### 3.2 不包含

- 修改 `long-march` 专题时间范围；
- schema 变更；
- UI 渲染逻辑；
- 西路军各军、师逐条路线；
- 版本号、部署、tag。

## 5. 实施步骤

1. 记录本轮需求、专题边界与表述口径；
2. 新建 manifest、实体、6 个事件、2 段路线；
3. 将专题摘要加入 `data/atlases/index.json`；
4. 运行 `pnpm validate:data`、`pnpm check:routes --atlas xi-lu-jun`；
5. 运行 `pnpm build:search-index`、`pnpm build:mobile-data`；
6. 运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`；
7. 更新 CHANGELOG 与本轮文档。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 西路军历史评价敏感 | 表述风险 | 高 | 只做事实节点，不展开路线斗争评价 |
| 梨园口、石窝山无精确坐标 | 点位偏差 | 高 | 用代表点，标 `approx`，描述注明待实测 |
| 伤亡数字统计不一 | 数字争议 | 中 | 采用公开党史常用数字，未决问题注明 |
| 新专题未加入 index | 搜索/移动端缺失 | 高 | 先加 index 再 build |
| 移动端文本文件数量变化 | 内置映射缺失 | 中 | 运行 `build:mobile-data --check` |
