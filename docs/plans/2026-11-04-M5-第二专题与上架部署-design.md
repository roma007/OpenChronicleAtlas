## 2. 第二专题：郑和下西洋（1405—1433）

### 2.1 选题理由

- 时间跨度 28 年，正年份，适合时间轴；
- 航线跨东南亚、印度洋、阿拉伯海、东非，适合地图展示；
- 多航线/多主体，可验证 schema 的多实体能力；
- 史料相对丰富，便于标注来源。

### 2.2 数据包结构

```
data/atlases/zheng-he/
├── manifest.json
├── routes/
│   └── voyages.geojson
├── events/
│   └── events.json
└── assets/
    └── cover.jpg
```

### 2.3 实体

| id | 名称 | 颜色 | 说明 |
| --- | --- | --- | --- |
| ming-fleet | 明朝宝船队 | `#1f5f8b` | 郑和统率的main fleet |
| detached-squadron | 分䑸 | `#b8863b` | 分头访问的支队 |
| port-states | 沿途邦国 | `#5b7f6b` | 满剌加、古里、忽鲁谟斯等 |

### 2.4 航线

`routes/voyages.geojson` 按 7 次航行拆分为 6–7 段，每段：

```jsonc
{
  "entityId": "ming-fleet",
  "startDate": "1405-07-11",
  "endDate": "1407-10-02",
  "order": 1,
  "name": { "zh": "第一次下西洋" }
}
```

主要节点：南京/太仓 → 泉州 → 占城 → 满剌加 → 锡兰山 → 古里 → 忽鲁谟斯 → 麻林地（东非）。

### 2.5 事件（24 个）

覆盖：首次出航、宝船建造、满剌加设官厂、锡兰山之战、古里立碑、忽鲁谟斯、东非麻林、第七次出航、卒于古里等。
每个事件包含 `sources`，标注「初稿待校订」。

### 2.6 时间范围

`1405-07-11` — `1433-07-22`。

### 2.7 封面

自制 SVG → JPEG（1200×675），与长征封面同一视觉体系。

## 3. 多专题行为

- 首页读取 `index.json`，两张卡片；
- 搜索页 `loadSearchData` 加载两个专题，`buildSearchIndex` 自动合并；
- 专题页只加载当前 manifest 与 routes/events；
- 不修改任何加载/渲染代码，验证「专题可插拔」。

---

## 4. 隐私政策页面

新增 Web 路由 `/privacy`，内容：

1. 我们收集什么：不收集账号信息；地图 SDK 可能收集设备/网络信息与地图交互信息；
2. 高德 SDK 披露：高德软件有限公司、高德地图 SDK、信息类型、用途、官方隐私政策链接；
3. 权限说明：M5 不申请定位权限；如未来启用，会先征得同意；
4. 数据存储：静态数据包不含个人信息；分享链接只含专题/时间/事件/视野；
5. 联系方式与更新日期。

移动端同意页的「查看隐私政策」链接到 `EXPO_PUBLIC_PRIVACY_URL`（默认部署域名 `/privacy`）。

## 5. 图标与启动图

### 5.1 设计

- 主色：墨色底 + 暗红路线 + 土黄印章；
- 图形：抽象路线 + 罗盘/时间刻度；
- 无文字，避免小尺寸不可读。

### 5.2 产物

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `icon.svg` | 1024×1024 | 源文件 |
| `icon.png` | 1024×1024 | iOS/通用 |
| `adaptive-icon.png` | 1024×1024 | Android 前景 |
| `splash.png` | 1284×2778 | 启动图 |
| `favicon.svg/png` | 64/32 | Web |

生成方式：SVG → `qlmanage`/`sips` → PNG；源文件入库，二进制按需入库（图标体积小）。

### 5.3 配置

```jsonc
// app.json
{
  "expo": {
    "icon": "./assets/icon.png",
    "splash": { "image": "./assets/splash.png", "resizeMode": "contain", "backgroundColor": "#f3ead9" },
    "android": { "adaptiveIcon": { "foregroundImage": "./assets/adaptive-icon.png", "backgroundColor": "#231c15" } },
    "web": { "favicon": "./assets/favicon.png" }
  }
}
```

## 6. 部署方案

### 6.1 Vercel

```json
{
  "buildCommand": "pnpm --filter @atlas/web build",
  "outputDirectory": "apps/web/dist",
  "installCommand": "pnpm install --frozen-lockfile",
  "framework": "vite",
  "headers": [
    { "source": "/data/(.*)", "headers": [{ "key": "Cache-Control", "value": "public, max-age=3600" }] }
  ]
}
```

环境变量：

```
VITE_AMAP_KEY
VITE_AMAP_SECURITY_CODE
VITE_AMAP_STYLE_ID (可选)
```

### 6.2 Cloudflare Pages 备选

- Build command: `pnpm --filter @atlas/web build`
- Output: `apps/web/dist`
- 环境变量同上。
- 数据随构建拷贝到 `dist/data`。

### 6.3 移动端

```
EXPO_PUBLIC_DATA_BASE_URL=https://<域名>/data/atlases
EXPO_PUBLIC_PRIVACY_URL=https://<域名>/privacy
```

生产环境必须 HTTPS；Android 的 `usesCleartextTraffic` 仅用于开发。
