## 1. 需求

用户发现郑和专题的明疆域面没有覆盖台湾本岛，追问“明朝时台湾不属于明吗”。查证后确认：

- 按明朝正式行政疆域（府县、卫所、编户、征税），台湾本岛不属于明；
- 明朝将台澎视为东南海防要地，多次派兵入台追剿海盗与倭寇，明末官员也提出过在台湾设郡县的设想，但未实施。

用户要求在专题中加上说明。

## 2. 史实依据

| 史料 | 关键内容 |
| --- | --- |
| 《明史》卷 45《地理六·福建》 | 福建布政使司领八府一州五十七县，海中有彭湖屿，无台湾府县 |
| 明崇祯年间给事中何楷奏疏 | 台湾“其地广衍膏腴，可比一大县，中国版图所不载” |
| 清《续修台湾府志》 | “台湾，古未隶中国版图”；“海外苍茫岛屿，自古未有建郡县者……迨入国朝版图” |
| 《道光福建通志台湾府》 | “台湾府 康熙二十三年始入版图，立府”；明栏记作“东番地”“红毛地” |
| 中研院台湾史研究所 | 1661 年郑成功设承天府、天兴县、万年县，为台湾第一次正式行政区划 |
| 《明实录》等 | 嘉靖、万历年间明军多次入台追剿海盗倭寇；明末有“郡县彼土”之议，未实施 |

结论：**“海防要地”不等于“正式行政疆域”**。地图不应把台湾本岛涂成明朝疆域色，但应说明明朝对台澎的海防经营。

## 3. 实现

### 3.1 示意标注面

新增实体 `dongfan`（东番 / Dongfan）：

- 颜色 `#6b6256`，`order: 23`；
- 只用于表示台湾本岛的示意标注，不表示明朝疆域；
- 在地图上画台湾本岛轮廓，`opacity: 0`，只描边不填充；
- `label` 为“东番（台湾）· 未设府县”；
- `description` 说明明朝海防要地但未设府县。

该实体没有路线与事件，按 M163 的规则不进入图例，只作为疆域标注层显示。

### 3.2 图例说明

manifest 增加：

```json
"extensions": {
  "notes": [
    {
      "zh": "东番（台湾）：明朝海防要地，未设府县。",
      "en": "Dongfan (Taiwan): a Ming coastal-defence frontier, without Ming prefectures or counties."
    }
  ]
}
```

Web `Legend` 与移动端 `FilterSheet` 读取 `extensions.notes`，在图例/筛选面板显示“说明”块。该字段为通用扩展，其它专题不填则不显示。

### 3.3 生成

`scripts/build-zheng-he-territories.py` 增加东番示意面，`opacity` 支持按规则覆盖，重新生成 28 个疆域面。

## 4. 效果

- 图例：“说明：东番（台湾）：明朝海防要地，未设府县。”；
- 地图：台湾本岛有灰色细描边与“东番（台湾）· 未设府县”标识，不填明朝色；
- 不改变明、清、日本等任何现代边界表达；
- 其它专题不受影响。
