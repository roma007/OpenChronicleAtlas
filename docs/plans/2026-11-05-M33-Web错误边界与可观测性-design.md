## 1. 错误记录模块

新增 `apps/web/src/lib/observability.ts`：

```ts
export interface ClientErrorRecord {
  id: string;
  timestamp: string;
  message: string;
  stack?: string;
  context: string;
  url: string;
}

export function createErrorId(now?: number, random?: () => number): string;
export function serializeError(error: unknown): { message: string; stack?: string };
export function reportClientError(error: unknown, context?: string): ClientErrorRecord;
export function getRecentClientErrors(): ClientErrorRecord[];
export function installGlobalErrorHandlers(): () => void;
```

行为：

- 错误编号格式 `ERR-<base36 时间>-<4 位 base36 随机>`；
- `console.error` 输出带编号的结构化信息；
- 写入 `sessionStorage['atlas:error-log']`，最多 20 条；
- sessionStorage 不可用或 JSON 损坏时静默降级；
- 全局监听 `error` 与 `unhandledrejection`，返回清理函数；
- 不发送网络请求，不采集个人信息。

## 2. ErrorBoundary

新增 `apps/web/src/components/system/ErrorBoundary.tsx`：

- 类组件实现 `getDerivedStateFromError` + `componentDidCatch`；
- `componentDidCatch` 调用 `reportClientError`；
- 兜底页：
  - 标题与说明；
  - 错误编号；
  - 「重新加载」按钮；
  - 「返回专题」按钮；
- 兜底页使用 i18n，不依赖地图、专题数据或 Router。
