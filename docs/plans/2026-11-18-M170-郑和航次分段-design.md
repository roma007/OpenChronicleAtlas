# M170 郑和航次分段 — 数据方案

- **任务名**：郑和七次下西洋按航程阶段分段
- **日期**：2026-11-18
- **里程碑**：M170
- **触发**：用户提问「郑和下西洋每一次下西洋的线路为什么都只有 1 段？」
- **关联**：[M169 航线绕陆修正](2026-11-18-M169-郑和航线绕陆修正-design.md)

## 1. 问题

图例里的「N 段」数的是**路线要素（feature）个数**，不是航程里的港口数。郑和专题每个航次只存了一条
LineString，于是七次下西洋各显示「1 段」，与其它专题的做法相反：

| 专题 | 一个实体的段数 |
| --- | --- |
| 明朝抗击后金 | 114 |
| 长征中央红军 | 46 |
| 玄奘 | 20 |
| 徐霞客 | 21 |
| **郑和** | **1** |

### 副作用

1. **动画船位失真**：每个要素的线头进度 = 已过时间 / 该要素的时间区间，位置按**弧长比例**插值。
   一个航次一条线，意味着「去程 + 回程」被压成一条等长折线，船在航程中途就跑到古里，再慢慢走回来。
2. **回程线压在去程上**：同一要素的折线首尾重合，回程整段覆盖去程，视觉上一根线。
3. 时间轴上无法单独看「起航」「南洋」「东非」「归程」。

## 2. 方案

把每个航次拆成 **按航程阶段划分的、各自带日期区间的要素**，共 39 段：

| 航次 | 段数 | 分段 |
| --- | --- | --- |
| 一 | 5 | 起航·长乐·占城 / 爪哇·旧港（分䑸） / 满剌加·苏门答剌·锡兰山 / 印度西岸·古里 / 归程·旧港·满剌加 |
| 二 | 4 | 起航·长乐·占城 / 满剌加·苏门答剌·锡兰山 / 加异勒·柯枝·古里 / 归程 |
| 三 | 5 | 起航·长乐·占城 / 满剌加·苏门答剌·南巫里 / 锡兰山·加异勒·古里 / 锡兰山之战（回程） / 归程 |
| 四 | 6 | 起航 / 南洋至锡兰山 / 溜山·甘巴里·忽鲁谟斯 / 祖法儿·阿丹 / 东非四港 / 归程 |
| 五 | 6 | 起航 / 南洋至锡兰山 / 柯枝·古里·忽鲁谟斯 / 祖法儿·阿丹 / 东非三港 / 归程 |
| 六 | 6 | 起航 / 满剌加·苏门答剌 / 榜葛剌·锡兰山·古里 / 忽鲁谟斯·祖法儿·阿丹 / 东非四港 / 归程 |
| 七 | 7 | 起航·长乐（含长乐候风） / 旧港·爪哇（分䑸） / 满剌加·锡兰山·古里 / 忽鲁谟斯·阿丹 / 天方（分䑸） / 东非三港 / 古里·归程 |

### 2.1 分段原则

1. 段与段的端点**必须重合**（共用同一个港口锚点），满足 `check:heads` 的 10km 接续约束；
2. 段的时间区间取自该段所服务的**事件日期**，相邻段首尾相接；
3. 史料把同一批港口记在不同月份、从单一航线无法同时满足时（如「满剌加 1406-01」与「爪哇 1406-06」），
   该段标为 **分䑸**（detachment），允许时间区间重叠——这正是分遣队与主队并行的读法；
4. 每个非航线事件必须在**日期区间重叠的某一段**上 30km 以内（`check:routes`）；
5. `order` 在实体内唯一，按航程先后编号。

### 2.2 分䑸的三处

| 航次 | 分䑸 | 起止 | 与主队关系 |
| --- | --- | --- | --- |
| 一 | 爪哇·旧港 | 新加坡往返 | 主队北上满剌加，分䑸南下爪哇、旧港 |
| 七 | 旧港·爪哇 | 新加坡往返 | 同上 |
| 七 | 天方 | 阿丹往返 | 主队在东非，分遣队随商船赴麦加 |
| 六 | 榜葛剌 | 苏门答剌 → 察地港 → 锡兰山 | 已并入「榜葛剌·锡兰山·古里」段，不单独成段 |

```jsonc
    "description": { "zh": "第1次下西洋：印度西岸·古里（1406-08-01 至 1406-12-31）。", "en": "…" },

```

## 3. 代价与取舍

- 要素数 9 → 41，geojson 300KB → 320KB（顶点 4695 → 4830，几乎不变：拆分只切点，不加点）；
- 分段后不再有一条「完整闭合」的航次线，读者要靠 5–7 段拼出整趟行程——这是分段本身的代价；
- 时间区间重叠的段会出现两个线头同时推进，属分䑸的预期表现。
