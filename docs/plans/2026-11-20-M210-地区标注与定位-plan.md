# M210 开发计划：地区标注与定位

- **任务名**：地区标注、定位与事件详情地区路径
- **日期**：2026-11-20
- **里程碑**：M210
- **负责人**：AI 开发助手
- **关联文档**：[M209 design](2026-11-20-M209-抗战按地区浏览-design.md) / [M209 plan](2026-11-20-M209-抗战按地区浏览-plan.md) / [ADR-0011](../decisions/ADR-0011-地区索引与历史省界.md)

## 1. 目标

在 M209 的筛选与省界之上，让用户在**地图上直接看到当时的县市/地点名称**，并能一键定位到所选地区；事件详情同时显示所属的省/县/地点路径。

## 2. 范围

### 2.1 包含

- `regions.json` 为县/地点补 `point`（优先县治同名地点，其余由事件坐标与子地点平均生成）；
- Web 地图新增“地区标注”开关：院辖市、县、地点按缩放级别显示当时名称；
- 移动端地图新增同样的标注，优先显示选中地区及其子地区；
- 地区筛选新增“定位”按钮：按选区内的点、事件、路线与省界计算范围；
- 事件详情（Web / 移动端）新增“地区”一行：如“河北省 · 清苑县 · 保定”；
- 数据修正：`湖北武汉` 不再强行归到武昌县；`浙江衢州、金华、玉山一带` 的地点名去掉前导顿号。

### 2.2 不包含

- 县界多边形（仍无可靠可再分发数据）；
- 伪满/汪伪/根据地独立区划；
- 搜索结果页的地区筛选。

## 4. 验收标准

- [ ] 缩放 7 级以上，河北可见“清苑”“昌平”“迁安”等当时县名；
- [ ] 缩放 9 级以上，地点名可见；选中地区始终显示；
- [ ] “地区标注”可开关，关闭后地图恢复原状；
- [ ] 选中河北后点“定位”，地图缩放到河北范围；
- [ ] 事件详情显示“河北省 · 清苑县 · 保定”这类路径；
- [ ] `pnpm validate:data`、`typecheck`、`lint`、`test`、`build` 通过；
- [ ] 文档与 CHANGELOG 更新并发布。

## 5. 风险

| 风险 | 应对 |
| --- | --- |
| 标注过多、遮挡事件 | 按缩放分级；屏幕空间避让；选区优先；标注可关 |
| 移动端标注性能 | 最多 80 个；优先选中与上级区域；低缩放不显示 |
| 县坐标由事件平均得到，非县治 | 仅用于标注落点，不声称是县治；后续可用史料县治坐标替换 |
| 定位范围过大/过小 | 有省界时用省界；无面时用事件/子地点；单点则放大到 9 级 |
