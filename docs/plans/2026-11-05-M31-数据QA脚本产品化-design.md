## 1. 共享模块

新增 `packages/shared/src/qa/routes.ts`：

```ts
export interface RouteQaIssue {
  atlasId: string;
  eventId: string;
  entityId: string;
  kind: 'no-active-route' | 'too-far';
  distanceKm?: number;
}

export interface RouteQaOptions {
  thresholdKm?: number; // 默认 30
}

export function checkDatasetRoutes(
  dataset: AtlasDataset,
  options?: RouteQaOptions,
): RouteQaIssue[];
```

### 时间匹配

- 事件区间：`[event.date, event.endDate ?? event.date]`；
- 路线区间：`[route.startDate, route.endDate]`；
- 两区间有重叠即视为该路线在事件期间有效；
- `event.extensions.routeEvent === false` 的事件跳过。

### 距离计算

- 以事件点为原点做局部切平面投影：
  - `x = Δlng * 111.32 * cos(lat)`
  - `y = Δlat * 110.57`
- 计算点到折线各线段的最短距离；
- 经度差归一化到 `[-180, 180]`，避免跨日期变更线问题；
- 返回公里数。

## 2. CLI

新增 `scripts/check-event-routes.ts`：

```bash
pnpm check:routes
pnpm check:routes --atlas anti-japanese-war
pnpm check:routes --threshold 20
pnpm check:routes --json
```

输出：

- 每个专题一行：事件数、路线段数、问题数；
- 每个问题：事件 id、实体、类型、距离；
- 末尾汇总；
- 有问题时退出码为 1。
