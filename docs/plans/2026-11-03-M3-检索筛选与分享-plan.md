## 1. 目标（Goal）

让专题从「可回放的地图」变成「可查、可筛、可分享的历史工具」：

- 事件详情能完整呈现图文与史料；
- 用户能按事件名/地名/时间搜索，并按实体、类型、时间段筛选；
- 任意时间点 + 事件 + 地图视野可生成链接，打开后原样恢复。

## 2. 范围（Scope）

### 2.1 包含

1. `packages/shared` 检索与分享模块：
   - `buildSearchIndex(datasets)`：归一化事件/实体/地名，生成内存索引；
   - `searchEvents(query, index, options)`：子串匹配 + 评分 + 高亮片段；
   - `encodeShareState()` / `decodeShareState()`：URL query 编解码与校验；
   - 单测覆盖中英文、空查询、跨专题、非法参数。
2. 事件详情增强：
   - Markdown 渲染（`react-markdown` + `remark-gfm` + `rehype-sanitize`）；
   - 图片懒加载、图注、来源、许可；
   - 关联事件跳转；
   - 分享按钮（`navigator.share` 优先，否则复制链接）。
3. 专题内筛选：
   - 实体（沿用图例开关，统一为筛选条件）；
   - 事件类型多选；
   - 时间段（开始/结束日期）；
   - 筛选结果数量与「重置」。
4. 全局搜索页 `/search`：
   - 搜索框、跨专题/仅当前专题切换；
   - 结果列表（专题、事件名、日期、地点、类型、摘要片段）；
   - 点击结果 → 打开专题、跳转时间、选中事件。
5. 分享与深链：
   - `?t=YYYY-MM-DD&event=<id>&view=lng,lat,zoom`；
   - 专题页加载后恢复时间轴/事件/视野；
   - 复制成功/失败提示；
   - 无效参数降级为默认视图。
6. 无障碍与响应式：
   - 搜索框、结果列表、筛选 chip 键盘可操作；
   - 空状态、加载状态、错误状态；
   - 桌面侧栏 + 移动底部抽屉布局。
7. 文档：M3 对话、plan/design、ADR、CHANGELOG、release、tag `v0.3.0-m3`。

### 2.2 不包含（Out of Scope）

- 移动端搜索/分享（M4）。
- 拼音、分词、模糊纠错（M5 评估）。
- 后端搜索服务、短链、访问统计。
- 用户账号、收藏、评论。
- 第二个专题（M5）。
- 史料校订（持续任务）。

## 5. 实施步骤

1. **确认方案**：用户确认 plan/design/ADR-0006 与 Q1–Q6。
2. **T1–T2 shared**：先写纯函数与单测，确保搜索/分享不依赖 React。
3. **T3–T4 详情**：接入 Markdown 与分享按钮，保持现有视觉。
4. **T5–T6 筛选**：store 增加 filters；地图与时间轴只消费筛选后的事件。
5. **T7 搜索页**：加载 atlas 索引与数据，内存建索引；结果跳转带 query。
6. **T8–T9 分享/深链**：生成链接、复制、恢复状态；处理非法参数。
7. **T10 无障碍**：Tab 顺序、Enter 触发、空状态、移动布局。
8. **T11 验收**：typecheck/lint/test/build/validate + Playwright；更新文档并双推，打 tag `v0.3.0-m3`。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 全局搜索需加载全部专题，专题多时变慢 | 搜索页首屏慢 | 中 | M3 专题少；后续改为构建期索引；加载时显示进度 |
| Markdown XSS | 安全风险 | 中 | `rehype-sanitize` + 禁止原始 HTML；外链 `rel="noreferrer"` |
| 深链恢复与用户操作冲突 | 状态被覆盖 | 中 | 只在数据集加载完成后应用一次；后续操作不重置 |
| 筛选与时间轴叠加后结果为空 | 用户困惑 | 中 | 显示「筛选/时间轴共同导致 0 条」并提供重置 |
| URL 参数被篡改 | 崩溃 | 低 | 解码时校验日期/ID/经纬度，非法则忽略并提示 |
| 搜索子串匹配中文效果有限 | 召回低 | 中 | M3 接受；M5 评估分词/拼音 |
| 依赖体积增加 | 首屏变大 | 低 | Markdown 组件按需加载（React.lazy） |

## 7. 验收标准（DoD）

- [ ] `pnpm -r typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm validate:data` 全部通过。
- [ ] shared 搜索/分享单测覆盖：中文子串、英文大小写、空查询、跨专题、非法 URL 参数。
- [ ] 事件详情渲染 Markdown 段落、列表、链接、图片；恶意 HTML 被消毒。
- [ ] 专题内筛选：类型多选、时间段、实体开关；结果数量实时更新；重置可用。
- [ ] 全局搜索：输入「遵义」「贵州」「1935」均能命中；结果点击跳转正确。
- [ ] 分享链接包含 `t`、`event`、`view`；复制成功提示；新标签打开恢复时间/事件/视野。
- [ ] 无效 `t`/`event`/`view` 不崩溃，降级默认。
- [ ] 键盘可完成搜索、筛选、结果跳转、分享。
- [ ] 390px 下搜索/筛选/详情可用，无横向溢出。
- [ ] 文档齐全；双仓 HEAD 一致；tag `v0.3.0-m3`。

## 8. 回滚方案

- 搜索/分享为新增模块；回滚删除 `/search` 路由、筛选面板与分享按钮即可恢复 M2。
- Markdown 渲染可临时降级为纯文本段落。
- 数据契约不变，无迁移。
