## 1. 数据结构

```ts
export interface TimelineEventMarker {
  event: AtlasEvent;
  ratio: number;
  endRatio: number;
}

export function timelineEventMarkers(
  events: AtlasEvent[],
  timeline: Timeline,
): TimelineEventMarker[];
```

- `ratio`：事件起点在时间轴中的比例；
- `endRatio`：事件终点比例；无 `endDate` 时等于 `ratio`；
- 结果按 `ratio` 升序；
- 只做位置计算，不做筛选。

## 2. 筛选流程

Web / 移动端：

1. 按当前图层过滤事件；
2. 应用 `applyEventFilters`（类型、时间段）；
3. 用当前视口 `viewport` 计算 `ratio`；
4. 只保留 `endRatio >= 0 && ratio <= 1` 的事件；
5. 渲染事件点。

## 3. Web 渲染

- 在时间轴轨道上方增加 16px 高的事件点区域；
- 每个事件点：
  - 绝对定位 `left: ratio * 100%`；
  - 8px 圆点，`-translate-x-1/2`；
  - 当前事件使用朱红 + 放大；
  - 未来事件降低透明度；
- 点击：
  - `pause()`；
  - `setCurrentTime(eventStart(event))`；
  - `selectEvent(event.id)`；
- `aria-label` 使用事件名与日期；
- 事件点区域 `pointer-events-auto`，轨道拖动不受影响。

## 4. 移动端渲染

- 在轨道上方增加 14px 事件点区域；
- 使用 `Pressable`，点击区域 12px；
- 点击同样暂停、跳转、打开详情；
- 当前事件点使用朱红 + 外圈；
- 未来事件降低透明度；
- 事件点不参与 PanResponder，避免拖动冲突。

## 5. 缩放联动

- 使用当前 `viewport` 计算比例；
- 缩放后只显示视口内事件；
- 事件点位置随视口变化；
- 拖动/播放时当前事件点高亮自动更新。

## 6. 测试

- 无 endDate 时 `endRatio === ratio`；
- 有 endDate 时区间正确；
- 结果按 ratio 升序；
- 空数组返回空；
- 越界事件仍返回比例（由组件过滤）。
