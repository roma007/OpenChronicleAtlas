## 1. 共享样式

新增 `packages/shared/src/route-style.ts`：

```ts
export interface RouteStyle {
  weight: number;
  opacity: number;
  dash: 'solid' | 'dashed' | 'dotted';
}

export function routeStyleForSegmentType(type?: RouteSegmentType): RouteStyle;
export function segmentTypeLabel(type: RouteSegmentType | undefined, locale: Locale): string;
```

样式表：

| 类型 | 线宽 | 透明度 | 线型 |
| --- | --- | --- | --- |
| `advance` | 4 | 0.85 | solid |
| `counterattack` | 5 | 0.95 | solid |
| `defense` | 3 | 0.80 | dotted |
| `retreat` | 3 | 0.80 | dashed |
| `naval` | 4 | 0.85 | dashed |
| `supply` | 3 | 0.75 | dotted |
| `other` | 3 | 0.75 | solid |

## 2. Web

`MapCanvas`：

- 读取 `route.properties.segmentType`；
- 设置 `strokeWeight`、`strokeOpacity`；
- `dash === 'dashed'` → `strokeStyle: 'dashed'`, `strokeDasharray: [10, 6]`；
- `dash === 'dotted'` → `strokeStyle: 'dashed'`, `strokeDasharray: [2, 4]`；
- `solid` → `strokeStyle: 'solid'`。

`Legend`：

- 收集当前专题出现的 `segmentType`；
- 新增「路线样式」区块；
- 用 CSS `border-style` 与 `border-top-width` 画线型样例；
- 文案使用 `segmentTypeLabel`。

## 3. 移动端

`AtlasMap`：

- `routeShapes` 增加 `strokeWidth` 与 `dotted`；
- `Polyline` 传入 `strokeWidth` / `dotted`；
- iOS 不支持 `dotted`，以线宽区分。

`FilterSheet`：

- 在路线图层下方增加「路线样式」；
- 用 `View` 的 `borderStyle` 画样例；
- 文案使用 `segmentTypeLabel`。

## 4. 文案

新增 i18n：

- `legend.routeStyles`：路线样式 / Route styles。
