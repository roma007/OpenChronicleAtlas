## 1. 分享状态结构

```ts
export interface ShareState {
  atlasId?: string;
  time?: DateString;
  eventId?: string;
  view?: ShareView;
  locale?: Locale;
  entities?: string[];
  categories?: string[];
  from?: DateString;
  to?: DateString;
}
```

## 2. URL 参数

| 参数 | 示例 | 校验 |
| --- | --- | --- |
| `t` | `1935-01-15` | 日期合法 |
| `event` | `zunyi-1935-01` | ID 正则 |
| `view` | `106.92,27.72,7.00` | 经纬度/缩放范围 |
| `lang` | `zh` / `en` | 仅两种 |
| `entities` | `central-red-army,red-4-army` | 逗号分隔，ID 正则，去重 |
| `categories` | `重要会议,会师` | 逗号分隔，非空，去重 |
| `from` | `1935-01-01` | 日期合法 |
| `to` | `1935-12-31` | 日期合法，且不早于 from |

- `categories` 使用 `URLSearchParams` 自动编码中文；
- 单参数最多 50 项，防止恶意超长 URL；
- 旧链接只有 `t/event/view` 时仍可解析。

## 3. 编码

```ts
if (state.locale) params.set('lang', state.locale);
if (state.entities?.length) params.set('entities', state.entities.join(','));
if (state.categories?.length) params.set('categories', state.categories.join(','));
if (state.from) params.set('from', state.from);
if (state.to) params.set('to', state.to);
```

## 4. 解码与安全

- `lang`：仅 `zh`/`en`，否则忽略；
- `entities`：按逗号拆分，过滤不匹配 ID 正则的项，去重，截断 50；
- `categories`：按逗号拆分，过滤空值，去重，截断 50；
- `from`/`to`：复用 `parseDateString` 校验；
- `to < from` 时忽略 `to`；
- 若所有字段都非法，返回 `null`。

## 5. Web 恢复

`AtlasPage` 在数据集加载后：

1. `setLocale(state.locale)`；
2. `setActiveEntities(state.entities)`（与 manifest 实体取交集）；
3. `setFilters({ categories, from, to })`；
4. 设置时间点；
5. 选中事件；
6. 恢复地图视野。

`useShare` 在分享时传入：

- `locale`；
- `activeEntityIds`；
- `filters.categories` / `from` / `to`。

## 6. 移动端恢复

- `EventSheet` 分享时附加同样字段；
- `App.parseDeepLink` 解析 queryParams，构造 `URLSearchParams` 后调用 `decodeShareState`；
- `AtlasScreen` 接收 `share` 参数，在数据集加载后应用；
- 移动端 store 增加 `setActiveEntities`。

## 7. store 变更

```ts
setActiveEntities(ids: string[]): void;
```

实现：

```ts
const valid = new Set(get().dataset?.manifest.entities.map((e) => e.id) ?? []);
set({ activeEntityIds: new Set(ids.filter((id) => valid.has(id))) });
```

若 `ids` 为空或全部非法，保持当前图层不变，避免分享链接导致空白地图。
