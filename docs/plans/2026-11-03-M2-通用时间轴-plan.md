## 1. 目标（Goal）

在 Web 端把「静态地图」升级为「可拖动的时空回放」：
时间轴范围由专题 manifest 动态生成，拖动或播放时路线按时间生长、事件按时间显隐、当前事件高亮并弹出气泡；
所有时间计算抽到 `packages/shared`，为 M4 移动端复用。

## 2. 范围（Scope）

### 2.1 包含

1. `packages/shared` 时间轴引擎：
   - `createTimeline()`、`timeToRatio()`、`ratioToTime()`、`snapToDay()`；
   - 自适应刻度 `generateTicks()`（年/月/日）；
   - 路线累计长度与 `partialPathAt()` 插值；
   - `visibleEventsAt()`、`activeEventAt()`；
   - 播放推进 `advancePlayback()`。
2. 单元测试：时间比例往返、刻度选择、路径插值、事件显隐、播放边界。
3. Web 时间轴 UI：
   - 底部面板、轨道、主/次刻度、拖动手柄；
   - 播放/暂停、倍速 0.5/1/2/4x；
   - 点击轨道跳转、日期输入跳转；
   - 键盘操作（←/→、Shift+←/→、Home/End、空格）。
4. 地图联动：
   - 路线按当前时间截断生长（`Polyline.setPath`）；
   - 事件 Marker 按时间显隐；
   - 当前事件 Marker 高亮 + `InfoWindow` 气泡；
   - 播放跨过事件时自动弹出气泡（4 秒后自动关闭）。
5. 无障碍：时间轴 `role="slider"`、`aria-valuenow/min/max/text`、焦点样式、对比度。
6. 响应式：桌面 1440px、移动浏览器 390px 可用。
7. 文档：M2 对话档案、plan/design、ADR、CHANGELOG、release、tag `v0.2.0-m2`。

### 2.2 不包含（Out of Scope）

- 搜索、筛选、分享链接（M3）。
- 移动端地图与时间轴（M4）。
- 第二个专题（M5）。
- Marker 聚合（数据量增大后再做，M3/M5）。
- 独立的时间轴缩放控件（M2 先做跳转与自适应刻度，Q4 待确认）。
- 史料校订（持续任务）。
- 后端服务与持久化。

## 5. 实施步骤

1. **确认方案**：用户确认 plan/design/ADR-0005 与 Q4。
2. **T1–T5 shared**：先写纯函数与单测，不碰 UI；`pnpm --filter @atlas/shared test` 全绿。
3. **T6 状态**：在 Zustand 增加 timeline slice；加载专题时初始化 `currentTime = timeRange.start`。
4. **T7 UI**：先静态刻度与拖动，再接播放；确保键盘可用。
5. **T8 地图**：预计算路线累计长度；时间变化时只更新 path 与 Marker 可见性。
6. **T9 气泡**：播放跨过事件时打开 `InfoWindow`，点击气泡暂停并打开详情。
7. **T10 无障碍**：ARIA、焦点顺序、对比度、390px 检查。
8. **T11 验收**：typecheck / lint / test / build / validate:data + Playwright 截图；更新文档并双推，打 tag `v0.2.0-m2`。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| `Polyline.setPath` 每帧更新导致卡顿 | 播放不流畅 | 中 | 预计算累计长度；更新节流 30fps；进度变化 < 0.1% 跳过 |
| 刻度标签重叠 | 时间轴不可读 | 中 | 按宽度计算目标刻度数；主/次刻度分级；390px 只显示主刻度 |
| 拖动与播放状态冲突 | 时间跳变、动画抖动 | 高 | 拖动即暂停；播放循环用单一 `requestAnimationFrame` |
| 事件密集区 Marker 闪烁 | 视觉噪声 | 中 | 只切换 `show/hide`，不重建 Marker；高亮用 class |
| 时区/闰年导致刻度偏移 | 日期错一天 | 低 | 全部使用 UTC 日粒度；复用 `parseDateString` |
| `InfoWindow` 与详情面板互相遮挡 | 交互混乱 | 中 | 气泡只显示摘要，点击后关闭气泡并打开详情 |
| 范围蔓延到搜索/分享 | M2 延期 | 中 | 严格按 §2.2 排除；新需求先写文档再排期 |

## 7. 验收标准（DoD）

- [ ] `pnpm -r typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm validate:data` 全部通过。
- [ ] shared 时间轴单测覆盖：比例往返、刻度单位选择、路径 0/50%/100%、事件显隐、播放到端点停止。
- [ ] 时间轴范围来自 manifest，1440px 与 390px 下刻度不重叠。
- [ ] 拖动时间轴：路线截断、Marker 显隐、当前事件高亮实时更新。
- [ ] 播放/暂停、0.5/1/2/4x 正常；播放到终点自动停止。
- [ ] 点击轨道/输入日期可跳转。
- [ ] 键盘：←/→ 步进 1 天，Shift+←/→ 步进 7 天，Home/End 跳转，空格播放/暂停。
- [ ] 播放跨过事件时弹出气泡；点击气泡暂停并打开详情。
- [ ] 代码中无专题硬编码；时间计算只在 shared。
- [ ] 文档：对话档案、plan/design、ADR、CHANGELOG、release 齐全；双仓 HEAD 一致；tag `v0.2.0-m2`。

## 8. 回滚方案

- 时间轴为新增模块；回滚删除 `timeline/`、`Timeline.tsx` 与 store slice，恢复 M1 占位组件即可。
- 地图联动若出现性能问题，可临时降级为「按时间过滤整段显示」，不阻断其他功能。
- 数据契约不变，无需迁移。
