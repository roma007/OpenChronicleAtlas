## 1. 索引文件

`data/atlases/search-index.json`：

```json
{
  "schemaVersion": "1.0.0",
  "generatedAt": "2026-11-05T...",
  "entries": [
    {
      "atlasId": "long-march",
      "atlasTitle": { "zh": "长征", "en": "The Long March" },
      "event": { "...": "完整事件对象" },
      "fields": {
        "name": "...",
        "place": "...",
        "summary": "...",
        "description": "...",
        "category": "...",
        "entities": "...",
        "date": "...",
        "pinyin": "...",
        "initials": "..."
      }
    }
  ]
}
```

- `atlasTitle` 改为 `LocalizedString`；
- 完整事件对象用于结果展示与跳转；
- 拼音字段在构建期写入。

## 2. 构建脚本

`scripts/build-search-index.ts`：

1. 扫描 `data/atlases` 目录；
2. 用 `FsDataSource` + `loadAtlas` 加载全部专题；
3. `await loadPinyinProvider()`；
4. `buildSearchIndex(datasets, provider)`；
5. 写入 `data/atlases/search-index.json`；
6. 输出专题数、事件数、文件大小。

`package.json`：

```json
"build:search-index": "tsx scripts/build-search-index.ts",
"build": "pnpm build:search-index && pnpm -r build"
```

`vercel.json`：

```json
"buildCommand": "pnpm build:search-index && pnpm --filter @atlas/web build"
```

## 3. 共享加载器

`packages/shared/src/data/loader.ts` 增加：

```ts
export async function loadSearchIndex(
  indexUrl: string,
  options: LoadAtlasOptions = {},
): Promise<SearchIndexFile>;
```

- 校验 `entries` 为数组；
- 返回 `SearchIndexFile`。

## 4. Web

- `data/client.ts` 增加 `fetchSearchIndex()`；
- store 用 `searchIndex` 替代 `searchDatasets`；
- `loadSearchData()` 只请求索引；
- `SearchPage`：
  - `searchEvents(debounced, searchIndex, options)`；
  - 专题筛选从 `entries` 去重得到；
  - 分类从 `entries.map(e => e.event)` 收集；
  - 结果标题用 `resolveLocalized(hit.atlasTitle, locale)`。

## 5. 移动端

- `data/client.ts` 增加 `fetchSearchIndex()`；
- store 用 `searchIndex`；
- `SearchScreen` 与 Web 相同的查询与筛选逻辑。

## 6. 类型

`search/types.ts`：

```ts
export interface SearchEntry {
  atlasId: string;
  atlasTitle: LocalizedString;
  event: AtlasEvent;
  fields: { ... };
}

export interface SearchIndexFile {
  schemaVersion: string;
  generatedAt: string;
  entries: SearchEntry[];
}
```

## 7. 兼容性

- 数据契约不变；
- 索引文件为生成产物，提交到仓库；
- 构建前必须重新生成，避免数据与索引不一致；
- 旧搜索 API 不变。
