# M159 常驻线：龙山不再凭空出现 — 方案

- **日期**：2026-11-16
- **里程碑**：M159（渲染与数据）
- **状态**：内容已实施并通过校验
- **关联**：[M155 苏区网络细化](2026-11-16-M155-苏区网络细化-design.md)

## 1. 问题

用户问：忠堡、板栗园从龙山出发，但红二方面军为什么突然从龙山冒出来？

核对发现不是缺线，而是**渲染方式**的问题：

- 桑植—龙山（order 16）与龙山—来凤（order 17）是 1934-11-16 至 1935-11-19 的苏区内部机动线；
- 地图按日期线性推进每段路线：到 1935-06-12 时，order 16 只画到全程约 56%，还没到龙山；
- 于是忠堡、板栗园的出击线从龙山起画，而桑植—龙山还没画到那里，看起来就是「龙山凭空冒出来」。
- 苏区主线永顺—桑植（order 2）同理，6 月也只画了一半。

## 2. 根因

苏区内部机动线是**常驻线**（根据地一直握在手里），不是逐日行军路线。用「按日期推进」的画法会把常驻线误读成一支正在慢慢走过去的部队。

## 3. 修法

给路线扩展增加 `static: true`，渲染时对常驻线不做逐日推进：

```json
"extensions": { "precision": "schematic", "static": true }
```

- 进入起始日后整段显示，不再按日期比例截断；
- 起始日之前仍然隐藏；
- 结束之后按现有累计逻辑继续显示（与其它已完成路线一致）。

标记为常驻线的三段：

| order | 路线 |
| --- | --- |
| 2 | 永顺—桑植 |
| 16 | 桑植—龙山（苏区内部机动线） |
| 17 | 龙山—来凤（苏区内部机动线） |

## 4. 效果

1935-06-12 与 1935-08-03 时，永顺—桑植—龙山—来凤整段完整显示，忠堡、板栗园的出击线从龙山、从来凤出发都有清楚的来路，不再凭空出现。

## 5. 验证

- `pnpm validate:data`：11 专题 / 845 事件 / 641 路线段；
- `pnpm check:heads`：121 段路线，0 个无来由端点；
- `pnpm check:routes --atlas long-march`：0 个问题；
- 数据版本 `2026-11-16-d97feab94f29`。

## 6. 未决问题

- `static` 目前只用于苏区内部机动线；其它专题若有常驻线，可在需要时加同一标记；
- 苏区线仍是示意，具体道路待考。
