## 1. 背景

长征专题的 `kmt-army` 实体只有名称与说明，没有路线与事件，导致地图上无法看到国民党军的封锁与追堵方向。

## 2. 目标

1. 新增国民党军路线文件，覆盖湘江、乌江、金沙江、大渡河、腊子口、直罗镇；
2. 新增 5 个封锁/追堵事件；
3. 直罗镇战役加入国民党军实体；
4. 更新实体说明与专题描述；
5. 重新生成搜索索引。

## 3. 范围

- `data/atlases/long-march/routes/kmt-army.geojson`（新建）；
- `data/atlases/long-march/manifest.json`；
- `data/atlases/long-march/events/events.json`；
- `data/atlases/search-index.json`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | KMT 路线文件 | routes |
| S3 | KMT 事件与直罗镇修改 | events |
| S4 | manifest 与索引 | data |
| S5 | 校验、构建、部署、tag | `v0.44.0-m44` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 封锁线位置粗略 | 准确性 | 标为示意简化，待史料校订 |
| KMT 事件与红军事件重复 | 时间轴拥挤 | 事件名明确「国民党军」 |
| 直罗镇事件加入 KMT 后校验失败 | 构建失败 | 新增直罗镇进攻路线并跑 `check:routes` |

## 6. 验收

- 6 段 KMT 路线；
- 5 个 KMT 事件；
- 直罗镇事件含 `kmt-army`；
- 事件-路线 0 个 >30km；
- 全项目 132 事件 / 133 路线段；
- 双仓 tag 一致。
