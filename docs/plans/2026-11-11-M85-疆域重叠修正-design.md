## 1. 重叠原因

| 原因 | 例子 |
| --- | --- |
| 独立绘制、未共用边界 | 魏、汉、吴在荆州互相侵入 |
| 时间区间重叠 | 金 1115 起、北宋 1127 止；蒙古 1206 起、金 1234 止 |
| 政权范围取了最大版图 | 金面直接使用 1141 年后范围，却从 1115 年开始显示 |
| 有意叠加 | 安史叛军控制区位于唐境内 |

## 2. 修正原则

1. **同期不同政权共享边界节点**，面只相接、不重叠；
2. **时间区间首尾衔接**，避免同一区域同时挂两个政权；
3. **最大版图不提前**：金先用兴起时的小范围，1127 年后再切华北范围；
4. **占领区例外**：安史控制区保留叠加，但用更高透明度与说明区分。
