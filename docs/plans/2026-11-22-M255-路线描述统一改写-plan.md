# M255 路线描述统一改写计划

- **日期**：2026-11-22
- **专题**：`anti-japanese-war`
- **前置**：M252 路线校订第一批（#3 史实纠错、去重复、总览线标注）
- **触发**：M252 后仍有 46 段路线描述只有一句「示意简化路线，待史料校订。」，
  等于没有说明；而沿线已有大量**已考证事件**可以直接引用。
- **目标**：把 46 段描述改写成「起止 + 经过 + 示意说明」，**不改几何、不改日期、不改类型**。
- **对照表**：[路线描述统一改写](../research/units/anti-japanese-war-route-descriptions.md)

## 1. 改写口径

1. 结构统一：`起止日期 + 主要经过（引用已有事件）+ 路线示意简化；经过据本专题事件校订。`
2. 战役总览线（`precision: campaign`）在描述里明确写「本段为战役总览，非单次行动」。
3. 防御线（#48）、运输线（#64）写「非进攻路线」。
4. 删除「待史料校订 / 待页码核对」占位语。
5. **只改 `description`**：几何、起止日期、`segmentType`、`order` 一律不动。

## 2. 依据来源

只引用本专题**已有事件的日期与地名**——这些事件本身已满足「≥2 条独立来源」，
所以改写不引入新史实，也不会制造新的待考项。

## 3. 验证

```bash
node /tmp/rewrite-route-desc.mjs      # 改写 46 段
python3 scripts/build-region-data.py  # 重建 regionIndex（本批未改段数，仍照做）
pnpm validate:data

pnpm check:heads --atlas anti-japanese-war
pnpm build:search-index
pnpm build:mobile-data --check
pnpm typecheck && pnpm lint && pnpm test
```

## 4. 结果

- 改写 **46** 段；带「待史料校订 / 待页码核对」字样的路线 **46 → 0**。
- 事件 1026 / 路线 563 / 地区 862 均不变。
- 全部校验通过，0 个路线-事件超距、0 个无来由端点。
