# M22 发布阻塞项内部修复 — 计划

- **日期**：2026-11-05
- **里程碑**：M22（v0.22.0-m22）
- **状态**：已完成
- **关联**：
  - [对话档案](../conversations/2026-11-05-M22启动与发布阻塞项修复.md)
  - [M22 方案](2026-11-05-M22-发布阻塞项内部修复-design.md)

## 1. 背景

M20 发布检查清单发现：

- iOS `Info.plist` 仍为 `0.5.0 (1)`；
- iOS `LSMinimumSystemVersion` 12.0 与 Xcode 16.4 不一致；
- Android 主 manifest `usesCleartextTraffic="true"`；
- 主 manifest 保留 `SYSTEM_ALERT_WINDOW`；
- 缺少三端版本一致性检查。

## 2. 目标

1. iOS 版本对齐 0.21.0 / build 18；
2. iOS 最低系统对齐 16.4；
3. Android 主 manifest 关闭明文流量；
4. 主 manifest 移除悬浮窗权限，debug 保留；
5. 新增 `pnpm check:versions`；
6. 发布 v0.22.0。

## 3. 范围

- `apps/mobile/ios/app/Info.plist`
- `apps/mobile/android/app/src/main/AndroidManifest.xml`
- `apps/mobile/app.config.ts`
- `scripts/check-versions.ts`
- `package.json`（脚本）
- 文档、版本、tag

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | iOS 版本与最低系统 | Info.plist |
| S2 | Android manifest | 明文流量/权限 |
| S3 | 版本检查脚本 | `check:versions` |
| S4 | 文档与版本 | `v0.22.0-m22` |
| S5 | 构建、部署、tag | 发布 |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 关闭明文流量影响本地调试 | 本地数据加载失败 | debug manifest 保留 true |
| prebuild 覆盖手动 manifest | 配置回退 | app.config 同步设置 |
| 版本检查脚本误报 | CI 阻塞 | 只检查存在的文件，缺失则跳过 |

## 6. 验收

- iOS 版本 0.21.0 / build 18；
- 主 manifest 无 `SYSTEM_ALERT_WINDOW`、`usesCleartextTraffic=false`；
- debug manifest `usesCleartextTraffic=true`；
- `pnpm check:versions` 通过；
- lint / typecheck / test / build 通过；
- 双仓 tag 一致。
