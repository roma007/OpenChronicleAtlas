# M154 苏区出击重排：三次战斗改从最近的根据地落点出发 — 方案

- **日期**：2026-11-16
- **里程碑**：M154（路线校订批次）
- **状态**：内容已实施并通过校验
- **关联**：[M153 苏区三战回师](2026-11-16-M153-苏区三战回师-design.md)

## 1. 问题

M153 补了三次战斗的战后回师，但出击线仍都从永顺（十万坪）起画。用户指出这个结构不自然：陈家河在桑植县境、忠堡在咸丰、板栗园在宣恩，三次出击不应都从永顺出发。

## 2. 史实

1935 年反「围剿」期间，红二、六军团的根据地在桑植、永顺、龙山、来凤一带：

- 陈家河（4/13）在桑植县境，从桑植出击最近；
- 忠堡（6/12）在咸丰县境，从龙山出击最近（忠堡战斗本身就是围困龙山时的打援）；
- 板栗园（8/3）在宣恩县境，从龙山北上最近。

新增的 order 16 是桑植—龙山的苏区内部机动线，类型 `other`，1934-11-16 至 1935-11-19，作为三次出击的根据地连接线。这样：

```
桑植 → 陈家河 → 桑植
龙山 → 忠堡 → 龙山
龙山 → 板栗园 → 龙山
永顺 → 桑植 → 龙山（苏区主线 + 内部机动线）
```

三次出击不再从十万坪统一长出，也不再悬空；回师线缩短为战场至出击据点的一段，由苏区线完成回到桑植、永顺的行程。
