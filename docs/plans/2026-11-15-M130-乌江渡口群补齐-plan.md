## 1. 背景

M123 只拆出江界河、回龙场、茶山关，孙家渡、桃子台、楠木渡、袁家渡仍缺；渡口群路线只有 3 个点。

## 2. 目标

1. 新增 4 个渡口事件；
2. 渡口群路线扩为 7 个控制点；
3. 更新专题描述与 `updatedAt`，重新生成搜索索引与移动端内置数据映射；
4. 提交并发布到服务器（按提交铁律）。

## 3. 范围

### 3.1 包含

- `data/atlases/long-march/events/events.json`
- `data/atlases/long-march/routes/central-red-army.geojson`
- `data/atlases/long-march/manifest.json`
- `data/atlases/search-index.json`、`data/atlases/index.json`
- `apps/mobile/src/generated/atlasData.ts`
- 本轮 docs 与 CHANGELOG

### 3.2 不包含

- 其他专题；
- schema 变更；
- UI 渲染逻辑；
- 梁家渡、沙湾、马落渡等小渡口；
- 红 9 军团袁家渡以北掩护阵地；
- 版本号手动修改。

## 5. 实施步骤

1. 记录本轮需求与点位口径；
2. 按孙家渡、袁家渡、桃子台、楠木渡补事件；
3. 渡口群路线扩为 7 点；
4. 更新专题描述；
5. 运行 `pnpm validate:data`、`pnpm check:routes --atlas long-march`；
6. 运行 `pnpm build:search-index`、`pnpm build:mobile-data`；
7. 运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`；
8. 更新 CHANGELOG，提交（钩子升版）、tag、推送；
9. 执行 `pnpm release`，更新服务器并登记。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 渡口坐标只能估算 | 点位偏差 | 高 | 用代表点，标 `approx` |
| 袁家渡县属不清 | 地点表述错误 | 中 | 只写「贵州乌江袁家渡（今沿江渡）」 |
| 把袁家渡误当主渡口 | 史实失真 | 中 | 明确写佯渡、侦察、掩护 |
| 路线扩点后事件偏离 | 校验失败 | 低 | 跑 `check:routes` 验证 |
| 发布被 /srv/ops 请求阻塞 | 无法发布 | 低 | 先处理或显式 `--ack-open` |
