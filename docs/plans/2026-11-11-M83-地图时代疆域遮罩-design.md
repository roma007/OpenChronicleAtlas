## 1. 数据契约

```ts
// manifest.json
territories?: string[];

interface AtlasTerritoryFeature {
  type: 'Feature';
  geometry:
    | { type: 'Polygon'; coordinates: [number, number][][] }
    | { type: 'MultiPolygon'; coordinates: [number, number][][][] };
  properties: {
    entityId: string;
    startDate: string;
    endDate: string;
    order?: number;
    name?: LocalizedString;
    description?: LocalizedString;
    opacity?: number;
    extensions?: Record<string, unknown>;
  };
}
```

- 文件路径建议 `<atlas>/territories/territories.geojson`；
- `opacity` 限制 0—0.6，默认 0.16；
- 环至少 4 点，经纬度范围与路线一致；
- `entityId` 必须存在于 `manifest.entities`；
- `endDate` 不得早于 `startDate`。

## 2. 渲染逻辑

| 项 | 实现 |
| --- | --- |
| 图层 | `AMap.Polygon`，`zIndex: 10`，位于路线（50）与标记（100）之下 |
| 填充 | 实体 `color`，`fillOpacity = opacity ?? 0.16` |
| 描边 | 实体 `color`，`strokeOpacity 0.4`，`strokeWeight 1` |
| 显隐 | `startDate <= currentTime <= endDate` 且实体在 `activeEntityIds` 中 |
| 开关 | 图例「时代疆域遮罩」按钮，默认显示 |
| 多面 | Polygon 作为单面；MultiPolygon 拆为多个 `AMap.Polygon` |
| 交互 | `bubble: true`，不拦截地图与标记点击 |
