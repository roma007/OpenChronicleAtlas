## 1. 总体设计

```
AsyncStorage
├── atlas-locale            # zh / en
└── atlas-cache:v1:<url>    # 专题 JSON 原文

useAtlasStore
├── locale / setLocale      # 写 atlas-locale
├── hydrateLocale()         # 启动读取 atlas-locale
├── fromCache               # 本次加载是否命中缓存
└── clearCache()            # 删除 atlas-cache:v1:* 并重置 fromCache
```

## 2. 缓存命中标记

`data/cache.ts` 增加模块级标记：

```ts
let cacheHit = false;

export function resetCacheHit(): void {
  cacheHit = false;
}

export function consumeCacheHit(): boolean {
  const value = cacheHit;
  cacheHit = false;
  return value;
}
```

`CachedHttpDataSource.readText`：

- 网络成功：写缓存，返回；
- 网络失败且命中缓存：`cacheHit = true`，返回缓存；
- 网络失败且无缓存：抛原错误。

每次 `loadIndex` / `loadAtlas` / `loadSearchData` 开始前调用 `resetCacheHit()`，结束后 `set({ fromCache: consumeCacheHit() })`。

## 3. 清除缓存

```ts
const CACHE_PREFIX = 'atlas-cache:v1:';

export async function clearAtlasCache(): Promise<void> {
  const keys = await AsyncStorage.getAllKeys();
  const cacheKeys = keys.filter((key) => key.startsWith(CACHE_PREFIX));
  if (cacheKeys.length > 0) await AsyncStorage.multiRemove(cacheKeys);
}
```

- 只删除数据缓存，不影响 `atlas-locale`；
- 清除后 `fromCache` 重置为 `false`。

## 4. 语言持久化

`useAtlasStore`：

```ts
setLocale(locale) {
  set({ locale });
  void AsyncStorage.setItem('atlas-locale', locale);
}

async hydrateLocale() {
  try {
    const stored = await AsyncStorage.getItem('atlas-locale');
    if (stored) set({ locale: normalizeLocale(stored) });
  } catch {
    // 忽略，保持默认中文
  }
}
```

`App` 启动时调用 `hydrateLocale()`。

## 5. UI

### 5.1 首页

- 页头显示缓存徽标（`fromCache` 为 true 时）；
- FlatList footer 增加「清除离线缓存」按钮；
- 点击后 `Alert.alert` 确认，确认后调用 `clearCache()`，显示「已清除」。

### 5.2 专题页

- 标题旁显示小型「离线缓存」徽标；
- 不改变现有筛选/搜索/语言切换布局。

### 5.3 文案

| key | 中文 | English |
| --- | --- | --- |
| `offline.cacheBadge` | 离线缓存 | Offline cache |
| `cache.clear` | 清除离线缓存 | Clear offline cache |
| `cache.clearConfirm` | 确定清除已缓存的专题数据？ | Clear cached atlas data? |
| `cache.clearHint` | 清除后再次打开专题需要联网。 | You will need a network connection to reopen atlases after clearing. |
| `cache.cleared` | 已清除 | Cleared |
| `cache.cancel` | 取消 | Cancel |

## 6. 兼容性

- 不新增原生依赖；
- 不影响 Web；
- 不影响数据契约；
- 清除缓存只影响移动端本地副本。
