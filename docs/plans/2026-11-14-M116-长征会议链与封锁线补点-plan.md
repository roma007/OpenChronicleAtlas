## 1. 背景

长征专题已有 127 个事件 / 93 段路线，主干叙事基本成形，但仍有两类断点：

- 会议链缺扎西、苟坝，导致「遵义会议 → 四渡赤水 → 新三人团」的决策链不完整；
- 封锁线与战术节点缺第二道封锁线、南渡乌江、佯攻贵阳、达维会师、青石嘴战斗、切尾巴战役。

这些节点均有公开史料、纪念馆或文保单位支撑，本轮一次性补齐。

## 2. 目标

1. 新增第二道封锁线、扎西会议、苟坝会议、南渡乌江、佯攻贵阳、达维会师、青石嘴战斗、切尾巴战役 8 个事件；
2. 修正于都—宜章、太平渡—皎平渡、夹金山—懋功 3 段路线，补城口、南渡乌江、达维控制点；
3. 新增国民党军第二道封锁线湘军、粤军 2 段短防线；
4. 重新生成搜索索引与移动端内置数据映射；
5. 不改版本号、不部署、不打 tag。

1. 记录本轮需求、点位口径与争议表述；
2. 按第二道封锁线、扎西、苟坝、南渡乌江、佯攻贵阳、达维、青石嘴、切尾巴补事件；

5. 运行 `pnpm validate:data`、`pnpm check:routes --atlas long-march`；

7. 运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`；
8. 更新 CHANGELOG 与本轮文档。
