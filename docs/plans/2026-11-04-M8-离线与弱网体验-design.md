## 1. 总体设计

```
Web
├── vite-plugin-pwa (Workbox)
│   ├── precache: app shell (js/css/html)
│   ├── runtime: data (StaleWhileRevalidate)
│   ├── runtime: covers (CacheFirst)
│   └── runtime: AMap tiles (CacheFirst, capped)
├── useOnlineStatus + OfflineBanner
└── Vercel: /sw.js no-cache

Mobile
├── CachedHttpDataSource (DataSource)
│   ├── 先请求网络，成功写 AsyncStorage
│   └── 失败读 AsyncStorage
└── fetchAtlasIndex / fetchAtlas 使用缓存数据源
```

## 2. Web 缓存策略

| 资源 | 策略 | 缓存名 | 限制 |
| --- | --- | --- | --- |
| JS / CSS / HTML | 预缓存 | `workbox-precache` | 构建版本 |
| `/data/atlases/**/*.json` | StaleWhileRevalidate | `atlas-data` | 100 条 / 7 天 |
| `/data/atlases/**/*.geojson` | StaleWhileRevalidate | `atlas-data` | 同上 |
| 封面图片 | CacheFirst | `atlas-images` | 60 条 / 30 天 |
| 高德地图瓦片 | CacheFirst | `amap-tiles` | 500 条 / 30 天 |
| 高德 JS API | StaleWhileRevalidate | `amap-js` | 10 条 / 30 天 |

- `registerType: 'autoUpdate'`；
- `cleanupOutdatedCaches: true`；
- `navigateFallback: '/index.html'`，保证 SPA 深链离线可用；
- 不缓存 `VITE_AMAP_KEY` / `VITE_AMAP_SECURITY_CODE` 等构建注入值以外的请求参数。

## 3. Web 离线提示

`useOnlineStatus`：

```ts
const [online, setOnline] = useState(navigator.onLine);
useEffect(() => {
  const on = () => setOnline(true);
  const off = () => setOnline(false);
  window.addEventListener('online', on);
  window.addEventListener('offline', off);
  return () => { ... };
}, []);
```

`OfflineBanner` 固定在顶部，文案：

- 中文：`当前离线，已缓存内容仍可浏览。`
- 英文：`You are offline. Cached content is still available.`

## 4. 移动端缓存

### 4.1 数据源

实现 `CachedHttpDataSource`，包装 shared 的 `HttpDataSource`：

```ts
class CachedHttpDataSource implements DataSource {
  async readText(path) {
    try {
      const text = await this.inner.readText(path);
      await AsyncStorage.setItem(key(path), text);
      return text;
    } catch (error) {
      const cached = await AsyncStorage.getItem(key(path));
      if (cached) return cached;
      throw error;
    }
  }
  resolve(...) / dirname(...) // 委托
}
```

### 4.2 缓存键

- 前缀：`atlas-cache:v1:`；
- 键为完整 URL，避免不同 `EXPO_PUBLIC_DATA_BASE_URL` 冲突；
- 只缓存 `index.json`、manifest、routes、events 等公开静态 JSON。

### 4.3 失败回退

- 网络成功：写缓存并返回；
- 网络失败：读缓存；缓存存在则返回，否则抛出原错误；
- 缓存读写失败不阻塞主流程。

## 5. 兼容性

- 数据契约不变；
- Web 旧浏览器不支持 Service Worker 时自动降级为普通网络加载；
- 移动端 AsyncStorage 是新增原生依赖，下次打包需重新 prebuild；
- 不改变任何页面交互与数据格式。
