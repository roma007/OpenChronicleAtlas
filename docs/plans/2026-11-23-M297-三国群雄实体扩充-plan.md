## 1. 背景

三国专题此前只有曹魏、蜀汉、东吴、西晋四个实体。190—208 年的袁绍、公孙瓒、刘表、
公孙氏（辽东）都是独立军阀，不能借用四国实体。用户确认按 B 方案新增四个群雄实体。

## 2. 目标

1. 新增 `yuan-shao`、`gongsun-zan`、`liu-biao`、`gongsun-liaodong` 四个实体；
2. 补界桥、易京、官渡袁绍侧、刘表荆州、公孙氏辽东；
3. 同一战役按双方分事件，不串主体；
4. 校验全绿，生成物与数据同一次提交。
