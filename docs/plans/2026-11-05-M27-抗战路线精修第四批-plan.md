M26 已加入第一次长沙会战。抗日战争专题在 1941–1942 年仍缺第二次、第三次长沙会战，时间轴在武汉失守与百团大战之间存在明显空档。

## 2. 目标

1. 新增第二次长沙会战事件；
2. 新增第三次长沙会战事件；
3. 两次会战各补日军与中国军队路线；
4. 重新生成搜索索引；
5. 保持数据契约与既有路线风格不变。
