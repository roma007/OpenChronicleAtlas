## 1. 背景

M5 已完成两专题、三端基础交互、部署与上架素材，但原始需求中的两项核心体验仍未实现：

1. 地图节点未做聚合，事件密集时 Marker 重叠；
2. 时间轴只能看全量跨度，无法放大到月/日。

M5 收尾审计将「无 Marker 聚合/离线」列为 A7 遗留项。本轮先解决聚合与时间轴缩放，离线与 i18n 留待后续。

## 2. 目标

1. 事件 Marker 随地图缩放自动聚合，聚合点显示数量；
2. 点击聚合点放大地图，放大到一定程度后恢复单个事件；
3. Web / 移动端时间轴支持 0—8 级缩放；
4. 缩放后刻度、拖动、日期输入、播放、事件高亮保持一致；
5. 聚合算法进入共享层并有单测。

## 3. 范围

### 3.1 包含

- `packages/shared` 新增事件聚合工具与测试；
- Web `MapCanvas` 聚合 Marker；
- Web `Timeline` 视口缩放；
- 移动端 `AtlasMap` 聚合 Marker；
- 移动端 `Timeline` 视口缩放；
- 版本号、CHANGELOG、发布说明、对话归档。

### 3.2 不包含

- 离线缓存 / Service Worker；
- 英文 UI 与 i18n 切换；
- iOS 真机、商店提审、自定义域名；
- 数据内容新增。

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 网格聚合在网格边界拆分邻近点 | 视觉上两个聚合点很近 | 可接受；高缩放级别自动细分 |
| 缩放时间轴后拖动映射错误 | 时间跳变 | 用视口起点 + 视口跨度计算，单测覆盖核心换算 |
| 移动端地图 SDK 不支持聚合 | 无法复用 Web 实现 | 使用共享网格算法 + 普通 Marker 渲染 |
| 播放时频繁重建 Marker | 卡顿 | 聚合只在缩放变化时重建，时间变化只更新数量与显隐 |
| 版本升级影响 Android 包 | 需重新打包 | 本轮只升版本号并 typecheck；APK 按需重建 |

## 6. 验收标准

- `pnpm validate:data` 不变；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 聚合单测覆盖：同格合并、跨格分离、缩放变化、空输入；
- Web 手动验收：默认缩放出现聚合点；点击聚合点放大；放大后单点可打开详情；时间轴 +/− 后刻度和拖动正确；
- 移动端 typecheck 通过，逻辑与 Web 一致；
- 双仓 `main` 与 tag `v0.6.0-m6` 一致。
