# L1 滇东分路核查：三军团不经曲靖 — 方案

- **关联**：[端点史实核查计划](2026-11-16-端点史实核查-plan.md)、[台账](../research/route-endpoints/long-march.md)

## 1. 核查方法

按台账逐条查线头的前置事实，先找记录，再改线。L1 覆盖 1935 年 4—5 月中央红军在滇东的分路与渡江准备，共 6 条：

1. order 21 三军团起点；
2. order 43 一军团起点；
3. order 44 右纵队长顺至江龙；
4. order 45 左纵队紫云至册亨；
5. order 37 军委纵队曲靖至皎平渡；
6. order 36 九军团起点。

## 2. 核查结果

### 2.1 发现一处实质错误：三军团不经曲靖

此前为消除 order 21 的线头，把起点放在曲靖，再接沾益。查到的事实是：

- 4/26 三军团主力由富源寨子口出发，经下河沟进抵白水一带；
- 4/27 主力由白水出发，一部进至马龙晏官屯、黄家冲，一部继续包围监视沾益；
- 4/28 全部撤出沾益，往寻甸方向。

三军团走的是**富源—白水—沾益—寻甸**，没有经过曲靖城。原「曲靖—沾益」是硬接。

### 2.2 一军团与军委纵队的记录支持原线

- 一军团 4/27 从曲靖珠街出发，经麻黄冲、冯官桥、三岔、上下西山、长冲、大瓦仓，约 85 里到马龙鸡头村，当晚指挥攻克马龙；「曲靖—马龙」成立。
- 军委纵队 4/27 由沾益岗路、甘塘出发，经曲靖城北至上下西山、西屯；4/28 由三元宫经鸡头村至寻甸鲁口哨；4/30 柯渡；5/3 皎平渡；「曲靖—寻甸—柯渡—皎平渡」成立。

### 2.3 右纵队与左纵队的中间落点

- 右纵队：4/13 从广顺进入安顺，三军团驻鸡场；4/14 经岩腊至江龙；4/16 至弄染；4/17—18 由坝草、白层渡江。原线只有「长顺—江龙」，缺广顺、岩腊。
- 左纵队：4/16 先遣团由紫云纳寒进入望谟坡架、观文、播东到羊架；4/18 到者坪架桥；4/19 过江经册亨坡妹、庆坪、安龙龙山到兴仁。原线「紫云—册亨」缺望谟。

### 2.4 九军团的示意分兵点

原 order 36 从 order 19 上的 `106.369,27.61` 起画，这个点是为接线临时加的，没有记录。事实是：九军团 3/21—22 随主力由太平渡、二郎滩一带四渡赤水，3/24 起在长干山、枫香坝佯动。起点应回到太平渡，而不是主线上的一个假点。

## 3. 修法

| order | 修改 |

| 21 | 起点由曲靖改为富源，经白水、沾益到寻甸；名称改为「富源—白水—沾益—寻甸—禄劝—马鹿塘—洪门渡」 |
