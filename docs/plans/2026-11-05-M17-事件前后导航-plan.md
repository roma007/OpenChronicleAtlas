# M17 事件前后导航 — 计划

- **日期**：2026-11-05
- **里程碑**：M17（v0.17.0-m17）
- **状态**：待确认 / 执行中
- **关联**：
  - [对话档案](../conversations/2026-11-05-M17启动与事件前后导航方案.md)
  - [M17 方案](2026-11-05-M17-事件前后导航-design.md)

## 1. 背景

时间轴可以点击事件点，但打开详情后只能关闭再找下一个事件。缺少「上一事件 / 下一事件」导航，连续阅读体验不完整。

## 2. 目标

1. 详情内提供上一/下一事件；
2. 按当前筛选与图层排序；
3. Web 支持 Alt+← / Alt+→；
4. 首尾事件按钮禁用；
5. 共享邻居计算与单测。

## 3. 范围

### 3.1 包含

- shared `neighborEvents`；
- Web EventDetailPanel 导航与快捷键；
- 移动端 EventSheet 导航；
- 文案、测试、版本、发布说明、tag。

### 3.2 不包含

- 事件自动播放；
- 关联事件图；
- 新增事件；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |

| S3 | Web 导航与快捷键 | `EventDetailPanel.tsx` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 筛选集合不含当前事件 | 无导航 | 回退全量事件 |
| 快捷键与浏览器冲突 | 行为异常 | 使用 Alt+方向键 |
| 事件日期相同 | 顺序不稳定 | 日期相同时按 ID 排序 |
| 移动端按钮过多 | 布局拥挤 | 放在详情底部 |

## 6. 验收标准

- 详情显示上一/下一事件；
- 点击后跳转并更新详情；
- 首尾事件按钮禁用；
- Alt+← / Alt+→ 可用；
- 筛选后导航只走当前筛选集合；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.17.0-m17` 一致。
