## 2. 事件聚合

### 2.1 数据结构

```ts
export interface AtlasEventCluster {
  id: string;
  events: AtlasEvent[];
  /** WGS84 平均中心 */
  center: [number, number];
}

export function clusterEvents(events: AtlasEvent[], zoom: number): AtlasEventCluster[];
```

### 2.2 网格算法

- 网格边长（度）：`cell = max(0.05, 56.25 / 2 ** zoom)`；
- 网格锚点：全球固定，从 `(-180, -90)` 起算，避免平移时聚合结果跳动；
- 网格键：`floor((lng + 180) / cell) + ':' + floor((lat + 90) / cell)`；
- 同格事件合并，中心取经纬度平均值；
- 返回顺序按网格键排序，保证渲染稳定。

### 2.3 缩放与点击

| 缩放级别 | 行为 |
| --- | --- |
| 低缩放 | 多个事件合并为聚合点，显示数量 |
| 高缩放 | 网格变小，自然拆分为单点 |
| 点击聚合点 | 地图放大 2 级，最多到 12 级 |
| 点击单点 | 打开事件详情 |

### 2.4 时间与筛选

- 聚合成员基于「筛选后、当前图层」的全部事件，不随播放时间变化；
- 时间变化时只更新聚合点内「已发生事件」数量与显隐；
- 数量为 0 时隐藏聚合点；
- 当前最新事件所在聚合点显示 active 状态。

## 3. 时间轴缩放

### 3.1 视口模型

- 全量时间轴：`timeline.start` — `timeline.end`；
- 缩放级别 `level ∈ [0, 8]`；
- 视口跨度：`span = max(DAY_MS, timeline.totalMs / 2 ** level)`；
- 视口起点 `viewStart`，终点 `viewStart + span`；
- 视口始终限制在全量范围内。

### 3.2 交互

| 操作 | 行为 |
| --- | --- |
| 点击 `+` | 级别 +1，以当前时间为中心重新计算视口 |
| 点击 `−` | 级别 −1，以当前时间为中心重新计算视口 |
| 拖动 | 按视口比例换算绝对时间 |
| 日期输入 | 设置绝对时间；若在视口外，自动把视口移动到该时间附近 |
| 播放 | 当前时间超出视口时自动跟随 |
| 键盘 | 保留原有方向键/PageUp/PageDown/Home/End/空格 |

### 3.3 刻度

- 用视口 `{start, end, totalMs, totalDays}` 调用现有 `generateTicks`；
- 缩放后自动从年刻度细化到月/日刻度；
- 刻度标签格式沿用现有逻辑。

## 4. Web 实现

### 4.1 MapCanvas

- 增加 `zoom` state，在 `zoomend` 时更新；
- 路线与 Marker 的创建拆成两个 effect：
  - 路线：依赖 dataset / 图层；
  - Marker：依赖 dataset / 图层 / 筛选 / zoom；
- `MarkerEntry` 改为保存 `AtlasEventCluster`；
- 聚合点 DOM：

```html
<button class="atlas-marker atlas-marker--cluster">
  <span class="atlas-marker__count">3</span>
</button>
```

- 点击聚合点：`map.setZoomAndCenter(Math.min(map.getZoom() + 2, 12), center)`；
- 时间 effect 更新数量、显隐与 active 状态。

### 4.2 Timeline

- 新增 `zoomLevel`、`viewStart` state；
- `viewport` 用 `useMemo` 计算；
- `ratio` 改为相对视口；
- `seekFromClientX` 改为 `setCurrentTime(viewStart + ratio * span)`；
- `+` / `−` 按钮放在倍速控件旁，带 `aria-label` 与禁用状态；
- 日期输入超出视口时，由 `useEffect` 自动调整 `viewStart`。

## 5. 移动端实现

### 5.1 AtlasMap

- 从 store 的 `mapView.zoom` 读取当前缩放级别（`onCameraIdle` 已写入）；
- 用 `clusterEvents` 计算聚合；
- 聚合点用 `Marker` + 圆形 `View`，显示数量；
- 点击聚合点：`moveCamera({ target, zoom: min(zoom + 2, 12) }, 300)`；
- 单点点击仍打开详情。

### 5.2 Timeline

- 与 Web 相同的 `zoomLevel` / `viewStart` 模型；
- `PanResponder` 的 `seekFromX` 按视口换算；
- 底部行增加 `−` / `+` 按钮；
- 日期输入与播放跟随逻辑与 Web 一致。

## 6. 兼容性与取舍

- 不改变 `AtlasEvent` / `AtlasRouteFeature` 数据结构；
- 不改变数据契约版本；
- 聚合只影响 Marker 展示，不影响搜索、筛选、详情、分享；
- 时间轴缩放只影响视口，不改变 `currentTime` 的绝对语义；
- 移动端不引入新原生依赖，避免重新 prebuild。

## 7. 测试

### 7.1 共享单测

- 空数组返回空；
- 同格两个事件合并为一个 cluster，中心为平均坐标；
- 跨格事件不合并；
- zoom 增大后同一批事件拆分；
- cluster id 稳定。
