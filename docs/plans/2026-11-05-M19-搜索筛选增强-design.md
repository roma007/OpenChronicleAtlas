## 1. 状态

Web / 移动端搜索页新增：

```ts
const [category, setCategory] = useState('');
const [from, setFrom] = useState('');
const [to, setTo] = useState('');
```

- `category` 使用原始中文分类键（如 `重要会议`）；
- `from` / `to` 为 `YYYY-MM-DD` 字符串；
- 重置只清空筛选，不清关键词。

## 2. 查询

```ts
const parseDate = (value: string) => {
  try { return value ? parseDateString(value) : undefined; } catch { return undefined; }
};

searchEvents(debounced, index, {
  atlasId: atlasFilter || undefined,
  category: category || undefined,
  from: parseDate(from),
  to: parseDate(to),
  limit: 50,
});
```

## 3. Web UI

- 在专题筛选下方增加：
  - 类型 chips（全部 + `collectCategories`）；
  - 开始/结束日期输入；
  - 「重置筛选」按钮。
- 类型 chips 显示 `categoryLabel(category, locale)`；
- 日期输入使用 `type="date"`；
- 重置按钮清空 `category/from/to`；
- 结果计数与空状态复用现有文案。

## 4. 移动端 UI

- 专题 chips 下方增加类型 chips 横向滚动；
- 日期输入两个 `TextInput`，`onEndEditing` 应用；
- 「重置筛选」按钮；
- 使用 `categoryLabel`；
- 结果计数与空状态复用现有文案。
