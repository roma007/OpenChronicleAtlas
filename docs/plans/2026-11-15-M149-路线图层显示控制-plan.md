## 1. 背景

路线图层每行只有整行可点，切换不可见；没有独显，也没有全显。

## 2. 目标

1. 每个主体行增加显示/隐藏、独显两个按钮；
2. 「路线图层」标题右侧增加全显按钮；
3. 独显可再次点击恢复之前的选择；
4. 中英文案齐全，保留键盘与屏幕阅读器语义；
5. 不改数据结构，不引入新依赖。

## 3. 范围

- `apps/web/src/components/layout/Legend.tsx`
- `apps/web/src/stores/useAtlasStore.ts`
- `packages/shared/src/i18n/messages.ts`
- 本轮 docs 与 CHANGELOG

不包含：路线数据、地图渲染逻辑、移动端原生 UI。
