# 陕甘边苏区历史补全 — 方案

- **日期**：2026-11-16
- **里程碑**：M172
- **状态**：已实施并通过校验
- **关联**：[端点史实核查计划](2026-11-16-端点史实核查-plan.md)、[长征台账](../research/route-endpoints/long-march.md)

## 1. 问题

长征专题里 `shaanxi-red-army`（陕北红军）只有 6 段路线、10 个事件，大多是「示意简化路线，待史料校订」。陕甘边苏区是长征落脚点的由来，但 1931—1935 年的创建、反「围剿」、建政过程基本空白；1934 年第一次反「围剿」还被口头误并成「陕北、陕甘边一起活了下来」。

## 2. 事实骨架（据新华社、人民网、《陇东老区红军史》）

| 时间 | 事实 |
| --- | --- |
| 1931/10 | 晋西游击队到南梁，与刘志丹游击队会合，组成西北抗日反帝同盟军 |
| 1932/2 | 改编为中国工农红军陕甘游击队 |
| 1932/3 | 正宁寺村塬建立陕甘边区革命委员会（第一个红色政权） |
| 1932/12/24 | 宜君转角镇改编为红 26 军（200 余人） |
| 1933/11/3—5 | 合水包家寨会议：恢复红 26 军、成立 42 师，以南梁为中心，设三路游击区 |
| 1934/2—5 | 陕甘边第一次反「围剿」：敌 8 个团万余人分八路合击南梁；红 42 师外线，30 余战，歼敌 3000 余人 |
| 1934/2/25 | 陕甘边区革命委员会在南梁小河沟四合台成立（习仲勋主席） |
| 1934/7—8 | 陕北苏区第一次反「围剿」：谢子长率游击队，7/17 袭占安定，8 月河口镇负伤 |
| 1934/11/1—7 | 陕甘边区苏维埃政府在南梁荔园堡成立 |
| 1935/1/30 | 红 27 军成立 |
| 1935/2—6 | 第二次反「围剿」：敌 5 省 4 万余人；2/5 周家硷会议成立西北工委与军委；6 月底粉碎，解放 6 城 |
| 1935/9/16 | 永坪会师，红 25 军与陕北红军会合，9/18 成立红 15 军团 |
| 1935/10 | 劳山、榆林桥战斗；11 月直罗镇战役 |

## 3. 处理原则

- 1933/11 以后的事件挂在 `shaanxi-red-army` 的路线上；
- 劳山、榆林桥属红 15 军团战果，事件挂 `red-15-army`，不混入陕北红军；
- 1931—1932 年前史（南梁会合、寺村塬、红 26 军成立）无对应行军线，写入实体描述与包家寨会议正文，不单列事件，避免「事件无活动路线」；
- 第一次反「围剿」的表述改为「粉碎围剿、巩固并扩大南梁根据地」，不写「让苏区活了下来」。
