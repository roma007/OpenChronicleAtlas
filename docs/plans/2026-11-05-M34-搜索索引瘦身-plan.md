## 1. 背景

`search-index.json` 当前 323.7 KB，每个条目同时保存完整事件对象与搜索字段。完整事件中的 `description`、`sources`、`images`、`relatedIds` 在搜索结果页与跳转中并不需要，造成重复与冗余。

## 2. 目标

1. 新增 `SearchEvent` 摘要类型；
2. `buildSearchIndex` 只写入摘要；
3. 保持搜索 API 与结果页行为不变；
4. 索引体积降到 260 KB 以内；
5. 补充测试并更新文档。

## 3. 范围

- `packages/shared/src/search/types.ts`；
- `packages/shared/src/search/index.ts`；
- `packages/shared/src/timeline/events.ts`；
- `packages/shared/src/filters.ts`；
- `packages/shared/src/__tests__/search.test.ts`；
- `data/atlases/search-index.json`；
- 文档、版本、tag。

## 4. 实施步骤

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 搜索结果页依赖完整事件字段 | 运行时错误 | 先 grep 所有 `hit.event` 用法，只保留摘要字段 |
| 描述搜索召回下降 | 搜索体验 | 保留 `fields.description` |
| 索引类型变化影响移动端 | 编译失败 | typecheck 覆盖 Web 与移动端 |

## 6. 验收

- 索引 4 专题 / 114 事件；
- 体积 ≤ 260 KB；
- 索引事件不含 description/sources/images/relatedIds；
- 搜索测试全部通过；
- lint / typecheck / test / build 通过；
- 双仓 tag 一致。
