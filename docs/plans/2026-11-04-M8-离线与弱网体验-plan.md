## 1. 背景

M5 审计遗留 A7：无 Marker 聚合/离线。Marker 聚合已在 M6 完成；本轮解决离线与弱网：

- Web 每次访问都依赖网络加载 JS、数据与图片；
- 移动端断网后无法再次进入已看过的专题；
- 地图瓦片与封面重复下载。

## 2. 目标

1. Web 应用壳离线可打开；
2. 专题数据、封面、已浏览地图瓦片可缓存；
3. 弱网下优先显示缓存，再后台更新；
4. 移动端断网可加载已缓存专题；
5. 离线状态有明确提示；
6. 不缓存任何密钥或个人信息。

## 3. 范围

### 3.1 包含

- Web：`vite-plugin-pwa`、Workbox 运行时缓存、离线提示；
- 移动端：AsyncStorage 缓存数据源；
- Vercel 缓存头；
- 版本、CHANGELOG、发布说明、tag。

### 3.2 不包含

- APK / IPA 打包；
- 离线写入 / 离线编辑；
- 地图瓦片全量预下载；
- 移动端网络状态提示。

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| Service Worker 缓存旧版本 | 用户看到旧页面 | `autoUpdate` + `cleanupOutdatedCaches` |
| 缓存地图瓦片过多 | 占用磁盘 | 限制条目与 30 天过期 |
| 移动端新增原生依赖 | 下次打包需重新 prebuild | 使用 Expo 兼容的 AsyncStorage，并在文档注明 |
| 离线时高德地图不可用 | 地图空白 | 提示条说明；时间轴与详情仍可用 |
| 缓存隐私数据 | 合规风险 | 只缓存公开静态数据，不缓存 Key/用户输入 |

## 6. 验收标准

- 首次访问后断网，Web 刷新仍显示首页与专题；
- 离线提示条出现；
- 数据请求命中缓存时页面正常渲染；
- 移动端 typecheck 通过，缓存逻辑有单元测试或可验证的封装；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm validate:data`、Web 构建通过；
- 双仓 `main` 与 tag `v0.8.0-m8` 一致。
