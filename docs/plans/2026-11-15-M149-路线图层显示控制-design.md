# M149 路线图层显示控制：显示/隐藏、独显、全显 — 方案

- **日期**：2026-11-15
- **里程碑**：M149（Web 交互批次）
- **状态**：内容已实施并通过校验
- **关联**：[M148 线头审计](2026-11-15-M148-线头审计-design.md)

## 1. 问题

路线图层菜单里每个主体只有一整行可点，点击即切换显示/隐藏。问题有三个：

1. 可点区域虽然大，但没有可见的「切换」控件，用户不知道这一行能点，门槛高；
2. 没有「只看这一条」的入口，要独显只能把其它十几行逐个关掉；
3. 关掉多条之后没有「一键全显」，只能逐行点回来。

## 2. 方案

每个主体行右侧增加两个 24×24 的按钮，标题栏右侧增加一个「全显」按钮。

| 控件 | 位置 | 行为 |
| --- | --- | --- |
| 眼睛按钮 | 每行右侧第一个 | 显示/隐藏该主体；隐藏时图标带斜线，按下态为朱红底色 |
| 准星按钮 | 每行右侧第二个 | 独显：只保留该主体；再次点击恢复独显前的选择 |
| 全显按钮 | 「路线图层」标题右侧 | 一次显示全部主体；已全部显示时禁用 |

行内的颜色圆点 + 名称仍然可点，保留原来的切换方式，作为大目标兼容；两个图标按钮是新增的显式入口。

## 3. 状态设计

`useAtlasStore` 增加：

- `preSoloEntityIds: Set<string> | null`：进入独显前的选择快照；
- `soloEntity(entityId)`：若不是「仅该主体」，先存快照再设为单元素；若已是该主体独显且有快照，则恢复快照；
- `showAllEntities()`：设为全部主体并清空快照。

`toggleEntity`、`setActiveEntities`、`loadAtlas` 都会清空快照，避免恢复成过期状态。

## 4. 可访问性

- 眼睛按钮 `aria-pressed` 表示当前是否显示，`aria-label`/`title` 在「显示该路线」「隐藏该路线」之间切换；
- 准星按钮 `aria-pressed` 表示是否独显，`aria-label`/`title` 为「独显该路线（隐藏其他）」；
- 全显按钮在全部显示时 `disabled`；
- 图标均 `aria-hidden`，语义由按钮标签承担。

## 5. 兼容性

- 不改数据 schema、不改路线数据；
- 只改 `Legend.tsx`、`useAtlasStore.ts` 与中英文案；
- 桌面端与移动端共用 Web 构建，行为一致；
- 移动端窄屏下两个 24px 按钮与段数文本仍能放下（名称区域 `min-w-0` 截断）。

## 6. 验证

- `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过；
- 浏览器 DOM 实测：独显后仅该主体 `aria-pressed=true`；再点一次恢复独显前的选择；全显后全部为 true 且全显按钮变禁用；眼睛按钮可单独隐藏一个主体。
