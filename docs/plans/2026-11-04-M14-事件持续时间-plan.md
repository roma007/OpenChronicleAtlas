- **日期**：2026-11-04

- **关联**：

## 1. 背景

数据契约支持事件 `endDate`，详情页也会显示日期范围，但时间轴只显示事件起点。多日会议、战役在时间轴上被压缩成一个点，用户无法看出持续时间。

## 2. 目标

1. 为史料明确的多日事件补充 `endDate`；
2. 时间轴显示持续时间条；
3. 当前事件区间高亮；
4. 不影响事件点点击与筛选；
5. 共享标记计算兼容区间。

## 3. 范围

### 3.1 包含

- 长征专题 5 个多日事件补 `endDate`；
- Web / 移动端时间轴持续时间条；
- 测试、版本、发布说明、tag。

### 3.2 不包含

- 事件时长统计；
- 动画按区间推进；
- 新增事件；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | 补充多日事件 `endDate` | `events.json` |
| S3 | Web 持续时间条 | `Timeline.tsx` |
| S4 | 移动端持续时间条 | `Timeline.tsx` |
| S5 | 测试、构建、部署、tag | `v0.14.0-m14` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| `endDate` 史实不准 | 数据错误 | 只补史料明确的多日事件 |
| 持续时间条遮挡事件点 | 点击困难 | 条在点下方，点保持在上层 |
| 区间过短不可见 | 视觉不明显 | 最小宽度 2px |
| 筛选按起点 | 与区间不一致 | 保持现有行为并文档说明 |

## 6. 验收标准

- 多日事件显示持续时间条；
- 当前事件条高亮；
- 事件点点击仍正常；
- 详情日期范围正确；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.14.0-m14` 一致。
