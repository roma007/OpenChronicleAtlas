# M209 技术方案：抗日战争按地区浏览（省/县市 + 历史省界示意）

- **任务名**：抗日战争按地区筛选与历史省界
- **日期**：2026-11-20
- **里程碑**：M209
- **关联 plan**：[M209 plan](2026-11-20-M209-抗战按地区浏览-plan.md)
- **状态**：已完成（as-built 见第 11 节；后续扩展见 M210/M211）
- **关联契约**：[Atlas Schema v1.2.0](../schema/atlas-schema-v1.2.0.md)

## 1. 背景与问题

抗日战争专题现有 529 个事件、308 段路线。用户希望：

1. 事件和路线可以按省、市、县分层浏览；
2. 跨省/市路线不要裁剪，保留整条并显示起终点；
3. 可以筛选省/市/县；
4. 显示当时的省/市/县名称，并绘制当时的地界。

现状：

- 事件只有自由文本 `location.place`，没有行政区编码；
- 路线只有坐标与名称，没有经过的行政区；
- 底图是高德现代地图，专题没有历史行政区面；
- 320 个不同地名，520/529 能读出省级前缀，但仅 24 个明确含“县”；
- 1930—1940 年代没有今天的地级市层级，且省界、县界随政权更迭变化。

## 3. 历史口径

### 3.1 参考系

采用 **中华民国 1937 年 7 月名义省区** 作为主参考系：

- 省：江苏、浙江、安徽、江西、湖北、湖南、四川、西康、福建、广东、广西、云南、贵州、河北、山东、河南、山西、陕西、甘肃、宁夏、青海、绥远、察哈尔、热河、辽宁、吉林、黑龙江、新疆、西藏、台湾（1945 年光复后）；
- 院辖市：南京、上海、北平、天津、青岛、重庆、西安（按事件日期出现的，作为省级并列）；
- 海外：日内瓦、东京、华盛顿、珍珠港等，单列“海外”。

省界按日期切换四张快照：

| 日期范围 | 快照 | 说明 |
| --- | --- | --- |
| 1931-09-18 — 1931-12-31 | `s_roc_b0` | 九一八前后 |
| 1932-01-01 — 1937-12-31 | `s_roc` | 全面抗战爆发前 |
| 1938-01-01 — 1944-12-31 | `s_roc_1938` | 抗战相持阶段 |
| 1945-01-01 — 1945-12-31 | `s_roc_c` | 抗战胜利、台湾光复 |

### 3.2 伪政权与根据地

- 东北 1932 年后实际由伪满洲国控制，但本方案仍按中华民国名义省区标注，并在地区说明中注明“伪满实际控制”；
- 汪伪政权控制区不单独建行政区，沿用名义省区；
- 抗日根据地不是正式行政区，不建“省界”，只作为事件/路线图层；
- 1945 年后的行政区变化不在本专题范围内。

### 3.3 为什么没有“地级市”

1930—1940 年代没有今天的地级市。本方案层级为：

```text
省 / 院辖市（province / municipality）
  └── 县 / 市 / 地点（county / place）
```

- “县/市/地点”是二级筛选单位；
- 地名明确到县的，显示“代县”“灵丘县”等；
- 只明确到镇、关、岛的，显示“阳明堡”“平型关”“三灶岛”等，并在 `modernName` 中给出今属；
- 不虚构“地级市”层级。

### 4.5 边界数据来源与许可

省界取自 **江山时序（jiangshan-map）** 的手绘一级政区 `region` 图层：

- 来源：https://github.com/DeanChensj/jiangshan-map
- 许可：GPL-3.0（仅 `region` 图层；其 `prefecture` 图层来自 CHGIS，本方案不使用、不转载）
- 精度：手工绘制示意，非测绘边界
- 修改：筛选 1931/1932-37/1938-44/1945 四张快照，提取 `layer=region`，简化到约 0.01°，补 `regionId`、短名、标识点、日期范围
- 声明：`data/atlases/ATTRIBUTION.md` 增加专节，界面注记“省界示意”

**不使用县界**：民国 1930—1940 年代县界没有可自由再分发的公开矢量数据；CHGIS 的县界许可仅限学术、禁止再分发，且为 1911 年口径。强行用现代县界套历史名称会造成“界线是现代、名字是当时”的错配，本方案不做。

## 5. 地区归属算法

### 5.1 事件 → 省

构建时按事件日期选择省界快照，做点面判断：

1. 院辖市：地点前缀命中南京/上海/北平/天津/青岛/重庆/西安/武汉时，直接归入院辖市；
2. 海外：地点在已知海外清单时，归入 `overseas`；
3. 其余：对省界多边形做 point-in-polygon，得到省 id；
4. 边界争议或落在海上：取最近省界质心，标记 `regionConfidence: low`。

### 5.2 事件 → 县/市/地点

1. 用 `place` 原文在 `regions.json` 的 `aliases` 中精确匹配；
2. 去括号注释后再匹配；
3. 匹配不到时，按“省 + 地名”生成新的 place 条目，标记 `regionConfidence: low`，不阻断构建；
4. 县名只在有把握时填写 `parentId` 指向县，否则直接挂省。

### 5.3 路线 → 省

1. 对路线几何按等弧长采样，间隔约 10km；
2. 每个采样点做 point-in-polygon；
3. 起点、终点单独计算，写入 `endpointRegionIds`；
4. 结果去重，保留省顺序；
5. 防御线、航线、补给线同样处理，不特殊豁免。

### 5.4 跨省路线展示

- 筛选某省时，只要 `regionIds` 含该省，整条路线保留；
- 不做几何裁剪，避免产生假线头；
- 在起点、终点各加一个端点标记，标签取路线名 `A—B` 的两端；名称无法解析时用最近事件地名；
- 路线在选区外的部分降低透明度，选区内保持原色；
- 图例显示“跨省路线：整条保留，起终点标注”。

## 7. 技术取舍

| 选项 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 手工给 529 个事件写行政区 | 可控 | 529 条易错、难维护 | 不采纳 |
| 按地名文本解析 | 快 | 县级覆盖低，易错 | 只作兜底 |
| 点面判断 + 地名表 | 省界可靠、可复现 | 需要省界数据 | **采纳** |
| 用现代县界套历史名称 | 数据易得 | 史实错配 | 不采纳 |
| 用 CHGIS 1911 县界 | 学术质量高 | 许可禁止再分发、年代不符 | 不采纳 |
| 跨省路线裁剪到省内 | 视觉干净 | 产生假线头、违背路线铁律 | 不采纳 |
| 跨省路线整条保留 + 端点标注 | 史实完整 | 选区外仍有线 | **采纳** |

## 8. 兼容性、性能与安全

- **兼容性**：新增字段全部可选；旧客户端忽略 `regions` / `regionIndex`，不影响现有专题；
- **数据量**：省界 4 张快照简化后目标 < 800KB；`region-index.json` 目标 < 300KB；移动端可接受；
- **性能**：地区筛选在构建时预计算，运行时只做 Set 交集；地图只增加 30 个多边形和少量端点标记；
- **安全**：不新增外部请求、不上传定位；省界为静态资源；
- **移动端**：`expo-gaode-map` 已支持 `Polygon`；本期移动端先接筛选，省界面按同一数据渲染，低端机可关闭。

## 9. 测试策略

- 单元测试：point-in-polygon、地名归一化、事件/路线筛选、分享参数编解码；
- 数据测试：所有 `regionIds` 必须存在于 `regions.json`；每个事件必须有省或 `overseas`；路线键唯一；
- 回归：`pnpm validate:data`、`pnpm check:heads`、`pnpm check:land`、`pnpm typecheck`、`pnpm lint`；
- 手工验收：选河北 → 只见河北事件与经过河北的路线；跨省路线两端有标签；切换 1938/1945 省界无破面。

## 10. 未决问题

1. 院辖市是否单独画小边界？本期只做点标记与事件归属，不画市界。
2. 伪满省份是否另建一套？本期沿用名义省区，后续如需要再开“政权口径”开关。
3. 县级地名表覆盖到什么程度？本期优先覆盖事件中出现的地名，未覆盖的标“地点”，后续按专题校订逐批补。
