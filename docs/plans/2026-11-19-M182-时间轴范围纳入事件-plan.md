## 1. 问题

用户指出：塘沽协定是 1933-05-31，归在「中国政府与民众」主体，
但该主体的进度起始日期是 1933-06-20。

核查确认：

- 「中国政府与民众」层拆分后只剩 1 段路线：张家口—多伦，`startDate = 1933-06-20`；
- 塘沽协定是该层事件，`routeEvent: false`，日期 `1933-05-31`；
- 时间轴范围由 `routeDateRange()` 只根据**路线**计算，事件不参与；
- `Timeline.tsx` 的事件节点又限定在 `timeline.start..timeline.end` 内，
  所以 1933-05-31 的塘沽协定在单独查看该层时被裁掉。

这是通用问题：任何「事件早于首条路线」的图层都会出现同样现象。

## 2. 修复

1. `packages/shared/src/timeline/core.ts` 新增 `datasetDateRange(routes, events, isIncluded)`：
   - 取路线 `startDate` / `endDate` 与事件 `date` / `endDate` 的最早、最晚值；
   - 事件即使 `routeEvent: false` 也参与，因为事件节点仍显示在时间轴上；
   - 没有任何路线与事件时返回 `null`，调用方回退到专题 `timeRange`。
2. Web 与移动端 `useAtlasStore` 改用 `datasetDateRange`，函数改名
   `timelineForActiveLayers`，注释同步。
3. 保留 `routeDateRange` 供已有测试与其它调用方使用。

## 3. 影响

- 时间轴范围现在会覆盖当前图层的全部事件，早期政治、外交事件不再被裁掉；
- 对「事件与路线范围一致」的图层无可见变化；
- 不修改任何专题数据。
