# M12 分享链接增强 — 计划

- **日期**：2026-11-04
- **里程碑**：M12（v0.12.0-m12）
- **状态**：待确认 / 执行中
- **关联**：
  - [对话档案](../conversations/2026-11-04-M12启动与分享链接增强方案.md)
  - [M12 方案](2026-11-04-M12-分享链接增强-design.md)

## 1. 背景

当前分享链接只保存 `t` / `event` / `view`，打开后语言、图层、事件类型与时间段筛选全部丢失。用户分享「1935 年、只看中央红军、只看会议」的视图，接收者看到的却是默认状态。

## 2. 目标

1. 分享链接保存语言；
2. 保存图层开关；
3. 保存事件类型筛选；
4. 保存时间段筛选；
5. 打开链接后恢复；
6. 非法参数安全忽略。

## 3. 范围

### 3.1 包含

- `ShareState` 扩展与编解码；
- Web `useShare` / `AtlasPage` 恢复；
- 移动端 `EventSheet` / `App` 深链 / `AtlasScreen` 恢复；
- store 新增 `setActiveEntities`；
- 测试、版本、发布说明、tag。

### 3.2 不包含

- 服务端短链；
- 二维码；
- 分享统计；
- 新增专题；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| URL 过长 | 部分平台截断 | 只存 ID/类型/日期，不存完整对象 |
| 旧链接不兼容 | 打开失败 | 新字段可选，旧链接仍可解析 |
| 注入不存在的实体/类型 | 界面异常 | 恢复时与专题实际数据取交集 |
| 移动端 URLSearchParams 兼容性 | 解析失败 | 复用 `Linking.parse` 的 queryParams，手动构造 |

## 6. 验收标准

- 分享链接包含 `locale`、`entities`、`categories`、`from`、`to`；
- Web 打开链接后语言、图层、筛选、时间点恢复；
- 移动端深链恢复同样生效；
- 非法参数被忽略；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.12.0-m12` 一致。
