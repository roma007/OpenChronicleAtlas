## 1. 背景与问题

M1 要回答三个问题：

1. **结构是否可持续**：monorepo 能否让 Web / RN / shared 真正共享逻辑，而不是三份拷贝？
2. **契约是否可落地**：需求给出的 manifest / GeoJSON / 事件 JSON 能否被校验、加载、索引，并支撑后续时间轴？
3. **数据是否可插拔**：Web 端能否在「零专题硬编码」的前提下渲染任意符合契约的数据包？

M1 不解决时间轴交互与动画，但必须把数据结构与加载链路设计到「M2 只需加计算、不改契约」的程度。

## 2. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        data/atlases/                        │
│  index.json                                                 │
│  long-march/{manifest.json, routes/*.geojson, events/*.json}│
└───────────────────────────┬─────────────────────────────────┘
                            │ 静态 JSON / GeoJSON（HTTP）
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                  packages/shared（纯 TS）                    │
│  schema/  zod 契约 + 跨文件校验                              │
│  data/    DataSource → loadAtlas() → AtlasDataset（索引）    │
│  time/    日期解析 / UTC 日粒度 / 格式化                     │
│  geo/     WGS84 ↔ GCJ-02 坐标转换（高德底图适配）            │
│  i18n/    resolveLocalized()                                │
│  selectors/ 事件/实体/时间过滤（M2 扩展）                    │
└───────────────┬──────────────────────────────┬──────────────┘
                │ workspace:*                  │ workspace:*
                ▼                              ▼
┌───────────────────────────────┐  ┌───────────────────────────┐
│ apps/web                      │  │ apps/mobile (M1 空壳)     │
│ React + Vite + 高德 JS API 2.0│  │ Expo + RN + expo-gaode-map│
│ Zustand store                 │  │ （M4 落地地图/时间轴）     │
│ 页面 / 地图 / 详情 / 图例      │  │                           │
└───────────────────────────────┘  └───────────────────────────┘
```

**关键边界**：

- `shared` 不 import `react` / `react-native` / `@amap/*` / `maplibre-*`，只处理数据与纯计算。
- 地图渲染、DOM/原生手势、路由、状态管理留在各端。
- 数据加载通过 `DataSource` 接口注入，Web 用 `fetch`，RN 可复用同一实现（RN 的 fetch 兼容）。
- **坐标转换属于 shared**：数据层统一 WGS84，渲染层进入高德前统一转 GCJ-02，禁止各端各写一份。

### 4.2 索引文件 `data/atlases/index.json`

首页卡片墙只读这一个文件，避免加载全部专题：

```jsonc
{
  "schemaVersion": "1.0.0",
  "atlases": [
    {
      "id": "long-march",
      "title": { "zh": "长征", "en": "The Long March" },
      "subtitle": { "zh": "1934—1936" },
      "cover": "long-march/assets/cover.jpg",
      "timeRange": { "start": "1934-10-10", "end": "1936-10-22" },
      "tags": ["中国近代史", "军事"],
      "path": "long-march/manifest.json"
    }
  ]
}
```

> 索引是 manifest 的**投影**，新增专题时需同步；M5 可加脚本自动生成索引。

### 4.3 时间模型

- 所有日期解析为 `Date.UTC(y, m-1, d)`，**不使用本地时区**，避免跨时区偏移一天。
- `AtlasTime` 是数字，便于比较、插值、序列化（分享链接用 `?t=1935-01-15` 而非 epoch，可读性更好）。
- 日粒度足够表达历史事件；若未来需要「时」精度，按 MINOR 增加 `precision` 字段（见契约 §8）。

### 4.4 数据流

```
AtlasGalleryPage → loadAtlasIndex(base) → AtlasSummary[]
AtlasPage        → loadAtlas(`${base}/${id}`) → AtlasDataset
                 → store.setDataset(dataset)
                 → MapCanvas 读 routes/entities → new AMap.Polyline（坐标转 GCJ-02）
                 → EventMarkers 读 events → AMap.Marker
                 → 点击 marker → store.selectEvent(id) → EventDetailPanel
```

### 4.5 坐标体系

| 环节 | 坐标系 | 说明 |
| --- | --- | --- |
| 数据包（GeoJSON / 事件） | **WGS84** | 与公开史料、QGIS、OSM 等工具一致 |
| shared 业务计算（距离/排序/筛选） | WGS84 | 不感知底图 |
| 渲染到高德地图 | **GCJ-02** | 渲染前统一 `wgs84ToGcj02` |
| 用户在地图取点 | GCJ-02 → WGS84 | 入库前转回，避免污染数据 |

```ts
// packages/shared/src/geo/coordinate.ts
export interface LngLat { lng: number; lat: number }
export function wgs84ToGcj02(lng: number, lat: number): LngLat;
export function gcj02ToWgs84(lng: number, lat: number): LngLat;  // 迭代逼近
export function outOfChina(lng: number, lat: number): boolean;   // 境外不偏移
```

- 使用公开的离线偏移算法（GCJ-02 加密算法），误差约 1–2 米，不调用高德 `convertFrom` 网络接口。
- 单测覆盖：北京/上海/乌鲁木齐/境外点、往返误差 < 5 米、边界值。
- 若未来更换底图（如 MapLibre + WGS84），只需在渲染层去掉转换，数据层不动。

## 5. 接口设计

### 5.1 shared：DataSource

```ts
export interface DataSource {
  /** 读取文本（JSON/GeoJSON），path 为已解析的绝对/完整 URL */
  readText(path: string): Promise<string>;
  /** 将相对路径解析为可读取路径 */
  resolve(base: string, relative: string): string;
}

export class HttpDataSource implements DataSource {
  constructor(private readonly fetchImpl: typeof fetch = fetch) {}
  async readText(path: string): Promise<string> {
    const res = await this.fetchImpl(path);
    if (!res.ok) throw new AtlasDataError(`加载失败 ${path}: HTTP ${res.status}`);
    return res.text();
  }
  resolve(base: string, relative: string): string {
    return new URL(relative, base.endsWith('/') ? base : `${base}/`).toString();
  }
}
```

### 5.2 shared：加载器

```ts
export interface LoadAtlasOptions {
  dataSource?: DataSource;
  locale?: string;              // 预留：用于校验多语言完整性
  onWarning?: (issue: AtlasIssue) => void;
}

export async function loadAtlas(
  manifestUrl: string,
  options?: LoadAtlasOptions,
): Promise<AtlasDataset>;

export async function loadAtlasIndex(
  indexPath: string,
  options?: LoadAtlasOptions,
): Promise<AtlasIndex>;
```

- 并行加载 `routes[]` 与 `events[]`（`Promise.all`）。
- 每个文件先 `JSON.parse`，再 zod 校验；错误聚合成 `AtlasIssue[]` 后一次性抛出 `AtlasValidationError`。
- 跨文件校验（entityId、atlasId、事件 id 唯一、时间越界）在加载完成后执行。
- 返回的 Map 索引为只读视图，避免调用方意外修改。

### 5.5 Web：地图渲染接口（高德 JS API 2.0）

```ts
// RouteLayers：每个实体一组 Polyline（按分段绘制，避免跨越段间空隙连线）
const path = feature.geometry.coordinates.map(([lng, lat]) => {
  const p = wgs84ToGcj02(lng, lat);       // shared/geo：数据 WGS84 → 高德 GCJ-02
  return new AMap.LngLat(p.lng, p.lat);
});

const polyline = new AMap.Polyline({
  path,
  strokeColor: entity.color,
  strokeWeight: 4,
  strokeOpacity: 0.9,
  lineJoin: 'round',
  lineCap: 'round',
  showDir: true,                          // 行进方向箭头
  zIndex: 50,
});
polyline.setExtData({ entityId: entity.id, segmentOrder: feature.properties.order });
map.add(polyline);
```

- 每个 `entity` 维护 `Polyline[]`，图例开关时统一 `show()/hide()`。
- M1 不做时间过滤，全部路线可见；M2 用 `polyline.setPath(partialPath)` 按时间比例截断实现生长动画（不用 `line-gradient`）。
- Marker 用 `AMap.Marker`，位置同样先转 GCJ-02；24 个无需聚合，M3 数据量大时用 `AMap.MarkerCluster`。
- 事件点击：Marker 绑定 `click` → `store.selectEvent(id)`；地图空白点击 → 清除选择。
- 底图风格：`new AMap.Map(container, { mapStyle: 'amap://styles/<styleId>' })`，样式 ID 来自 `VITE_AMAP_STYLE_ID`。
- 自定义样式未配置时使用高德默认样式，并在开发模式提示「未配置历史风格样式」。

## 6. 关键流程

### 6.1 加载与校验

```
loadAtlas(manifestUrl)
  ├─ readText(manifestUrl) → JSON.parse → manifestSchema.parse
  ├─ resolve(base, routePath) × N ─┐
  ├─ resolve(base, eventPath) × M ─┤ Promise.all
  │                                ├─ parse + routeFileSchema / eventFileSchema
  ├─ buildIndexes()
  ├─ validateCrossFile() → issues[]
  └─ if errors.length → throw AtlasValidationError(errors)
     else return dataset (warnings 附带)
```

### 6.2 错误分级

| 等级 | 场景 | 行为 |
| --- | --- | --- |
| `error` | JSON 语法错误、必填字段缺失、类型错误、entityId 不存在、event.id 重复、日期非法 | 阻断加载，页面显示可读错误与 JSON Path |
| `warning` | relatedIds 无法解析、时间越界、order 重复、sources 为空 | 控制台输出，开发模式显示角标；生产静默 |

### 6.3 Web 首屏

```
/index                    → AtlasGalleryPage（读 index.json，骨架屏 → 卡片墙）
/atlas/:atlasId           → AtlasPage
                             ├─ loading：地图容器 + 侧栏骨架
                             ├─ error：错误面板 + 返回首页
                             └─ ready：MapCanvas + 图例 + 详情侧栏
```

M1 不做时间轴 UI，但页面底部预留 `TimelinePlaceholder`（显示时间跨度文本），M2 替换为真实组件，避免布局大改。

## 7. 技术取舍（Trade-offs）

| 议题 | 选项 | 结论与理由 |
| --- | --- | --- |
| 数据位置 | A. 各端各存一份 / B. 仓库根 `data/` 单一来源 | **B**。需求明确禁止各端维护副本；Web 构建时拷贝，RN 走同一 URL |
| shared 构建 | A. 预编译 dist / B. 直接引用 TS 源码 | **B**（M1）。免构建、类型即时；发布 npm 包时再切 A |
| 校验方案 | A. 手写守卫 / B. zod / C. JSON Schema | **B**。运行时校验 + `z.infer` 单一事实源，错误路径清晰 |
| 时间库 | A. dayjs / B. date-fns / C. 自研 UTC 日粒度 | **C**。历史数据只需日粒度，自研 < 100 行，避免时区与体积问题 |
| 地图底图 | A. 天地图 / B. MapTiler / C. OSM / D. 高德 | **D（高德）**。用户决定；国内稳定、中文注记、合规；代价是 GCJ-02 转换与厂商锁定（ADR-0004） |
| 地图渲染 | A. MapLibre GL / B. 高德 JS API | **B**。与底图同源，避免 GCJ-02 栅格错位与非官方瓦片条款风险 |
| 坐标体系 | A. 数据直接存 GCJ-02 / B. 数据存 WGS84、渲染时转换 | **B**。保持与公开史料/GIS 工具互操作；转换集中在 shared |
| 数据托管 | A. 打包进 JS / B. 静态文件 fetch / C. 后端 API | **B**。可 CDN 缓存、专题可独立更新；后续平滑迁移 C |
| Web 状态 | A. Context / B. Zustand / C. Redux | **B**。轻量、无 Provider 嵌套，适合地图这种高频局部更新 |
| 移动端 | RN(Expo) vs Flutter | **RN(Expo)**，见 ADR-0001 |
| 样式 | Tailwind vs CSS Modules | **Tailwind**，快速响应式；复杂地图控件用少量 CSS |

## 8. 兼容性、性能与安全

### 8.1 兼容性

- Web：Chrome / Edge / Safari / Firefox 最近两个大版本；移动浏览器 iOS Safari 15+、Chrome Android 最新。
- 高德 JS API 2.0 以 WebGL 为主；不支持 WebGL 时显示降级提示（静态图片 + 事件列表）。
- Android 8.0+（API 26），iOS 14+（M4 验证；以高德 SDK 最低系统要求为准）。
- schema：客户端只接受 `1.x`；遇到更高 MAJOR 显示「请升级应用」。

### 8.2 性能

- 首页只加载 `index.json`（< 20 KB）；专题页按需加载。
- 24 事件 / 6 路线规模下无需虚拟化；M2 后若单专题 > 500 事件，Marker 改聚合、详情按需渲染。
- 路线按实体合并为 1 个 source，避免每条线段一个 layer。
- 数据文件启用 gzip/brotli（Vercel/Cloudflare 默认）。
- 地图 style 精简，避免加载无用图层。

### 8.3 安全与隐私

- 所有 API key 走 `.env.local` / 部署平台环境变量，**不入库**。
- 移动端签名文件、证书不入库（`.gitignore` 已覆盖）。
- 定位权限仅用于「地图定位」，不采集、不上传；隐私政策在 M5 补齐。
- 外链图片需 `referrerpolicy="no-referrer"` 与 `loading="lazy"`。
- 事件描述 Markdown 渲染需消毒（M3 引入 `rehype-sanitize`），M1 仅纯文本摘要。

### 8.4 无障碍

- 地图容器提供 `aria-label`；Marker 可 Tab 聚焦，Enter 打开详情。
- 详情面板焦点管理：打开时聚焦标题，Esc 关闭并归还焦点。
- 颜色对比度 ≥ 4.5:1；路线颜色不只靠色相区分，图例带实体名。
- 时间轴（M2）支持方向键步进、Home/End 跳转、空格播放/暂停。

### 10.2 `packages/shared/src/data/loader.ts`

```ts
import type { AtlasDataset, AtlasEvent, AtlasIssue, AtlasManifest } from '../types';
import { manifestSchema, eventSchema, routeFeatureSchema } from '../schema/atlas';
import { validateCrossFile } from '../schema/validate';
import { HttpDataSource, type DataSource } from './source';

export class AtlasDataError extends Error {}
export class AtlasValidationError extends AtlasDataError {
  constructor(public readonly issues: AtlasIssue[]) {
    super(`专题数据校验失败（${issues.length} 项）`);
  }
}

export async function loadAtlas(
  manifestUrl: string,
  options: { dataSource?: DataSource } = {},
): Promise<AtlasDataset> {
  const ds = options.dataSource ?? new HttpDataSource();
  const issues: AtlasIssue[] = [];

  const manifest = manifestSchema.parse(await readJson(ds, manifestUrl));
  const base = new URL('.', manifestUrl).toString();

  const [routeFiles, eventFiles] = await Promise.all([
    Promise.all(manifest.routes.map((p) => readJson(ds, ds.resolve(base, p)))),
    Promise.all(manifest.events.map((p) => readJson(ds, ds.resolve(base, p)))),
  ]);

  const routes = routeFiles.flatMap((file, i) =>
    (file.features ?? []).map((f: unknown) => {
      const r = routeFeatureSchema.safeParse(f);
      if (!r.success) {
        issues.push({ level: 'error', path: `routes[${i}]`, message: r.error.message });
        return null;
      }
      return r.data;
    }).filter(Boolean),
  );

  const events = eventFiles.flatMap((file, i) =>
    (Array.isArray(file) ? file : []).flatMap((e: unknown, j: number) => {
      const r = eventSchema.safeParse(e);
      if (!r.success) {
        issues.push({ level: 'error', path: `events[${i}][${j}]`, message: r.error.message });
        return [];
      }
      return [r.data];
    }),
  );

  issues.push(...validateCrossFile(manifest, routes, events));
  const errors = issues.filter((x) => x.level === 'error');
  if (errors.length) throw new AtlasValidationError(errors);

  const eventsById = new Map(events.map((e) => [e.id, e]));
  const entitiesById = new Map(manifest.entities.map((e) => [e.id, e]));
  const eventsByEntity = new Map<string, AtlasEvent[]>();
  for (const e of events) {
    for (const id of e.entityIds) {
      eventsByEntity.set(id, [...(eventsByEntity.get(id) ?? []), e]);
    }
  }
  for (const list of eventsByEntity.values()) {
    list.sort((a, b) => a.date.localeCompare(b.date));
  }

  return {
    manifest,
    routes: routes as AtlasDataset['routes'],
    events,
    eventsById,
    entitiesById,
    eventsByEntity,
    warnings: issues.filter((x) => x.level === 'warning'),
  };
}

async function readJson(ds: DataSource, url: string): Promise<any> {
  const text = await ds.readText(url);
  try {
    return JSON.parse(text);
  } catch (e) {
    throw new AtlasDataError(`${url} 不是合法 JSON：${(e as Error).message}`);
  }
}
```

```ts
import type { AtlasTime, DateString } from '../types';

const DATE_RE = /^(\d{4})-(\d{2})-(\d{2})$/;

export function parseDateString(input: DateString): AtlasTime {
  const m = DATE_RE.exec(input);
  if (!m) throw new Error(`非法日期：${input}`);
  const [, y, mo, d] = m;
  const t = Date.UTC(Number(y), Number(mo) - 1, Number(d));
  const check = new Date(t);
  if (check.getUTCFullYear() !== Number(y) || check.getUTCMonth() !== Number(mo) - 1 ||
      check.getUTCDate() !== Number(d)) {
    throw new Error(`非法日期：${input}`);
  }
  return t;
}

export function toDateString(t: AtlasTime): DateString {
  return new Date(t).toISOString().slice(0, 10);
}

export function clampTime(t: AtlasTime, start: AtlasTime, end: AtlasTime): AtlasTime {
  return Math.min(Math.max(t, start), end);
}

export function diffDays(a: AtlasTime, b: AtlasTime): number {
  return Math.round((a - b) / 86_400_000);
}

export function formatDate(t: AtlasTime, locale = 'zh-CN'): string {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric', month: 'long', day: 'numeric', timeZone: 'UTC',
  }).format(t);
}
```

```tsx
import { useEffect, useRef } from 'react';
import AMapLoader from '@amap/amap-jsapi-loader';
import { wgs84ToGcj02 } from '@atlas/shared';
import { useAtlasStore } from '../../stores/useAtlasStore';

declare global {
  interface Window {
    _AMapSecurityConfig?: { securityJsCode: string };
  }
}

export function MapCanvas() {
  const containerRef = useRef<HTMLDivElement>(null);
  const mapRef = useRef<any>(null); // AMap.Map，类型可用 @amap/amap-jsapi-types 收紧
  const dataset = useAtlasStore((s) => s.dataset);

  useEffect(() => {
    let disposed = false;
    if (!containerRef.current) return;

    window._AMapSecurityConfig = {
      securityJsCode: import.meta.env.VITE_AMAP_SECURITY_CODE,
    };

    AMapLoader.load({
      key: import.meta.env.VITE_AMAP_KEY,
      version: '2.0',
      plugins: ['AMap.Scale', 'AMap.ToolBar'],
    }).then((AMap) => {
      if (disposed || !containerRef.current) return;
      const map = new AMap.Map(containerRef.current, {
        viewMode: '2D',
        zoom: 4,
        center: [108, 30],
        mapStyle: import.meta.env.VITE_AMAP_STYLE_ID
          ? `amap://styles/${import.meta.env.VITE_AMAP_STYLE_ID}`
          : undefined,
      });
      map.addControl(new AMap.Scale());
      map.on('click', () => useAtlasStore.getState().selectEvent(null));
      mapRef.current = map;
    });

    return () => {
      disposed = true;
      mapRef.current?.destroy();
      mapRef.current = null;
    };
  }, []);

  useEffect(() => {
    const map = mapRef.current;
    if (!map || !dataset) return;
    const [lng, lat] = dataset.manifest.defaultView.center;
    const p = wgs84ToGcj02(lng, lat);
    map.setZoomAndCenter(dataset.manifest.defaultView.zoom, [p.lng, p.lat]);
  }, [dataset]);

  return <div ref={containerRef} className="h-full w-full" aria-label="历史专题地图" />;
}
```

```ts
import { loadAtlas, loadAtlasIndex, type AtlasDataset, type AtlasSummary } from '@atlas/shared';

interface AtlasState {
  index: AtlasSummary[] | null;
  dataset: AtlasDataset | null;
  loading: boolean;
  error: string | null;
  selectedEventId: string | null;
  activeEntityIds: Set<string>;
  loadIndex(): Promise<void>;
  loadAtlas(id: string): Promise<void>;
  selectEvent(id: string | null): void;
  toggleEntity(id: string): void;
}

const BASE = import.meta.env.VITE_DATA_BASE_URL ?? '/data/atlases';

export const useAtlasStore = create<AtlasState>((set, get) => ({
  index: null,
  dataset: null,
  loading: false,
  error: null,
  selectedEventId: null,
  activeEntityIds: new Set(),

  async loadIndex() {
    set({ loading: true, error: null });
    try {
      const index = await loadAtlasIndex(`${BASE}/index.json`);
      set({ index: index.atlases, loading: false });
    } catch (e) {
      set({ error: (e as Error).message, loading: false });
    }
  },

  async loadAtlas(id) {
    set({ loading: true, error: null, dataset: null, selectedEventId: null });
    try {
      const dataset = await loadAtlas(`${BASE}/${id}/manifest.json`);
      set({
        dataset,
        loading: false,
        activeEntityIds: new Set(dataset.manifest.entities.map((e) => e.id)),
      });
    } catch (e) {
      set({ error: (e as Error).message, loading: false });
    }
  },

  selectEvent(id) { set({ selectedEventId: id }); },

  toggleEntity(id) {
    const next = new Set(get().activeEntityIds);
    next.has(id) ? next.delete(id) : next.add(id);
    set({ activeEntityIds: next });
  },
}));
```

```ts
import { defineConfig, type Plugin } from 'vite';
import react from '@vitejs/plugin-react';

const DATA_DIR = path.resolve(__dirname, '../../data');

/** 开发时把 /data 映射到仓库根 data/；构建时拷贝到 dist/data */
function atlasDataPlugin(): Plugin {
  return {
    name: 'atlas-data',
    configureServer(server) {
      server.middlewares.use('/data', (req, res, next) => {
        const file = path.join(DATA_DIR, decodeURIComponent(req.url ?? ''));
        if (!file.startsWith(DATA_DIR) || !fs.existsSync(file)) return next();
        res.setHeader('Content-Type', file.endsWith('.geojson') ? 'application/geo+json' : 'application/json');
        fs.createReadStream(file).pipe(res);
      });
    },
    closeBundle() {
      const out = path.resolve(__dirname, 'dist/data');
      fs.cpSync(DATA_DIR, out, { recursive: true });
    },
  };
}

export default defineConfig({
  plugins: [react(), atlasDataPlugin()],
  resolve: { alias: { '@': path.resolve(__dirname, 'src') } },
```

```ts
import fs from 'node:fs';
import path from 'node:path';
import { loadAtlas } from '../packages/shared/src';

class FsDataSource implements DataSource {
  readText(p: string) { return Promise.resolve(fs.readFileSync(p, 'utf8')); }
  resolve(base: string, rel: string) { return path.resolve(path.dirname(base), rel); }
}

const root = path.resolve('data/atlases');
const dirs = fs.readdirSync(root).filter((d) => fs.statSync(path.join(root, d)).isDirectory());
let failed = 0;

for (const dir of dirs) {
  try {
    const ds = new FsDataSource();
    const dataset = await loadAtlas(path.join(root, dir, 'manifest.json'), { dataSource: ds });
    const warnings = dataset.warnings.length;

    failed++;
    console.error(`❌ ${dir}:`, (e as Error).message);
```
