## 1. PWA 更新提示

### 1.1 配置

`vite.config.ts`：

```ts
VitePWA({
  registerType: 'prompt',
  injectRegister: 'auto',
  // ...workbox
})
```

### 1.2 React 集成

```tsx
import { useRegisterSW } from 'virtual:pwa-register/react';

const {
  needRefresh: [needRefresh, setNeedRefresh],
  updateServiceWorker,
} = useRegisterSW();
```

- `needRefresh` 为 true 时显示提示；
- 点击「刷新」调用 `updateServiceWorker(true)`；
- 点击「稍后」调用 `setNeedRefresh(false)`；
- 提示固定在顶部中间，`z-[70]`，不遮挡时间轴。

### 1.3 类型

Web `tsconfig.json` 增加：

```json
"types": ["vite/client", "node", "vite-plugin-pwa/client"]
```

```ts
define: {
  __APP_VERSION__: JSON.stringify(pkg.version),
}
```

`vite-env.d.ts`：

```ts
declare const __APP_VERSION__: string;
```

## 3. 缓存管理

### 3.1 读取

```ts
const estimate = await navigator.storage?.estimate?.();
const keys = await caches.keys();
```

- 占用 = `estimate.usage`；
- 条目 = `keys.length`；
- 不支持时显示「未知」。

### 3.2 清除

```ts
const keys = await caches.keys();
await Promise.all(keys.map((key) => caches.delete(key)));
window.location.reload();
```

- 清除后刷新页面；
- 只删除 Cache Storage，不影响 localStorage（语言等）。

### 3.3 Hook

`useCacheInfo()` 返回：

```ts
{ usage: number | null; quota: number | null; entries: number | null; refresh(): void }
```
