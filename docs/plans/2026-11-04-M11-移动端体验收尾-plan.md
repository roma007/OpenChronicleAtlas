## 1. 背景

M7 的双语切换在移动端只保持会话内；M8 的 AsyncStorage 缓存没有状态提示和清理入口。用户重启应用会回到中文，断网时也无法判断当前数据是否来自缓存。

## 2. 目标

1. 语言选择持久化，启动时恢复；
2. 数据来自缓存时显示「离线缓存」徽标；
3. 首页提供清除离线缓存入口；
4. 清除缓存不影响语言设置；
5. 文案中英双语。

## 3. 范围

### 3.1 包含

- 移动端 `useAtlasStore`：`hydrateLocale`、`fromCache`、`clearCache`；
- `data/cache.ts`：缓存命中标记、清除缓存、重置标记；
- GalleryScreen：缓存徽标与清除入口；
- AtlasScreen：缓存徽标；
- 新增中英文案；
- 版本、CHANGELOG、发布说明、tag。

### 3.2 不包含

- APK / IPA 打包；
- Web PWA 更新提示；
- 缓存 TTL/容量统计；
- 新增专题。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 缓存标记未重置 | 下次加载误报离线 | 每次加载前 reset，加载后 consume |
| 清除缓存误删语言 | 用户语言设置丢失 | 只删 `atlas-cache:v1:` 前缀 |
| AsyncStorage 读写失败 | 启动恢复失败 | 捕获错误，回退默认中文 |
| 移动端无自动化测试 | 回归风险 | typecheck + 逻辑审查 |

## 6. 验收标准

- 切换英文后重启应用仍为英文；
- 断网进入已缓存专题显示「离线缓存」；
- 首页清除缓存后，再次断网进入专题会提示加载失败；
- 语言设置不受清除缓存影响；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.11.0-m11` 一致。
