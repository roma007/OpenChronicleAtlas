# M153 苏区三战回师：陈家河、忠堡、板栗园不再断头 — 方案

- **日期**：2026-11-16
- **里程碑**：M153（路线校订批次）
- **状态**：内容已实施并通过校验
- **关联**：[M148 线头审计](2026-11-15-M148-线头审计-design.md)

## 1. 问题

用户发现：红二方面军的陈家河、忠堡、板栗园三段都从十万坪大捷（永顺）出发，到战场就断头；同时另有一条线从十万坪继续走。

核对后确认：

- 这三段是 M52（2026-11-06）加的「苏区支线」，只画了从永顺出击的一段，回师路线没画；
- 「继续走」的那条是苏区主线「永顺—桑植」，1935 年 11 月从桑植出发长征；
- 三段都从永顺起，是因为 M52 用永顺作苏区锚点统一起画，并没有按各自最近的根据地落点分线。

## 2. 史实

1935 年 2—8 月，国民党军十万余人「围剿」湘鄂川黔苏区。红二、六军团以运动战应对，先后取得陈家河、桃子溪、忠堡、板栗园等战斗胜利，至 8 月粉碎「围剿」。三次战斗都是**从苏区出击、战后回师**，不是单程转移：

- 陈家河（4/13）在桑植县境，战后回师桑植，恢复桑植县城；
- 忠堡（6/12）在咸丰县境，战后经龙山县境回师桑植、永顺；
- 板栗园（8/3）在宣恩县境，战后经鹤峰县境回师桑植、永顺。

## 3. 修法

新增三段 `retreat` 回师路线，接住三段的战场终点，回到苏区主线终点桑植：

| order | 路线 | 日期 |
| --- | --- | --- |
| 13 | 陈家河—桑植（战后回师） | 4/14 |
| 14 | 忠堡—龙山—桑植（战后回师） | 6/13—6/15 |
| 15 | 板栗园—鹤峰—桑植（战后回师） | 8/4—8/6 |

三段回师线与出击线、苏区主线「永顺—桑植」形成闭环：

```
永顺 → 陈家河 → 桑植 → 永顺
永顺 → 忠堡 → 龙山 → 桑植 → 永顺
永顺 → 板栗园 → 鹤峰 → 桑植 → 永顺
```

龙山、鹤峰取 OSM 县城点，作为回师途中代表点；回师道路为示意。

## 4. 保留的简化

三段出击线仍从永顺（十万坪）起画，这是 M52 的苏区锚点简化。严格按地理，陈家河应从桑植出击、忠堡应从龙山出击、板栗园应从鹤峰出击；要这样改需要先补「桑植—龙山」「桑植—鹤峰」两条苏区内部机动线，属于下一步的苏区网络细化，本批不做。
