## 1. 数据契约

```ts
interface AtlasTerritoryProperties {
  entityId: string;
  startDate: DateString;
  endDate: DateString;
  order?: number;
  name?: LocalizedString;
  description?: LocalizedString;
  /** 可选：地图上的短标识，如「魏」「汉」「吴」 */
  label?: LocalizedString;
  /** 可选：标识落点 [lng, lat]，缺省取外环顶点平均值 */
  labelPoint?: [number, number];
  opacity?: number;
  extensions?: Record<string, unknown>;
}
```

- 两个字段均可选，旧数据无需修改；
- `label` 缺省回退到 `name`，再回退到实体 `name`；
- `labelPoint` 缺省取外环所有顶点平均值；
- `labelPoint` 与面一样使用 WGS84，渲染前转 GCJ-02。

## 2. 渲染

| 项 | 实现 |
| --- | --- |
| 元素 | `AMap.Text`，`zIndex: 20`（面 10，路线 50，标记 100） |
| 样式 | 实体色文字、半透明羊皮纸底、圆角胶囊、小字号衬线 |
| 交互 | `pointer-events: none` + `bubble: true`，不拦截地图点击 |
| 显隐 | 与疆域面共用 `showTerritories && 实体开启 && 时间在区间内` |
| 多语言 | 重建文字层时按当前 `locale` 解析 `label` |
| 多面 | MultiPolygon 只生成一个标识，位置取 `labelPoint` 或首个外环平均值 |
