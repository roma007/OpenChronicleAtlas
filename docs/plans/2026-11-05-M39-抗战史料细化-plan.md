## 1. 背景

抗日战争专题已有 44 个事件，但存在三类可细化项：

1. `events.json` 数组顺序与日期不完全一致；
2. 平型关事件坐标偏东约 18km；
3. 主要战役缺少通行别名，搜索召回不足。

## 2. 目标

1. 事件数组按日期稳定排序；
2. 修正平型关坐标；
3. 为主要战役补充别名；
4. 产出覆盖全部事件的史料与坐标校订报告；
5. 重新生成搜索索引。

## 3. 范围

- `data/atlases/anti-japanese-war/events/events.json`；
- `data/atlases/search-index.json`；
- `docs/releases/2026-11-05-抗日战争史料与坐标校订.md`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |

| S1 | 对话、plan/design 留档 | docs |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 别名过多导致搜索噪声 | 体验 | 只补充通行史称 |
| 坐标修正影响路线检查 | 误报 | 运行 `check:routes` 验证 |
| 排序改变事件数组顺序 | 无 | loader 本就会按日期排序 |

## 6. 验收

- 事件数组按日期排序；
- 平型关坐标 113.75, 39.34；
- 主要战役别名可搜索；
- 校订报告覆盖 44 个事件；
- 版本 `0.39.0`，双仓 tag 一致。
