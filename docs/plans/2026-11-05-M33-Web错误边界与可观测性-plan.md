## 1. 背景

Web 端目前只有页面级加载错误提示，没有 React 渲染错误边界；未捕获异常与 Promise rejection 只停留在控制台，用户无法提供可定位的错误编号。

## 2. 目标

1. 增加 React ErrorBoundary，渲染异常时显示兜底页；
2. 生成错误编号并写入 sessionStorage；
3. 监听全局 `error` 与 `unhandledrejection`；
4. 兜底页支持重新加载与返回专题；
5. 补充中英文案与纯函数单测。

## 3. 范围

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 错误记录含敏感信息 | 隐私风险 | 只记录 message/stack/url，不联网 |
| sessionStorage 不可用 | 记录失败 | try/catch 降级为仅 console |
| ErrorBoundary 自身异常 | 仍然白屏 | 兜底页保持简单，不依赖地图与数据 |

## 6. 验收

- 渲染异常显示兜底页；
- 全局错误写入 sessionStorage；
- 错误编号可读；
- 单测覆盖编号与序列化；
- lint / typecheck / test / build 通过；
- 双仓 tag 一致。
