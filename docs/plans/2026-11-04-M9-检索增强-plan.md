## 1. 背景

当前搜索只做原文子串匹配，搜索页明确提示「暂不支持拼音与分词」。中文用户常用拼音输入，无法用 `zunyi` 找到「遵义」，体验不完整。

## 2. 目标

1. 支持中文全拼搜索；
2. 支持首字母搜索；
3. 支持中英文混合查询；
4. 保持原文匹配优先；
5. 不显著拖慢搜索索引构建。

## 3. 范围

### 3.1 包含

- `pinyin-pro` 依赖；
- 搜索索引增加全拼与首字母字段；
- 搜索评分与片段逻辑调整；
- 搜索提示文案更新；
- 测试、版本、发布说明、tag。

### 3.2 不包含

- 分词；
- 拼写纠错；
- 同义词/别名；
- 搜索结果分页；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |

| S3 | 扩展 SearchEntry 与索引构建 | `search/index.ts` |
| S4 | 调整评分与片段 | `search/query.ts` |
| S5 | 更新搜索提示文案 | `messages.ts` |
| S6 | 单测、构建、部署、tag | `v0.9.0-m9` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 拼音库体积较大 | Web/移动端包体增加 | 只在 shared 引入，构建时 tree-shaking；可接受 |
| 首字母误命中多 | 结果噪音 | 首字母权重低于全拼与原文 |
| 多音字 | 个别拼音不准 | 使用 pinyin-pro 默认词典，后续可加自定义词典 |
| 拼音片段无法高亮 | 结果片段无高亮 | 回退原文片段，不强行高亮 |

## 6. 验收标准

- `zunyi`、`zy`、`zunyi huiyi` 命中遵义会议；
- 原文「遵义」排序高于拼音命中；
- 英文查询不受影响；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm validate:data`、Web 构建通过；
- 双仓 `main` 与 tag `v0.9.0-m9` 一致。
