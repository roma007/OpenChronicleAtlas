## 1. 背景

M293 补完汉末、称帝、南征、灭蜀主线后，三国中期仍缺两段：
一是 213—224 年孙曹在濡须口、皖城、荆州、广陵的拉锯；
二是 255—264 年姜维北伐与钟会灭蜀的收尾。本批按「一个历史簇一个批次」补齐。

## 2. 目标

1. 补孙曹江淮/荆州拉锯与姜维北伐两个簇；
2. 每条事件至少两条独立出处；无行军的政治事件标 `routeEvent = false`；
3. 新增路线端点接既有路线或本实体事件，不调阈值；
4. 校验全绿，生成物与数据同一次提交。
