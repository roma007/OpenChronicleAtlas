## 1. 背景与问题

M1 已经能加载专题并静态渲染路线与事件。M2 要把它变成「时空回放」：

1. 时间范围不是写死的，而是来自 `manifest.timeRange`；
2. 刻度要随专题跨度和屏幕宽度自适应（年/月/日）；
3. 拖动/播放时，路线只显示到当前时间，并沿线生长；
4. 事件按时间显隐，当前事件高亮并弹出气泡；
5. 时间计算必须放在 shared，M4 移动端直接复用。

难点在**时间轴 UI 与地图渲染的解耦**：时间轴只产生一个 `AtlasTime`，地图根据它计算路线进度与事件可见性。

## 4. 数据结构与算法

### 4.1 时间轴基础（`timeline/core.ts`）

```ts
export interface Timeline {
  start: AtlasTime;
  end: AtlasTime;
  totalMs: number;
  totalDays: number;
}

export function createTimeline(range: { start: DateString; end: DateString }): Timeline;

/** 当前时间在时间轴上的比例 0..1 */
export function timeToRatio(time: AtlasTime, timeline: Timeline): number;

/** 比例 → 时间，四舍五入到日 */
export function ratioToTime(ratio: number, timeline: Timeline): AtlasTime;

/** 吸附到 UTC 日边界 */
export function snapToDay(time: AtlasTime): AtlasTime;

/** 按天步进 */
export function stepDays(time: AtlasTime, days: number): AtlasTime;
```

- `ratioToTime` 内部 `snapToDay`，保证时间轴永远落在某一天。
- `totalDays` 用 `Math.round((end - start) / DAY_MS)`，与现有 `diffDays` 一致。

### 4.2 自适应刻度（`timeline/ticks.ts`）

```ts
export type TickUnit = 'year' | 'month' | 'day';

export interface Tick {
  time: AtlasTime;
  ratio: number;
  label: string;
  unit: TickUnit;
  major: boolean;
}

export function generateTicks(
  timeline: Timeline,
  widthPx: number,
  options?: { minLabelPx?: number; locale?: string },
): Tick[];
```

算法：

1. 目标刻度数 `target = clamp(floor(widthPx / minLabelPx), 4, 12)`（默认 `minLabelPx = 72`，移动端可传 56）。
2. 计算候选单位的最小刻度数：
   - `year`：`endYear - startYear + 1`；
   - `month`：`(endYear-startYear)*12 + (endMonth-startMonth) + 1`；
   - `day`：`totalDays + 1`。
3. 从大到小选择第一个满足 `count <= target` 且 `count >= 3` 的单位；若都不满足，选 `day` 并按 `step` 抽稀。
4. 步长候选：
   - year：`1, 2, 5, 10`；
   - month：`1, 3, 6`；
   - day：`1, 2, 5, 10, 30`。
   选择使刻度数 ≤ target 的最大步长。
5. 刻度对齐到单位边界（1 月 1 日 / 每月 1 日 / 每日 0 点），过滤超出 `[start, end]` 的值。
6. 标签：
   - year：`1935`；
   - month：`1935-01`；
   - day：`01-15`（跨年时 `1935-01-15`）。
7. `major`：year/month 全为 true；day 单位下每 5 或 10 个为 true，其余为 false（用于次刻度）。

> 例：长征 1934-10-10 → 1936-10-22，宽度 1200px，target=12 → year 刻度 1935、1936（2 个，<3），month 刻度 25 个（>12），最终选 year 并补 1934/1937 边界？实现中若 year 数量 <3，则改用 month 并每 3 个月一个刻度。验收以实际渲染为准。

### 4.3 路线插值（`timeline/route.ts`）

```ts
export interface RouteGeometry {
  coordinates: [number, number][];
  /** 每个顶点的累计长度（米） */
  cumulative: number[];
  totalLength: number;
}

export function buildRouteGeometry(feature: AtlasRouteFeature): RouteGeometry;

/** progress 0..1 → 截断后的坐标数组 */
export function partialPathAt(geometry: RouteGeometry, progress: number): [number, number][];
```

- 长度用 haversine（米），避免高纬度经度失真。
- `partialPathAt` 二分查找所在线段，线性插值经纬度，返回从起点到该点的坐标数组。
- `progress <= 0` 返回 `[]`；`>= 1` 返回完整坐标。
- 分段路线各自独立计算，不跨段插值。

### 4.4 事件显隐与当前事件（`timeline/events.ts`）

```ts
export function eventStart(event: AtlasEvent): AtlasTime;
export function eventEnd(event: AtlasEvent): AtlasTime;

/** 该时间点之前已发生的事件 */
export function visibleEventsAt(events: AtlasEvent[], time: AtlasTime): AtlasEvent[];

/** 当前事件：时间点之前最近发生、且仍在持续期内的事件 */
export function latestEventAt(events: AtlasEvent[], time: AtlasTime): AtlasEvent | undefined;

export function isEventActive(event: AtlasEvent, time: AtlasTime): boolean;
```

- `isEventActive`：`start <= time && time <= end`；无 `endDate` 时 `end = start + 1 天`。
- `latestEventAt`：在 `visibleEventsAt` 中取 `start` 最大者；用于高亮与气泡。
- 播放跨过事件时，气泡只在「事件变化」时打开，避免每帧刷新。

### 4.5 播放推进（`timeline/playback.ts`）

```ts
export interface PlaybackStep {
  time: AtlasTime;
  ended: boolean;
}

/**
 * @param deltaMs 真实经过的毫秒
 * @param durationMs 1x 下走完整条时间轴所需毫秒（默认 60_000）
 * @param speed 0.5 | 1 | 2 | 4
 */
export function advancePlayback(
  current: AtlasTime,
  deltaMs: number,
  timeline: Timeline,
  speed: number,
  durationMs?: number,
): PlaybackStep;
```

- `timeDelta = (deltaMs / durationMs) * timeline.totalMs * speed`；
- 结果 `snapToDay`，clamp 到 `[start, end]`；
- 到达 `end` 返回 `ended: true`，播放器停止。

## 5. 接口设计（Web）

### 5.1 Store timeline slice


- `loadAtlas` 成功后调用 `initTimeline(dataset.manifest.timeRange)`，`currentTime = start`。
- 拖动时间轴时 `pause()` + `setCurrentTime()`；播放时由 `usePlayback` 调用 `setCurrentTime()`。

### 5.2 `usePlayback`

```ts
export function usePlayback(): void;
```

- 依赖 `playing`、`speed`、`timeline`；
- `requestAnimationFrame` 循环，记录 `lastTs`；
- 每帧 `advancePlayback`，更新 store；
- `ended` 时 `pause()` 并把时间固定在终点；
- 卸载/暂停时 `cancelAnimationFrame`；
- 页面隐藏（`document.visibilityState === 'hidden'`）时暂停，避免后台跳变。

### 5.3 `Timeline` 组件

```tsx
<Timeline />
```

内部：

- 从 store 取 `timeline/currentTime/playing/speed` 与 `dataset`；
- `trackRef` + `ResizeObserver` 获取宽度，`generateTicks(timeline, width, { minLabelPx: isMobile ? 56 : 72 })`；
- 指针事件：`pointerdown` → `setPointerCapture` → `pause()`；`pointermove` → `seekRatio`；`pointerup` → 释放；
- 点击刻度/轨道跳转；
- 播放按钮、倍速分段按钮、日期输入（`type="date"`，min/max 来自 manifest）；
- 键盘：`ArrowLeft/Right` ±1 天，`Shift` ±7 天，`Home/End`，`Space` 播放/暂停；
- ARIA：`role="slider"`、`aria-valuemin/max/now`、`aria-valuetext`（格式化日期）。

### 5.4 地图联动

`MapCanvas` 拆成两个 effect：

1. **建层 effect**（依赖 `dataset`、`activeEntityIds`）：
   - 为每条路线创建 `AMap.Polyline`，保存 `lineByKey`；
   - 为每个事件创建 `AMap.Marker`，保存 `markerByEventId`；
   - 预计算 `routeGeometryByKey`。
2. **时间 effect**（依赖 `currentTime`、`activeEntityIds`）：
   - 每条路线：`progress = clamp((t - start) / (end - start), 0, 1)`；
   - `progress <= 0` → `line.hide()`；否则 `line.setPath(partialPathAt(geometry, progress))` + `line.show()`；
   - Marker：`event.date <= t` → `show()`，否则 `hide()`；
   - 当前事件 Marker 加 `atlas-marker--active` class；
   - 当前事件变化且 `playing` → 打开 `InfoWindow`，4 秒后关闭。

> 性能：`setPath` 只在 progress 变化 > 0.001 时调用；Marker 只切换可见性，不重建。

### 5.5 事件气泡

- 使用 `AMap.InfoWindow`（`isCustom: true`）或默认样式；
- 内容：事件名 + 日期 + 「查看详情」按钮；
- 打开时 `map.setCenter` 不强制，避免打断播放；
- 点击按钮：`pause()` + `selectEvent(id)` + `infoWindow.close()`；
- 事件切换时先关闭旧气泡再开新气泡。

## 6. 关键流程

### 6.1 拖动

```
pointerdown → pause() + setPointerCapture
pointermove → ratio = (x - rect.left) / rect.width
            → seekRatio(ratio) → currentTime
            → MapCanvas 时间 effect 更新路线/Marker
pointerup   → releasePointerCapture（保持暂停）
```

### 6.2 播放

```
play() → playing=true
rAF 循环：
  delta = now - last
  { time, ended } = advancePlayback(current, delta, timeline, speed)
  setCurrentTime(time)
  if ended → pause()
  else requestAnimationFrame
```

### 6.3 气泡触发

```
latest = latestEventAt(events, currentTime)
if (playing && latest?.id !== lastBubbleEventId) {
  openInfoWindow(latest)
  lastBubbleEventId = latest.id
  setTimeout(close, 4000)
}
```

## 7. 技术取舍（Trade-offs）

| 议题 | 选项 | 结论与理由 |
| --- | --- | --- |
| 路线动画 | A. 整段显隐 / B. `Polyline.setPath` 截断 / C. Canvas 自绘 | **B**。实现成本低、与高德渲染一致；C 性能最好但工作量大 |
| 时间驱动 | A. CSS 动画 / B. rAF + 状态 / C. 高德 `moveAlong` | **B**。时间轴需要任意跳转，`moveAlong` 只适合固定轨迹 |
| 刻度算法 | A. 固定年/月/日 / B. 按跨度 + 宽度自适应 | **B**。满足任意专题跨度 |
| 时间粒度 | A. 毫秒 / B. 日 | **B**。历史数据只需日粒度，避免时区问题 |
| 气泡 | A. 详情面板 / B. `InfoWindow` | **B**。地图上就近展示，符合「事件气泡」需求 |
| 状态 | A. 组件内 state / B. Zustand | **B**。地图与时间轴跨组件共享 |

## 8. 兼容性、性能与无障碍

### 8.1 兼容性

- 桌面 Chrome/Edge/Safari/Firefox 最近两个大版本；移动浏览器 iOS Safari 15+。
- 不支持 `requestAnimationFrame` 的环境降级为 `setInterval(100ms)`。
- 日期输入 `type="date"` 在不支持的浏览器降级为文本输入 + 校验。

### 8.2 性能

- 9 段路线、28 事件规模下无压力；目标 60fps UI、30fps 地图更新。
- 预计算路线累计长度，避免每帧重复计算。
- 播放时只更新 `setPath` 与 `show/hide`，不重建 overlay。
- 页面隐藏时暂停。

### 8.3 无障碍

- 时间轴 `role="slider"`，`tabIndex=0`，方向键/Home/End/空格可用。
- `aria-valuetext` 使用 `formatDate` 输出中文日期。
- 播放/倍速按钮有 `aria-label` 与 `aria-pressed`。
- 焦点样式可见；对比度 ≥ 4.5:1。
- 事件气泡可通过键盘关闭（Esc）。

## 10. 关键代码骨架

### 10.1 `timeline/core.ts`

```ts
import type { AtlasTime, DateString } from '../types';
import { DAY_MS, parseDateString, toDateString } from '../time/date';

export interface Timeline {
  start: AtlasTime;
  end: AtlasTime;
  totalMs: number;
  totalDays: number;
}

export function createTimeline(range: { start: DateString; end: DateString }): Timeline {
  const start = parseDateString(range.start);
  const end = parseDateString(range.end);
  if (end < start) throw new Error('timeRange.end 不能早于 start');
  return { start, end, totalMs: end - start, totalDays: Math.round((end - start) / DAY_MS) };
}

export function timeToRatio(time: AtlasTime, timeline: Timeline): number {
  if (timeline.totalMs === 0) return 0;
  return Math.min(1, Math.max(0, (time - timeline.start) / timeline.totalMs));
}

export function snapToDay(time: AtlasTime): AtlasTime {
  const d = new Date(time);
  return Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate());
}

export function ratioToTime(ratio: number, timeline: Timeline): AtlasTime {
  const clamped = Math.min(1, Math.max(0, ratio));
  return snapToDay(timeline.start + clamped * timeline.totalMs);
}

export function stepDays(time: AtlasTime, days: number): AtlasTime {
  return snapToDay(time + days * DAY_MS);
}

export { toDateString };
```

### 10.2 `timeline/route.ts`

```ts
const R = 6_371_000;

function haversine(a: [number, number], b: [number, number]): number {
  const toRad = (v: number) => (v * Math.PI) / 180;
  const dLat = toRad(b[1] - a[1]);
  const dLng = toRad(b[0] - a[0]);
  const lat1 = toRad(a[1]);
  const lat2 = toRad(b[1]);
  const h =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLng / 2) ** 2;
  return 2 * R * Math.asin(Math.sqrt(h));
}

export function buildRouteGeometry(feature: AtlasRouteFeature): RouteGeometry {
  const coordinates = feature.geometry.coordinates;
  const cumulative = [0];
  for (let i = 1; i < coordinates.length; i += 1) {
    cumulative.push(cumulative[i - 1]! + haversine(coordinates[i - 1]!, coordinates[i]!));
  }
  return { coordinates, cumulative, totalLength: cumulative.at(-1) ?? 0 };
}

export function partialPathAt(geometry: RouteGeometry, progress: number): [number, number][] {
  const p = Math.min(1, Math.max(0, progress));
  if (p <= 0 || geometry.totalLength === 0) return [];
  if (p >= 1) return geometry.coordinates;

  const target = geometry.totalLength * p;
  let lo = 0;
  let hi = geometry.cumulative.length - 1;
  while (lo < hi) {
    const mid = Math.floor((lo + hi) / 2);
    if (geometry.cumulative[mid]! < target) lo = mid + 1;
    else hi = mid;
  }

  const i = Math.max(1, lo);
  const start = geometry.coordinates[i - 1]!;
  const end = geometry.coordinates[i]!;
  const segStart = geometry.cumulative[i - 1]!;
  const segLen = geometry.cumulative[i]! - segStart;
  const t = segLen === 0 ? 0 : (target - segStart) / segLen;

  const point: [number, number] = [
    start[0] + (end[0] - start[0]) * t,
    start[1] + (end[1] - start[1]) * t,
  ];

  return [...geometry.coordinates.slice(0, i), point];
}
```

### 10.3 `timeline/ticks.ts`（核心选择逻辑）

```ts
const STEP_CANDIDATES: Record<TickUnit, number[]> = {
  year: [1, 2, 5, 10],
  month: [1, 3, 6],
  day: [1, 2, 5, 10, 30],
};

function unitCount(timeline: Timeline, unit: TickUnit, step: number): number {
  const start = new Date(timeline.start);
  const end = new Date(timeline.end);
  if (unit === 'year') return Math.floor((end.getUTCFullYear() - start.getUTCFullYear()) / step) + 1;
  if (unit === 'month') {
    const months =
      (end.getUTCFullYear() - start.getUTCFullYear()) * 12 +
      (end.getUTCMonth() - start.getUTCMonth());
    return Math.floor(months / step) + 1;
  }
  return Math.floor(timeline.totalDays / step) + 1;
}

export function generateTicks(timeline: Timeline, widthPx: number, options = {}): Tick[] {
  const target = Math.min(12, Math.max(4, Math.floor(widthPx / (options.minLabelPx ?? 72))));
  const units: TickUnit[] = ['year', 'month', 'day'];

  for (const unit of units) {
    const step = STEP_CANDIDATES[unit].find((s) => unitCount(timeline, unit, s) <= target);
    if (step) return buildTicks(timeline, unit, step);
  }
  return buildTicks(timeline, 'day', 1);
}
```

> `buildTicks` 按单位边界迭代，生成 `{ time, ratio, label, unit, major }`；跨年 day 标签带年份。

### 10.4 `usePlayback.ts`

```ts
export function usePlayback() {
  const { playing, speed, timeline, setCurrentTime, pause } = useTimelineStore();

  useEffect(() => {
    if (!playing || !timeline) return;
    let frame = 0;
    let last = performance.now();

    const tick = (now: number) => {
      const delta = now - last;
      last = now;
      const { time, ended } = advancePlayback(
        useTimelineStore.getState().currentTime,
        delta,
        timeline,
        speed,
      );
      setCurrentTime(time);
      if (ended) {
        pause();
        return;
      }
      frame = requestAnimationFrame(tick);
    };

    frame = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(frame);
  }, [playing, speed, timeline, setCurrentTime, pause]);
}
```

### 10.5 地图时间 effect（节选）

```ts
useEffect(() => {
  const map = mapRef.current;
  if (!map || !dataset) return;

  for (const [key, entry] of lineEntriesRef.current) {
    const { feature, geometry, line } = entry;
    const start = parseDateString(feature.properties.startDate);
    const end = parseDateString(feature.properties.endDate);
    const progress = end === start ? (currentTime >= end ? 1 : 0) : (currentTime - start) / (end - start);

    if (progress <= 0) {
      line.hide();
      continue;
    }
    const path = partialPathAt(geometry, progress);
    if (path.length >= 2) {
      line.setPath(path);
      line.show();
    }
  }

  for (const [eventId, marker] of markerEntriesRef.current) {
    const event = dataset.eventsById.get(eventId);
    if (!event) continue;
    const visible = parseDateString(event.date) <= currentTime;
    marker[visible ? 'show' : 'hide']();
  }
}, [currentTime, dataset]);
```
