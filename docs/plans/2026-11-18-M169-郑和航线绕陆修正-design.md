# M169 郑和航线绕陆修正 — 数据与 QA 方案

- **任务名**：郑和七次下西洋航线「穿陆」修正
- **日期**：2026-11-18
- **里程碑**：M169
- **触发**：用户提问「为什么郑和下西洋的线路有些是横穿大陆？难道船走大陆？」

## 1. 问题定位

M168 补事件时用的是「加港 + 加航路点」的直线折线。折线顶点本身在海上，但**顶点之间是两点直线**，
在以下位置必然切过陆地：

| 现象 | 成因 |
| --- | --- |
| 占城（109.3E）直插暹罗湾 | 缺中南半岛东岸、湄公河口、马来半岛东岸航路点 |
| 孟加拉湾横穿 | 缺安达曼—尼科巴以西的下南洋航路 |
| 锡兰→古里→忽鲁谟斯 | 缺印度西岸贴岸与俾路支岸外航路 |
| 阿丹→东非 | 缺索马里外海、瓜达富伊角绕行 |
| 太仓、旧港 | 本身在内河／河口，直线必然「上岸」 |

结论不是「船走大陆」，而是**折线精度不足**：顶点少、间距大，帆船航迹被画成了跨陆弦线。

## 2. 方案

### 2.1 航线：栅格 A* 绕陆

1. 把 Natural Earth `ne_50m_land` 栅格化成 **0.05°** 海陆格网（离线脚本，一次性）；
2. 每个航次只给**有序港口 / 航路点锚点**，相邻锚点之间用 8 邻域 A* 走水面最短路径；
3. 每段用 Douglas–Peucker（`eps = 0.1°`，约 11km）化简；化简后**逐段回检**，
   若某条弦在陆地上连续超过 6km 就回退成原始折线；
4. 锚点本身已按 50m 岸线挪到近岸水域（如长乐 119.8/25.94、古里 75.72/11.2、马六甲 102.2/2.1）。

0.05° 是为了让马六甲海峡、新加坡海峡、霍尔木兹、曼德海峡、台湾海峡都能通过；
0.1° 会把新加坡海峡（约 16km）糊成陆地，A* 直接无解。

### 2.2 内河航段：显式折线 + 例外登记

只有两处不得不「上岸」，因为是真正的内河：

- **太仓 → 长江口**（`121.1,31.45 → 121.45,31.5`）：刘家港出海必走长江水道，
  50m 岸线把河口沙洲并作陆地；
- **旧港 → 穆西河口**（`104.92,-2.4 → 104.82,-2.62`）：巴邻旁在穆西河上游约 80km。

这些写成 `data/atlases/zheng-he/land-legs.allow.json`，逐条写 `reason`。

### 2.3 内陆目的地：不画航线

麦加、艾哈迈达巴德、榜葛剌王城都在内陆，船到不了。处理方式：

- 航线只到最近海港（吉达、坎贝、察地港）；
- 事件标 `extensions.routeEvent = false`，不参与 30km 距离校验。

### 2.4 新增 QA：`pnpm check:land`

`scripts/check-route-land.ts`：

- 只查 `segmentType: naval`（陆战、防线、补给线天然跨陆）；
- 沿航段每 2km 采样，统计**连续**陆地里程；
- **默认阈值 25km**：50m 岸线在三角洲 / 海峡 / 沙洲处只有几公里精度，阈值取小会把
  正常贴岸航行整片误报；25km 仍能拦住任何真正的跨陆直线（跨半岛、跨大陆都是数百公里）。
- 例外登记在专题目录 `land-legs.allow.json`，按 `entityId + from + to`（0.02° 容差）匹配。
- 默认查 `zheng-he`（与 `check:heads` 默认 `long-march` 同构），`--atlas` 指定专题，`--all` 全量。

## 3. 效果

| 指标 | 修正前 | 修正后 |
| --- | --- | --- |
| 航线顶点数（7 条合计） | 212 | 4695 |
| `check:land` 超阈值航段（≥25km） | 194 | 0（18 处内河例外已登记） |
| 最长连续穿陆 | 1548km（跨印度次大陆） | 24km（穆西河 / 长江口，均已登记） |
| `check:routes` | 0 问题 | 0 问题（110 事件全部 ≤30km） |
| `check:heads` | 0 无来由端点 | 0 |

代价：`voyages.geojson` 从 40KB 涨到 300KB，移动端内置数据同批增长。可接受——
这是唯一能让「船沿海走」在地图上成立的做法。
