## 1. 背景

郑和专题已有 41 个事件、22 段路线，但地图上没有政权疆域面；用户希望像三国专题一样，看到满剌加、古里、忽鲁谟斯等沿途邦国与明朝、印度洋各大政权的边界。

## 2. 目标

1. 为郑和专题补 1405—1433 年的相关政权疆域面；
2. 能用的数据优先用 Cliopatria，缺失的小国明确标为示意；
3. 与既有疆域专题共用同一渲染与图例开关；
4. 数据、索引、移动端生成物与文档同一次提交。

## 3. 范围

- `data/atlases/zheng-he/manifest.json`（实体、`territories`、许可、`updatedAt`）
- `data/atlases/zheng-he/territories/territories.geojson`（新增）
- `scripts/build-zheng-he-territories.py`（新增）
- `data/atlases/ATTRIBUTION.md`、`README.md`
- `data/atlases/index.json`、`data/atlases/search-index.json`（重建）
- `apps/mobile/src/generated/atlasData.ts`（重建）
- 本轮 docs 与 CHANGELOG

不包含：航线、事件、封面、时间轴与渲染层改动。
