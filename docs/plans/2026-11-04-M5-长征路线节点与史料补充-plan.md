## 1. 目标

在已完成「事件日期 = 路线到达位置」抽查的基础上，进一步提高长征专题数据的可读性与可追溯性：

1. 为各路线段补充中间途经节点，减少长直线带来的空间失真；
2. 为每个事件补充更具体的史料来源说明；
3. 保持现有事件日期、路线段起止点不变，确保抽查结果不回退。

## 2. 范围

- 仅修改 `data/atlases/long-march` 下的路线与事件数据；
- 不修改渲染逻辑、时间轴逻辑和移动端功能；
- 不新增专题、不新增事件。

## 4. 验收标准

- `pnpm validate:data` 通过；
- 28 个事件在事件日期仍与路线终点重合（0km）；
- 每个事件至少 3 条来源，其中至少 1 条为针对性说明；
- Web / 移动端构建、类型检查、测试通过。

## 5. 风险

| 风险 | 处理 |
| --- | --- |
| 中间节点坐标不精确 | 保留「示意简化」声明，仅使用公开常见地名与大致坐标 |
| 来源版本/年份不准确 | 使用常见权威版本，不写页码与 URL，避免过度声称 |
| 节点过多导致路线抖动 | 每段控制在 2—8 个节点，按实际走向排序 |
