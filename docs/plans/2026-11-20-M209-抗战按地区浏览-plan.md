# M209 开发计划：抗日战争按地区浏览（省/县市 + 历史省界示意）

- **任务名**：抗日战争按地区筛选与历史省界
- **日期**：2026-11-20
- **里程碑**：M209
- **负责人**：AI 开发助手
- **关联文档**：[design](2026-11-20-M209-抗战按地区浏览-design.md) / [ADR-0011](../decisions/ADR-0011-地区索引与历史省界.md) / [对话档案](../conversations/)

- **状态**：已完成（as-built 对账见本文第 10 节；后续扩展见 M210/M211）

## 1. 目标（Goal）

让抗日战争专题支持按“省 / 县市 / 地点”筛选事件与路线；跨省路线整条保留并标注起终点；显示当时省名与 1931—1945 年省界示意，并明确标注“示意、非精确勘界”。

## 2. 范围（Scope）

### 2.1 包含

> M209 本体完成后，M210/M211 追加了地区标注、县治点位、本区事件/路线、搜索页仅搜本区、路线详情等增量；不属于本表原始范围，见第 10 节。

- Schema v1.2.0：`regions`、`regionIndex`、事件/路线的 `regionIds`；
- `regions.json`：30 省（含 1945 台湾）+ 8 院辖市 + 海外 + 县市/地点条目；
- `scripts/build-region-data.py` + `scripts/check-region-index.ts`：事件点面归属、路线采样、地区索引生成、一致性校验；
- `region-index.json`：529 事件 + 308 路线的地区归属；
- 1931 / 1932—1937 / 1938—1944 / 1945 四张省界示意面；
- Web 图例地区筛选、地图高亮、跨省路线端点标注；
- 移动端筛选面板地区筛选、地图端点标注；
- 分享链接 `regions` 参数；
- 文档：design、plan、ADR、schema v1.2.0、ATTRIBUTION、CHANGELOG、对话档案。

### 2.2 不包含（Out of Scope）

> 注：其中“搜索结果页的地区筛选”在 M211 被追加为已接受的范围扩展，见第 10 节。


- 民国县级地界多边形；
- 伪满洲国、汪伪政权、抗日根据地的独立行政区划；
- 今天的地级市层级；
- 1945 年以后的行政区变化；
- 对全部 320 个地名做页码级史料校订（本期只做可用性校订，标 `confidence`）。

## 5. 实施步骤

1. **契约先行**：加 `AtlasRegion`、`regions`、`regionIndex`、`regionIds`，写 schema 文档与 ADR。
2. **省界数据**：从江山时序导出四张 `region` 快照，简化、补属性、写 `roc-provinces.geojson`。
3. **地区字典**：建 30 省（含 1945 台湾）+ 8 院辖市 + 海外 + 事件地名条目；县名有把握的挂县，否则挂省。
4. **索引脚本**：按日期选快照，事件点面 + 地名匹配；路线 10km 采样；生成 `region-index.json`，并校验所有 id。
5. **加载与筛选**：loader 合并索引；`applyEventFilters` 加 `regionIds`；路线过滤函数。
6. **Web**：地区筛选面板、省界开关、选中省高亮、跨省路线端点标记。
7. **移动端**：同样的筛选数据与逻辑；地图画省界、端点标记。
8. **分享**：`regions` 参数编码/解码，校验非法 id。
9. **验收**：数据、类型、lint、构建、手工抽查 5 个省 + 3 条跨省路线。
10. **发布**：更新 CHANGELOG、ATTRIBUTION、对话档案，提交并按铁律发布。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 省界数据许可与 MIT 冲突 | 法务风险 | 中 | 单独文件 GPL-3.0，ATTRIBUTION 明示；不使用 CHGIS 图层；代码仍 MIT |
| 历史省界与现代底图标签错位 | 视觉误导 | 高 | 只描边、不填充；标注“示意”；低缩放隐藏省名；可关闭 |
| 地名表县名误判 | 史实错误 | 中 | 有把握才挂县；其余挂“地点”；`confidence` 标记；后续校订 |
| 院辖市无面 | 筛选边界不完整 | 中 | 单独点标记；事件按前缀归属；路线按端点/采样归属 |
| 省界多边形破面/自交 | 渲染异常 | 低 | 构建时校验环闭合、面积、坐标范围；简化后做一次目检 |
| 移动端包体增大 | 首屏变慢 | 中 | 省界简化到 <800KB；低端机可关；后续按需加载 |
| 529 事件文本含模糊地名 | 归属不准 | 高 | 省级点面兜底；模糊地名挂省并标 `low`，不硬编县 |
| 跨省路线端点名称解析失败 | 标签缺失 | 中 | 回退到最近事件地名或坐标；无名称时不显示标签 |

## 8. 回滚方案

- 数据层：删除 `regions` / `regionIndex` 字段与两个新文件，客户端忽略未知字段，旧数据仍可加载；
- 界面层：地区筛选默认收起，关闭后行为与 v1.0.163 一致；
- 省界层：`历史省界` 开关默认关闭即可回退视觉；
- 发布层：按 `AGENTS.md` 第 7.4 节用 `/srv/atlas.prev` 秒级回滚。
