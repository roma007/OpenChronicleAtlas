## 1. 背景

红十五军团于 1935-09-18 由红二十五军与红二十六、二十七军在永坪合编而成。此前数据模型没有 `red-15-army` 实体，其成立后的劳山、榆林桥、直罗镇等行动被挂到 `red-25-army` 与 `shaanxi-red-army`，地图上无法单独显示。

## 2. 目标

1. 新增 `red-15-army` 实体与颜色、排序；
2. 新建 `routes/red-15-army.geojson`，补 3 段路线；
3. 新增红十五军团成立、劳山战役、榆林桥战役 3 个事件；
4. 直罗镇战役事件补入红十五军团；
5. 重新生成搜索索引。
