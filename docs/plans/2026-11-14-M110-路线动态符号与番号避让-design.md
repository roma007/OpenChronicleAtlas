# M110 路线动态符号与番号避让 — 方案

- **日期**：2026-11-14
- **里程碑**：M110（Web 地图渲染改进）
- **状态**：已实施并通过校验
- **关联计划**：[2026-11-14-M110-路线动态符号与番号避让-plan.md](2026-11-14-M110-路线动态符号与番号避让-plan.md)
- **前序批次**：[M109 地图路线军事符号原型](2026-11-13-M109-地图路线军事符号原型-design.md)

## 1. 问题

M109 用「番号牌 + 据点端点 + 防御齿线」把静态路线从「两点一线」提升为可读的军事地图语言，但还有两个明显缺口：

1. **路线是静态的**：播放时间轴时，线只会一段段变长，读者看不出当前推进到了哪里，也不知道下一步朝哪个方向。
2. **番号牌会互相压盖**：全州、宜章等路线密集处，缩放 6–8 时多个番号牌叠在一起，既有文字互相遮挡，也会被事件聚合圆点盖住。

## 2. 本轮范围

### 2.1 线头箭头

- 每条非防御路线生成一个线头箭头 Marker，位置取当前时间进度对应的路线点；
- 箭头按该点的切线方向旋转，指向推进方向；
- 显隐规则：
  - 缩放 ≥ 5；
  - 进度 > 1% 且 < 99.9%，路线走完后自动收起；
  - 防御 / 封锁线不显示（它们没有推进方向）；
- 播放时箭头随 30fps 的时间轴逐帧移动，暂停时停在当前位置；
- 尺寸固定 8×9 px，不随缩放变化。

### 2.2 番号牌屏幕空间避让

- 进入避让前先按「时间进度 ≥ 45% 且缩放 ≥ 6」筛选候选番号牌；
- 用文本估算外接框（汉字 11 px、西文 6.2 px、左右内边距 14 px、高 18 px），避免逐帧读取 DOM 引发布局抖动；
- 按优先级贪心放置：
  - 防御 / 封锁线番号优先（它们承载封锁线归属信息）；
  - 其余按路线 `order`，保证同一时间点的结果稳定、不会闪烁；
  - 与已放置番号牌重叠 3 px 以上则隐藏；
- 番号牌 `zIndex` 提到 120，高于事件聚合圆点（100/110），保证文字不会被「2」「6」这类计数气泡盖住。

### 2.3 图例

- 当专题存在非防御路线时，图例「路线样式」下增加说明：
  - 中文：「线头箭头表示路线当前推进到的位置。」
  - 英文：「The arrowhead marks the current head of an advancing route.」
- 与 M109 的防御说明并列显示；没有对应路线的专题不出现。

## 3. 阈值

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 线头箭头最小缩放 | 5 | 总览时仍能看到主要路线的推进方向 |
| 线头箭头显示进度 | 1% – 99.9% | 起点与终点不显示，避免和据点方块重叠 |
| 番号牌最小缩放 | 6 | 沿用 M109 |
| 番号牌最小进度 | 45% | 沿用 M109 |
| 标签重叠判定 | 3 px | 给相邻番号牌留一点呼吸空间 |
| 标签高度估算 | 18 px | 11 px 字号 + 上下内边距与边框 |

## 4. 技术取舍

| 选项 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 用 Polyline 动画实现流光 | 纯几何 | 高德 Polyline 不支持 dash offset，需频繁重建整条线 | 不采用 |
| 线头用 Marker + CSS 三角形 | 固定像素、旋转简单、随进度移动 | 每条路线一个 DOM marker | **采用** |
| 只给国民党军路线加线头 | 改动最小 | 红军主线反而没有方向提示 | 不采用 |
| 所有非防御路线加线头 | 视觉统一 | 其他专题新增 marker（每路线 1 个） | **采用**，量级可控 |
| 逐帧读取 DOM 计算标签尺寸 | 精确 | 30fps 下强制布局，明显掉帧 | 不采用 |
| 文本估算 + 贪心避让 | 稳定、无布局抖动 | 尺寸是近似值 | **采用** |
| 标签避让事件圆点 | 不遮挡计数 | 密集区大量番号牌被隐藏，信息损失更大 | 不采用，改为提高 zIndex |

## 5. 兼容性、性能与安全

- 数据契约无变化，不涉及 schema 与数据文件；
- 线头箭头对所有专题生效：每条非防御路线新增 1 个 Marker；长-march 73 个，anti-japanese-war 128 个，量级可控；
- 番号牌避让只在自身标签之间比较，复杂度 O(n²) 但 n 为当前专题番号牌数量（长征 21 个），可忽略；
- 移动端未接入本轮改动，仍使用原有渲染；
- 无新增网络请求、无定位权限变化。

## 6. 测试策略

- `pnpm validate:data`、`pnpm check:routes --atlas long-march`；
- `pnpm typecheck` / `pnpm lint` / `pnpm test`；
- 浏览器实测：
  - 长征 1934-11-30、缩放 6–9：线头箭头可见且方向正确；
  - 播放时箭头随日期移动，暂停后停在当前线头；
  - 番号牌在密集区按优先级避让，无两两重叠；
  - 番号牌位于事件聚合圆点之上；
  - 中英文切换后番号牌与图例说明同步；
  - anti-japanese-war：无齿线 / 据点，线头箭头与图例说明正常。

## 7. 未决问题

- 路线几何仍是示意折线，尚未沿公路、河谷、山口补真实控制点；
- 线头箭头与高德自带的沿线方向箭头视觉上略接近，后续可考虑把自带箭头关掉或改成更细的箭头；
- 密集区被避让隐藏的番号牌没有 hover / 点击补偿；
- 移动端尚未复用番号牌、齿线与线头箭头。
