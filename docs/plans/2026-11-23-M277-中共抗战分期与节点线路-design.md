# M277 中国共产党抗战分期与节点线路（设计）

- **日期**：2026-11-23
- **里程碑**：M277
- **专题**：`anti-japanese-war`
- **实体**：`ccp`（中国共产党）
- **目标**：把现有只覆盖东北党组织沿革的 `ccp` 层，扩展为覆盖 1931—1945 年全国抗战的政治决策、组织沿革、国共谈判与理论建设主线；补一组有史实锚点的党的机关／代表团移动线路。

## 1. 边界

`ccp` 层回答的是「谁下的决定、组织怎么变、谁去谈判、党的路线怎么形成」，不回答「哪支部队在哪打仗」。

| 内容 | 归属 |
| --- | --- |
| 中共中央宣言、决议、指示、会议、组织沿革 | `ccp` |
| 国共谈判、中共代表团往返、南方局等派出机关 | `ccp` |
| 毛泽东等党的领袖的理论著作与整风文献 | `ccp` |
| 八路军、新四军、华南游击队、东北抗联的作战与建制 | 各自军事层 |
| 根据地政权建设的具体实施 | `ccp` 只收中央决策；地方实施不单独立条 |

一条事件如果需要同时挂军事层，必须确认该军事层在事件日期有活动路线，否则只挂 `ccp`，避免为凑主体制造「无路线」错误。

## 2. 为什么要分期

抗战十四年，党的任务经历四次大转变：从苏维埃革命到抗日民族统一战线；从统一战线形成到全面抗战；从战略防御到相持阶段的整风与根据地建设；从局部反攻到战后争取和平。把节点按这四次转变分段，时间轴才不会变成一串互不相干的会议。

分期不是另造历史阶段，而是地图叙事的分层：

1. **政策转向期**（1931-09—1935-12）：从反帝宣言、对日宣战，到瓦窑堡会议确立统一战线。
2. **统一战线形成期**（1936-01—1937-07）：西北联合、逼蒋抗日、西安事变、五次谈判。
3. **全面抗战与路线统一期**（1937-08—1938-11）：洛川会议、六届六中全会。
4. **相持阶段建设期**（1938-11—1941-12）：南方局、三三制、新民主主义论、精兵简政。
5. **整风与一元化期**（1942-01—1943-12）：整风、文艺座谈会、九一决定、中央机构调整。
6. **联合政府与胜利期**（1944-01—1945-10）：六届七中全会、七大、重庆谈判、东北局。

## 4. 节点选择标准

按优先级取四类，不追求「一年一条」：

1. **路线转折**：瓦窑堡会议、六届六中全会、六届七中全会、七大。
2. **组织沿革**：中央迁驻延安、南方局成立、中央机构调整、东北局成立。
3. **国共关系**：致国民党书、逼蒋抗日指示、杭州／庐山谈判、重庆谈判。
4. **理论建设**：论持久战、新民主主义论、三大法宝、整风三篇、九一决定。

同一主题不重复立条：例如《论反对日本帝国主义的策略》并入瓦窑堡会议；《愚公移山》并入七大；皖南事变本身留在新四军层，只在党的层补「重建军部命令」。

## 5. 线路规则

1. **只画党的机关／代表团移动**：周恩来赴西安、杭州、庐山，南方局赴渝，毛泽东赴渝与返延，东北局赴沈。
2. **不重复军事路线**：八路军出师、新四军东进、抗联游击路线不复制到 `ccp` 层。
3. **端点必须有锚**：每段起终点落在同实体事件 10km 内，或与同实体另一段路线相接；首段起点、末段终点按规则豁免。
4. **全部 `precision: schematic`**：抗战时期交通受战局影响，具体路径不可考，线路只表示「从甲到乙」的政治行程，不表示实际车船航线。
5. **往返分开**：延安—重庆、重庆—延安分别成段，日期取实际起止，不用一条线表示整场谈判。

## 6. 史料与不确定性

- 会议、文件日期以中共中央党史和文献研究院「党史百年·天天读」、《中国共产党历史》第一卷、《毛泽东选集》为准。
- 谈判行程以周恩来年谱、地方志与当事人回忆互证；只知月份的，日期取有明确记载的一天，正文写明「某月」。
- 同一事件异说并存时并列写出，不为了让时间轴连续而改日期。
- 每条事件至少两条独立来源；纯属通行说法而未见原始文件的，正文标「待考」。

## 7. 与现有层的关系

- 现有 `ccp` 的 9 条东北党组织节点全部保留，只把层说明从「东北抗战相关」改为「全国抗战政治主线」，并保留「军队作战归军事层」的边界。
- 新增 `routes/ccp.geojson`，在 `manifest.json` 的 `routes` 中登记。
- 新增事件全部只挂 `ccp`；与军事层相关的内容在正文与 `relatedIds` 中关联，不重复挂实体。
