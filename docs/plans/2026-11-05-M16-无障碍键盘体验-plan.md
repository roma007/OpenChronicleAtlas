## 1. 背景

时间轴已支持方向键、PageUp/PageDown、Home/End、空格，但页面缺少跳转链接、详情焦点管理与屏幕阅读器提示。键盘用户打开详情后焦点仍停留在背景，关闭后也不知道回到哪里。

## 2. 目标

1. 提供「跳到主要内容」链接；
2. 详情打开时焦点进入，关闭后恢复；
3. 时间轴当前事件有礼貌播报；
4. 事件点标记当前状态；
5. 补齐关键可访问标签；
6. 不改变视觉设计。

## 3. 范围

### 3.1 包含

- Web Skip Link 与 `main` landmark；
- EventDetailPanel 焦点管理；
- Timeline `aria-live` / `aria-current`；
- PWA 更新提示 `role="status"`；
- 移动端卡片/事件点可访问标签；
- 文案、测试、版本、发布说明、tag。

### 3.2 不包含

- 完整焦点陷阱；
- 屏幕阅读器全量人工测试；
- 高对比度主题；
- APK/IPA 打包。

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 焦点管理影响鼠标用户 | 体验突兀 | 只在键盘/点击打开时聚焦，关闭恢复 |
| `aria-live` 播放时刷屏 | 屏幕阅读器噪音 | 只播报当前事件名，不播报逐帧日期 |
| Skip Link 样式 | 视觉突兀 | 仅聚焦时显示 |
| 移动端标签过多 | 朗读冗长 | 只给关键操作加标签 |

## 6. 验收标准

- Tab 首次聚焦显示 Skip Link；
- 激活后焦点进入主内容；
- 详情打开焦点进入，Escape 关闭后恢复；
- 当前事件点有 `aria-current`；
- 事件变化有礼貌播报；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.16.0-m16` 一致。
