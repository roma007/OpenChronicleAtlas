## 1. 背景

M35 已定义 `RouteSegmentType`，但数据尚未使用；路线精度只写在描述文案里，缺少可查询的结构化字段。三专题路线文案已统一为「示意简化路线/航线」，但精度没有分级。

## 2. 目标

1. 为全部 127 段路线补 `segmentType`；
2. 为全部路线补 `extensions.precision`；
3. 在 schema 文档记录 `precision` 约定；
4. 输出统计并校验；
5. 重新生成搜索索引。

## 3. 范围

- 4 个专题的全部 route GeoJSON；
- `docs/schema/atlas-schema-v1.1.0.md`；
- `data/atlases/search-index.json`；
- 文档、版本、tag。
