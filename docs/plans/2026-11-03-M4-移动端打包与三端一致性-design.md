## 1. 背景与问题

Web 端已经具备：专题卡片墙、高德地图、路线生长、时间轴、事件详情、搜索/筛选、分享。
M4 要把它搬到 Android/iOS，并保证：

1. **同一套数据**：移动端不维护数据副本；
2. **同一套逻辑**：时间轴、检索、筛选、分享编解码来自 `packages/shared`；
3. **一致的交互**：拖动/播放/倍速、路线生长、节点显隐/高亮、详情、筛选、搜索、分享；
4. **可交付**：Android APK/AAB、iOS IPA（或模拟器包）；
5. **合规**：高德 SDK 隐私同意、Key/证书不入库。

移动端不是 Web 的 WebView 套壳，而是原生地图 + RN UI。

## 2. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│ packages/shared（与 Web 完全相同）                            │
│  data/loader  timeline/*  search/*  filters  share/state     │
│  geo/coordinate  i18n  schema                                │
└───────────────┬─────────────────────────────────────────────┘
                │ workspace:*
                ▼
┌─────────────────────────────────────────────────────────────┐
│ apps/mobile（Expo SDK 58 / RN 0.88 / 新架构）                  │
│  navigation   React Navigation native-stack                  │
│  screens      Gallery / Atlas / Search                       │
│  map          expo-gaode-map（MapView / Polyline / Marker）    │
│  timeline     PanResponder + requestAnimationFrame           │
│  detail       Modal 底部抽屉 + react-native-markdown-display  │
│  store        Zustand（移动端独立 UI 状态）                    │
└───────────────┬─────────────────────────────────────────────┘
                │ HTTP（同一套静态数据）
                ▼
        https://<host>/data/atlases
```

**关键边界**：

- shared 不依赖 React / RN / DOM；移动端只做渲染与手势。
- 数据只从远端 `/data/atlases` 读取；移动端不复制 JSON。
- 高德坐标转换仍在 shared：数据 WGS84 → 渲染 GCJ-02。

## 4. 数据与状态

### 4.1 数据地址

```ts
// apps/mobile/src/data/client.ts
import { loadAtlas, loadAtlasIndex } from '@atlas/shared';

const BASE = (process.env.EXPO_PUBLIC_DATA_BASE_URL ?? 'http://10.0.2.2:5180/data/atlases')
  .replace(/\/+$/, '');

export const fetchAtlasIndex = () => loadAtlasIndex(`${BASE}/index.json`);
export const fetchAtlas = (id: string) => loadAtlas(`${BASE}/${id}/manifest.json`);
```

环境差异：

| 环境 | 地址 |
| --- | --- |
| Android 模拟器 | `http://10.0.2.2:5180/data/atlases` |
| iOS 模拟器 | `http://127.0.0.1:5180/data/atlases` |
| 真机 | `http://<开发机 LAN IP>:5180/data/atlases` |
| 生产 | `https://<部署域名>/data/atlases` |

> M4 不打包数据副本；离线需求在 M5 评估。

### 4.2 移动端 store

与 Web 类似，但只保留移动端需要的状态：

```ts
interface MobileAtlasState {
  index: AtlasSummary[] | null;
  dataset: AtlasDataset | null;
  loading: boolean;
  error: string | null;

  timeline: Timeline | null;
  currentTime: AtlasTime;
  playing: boolean;
  speed: 0.5 | 1 | 2 | 4;
  selectedEventId: string | null;

  activeEntityIds: Set<string>;
  filters: AtlasFilters;

  mapView: ShareView | null;
  bubbleEventId: string | null;

  loadIndex(): Promise<void>;
  loadAtlas(id: string): Promise<void>;
  // 时间轴/筛选/选择 actions 与 Web 对齐
}
```

- 时间轴、筛选、搜索、分享编解码全部调用 shared；
- store 不跨端共享（UI 状态），但行为一致。

## 6. 地图实现

### 6.1 组件

```tsx
import { MapView, Marker, Polyline } from 'expo-gaode-map';

<MapView
  style={StyleSheet.absoluteFill}
  initialCameraPosition={{ target: { latitude, longitude }, zoom }}
  mapType="standard"
  onLoad={...}
  onPress={...}
>
  {routes.map((route) => (
    <Polyline
      key={route.id}
      points={route.points.map(toGcj)}
      width={4}
      color={route.color}
    />
  ))}
  {events.map((event) => (
    <Marker
      key={event.id}
      position={toGcj(event.location)}
      onPress={() => selectEvent(event.id)}
    />
  ))}
</MapView>
```

> 具体 prop 名称以 T1 PoC 的 `expo-gaode-map` 版本为准；本方案只约定行为。

### 6.2 路线生长

- shared `partialPathAt(geometry, progress)` 返回 WGS84 截断路径；
- 渲染前 `wgs84ToGcj02`；
- 时间变化时节流 30fps 更新 `points`；
- 分段独立，不跨段连线。

### 6.3 标记与高亮

- Marker 按 `event.date <= currentTime` 显隐；
- 当前事件：放大/脉冲（RN `Animated` 或样式切换）；
- 事件密集时 M4 暂不聚合，M5 评估。

## 7. 时间轴

- 轨道宽度 `onLayout` 获取；
- `generateTicks(timeline, width, { minLabelPx: 56 })`；
- `PanResponder` 处理拖动：
  - 开始拖动 `pause()`；
  - 位置 → ratio → `ratioToTime`；
  - 结束保持暂停。
- 播放：`requestAnimationFrame` + `advancePlayback`，节流 30fps；
- 倍速按钮 0.5/1/2/4；
- 日期跳转：`@react-native-community/datetimepicker` 或简单文本输入（M4 先用文本 `YYYY-MM-DD`，减少依赖）。
- 无障碍：`accessibilityRole="adjustable"`、`accessibilityValue`、按钮 `accessibilityLabel`。

## 8. 详情、搜索、筛选、分享

### 8.1 详情抽屉

- `Modal` + `presentationStyle="pageSheet"`（iOS）/ 全屏（Android）；
- Markdown：`react-native-markdown-display`，链接用 `Linking.openURL`；
- 图片：`Image` + 懒加载占位；
- 来源、关联事件；
- 分享按钮：`Share.share({ message: url })`。

### 8.2 搜索

- 复用 shared 索引与查询；
- `FlatList` 渲染结果；
- 关键词高亮用简单分段 Text；
- 结果点击导航到 Atlas。

### 8.3 筛选

- 实体、类型、时间段；
- 与时间轴叠加；
- 移动端用底部 `Modal` 展示筛选面板。

### 8.4 分享与深链

- URL：`atlas://atlas/<id>?t=...&event=...&view=...`（开发）；
- 生产可换 Universal Links / App Links（M5）；
- `Linking.addEventListener('url', ...)` 解析并导航；
- 系统分享：`Share.share`。

## 9. 合规与权限

1. 首次启动展示隐私说明，用户同意后再渲染地图（SDK 初始化）。
2. 隐私政策列出高德 SDK：公司、SDK 名称、信息类型、目的、官方链接。
3. M4 不申请定位权限；如后续加「我的位置」，再补 `NSLocationWhenInUseUsageDescription` / Android 定位权限。
4. Key/证书/keystore 不入库；Android Key 绑定包名 + SHA1，iOS 绑定 Bundle ID。

## 10. 构建与签名

### 10.1 Android

```bash
cd apps/mobile
npx expo prebuild --platform android
cd android
./gradlew assembleRelease   # APK
./gradlew bundleRelease     # AAB
```

签名配置（仓库外）：

```properties
# ~/.openchronicle/atlas-keystore.properties（600）
storeFile=/Users/.../.openchronicle/atlas-release.keystore
storePassword=***
keyAlias=atlas
keyPassword=***
```

- `android/app/build.gradle` 的 `signingConfigs.release` 读取上述属性；
- `versionCode` 每次发布递增；
- 产物：`android/app/build/outputs/apk/release/app-release.apk`。

### 10.2 iOS

```bash
cd apps/mobile
npx expo prebuild --platform ios
open ios/*.xcworkspace
# Xcode: 选择 Team、Archive、Export IPA
```

- Bundle ID：`com.openchronicle.atlas`；
- 无 Apple 账号时：先 `npx expo run:ios` 模拟器构建，交付未签名 archive 与说明；
- 有账号时：Xcode 自动签名 + `xcodebuild -exportArchive` 导出 IPA。

### 10.3 EAS 备选

```bash
eas build -p android --profile preview
eas build -p ios --profile preview
```

用于本地环境阻塞时的备选；需 Expo 账号与凭证。

## 11. 三端一致性矩阵

| 能力 | Web | Android | iOS |
| --- | --- | --- | --- |
| 数据来源 | `/data/atlases` | 同一 URL | 同一 URL |
| 时间范围/刻度 | manifest 动态 | 同 shared | 同 shared |
| 拖动/播放/倍速 | ✅ | 待验收 | 待验收 |
| 路线生长 | Polyline setPath | 同 shared 截断 | 同 shared 截断 |
| 节点显隐/高亮 | ✅ | 待验收 | 待验收 |
| 详情 | 右侧面板 | 底部抽屉 | 底部抽屉 |
| 筛选 | 左侧栏/浮层 | 底部抽屉 | 底部抽屉 |
| 搜索 | `/search` | Search 页 | Search 页 |
| 分享 | Web Share/复制 | 系统分享 | 系统分享 |
| 深链 | URL query | `atlas://` | `atlas://` |

```tsx
const panResponder = useMemo(
  () =>
    PanResponder.create({
      onStartShouldSetPanResponder: () => true,
      onPanResponderGrant: (event) => {
        pause();
        seekFromX(event.nativeEvent.locationX);
      },
      onPanResponderMove: (event) => seekFromX(event.nativeEvent.locationX),
      onPanResponderRelease: () => {},
    }),
  [pause, seekFromX],
);
```
