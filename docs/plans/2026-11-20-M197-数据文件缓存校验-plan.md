## 1. 问题

发布 1.0.148 后，线上 `manifest.json` 与 `events.json` 已是新内容，但浏览器里仍显示旧图例：

- 中国政府「32 个事件」，且没有「国际组织与多边会议」；
- 用新 origin（`100.65.110.80:8081`）打开则是新内容。

检查响应头：

```
Cache-Control: public, max-age=3600
```

`fetchAtlas` 只给 `index.json`、`search-index.json` 加了 `?v=__APP_VERSION__`，
atlas 的 `manifest.json`、`events.json`、`routes/*.geojson` 没有版本参数，也没有
`cache` 选项，因此发布后最多 1 小时仍可能读到旧数据。

## 2. 修复

在 `HttpDataSource.readText` 的 `fetch` 中加 `{ cache: 'no-cache' }`：

- 每次都向服务器校验，内容未变返回 304，不重复下载；
- 内容变了立即拿到新数据；
- 比分发 `?v=` 简单，且对 manifest 递归解析出的 events / routes 一并生效。

## 3. 验收标准（DoD）

## 4. 回滚方案

- 代码回滚：`git revert <提交>` 后重新 `pnpm release`；
- 线上回滚：`ssh quizgo 'sudo rsync -a --delete /srv/atlas.prev/ /srv/atlas/'`。
