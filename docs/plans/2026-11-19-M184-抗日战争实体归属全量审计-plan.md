## 1. 缘起

用户在修正天羽声明、日本投降的归属后，要求「全检查一下，看还有没有错漏的」。
本轮对 `anti-japanese-war` 全部 314 个事件、219 段路线做实体归属审计。

## 2. 方法与结果

审计方法：

1. 按行为主体检查 `entityIds`；
2. 同日、同地（<20 km）事件两两比对，找重复；
3. 检查实体名与路线/事件层级（战区 / 集团军 / 军 / 师）；
4. 跑 `validate:data`、`check:routes`、`check:heads`。

发现问题 5 类，均已修正：

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | 藏本英明事件主体是日本 | 改为 `japanese-invasion` |
| 2 | 中国军队攻克畹町主体是中国远征军 | 加 `kmt-group-armies`，补龙陵—畹町线 |
| 3 | 第1/6/4战区路线与事件放在「集团军」层 | 移到 `kmt-forces` |
| 4 | 「桂柳反攻」与「第4战区桂柳反攻」重复 | 删除后者，合并说明 |
| 5 | 「日军进攻河南」与「日军进攻豫中」重复 | 删除前者 |
