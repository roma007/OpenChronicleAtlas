## 1. 背景

搜索页目前调用 `loadSearchData()` 加载全部专题的 manifest、routes、events，再在浏览器/移动端构建索引。专题增多后网络与计算成本线性上升。

## 2. 目标

1. 构建期生成 `data/atlases/search-index.json`；
2. 搜索页只加载该索引；
3. 索引包含中英标题、事件字段与拼音；
4. Web / 移动端行为一致；
5. 构建流程自动生成索引。

## 3. 范围

- `packages/shared/src/search/*`；
- `packages/shared/src/data/loader.ts`；
- `scripts/build-search-index.ts`；
- Web / 移动端 data client、store、搜索页；
- `vercel.json`、`package.json`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | 索引类型与加载器 | shared |
| S3 | 构建脚本 | `search-index.json` |
| S4 | Web 搜索页 | 直接读索引 |
| S5 | 移动端搜索页 | 直接读索引 |
| S6 | 构建集成、测试、部署、tag | `v0.25.0-m25` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 索引文件过大 | 首屏变慢 | 只保留搜索必需字段；压缩 JSON |
| 数据更新后索引过期 | 搜索结果旧 | 构建前强制重新生成 |
| 中英标题变化 | 英文界面显示中文 | `atlasTitle` 改为多语言对象 |
| 拼音运行时移除 | 拼音搜索失效 | 构建期写入拼音字段 |

## 6. 验收

- 索引 4 专题 / 103 事件；
- Web / 移动端只请求索引；
- 中英文、拼音、类型、时间段搜索通过；
- `pnpm build:search-index` 可重复执行；
- lint / typecheck / test / build 通过；
- 双仓 tag 一致。
