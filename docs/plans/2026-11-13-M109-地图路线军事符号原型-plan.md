- **日期**：2026-11-13
- **里程碑**：M109（UI / 数据契约原型，版本待发布窗口统一升级）
- **负责人**：AI 开发助手
- **关联文档**：
  - [M109 方案](2026-11-13-M109-地图路线军事符号原型-design.md)
  - [M108 方案](2026-11-13-M108-长征国民党军粤军西北军陕军-design.md)

## 1. 目标

把「两点一线」的路线升级为可读的军事地图语言：路线带番号，封锁线有齿线与据点，图例能解释符号；先以 long-march 国民党军路线为原型，不影响其他专题。

## 2. 范围

### 2.1 包含

- route properties 新增可选 `label` / `labelPoint`，同步 schema 与类型；
- 21 段长征国民党军路线补番号标签；
- 番号牌渲染：缩放 ≥ 6、进度 ≥ 45% 显示，支持中英文；
- 带 label 的防御线：细实线 + 固定像素齿线 + 首尾据点；
- 国民党军路线层级：线宽减一档、透明度降低；
- 图例增加齿线样例与说明，仅在存在带 label 的防御线时显示；
- M109 方案、计划、对话档案与 CHANGELOG。

### 2.2 不包含

- 路线几何补点、沿真实道路/河谷重绘；
- 进攻线流动箭头、播放线头光点；
- 面状封锁带、地形晕渲；
- 移动端番号牌与齿线；
- 番号牌碰撞避让；
- 版本号、部署与 tag。

## 3. 前置条件与依赖

- M108 的 21 段国民党军路线已在工作区；
- route schema 为 `passthrough`，可安全新增可选字段；
- 数据唯一真源为 `data/atlases/**`；
- 沿用 `AGENTS.md` 数据铁律。

## 5. 实施步骤

1. 在 `AtlasRouteProperties` 与 `routeFeatureSchema` 增加 `label` / `labelPoint`；
2. 用脚本给 21 段 KMT 路线补中英文短标签；
3. 在 `MapCanvas` 中为带 label 的路线创建 `AMap.Text` 番号牌；
4. 为带 label 的防御线创建齿线 Marker（CSS 旋转）与首尾据点 Marker；
5. 时间轴 effect 中按进度控制齿线、据点、番号牌显隐；
6. 图例对「防御 / 驻守」使用齿线样例并增加说明；
7. 执行数据管线与全部检查，浏览器验证 long-march 与 anti-japanese-war。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 齿线按公里绘制放大后变「梯子」 | 视觉粗糙 | 高 | 改为固定像素 Marker + CSS 旋转 |
| 所有防御线都加齿线 | 其他专题 marker 激增 | 中 | 以 `label` 作为 opt-in 开关 |
| 番号牌总览时重叠 | 地图变乱 | 高 | 缩放 ≥ 6、进度 ≥ 45% 才显示 |
| 标签语言切换不更新 | 中英文混排 | 中 | 路线重建 effect 依赖 locale |
| 图例符号与地图不一致 | 读者误解 | 中 | 只对带 label 的防御线显示齿线样例 |
