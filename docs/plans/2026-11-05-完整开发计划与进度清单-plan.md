## 五、更新规则

1. 本清单是**唯一总进度视图**；里程碑 plan 只记录单轮细节。
2. 完成一项后，立即把 `[ ]` 改为 `[x]`，并补充版本、提交或链接。
3. 新增待办时，写明所属分组（内容 / 发布 / 平台 / 文档）。
4. 外部阻塞项保持 `[ ]`，在条目后注明「阻塞：账号 / 设备 / 域名 / 许可」。
5. 每次里程碑收尾提交中，必须同时更新本清单、CHANGELOG 与发布说明。
