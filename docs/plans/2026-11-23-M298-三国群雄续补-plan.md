## 1. 背景

M297 已加袁绍、公孙瓒、刘表、公孙氏（辽东）四个群雄实体。用户要求「也画」，
把袁术、吕布、刘璋、凉州军阀，以及官渡北线一起补上。

## 2. 目标

1. 新增 `yuan-shu`、`lv-bu`、`liu-zhang`、`liangzhou-warlords` 四个实体；
2. 补袁术称帝与败亡、吕布夺徐州与败亡、刘璋益州、马超韩遂起兵；
3. 补袁绍白马延津、仓亭、去世，完成官渡北线；
4. 同战役按双方分事件，不串主体；
5. 校验全绿，生成物与数据同一次提交。
