# M278 日本登陆航线与原子弹空袭航线（设计）

- **日期**：2026-11-23
- **专题**：`anti-japanese-war`
- **目标**：
  1. 补日本在中国沿海及东南亚的登陆／海上输送航线，给已有的登陆事件配上线路；
  2. 补美国自提尼安岛对广岛、长崎的原子弹空袭航线，并补齐长崎节点。

## 4. 数据规则

1. `naval` 航线必须走水面，沿每 2km 采样，连续陆地不得超过 25km；如确有港内／河口段，登记 `land-legs.allow.json` 并写原因。
2. 登陆航线终点取登陆点，不取内陆城市；例如海防登陆不画到河内，缅甸不画成仰光登陆。
3. 原子弹航线是空袭，不是海路；用 `other`，不参与 `check:land`。
4. 不把东南亚战场写成中国战场：事件仍挂 `japanese-invasion`，说明写清「登陆东南亚，中国远征军随后在缅甸与之作战」。
5. 同一行动多路登陆时，可以分成多段（如马来亚的哥打巴鲁、宋卡两段），共用日期，不合并成一条直线。
