## 2. Android

### 2.1 主 manifest

`apps/mobile/android/app/src/main/AndroidManifest.xml`：

- 删除 `<uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW"/>`；
- `android:usesCleartextTraffic="false"`。

### 2.2 debug manifest

`apps/mobile/android/app/src/debug/AndroidManifest.xml` 已存在：

- 保留 `SYSTEM_ALERT_WINDOW`；
- `usesCleartextTraffic="true"`。

### 2.3 app.config.ts

- `expo-build-properties` 改为 `usesCleartextTraffic: false`；
- `blockedPermissions` 增加 `android.permission.SYSTEM_ALERT_WINDOW`。

> debug manifest 会覆盖主 manifest 的明文流量设置，保证本地 `10.0.2.2` 调试可用。

## 3. 版本一致性脚本

新增 `scripts/check-versions.ts`：

- 读取根 `package.json` 版本作为基准；
- 检查：
  - `apps/web/package.json`
  - `apps/mobile/package.json`
  - `packages/shared/package.json`
  - `apps/mobile/app.json` 的 `expo.version`
  - `apps/mobile/app.config.ts` 的 `version`
  - `apps/mobile/android/app/build.gradle` 的 `versionName` / `versionCode`
  - `apps/mobile/ios/app/Info.plist` 的 `CFBundleShortVersionString` / `CFBundleVersion`
- 版本不一致时退出码 1；
- 文件不存在时跳过并给出 warning。

`package.json` 增加：

```json
"check:versions": "tsx scripts/check-versions.ts"
```
