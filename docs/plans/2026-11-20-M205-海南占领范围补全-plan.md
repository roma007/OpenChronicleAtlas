# M205 海南占领范围补全计划

- 日期：2026-11-20
- 专题：`anti-japanese-war`
- 触发：用户追问「日本在海南只去到海口、琼海、昌江、东方、三亚这些地方吗？」
- 结论：不是。日军占领的是环岛沿海县城、港口和交通线；现有图层只标了海口、嘉积（琼海）、石碌（昌江）、八所（东方）、三亚/榆林五个关键点，容易把占领范围读窄。中部白沙县城和五指山周围山区未被长期占领，是琼崖抗日根据地。

## 1. 史实范围

据海南史志网《琼崖日伪政权》与人民网《日军侵入海南岛始末》：

- 1939-02-10 海口、府城；
- 1939-02-14 三亚、榆林；02-15 崖县县城；
- 1939-02-20 定安；02-22 文昌；
- 1939-04-14 澄迈金江；04-15 嘉积；04-18 临高、儋县新州；04-28 陵水；
- 1939-05-11 屯昌；06-27 感恩；07-18 昌江（新街、墩头、八所、北黎）；08-13 万宁；
- 1940-03-15 保亭、乐东；同日占石碌。
- 至 1940-03，全岛除白沙县城和五指山及其周围山区外，均被日军占领；日军在环岛沿海和内陆山区设 360 多个军事据点，在 14 县设 195 个维持会/分会。

## 3. 口径

- 日期以海南史志网《琼崖日伪政权》为主，人民网《日军侵入海南岛始末》校核；有异说的在正文注明：
  - 定安：02-20 进攻、02-22 占县城，有 02-20 说；
  - 文昌：02-21/02-22 有异说；
  - 临高：04-18 占县城，另有 09-25 新盈港登陆后占临城说；
  - 保亭：1940-03-15 与 1940-07-16 有异说。
- 不写“日军占领全岛”这种绝对表述；写明“除白沙县城和五指山周围山区外”。
- 360 多个据点、195 个维持会、14 县等数字来自海南史志网综述，正文标“据……资料/待页码级核对”。
