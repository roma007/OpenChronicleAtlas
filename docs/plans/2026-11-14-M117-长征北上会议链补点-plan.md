## 1. 背景

M116 补齐了遵义会议后的扎西、苟坝会议，但「懋功会师 → 北上 → 俄界」仍缺两河口、芦花、沙窝、巴西、俄界五次关键会议；同时毛儿盖会议坐标偏离毛儿盖镇约 56 km，包座战役只挂中央红军。

本轮补齐北上会议链，并修正毛儿盖、包座两个点位。

## 2. 目标

1. 新增两河口、芦花、沙窝、巴西、俄界 5 个会议事件；
2. 修正毛儿盖会议、包座战役坐标与实体；
3. 修正懋功—毛儿盖、毛儿盖—巴西、巴西—腊子口 3 段路线；
4. 重新生成搜索索引与移动端内置数据映射；
5. 不改版本号、不部署、不打 tag。
