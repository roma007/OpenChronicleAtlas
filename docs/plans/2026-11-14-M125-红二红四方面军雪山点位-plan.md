## 1. 背景

M124 只覆盖中央红军五座雪山。红四方面军西进康北翻越的党岭山、红二与红六军团北上翻越的雅哈雪山、大、小雪山、沙鲁里山、藏巴拉山都没有点位；红六军团 1936 年北上路线也不存在。

## 2. 目标

1. 新增 5 个雪山垭口事件，覆盖红二、红四方面军；
2. 修正红四方面军、红二方面军路线，补齐红六军团 1936 年北上路线；
3. 更新专题描述与 `updatedAt`，重新生成搜索索引与移动端内置数据映射；
4. 提交并发布到服务器（按提交铁律）。

## 3. 范围

### 3.1 包含

- `data/atlases/long-march/events/events.json`
- `data/atlases/long-march/routes/red-2-and-4.geojson`
- `data/atlases/long-march/routes/red-6-army.geojson`
- `data/atlases/long-march/manifest.json`
- `data/atlases/search-index.json`、`data/atlases/index.json`
- `apps/mobile/src/generated/atlasData.ts`
- 本轮 docs 与 CHANGELOG

### 3.2 不包含

- 其他专题；
- schema 变更；
- UI 渲染逻辑；
- 红四方面军瞻化奔袭四座雪山、红二军团得荣—巴塘段各垭口的逐点落位；
- 红六军团 1935 年 11 月至 1936 年 4 月湘黔滇段路线；
- 版本号手动修改。

## 5. 实施步骤

1. 记录本轮需求与点位口径；
2. 按党岭山、雅哈雪山、大、小雪山、沙鲁里山、藏巴拉山补事件；
3. 红四方面军路线补夏羌涅阿垭口；红二方面军路线改为经得荣、巴塘、白玉；
4. 新增红六军团 1936 年北上路线；
5. 运行 `pnpm validate:data`、`pnpm check:routes --atlas long-march`；
6. 运行 `pnpm build:search-index`、`pnpm build:mobile-data`；
7. 运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`；
8. 更新 CHANGELOG，提交（钩子升版）、tag、推送；
9. 执行 `pnpm release`，更新服务器并登记。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 垭口无精确坐标 | 点位偏差 | 高 | 用垭口代表点，标 `approx`，描述注明待实测 |
| 雅哈海拔、牺牲者记载冲突 | 表述失实 | 高 | 不取单一海拔、不写牺牲者姓名 |
| 红六军团新路线覆盖不全 | 路线断档 | 高 | 描述注明 1935-11—1936-04 段待补 |
| 新路线导致既有事件偏离 | 路线校验失败 | 中 | 跑 `check:routes`，必要时补控制点 |
| 发布被 /srv/ops 请求阻塞 | 无法发布 | 低 | 先处理或显式 `--ack-open` |
