## 1. 目标（Goal）

用一个**完全独立的数据包**接入第二个专题，证明平台「专题可插拔」；
补齐上架所需的图标、启动图、隐私政策、权限说明与商店元数据；
交付 Web 部署配置，并在双仓打 `v0.5.0-m5`。

## 2. 范围（Scope）

### 2.1 包含

1. **第二专题**：郑和下西洋（1405—1433）
   - manifest、6 条航线、24 个事件、3 个实体、封面、史料来源；
   - 更新 `data/atlases/index.json`；
   - `pnpm validate:data` 通过；不改加载/渲染代码。
2. **多专题验证**
   - 首页两张卡片；
   - 跨专题搜索、专题筛选；
   - 时间轴/路线/详情在第二专题正常。
3. **上架素材**
   - 应用图标 1024×1024、Android 自适应图标、启动图；
   - Web favicon / PWA 图标（可选）。
4. **隐私与合规**
   - Web `/privacy` 页面：高德 SDK、收集信息、用途、权限、联系方式；
   - 移动端隐私同意页链接到该页面；
   - Android/iOS 权限说明（不申请定位）；
   - 高德 SDK 合规清单。
5. **部署**
   - `vercel.json`、Cloudflare Pages 备选说明；
   - 环境变量清单（`VITE_AMAP_*`、`EXPO_PUBLIC_*`）；
   - 构建产物验证（`dist/data` 包含两个专题）。
6. **商店元数据**
   - 应用名称/副标题/描述/关键词/分类/年龄分级；
   - 隐私政策 URL、支持 URL；
   - 截图清单与占位。
7. **发布**
   - CHANGELOG、release、双仓 tag `v0.5.0-m5`。

### 2.2 不包含（Out of Scope）

- 实际提交 App Store / 应用商店（需账号、审核、可能需高德商用许可）。
- iOS 真机 IPA（需 Apple 账号/真机，M4 遗留）。
- 后端服务、账号系统、评论/收藏。
- 离线数据打包。
- 史料最终校订（持续任务）。

## 5. 实施步骤

1. **确认方案**：用户确认 plan/design/ADR-0008 与 Q1–Q5。
2. **T1 数据**：先写 manifest/路线/事件，`validate:data` 0 error。
3. **T2 验证**：Web 首页/搜索/专题页回归；移动端搜索跨专题。
4. **T3 合规**：隐私页 + 移动端链接；权限说明。
5. **T4 素材**：图标/启动图，更新 Expo/Web 配置。
6. **T5 部署**：Vercel 配置、构建、`dist/data` 校验；Cloudflare 备选。
7. **T6 商店**：元数据文档、截图清单。
8. **T7 构建**：Web + Android APK 重建（图标/数据）。
9. **T8 归档**：CHANGELOG、release、双推、tag `v0.5.0-m5`。

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 郑和史料日期/航线争议 | 数据可信度 | 中 | 标注「初稿待校订」；每条事件附 sources；航线示意 |
| 第二专题数据触发 schema 问题 | 接入失败 | 低 | `validate:data` + 单测；不改代码即验证可插拔 |
| 无部署账号/域名 | 无法真正上线 | 高 | 交付配置与本地构建验证；用户提供账号后执行 |
| 图标/启动图不符合商店规范 | 上架被拒 | 中 | 按 1024/自适应/无透明通道规范生成；保留源文件 |
| 高德商用许可未购买 | 上架风险 | 中 | 发布清单标注；上线前评估 |
| iOS 仍阻塞 | 三端不完整 | 高 | M5 记录遗留；真机/IPA 待账号 |
| 商店审核隐私政策不完整 | 被拒 | 中 | 按高德 SDK 合规清单逐项核对 |

## 7. 验收标准（DoD）

- [ ] `pnpm validate:data` 两个专题均 0 error。
- [ ] Web 首页显示两张专题卡片；搜索可跨专题命中；第二专题地图/时间轴/详情正常。
- [ ] `/privacy` 页面可访问，内容包含高德 SDK 披露与权限说明。
- [ ] 应用图标/启动图配置生效（Web favicon、Android 自适应、iOS 图标）。
- [ ] `vercel.json` 构建通过，`dist/data` 包含两个专题。
- [ ] 商店元数据与截图清单文档完成。
- [ ] Android APK 可重建并安装（含新图标）。
- [ ] 文档齐全；双仓 HEAD 一致；tag `v0.5.0-m5`。
- [ ] iOS 真机/IPA 与商店提交状态在发布说明中明确标注。

## 8. 回滚方案

- 第二专题为独立目录；删除并恢复 index 即可回滚。
- 图标/隐私页为新增资源；回滚不影响数据契约。
- 部署配置不影响本地构建。
