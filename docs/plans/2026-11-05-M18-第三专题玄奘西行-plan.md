# M18 第三专题「玄奘西行」— 计划

- **日期**：2026-11-05
- **里程碑**：M18（v0.18.0-m18）
- **状态**：已完成
- **关联**：
  - [对话档案](../conversations/2026-11-05-M18启动与第三专题玄奘西行方案.md)
  - [M18 方案](2026-11-05-M18-第三专题玄奘西行-design.md)

## 1. 背景

平台已接入长征、郑和两个专题。新增第三个专题是验证「专题可插拔」的最直接方式：只新增数据包，不改平台代码。

## 2. 目标

1. 新增 `data/atlases/xuanzang` 数据包；
2. 20 个事件，629—645 年；
3. 19 段路线，按事件日期切段；
4. 中英双语；
5. 封面 1200×675 JPEG；
6. 首页自动出现第三张专题卡片；
7. 事件-路线抽查 0km。

## 3. 范围

### 3.1 包含

- manifest、routes、events、cover；
- 专题索引更新；
- 数据校验与抽查；
- 版本、CHANGELOG、发布说明、tag。

### 3.2 不包含

- 平台代码修改；
- 新实体类型；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | manifest + 19 段路线 | `data/atlases/xuanzang` |
| S3 | 20 个事件与来源 | `events.json` |
| S4 | 封面生成 | `assets/cover.jpg` |
| S5 | 索引、校验、抽查 | `index.json` |
| S6 | 构建、部署、文档、tag | `v0.18.0-m18` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 事件日期为约数 | 数据准确性 | 标注「示意初稿，待史料校订」 |
| 路线为简化 | 与真实路线有差异 | 保留简化声明 |
| 单实体专题较简单 | 验证力度有限 | 先验证数据包接入，多实体留后续 |
| 封面素材 | 需要 JPEG | 用 SVG 渲染后转 JPEG |

## 6. 验收标准

- 首页显示三个专题；
- 新专题时间轴、路线、事件、详情正常；
- 20 个事件中英字段完整；
- 事件-路线抽查 0km；
- `pnpm validate:data` 通过；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.18.0-m18` 一致。
