## 1. 背景

M41 已为 127 段路线补 `segmentType`，但地图仍统一使用实体颜色的实线，用户无法从线型区分进攻、撤退、防御与反击。

## 2. 目标

1. 共享样式函数与中英文标签；
2. Web 地图按类型设置线宽、透明度与虚实；
3. Web 图例增加「路线样式」；
4. 移动端地图同步线宽/虚线；
5. 移动端筛选面板增加样式图例。

## 3. 范围

- `packages/shared/src/route-style.ts`（新建）；
- `packages/shared/src/index.ts`；
- `packages/shared/src/i18n/messages.ts`；
- `apps/web/src/components/map/MapCanvas.tsx`；
- `apps/web/src/components/layout/Legend.tsx`；
- `apps/mobile/src/components/map/AtlasMap.tsx`；
- `apps/mobile/src/components/filter/FilterSheet.tsx`；
- 文档、版本、tag。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 移动端虚线仅 Android 支持 | iOS 线型差异 | 以线宽为主，虚线作为增强 |
| 线型过多导致视觉噪声 | 可读性 | 只保留 4–5 种主要类型 |
| 图例过长 | 布局 | 只列当前专题存在的类型 |

## 6. 验收

- 各类型线型可区分；
- 图例与地图一致；
- 中英文标签完整；
- 类型检查与构建通过；
- 双仓 tag 一致。
