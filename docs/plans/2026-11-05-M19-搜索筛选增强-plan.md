# M19 搜索筛选增强 — 计划

- **日期**：2026-11-05
- **里程碑**：M19（v0.19.0-m19）
- **状态**：已完成
- **关联**：
  - [对话档案](../conversations/2026-11-05-M19启动与搜索筛选增强方案.md)
  - [M19 方案](2026-11-05-M19-搜索筛选增强-design.md)

## 1. 背景

搜索页目前只有关键词与专题筛选。`searchEvents` 已支持 `category/from/to`，但 UI 没有暴露，用户无法快速缩小结果。

## 2. 目标

1. 按事件类型筛选；
2. 按时间段筛选；
3. 类型与时间段可叠加；
4. 支持重置；
5. 结果计数与空状态更新；
6. 中英文案。

## 3. 范围

### 3.1 包含

- Web 搜索页类型 chips + 日期输入 + 重置；
- 移动端搜索页类型 chips + 日期输入 + 重置；
- 文案、测试、版本、发布说明、tag。

### 3.2 不包含

- 实体筛选；
- 分词/纠错；
- 搜索结果分页；
- APK/IPA 打包。

## 4. 实施步骤

| 步骤 | 内容 | 产出 |
| --- | --- | --- |
| S1 | 对话、plan/design 留档 | docs |
| S2 | Web 筛选 UI 与查询参数 | `SearchPage.tsx` |
| S3 | 移动端筛选 UI 与查询参数 | `SearchScreen.tsx` |
| S4 | 文案与重置 | messages |
| S5 | 测试、构建、部署、tag | `v0.19.0-m19` |

## 5. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 类型跨专题重复 | 筛选结果混乱 | 使用原始 category 作为值 |
| 日期非法 | 搜索报错 | try/catch 忽略 |
| 移动端空间不足 | 布局拥挤 | chips 横向滚动 |
| 重置误清关键词 | 用户困惑 | 只重置筛选 |

## 6. 验收标准

- 搜索页可按类型过滤；
- 可按时间段过滤；
- 类型与时间段可叠加；
- 重置后恢复全部结果；
- 中英文案正确；
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、Web 构建通过；
- 双仓 `main` 与 tag `v0.19.0-m19` 一致。
