## 1. 目标

把郑和专题每一次下西洋的线路事件补到「可以看出这一趟走了哪条线、做了什么」的密度：
七趟航次由当前的 3—15 个事件，普遍补到 10—20 个，且每个事件都落在该航次航线的停靠港上，
事件密度与航线走向相互印证。

合计 41 个事件；校验基线为 11 个专题 / 912 事件 / 641 段路线。

### 2.1 硬约束

1. `pnpm check:routes` 默认 30km：每个事件的坐标必须落在所属实体、且日期区间覆盖该事件的航线上；
2. `pnpm check:heads`：航次首尾仍在太仓，不受影响；
3. 事件日期必须落在该航次 `startDate`—`endDate` 之间（否则需 `extensions.routeEvent = false`）；
4. 非航线事件（如南京献俘、北京停罢）沿用 `extensions.routeEvent = false`；
5. 事件密度会改变时间轴标记与搜索索引，但不改变 `timeRange` 与进度条范围逻辑。

## 6. 各航次补事件要点

### 第一次（1405—1407）

长乐太平港候风 → 占城 → 满剌加册封 → 旧港招谕陈祖义 → 爪哇误杀官军 → 苏门答剌/南巫里 →
锡兰山 → 加异勒 → 小葛兰 → 柯枝 → 古里开市与立碑 → 旧港擒陈祖义 → 返航。

### 第二次（1408—1409）

长乐 → 占城 → 暹罗调解 → 满剌加 → 苏门答剌 → 南巫里 → 锡兰山布施佛寺（三体碑） →
加异勒 → 小葛兰 → 柯枝 → 古里 → 返航。

### 第三次（1410—1411）

长乐 → 占城 → 满剌加设官厂 → 苏门答剌 → 南巫里 → 初至锡兰山（察觉谋害，离去）→
加异勒 → 柯枝 → 古里 → 回程再至锡兰山，突袭王城擒亚烈苦奈儿 → 返航 →
南京献俘（`routeEvent: false`）。

### 第四次（1413—1415）

长乐 → 占城赐冠带 → 满剌加 → 苏门答剌 → 锡兰山 → 溜山 → 古里 → 甘巴里 → 阿拨把丹 →
忽鲁谟斯 → 祖法儿 → 阿丹 → 木骨都束 → 卜剌哇 → 竹步 → 麻林地 →
归程再至苏门答剌平苏干剌 → 返航 → 北京献俘、麻林献麒麟（`routeEvent: false`）。

### 第五次（1417—1419）

长乐 → 占城 → 满剌加 → 苏门答剌 → 锡兰山 → 柯枝封王（镇国山碑）→ 古里 → 忽鲁谟斯 →
阿丹 → 木骨都束 → 卜剌哇 → 麻林地 → 返航 → 诸国贡麒麟（`routeEvent: false`）。

### 第六次（1421—1422）

长乐 → 占城 → 满剌加 → 苏门答剌 → 分䑸访榜葛剌 → 锡兰山 → 古里 → 忽鲁谟斯 →
祖法儿开市 → 阿丹 → 木骨都束 → 卜剌哇 → 竹步 → 麻林地 → 返航。

### 第七次（1431—1433）

长乐驻泊 → 长乐天妃宫碑 → 敕谕暹罗（`routeEvent: false`）→ 占城 → 旧港 → 爪哇 →
满剌加 → 苏门答剌 → 锡兰山 → 古里分遣 → 忽鲁谟斯 → 阿丹 → 天方 → 东非 →
归程卒于古里 → 返航。

## 7. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
| --- | --- | --- | --- |
| 二、三次下西洋的锡兰事件归属存在争议 | 数据被质疑 | 高 | 采用主流说法（第二次布施、第三次之战），正文写清争议，来源并列 |
| 具体日份无确切记载 | 时间轴精度受质疑 | 高 | 统一用「YYYY-MM-DD 为研究推定」，来源备注说明 |
| 新增港口导致事件偏离航线 | `check:routes` 失败 | 中 | 同步补入航线顶点，事件坐标与顶点一致 |
| 事件变多使时间轴标记过密 | 可读性下降 | 中 | 只在停靠港布点，不逐日铺事件；不新增类别 |
| 事件增删导致移动端内置数据过期 | App 报缺文件 | 中 | 提交前 `build:mobile-data --check` |
