## 2. 共享标记

`timelineEventMarkers` 已返回 `endRatio`：

- 无 `endDate`：`endRatio === ratio`；
- 有 `endDate`：`endRatio > ratio`；
- 组件用 `endRatio > ratio` 判断是否画持续时间条。

## 3. Web 渲染

在事件点区域：

```tsx
{marker.endRatio > marker.ratio ? (
  <div
    className="absolute top-1/2 h-1 -translate-y-1/2 rounded-full ..."
    style={{
      left: `${marker.ratio * 100}%`,
      width: `${Math.max(0.2, (marker.endRatio - marker.ratio) * 100)}%`,
    }}
  />
) : null}
```

- 条高 4px；
- 最小宽度 0.2%；
- 当前事件条朱红；
- 已发生条朱红半透明；
- 未来条灰色；
- 条在事件点下方，事件点 `z-10` 保持可点击。

## 4. 移动端渲染

- 在事件点区域绘制 `View` 条；
- 高度 3px，最小宽度 2px；
- 当前事件条朱红，其余半透明；
- 事件点 `Pressable` 保持在上层。

## 5. 交互

- 点击事件点仍跳转到 `eventStart`；
