# M16 无障碍键盘体验 — 方案

- **日期**：2026-11-05
- **里程碑**：M16（v0.16.0-m16）
- **状态**：已完成
- **关联计划**：[2026-11-05-M16-无障碍键盘体验-plan.md](2026-11-05-M16-无障碍键盘体验-plan.md)

## 1. Skip Link

新增 `SkipLink` 组件，放在 App 最前：

```tsx
<a
  href="#main-content"
  className="sr-only focus:not-sr-only focus:fixed focus:left-4 focus:top-4 focus:z-[100] ..."
>
  {t('a11y.skipToContent')}
</a>
```

页面主内容增加：

```tsx
<main id="main-content" tabIndex={-1}>
```

AtlasPage 的地图容器增加 `id="main-content" tabIndex={-1}`。

## 2. 详情焦点管理

`EventDetailPanel`：

- `panelRef` 指向 `<aside>`；
- `previousFocusRef` 保存打开前的 `document.activeElement`；
- 事件打开时：
  - `requestAnimationFrame` 后聚焦关闭按钮；
- 事件关闭时：
  - 恢复 `previousFocusRef.current?.focus()`；
- `Escape` 已有关闭逻辑，保留；
- `<aside>` 增加 `role="dialog"`、`aria-modal="false"`、`aria-labelledby` 指向标题；
- 标题 `id="event-detail-title"`。

> 不做完整焦点陷阱：详情是侧栏，不是模态对话框；键盘用户仍可离开。

## 3. 时间轴 ARIA

- 当前事件文字容器增加 `aria-live="polite"` 与 `aria-atomic="true"`；
- 只播报事件名，不播报日期；
- 事件点按钮增加 `aria-current={active ? 'true' : undefined}`；
- 事件点 `aria-label` 已包含事件名与日期；
- 轨道 `role="slider"` 保留。

## 4. 更新提示

`PwaUpdatePrompt` 增加 `role="status"`、`aria-live="polite"`。

## 5. 移动端

- Gallery 卡片 `Pressable` 增加 `accessibilityRole="button"` 与 `accessibilityLabel`；
- 时间轴事件点已有 `accessibilityRole="button"` 与标签；
- 语言切换已有标签；
- 筛选/详情按钮已有标签。
