# 合规笔记：底图来源与审图号

> 用途：回答「本站是否需要自办测绘资质 / 审图号」。结论只对**当前底图实现**成立，
> 换底图必须重跑本节核对。

## 现状（2026-11-24 实测）

| 项 | 值 |
| --- | --- |
| 底图 | 高德地图 JS API 2.0（`@amap/amap-jsapi-loader`，见 `apps/web/src/map/amap.ts`） |
| 版权控件 | `.amap-copyright` 渲染在页面上，`display:block`、`visibility:visible`、`opacity:1` |
| 渲染文本 | `© 2026 AutoNavi - GS(2025)5996号` |
| 核验页 | `https://atlas.openapp.asia/atlas/long-march`（专题页才有地图；首页无） |
| 自建瓦片 | 无。不托管、不切片、不缓存地图瓦片 |

## 结论

**不需要我方自办「互联网地图服务」测绘资质或另行申请审图号。**

理由：地图由高德（甲级测绘资质持有者）以 JS API 提供，审图号 `GS(2025)5996号`
由高德自带的版权控件显示，用户可见。我方只做「调用 + 在其上叠加自己绘制的路线与标记」，
不生产、不发布地图数据本身。

## 红线

1. **不得用 CSS 隐藏 `.amap-logo` / `.amap-copyright`**，也不得把它们移到视口外、
   设为 `opacity:0`、或用同色遮挡。那是丢失审图号 + 违反高德服务条款的双重违规。
2. 不得裁掉地图容器底部的版权条（例如 `overflow:hidden` + 负 `bottom`）。
3. 换第三方底图（天地图 / Mapbox / 自建瓦片）时：
   - 天地图：需在其平台申请 key，审图号随底图标注；
   - 自建瓦片或对底图做实质性修改：**需重新评估是否需要自办资质与送审**，不得沿用本节结论。

## 待办

- About 页补一句「底图 © 高德地图」，标明数据来源（属文案改动，随下次文档改动一并做）。
- 若要支持离线底图（PWA 场景），必须重新评估——离线缓存地图瓦片属于「复制地图数据」，
  与在线调用不是一回事。
