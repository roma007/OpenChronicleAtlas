# 五代十国疆域细切片核查

- **日期**：2026-11-27（第四轮补福州 945—947、泉漳清源军）
- **触发**：用户要求补上此前留空的两块——李仁达据福州（945—947）与留从效、陈洪进清源军（泉漳）。
- **结论**：渲染层按每个面的 `startDate/endDate` 显示，没有问题；问题在数据。
  本专题除北宋外每个政权只有一个 Cliopatria 单切片。现以 Cliopatria 面做并/差，
  并用现代行政边界补出源数据没有的区域，共 **42 个疆域面**（含唐 2 面、清源军与福州各 1 面）。

## 推导方法

- 底图：各政权 Cliopatria 面（CC BY 4.0，单切片），交集/差集用 `shapely` 计算，坐标保留 4 位小数。
- 推得的公共面：
  - 燕云十六州 = 后唐 ∩ 辽 ≈ 15.97 万 km²
  - 淮南（江北）= 后周 ∩ 杨吴 ≈ 13.80 万 km²
  - 两川 = 前蜀 / 后蜀；福建 = 闽；湖南 = 马楚；荆南 = 荆南
- 源数据未覆盖、改用现代行政边界近似的区域（`precision: schematic`）：
  - **福州（威武军）** = （福州市 ∪ 宁德市）∩ 闽 ≈ 2.52 万 km²；亦等于吴越 947—978 面减 893—947 面
  - **秦凤四州** = （天水市 + 成县、徽县、两当、武都、康县 + 凤县）∩ 后蜀 ≈ 2.34 万 km²
  - **泉漳（清源军）** = （泉州市 ∪ 漳州市 ∪ 莆田市 ∪ 厦门市）∩ 闽 ≈ 2.96 万 km²
- **武平**：直接复用马楚湖南面，不另测绘。
- 每个派生面写 `extensions.derivation`（`op` / `base` / `plus` / `minus`）与 `note`。
  同时段任意两政权重叠 < 800 km²（实测 0 对）。

## 存疑与未做

1. **秦凤四州、福州、泉漳**为现代行政边界近似，不是五代州界；已在 `extensions.note` 与 `ATTRIBUTION.md` 注明。
2. **武平**复用马楚湖南面，未独立测绘。
3. **947 年 2—3 月中原**：后晋亡到后汉立之间约 19 天为辽太宗入汴，未单列辽据中原的短切片。
4. **后梁河北得失**：Cliopatria 后梁仅 911—921 一个切片，915—918 年河北易手无法细分。
5. **吴越 893—896 仍画两浙**：钱镠 893 年仅任镇海军节度使、据浙西（润、常、苏、杭、睦），
   浙东属董昌威胜军，湖州为忠国军；896 年破越州、兼镇东军后方有两浙。Cliopatria 只有
   960—979 一个吴越面，本轮未拆浙西/浙东，893—896 段仍按两浙范围近似，已写入该面 `extensions.note`。
   若要精确，需 CHGIS 镇海军/威胜军界线或现代地级市边界（杭州、湖州、嘉兴、苏锡常镇）∩ 吴越面，
   并单列董昌（威胜军）实体；本轮因边界来源不足未做。
6. **907 年 5 月衔接**：唐面止于 907-05-31，后梁面始于 907-06-01，两者首尾相接，不留空月。
   唐哀帝禅位（天祐四年三月）与朱温即位（四月）的具体公历日期待考；本专题后梁建立日取
   907-06-01，唐面随之延至前一日，属显示衔接，未改事件日期。
