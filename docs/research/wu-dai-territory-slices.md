# 五代十国疆域细切片核查

- **日期**：2026-11-27（第四轮补福州 945—947、泉漳清源军）
- **触发**：用户要求补上此前留空的两块——李仁达据福州（945—947）与留从效、陈洪进清源军（泉漳）。
- **结论**：渲染层按每个面的 `startDate/endDate` 显示，没有问题；问题在数据。
  本专题除北宋外每个政权只有一个 Cliopatria 单切片。现以 Cliopatria 面做并/差，
  并用现代行政边界补出源数据没有的区域；2026-11-27 第五轮后共 **73 个疆域面**（唐 4 面、38 个实体）。

## 推导方法

- 底图：各政权 Cliopatria 面（CC BY 4.0，单切片），交集/差集用 `shapely` 计算，坐标保留 4 位小数。
- 推得的公共面：
  - 燕云十六州 = 后唐 ∩ 辽 ≈ 15.97 万 km²
  - 淮南（江北）= 后周 ∩ 杨吴 ≈ 13.80 万 km²
  - 两川 = 前蜀 / 后蜀；福建 = 闽；湖南 = 马楚；荆南 = 荆南
- 源数据未覆盖、改用现代行政边界近似的区域（`precision: schematic`）：
  - **福州（威武军）** = （福州市 ∪ 宁德市）∩ 闽 ≈ 2.52 万 km²；亦等于吴越 947—978 面减 893—947 面
  - **秦凤四州** = （天水市 + 成县、徽县、两当、武都、康县 + 凤县）∩ 后蜀 ≈ 2.34 万 km²
  - **泉漳（清源军）** = （泉州市 ∪ 漳州市 ∪ 莆田市 ∪ 厦门市）∩ 闽 ≈ 2.96 万 km²
- **武平**：直接复用马楚湖南面，不另测绘。
- 每个派生面写 `extensions.derivation`（`op` / `base` / `plus` / `minus`）与 `note`。
  同时段任意两政权重叠 < 800 km²（实测 0 对）。

## 第五轮：把「据地」与「立国」分开（2026-11-27）

### 为什么改

此前疆域面只有「某政权在某段时间」一个维度，结果是：马殷 896 年已据湖南、刘隐 905 年已据岭南，
但楚、南汉的实体要到 907、917 年才出现，896—906 年湖南、905—916 年岭南在图上没有任何归属。
把它们直接提前到「建国年」会制造另一个错误——把藩镇据地说成立国。二者必须分开表达。

本轮引入 `properties.extensions.polityStatus`，取值：

| 值 | 含义 | 视觉 |
| --- | --- | --- |
| `state`（缺省） | 已立国：王朝、帝国、王国、汗国 | 实线、正常填充、正体标识 |
| `regime` | 藩镇 / 军镇据地，未立国 | 虚线、填充降至 55%、标识斜体 |
| `tribal` | 部族 / 羁縻，无国号 | 点线、浅填充、中性灰描边 |

实现位于 `packages/shared/src/territory-style.ts`（`territoryPolityStatus` / `territoryVisualStyle`），
Web 与移动端共用；图例新增「疆域状态」三行说明。另加 `extensions.minLabelZoom`，
小政权标识在低缩放级别隐藏，避免 907—930 年标识拥挤。

### 立国口径

以《十国春秋》与通行十国表的建国年为准：受封王爵、实际独立、国号见于史籍者算 `state`；
未入十国表的藩镇（岐、晋、定难军、朔方军、归义军、静海军、播州杨氏）一律按 `regime`，
只有刘守光 911 年称大燕皇帝单列为 `state`。

### 唐面重新切片

唐面原为 893—902、902—907 两段。本轮按据地起始年再切两刀（896 楚、905 南汉），共四段：
893-01-01—895-12-31、896-01-01—902-04-30、902-05-01—0904-12-31、905-01-01—907-05-31。
每段都用同期所有非唐面（含 `regime`、`tribal` 与独立政权）做差，只保留唐廷直接控制区，
并在 `extensions.clipNote` 记录扣减数量。扣除岐、晋、燕、定难、朔方、归义、静海、播州、牂牁等
唐末已自专的藩镇后，893 年唐面由约 303 万 km² 降至约 170 万 km²，896 年段约 132 万 km²，
902 年段约 132 万 km²，905 年段降至约 103 万 km²——这不是疆域缩水，而是把「名义臣属」与
「直接控制」分开。893—894 年幽州（李匡筹）名义属唐，并入首段；895 年起刘仁恭据幽州，

### 仍然存疑

1. **唐末藩镇名义归属**：893—906 年吴越、杨吴、闽、楚、前蜀均名义上仍是唐臣，本轮按「实际控制」画成据地并扣除唐面；
   若按「名义疆域」则应全部归唐。两种画法都成立，本专题选择前者，理由是用户要看的正是「谁实际占着」。
2. **大理国面跨期借用**：南诏、大长和、大天兴、大义宁、大理共用 Cliopatria 960—969 的大理面，
   与 9—10 世纪实际疆界有出入，已逐面写入 `extensions.note`。
3. **河西走廊三段**：归义军（沙瓜）、甘州回鹘（甘肃）、吐蕃诸部（凉兰鄯）按现代县市界切开，
   9—10 世纪这些州的实际归属反复（肃州、凉州尤甚），只能力求「不空、不张冠李戴」，不能当精确边界。
4. **交趾 939 年后**：吴朝、十二使君、丁朝、前黎朝并作一个「交趾」面，属区域名而非单一政权，
   已在实体描述中列明世系。
5. **楚 907 年即算立国**：采用十国表通行的 907 年（后梁封楚王），927 年进封楚国王未再单列。
6. **前蜀不含秦州**：秦州（今天水）为岐所据，前蜀面已扣除；后蜀面沿用源数据，秦州归属待进一步考订。
7. **凤翔府归属**：924 年岐国除后，凤翔府（今宝鸡）并入后唐，并随后的晋、汉、周、宋各面保留。
