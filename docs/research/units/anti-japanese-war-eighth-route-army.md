## 1. 梳理前的问题

八路军层原有 11 个事件、9 段路线，与正面战场层（91 个事件）严重失衡，具体表现为：

1. **时间断层**：1939、1943、1944、1945 年完全没有事件；1937 年只有「成立」和「平型关」，1938 年只有三条根据地与山东纵队。
2. **战役缺失**：雁门关、阳明堡、七亘村、神头岭、响堂铺、长乐村、齐会、黄土岭、关家垴、韩略村等八路军代表性战斗均未收录。
3. **只有「建」没有「战」**：根据地事件多，作战事件少，读者看不到八路军「敌后游击战」的具体形态。
4. **内容偏薄**：原有事件多为一句概述，未写番号、主官、战果与影响，难以与正面战场事件对照。
5. **路线是「根据地连线」而非作战线**：9 段路线从延安经平型关、阜平、兴县、辽县、沂水再折回黎城，只能表达「活动范围」，不能表达具体战斗。

## 2. 梳理原则

- **按行为主体归属**：八路军及中共领导的敌后武装归 `eighth-route-army`；日军「扫荡」、惨案归 `japanese-invasion`；民众支前、救亡归 `china-people`。
- **只写有据可查的番号与主官**：如第115师（林彪、聂荣臻）、第120师（贺龙、关向应）、第129师（刘伯承、邓小平）、晋察冀军区（聂荣臻）、山东纵队（张经武、黎玉）。
- **战果数字标注「通行说法」**：无页码级来源前不写成定论，统一加「待页码级核对」。
- **事件与路线成对**：新增战斗事件都配一段作战示意线，端点落在事件或既有路线上，满足 `check:heads` 与 `check:routes`。
- **不把「扫荡」与「反扫荡」混为一条**：日军「扫荡」是日军行为，八路军反「扫荡」是八路军行为。

## 4. 路线结构（27 段）

2026-11-20 复核时删除了两条无主体的「根据地连线」：

- **辽县—沂水**（1938-04-02 → 12-27）：终点正好落在「山东纵队成立」的沂水，会被读成
  八路军主力从太行走到山东、就地成立山东纵队。史实是山东纵队由山东本地起义武装
  （徂徕山、天福山、黑铁山、牛头镇等）编成，不是太行主力入鲁；1938 年也没有这样一次
  从辽县到沂水的行军。
- **沂水—黎城**（1938-12-28 → 1941-11-10）：把山东接回太行的虚构回程线，只为给
  「黄崖洞保卫战」（1941-11-10，黎城）提供日期锚点。

处理方式：

1. 两条线删除；山东纵队成立改为建制事件，标 `extensions.routeEvent = false`，不绘路线；
2. 真正入鲁的第115师保留「黎城—鄄城」（1939-01-01 → 03-04）；
3. 黄崖洞保卫战改由本地防御线「黄崖洞兵工厂防御」承接（1941-11-10，`segmentType: defense`）。

| 类型 | 路线 |
