# 明清专题疆域面史料/数据台账

- **专题**：ming-qing
- **批次**：M299（2026-11-23）
- **数据源**：Seshat Cliopatria `cliopatria_polities_only_v021.geojson`（CC BY 4.0），
  本地校验文件 165 MB / 13797 个要素，仅取 `Type = POLITY` 的中国政权行。
- **结论**：原先只用 1400/1500/1600/1700/1800/1900 六个百年快照，导致
  1616—1644 年后金与清（盛京时期）没有任何疆域面，图上只有明。本次改为按源数据
  的逐年段切片逐段对齐，补入后金、清入关前与南明。

## 2. 归属与命名考证

1. **1636 年改国号**：天聪十年（1636）四月皇太极称帝，改国号「大清」、改元崇德。
   源数据 1636—1644 三段仍标 `Later Jin Dynasty`（Wikidata Q1062546），
   系数据集的命名滞后。按史实归入 `qing`，`sourceFeature.name` 保留原值，
   并在 `note` 写明「源数据沿用 Later Jin Dynasty；1636 年皇太极已改国号大清」。
   几何上也可佐证：1642—1644 段与 1645—1647 段有 183/301 个顶点重合，属同一政权的连续演化。
2. **后金与清分列实体**：`houjin`（1616—1636）与 `qing`（1636—1912）分别建实体，
   与专题内既有「后金建立」「萨尔浒之战」等事件主体一致；两者时段不重叠，
   颜色接近不构成辨识问题。
3. **南明止于 1658**：源数据 1653—1658 段为永历退守云贵（20 万 km²），
   其后无切片。永历帝 1662 年遇害，但无对应疆域面，故图中南明面止于 1658，
   与实体说明一致，不自行补绘。

## 4. 校验

- 逐实体时段连续，无空档：
  - ming 1368-01-01 → 1644-04-30（27 段首尾相接）
  - houjin 1616-01-01 → 1635-12-31（5 段）
  - qing 1636-01-01 → 1912-02-12（64 段）
  - nanming 1644-05-01 → 1658-12-31（3 段）
- 明与后金/清入关前为并行时段：1619—1621、1622—1625 的后金面没有顶点落在明面内；
  1636 年后约 4% 顶点落在明面内（辽东—锦州一线），属源数据边界毛刺，叠加显示。
- 99 个疆域面的 `labelPoint` 均在面内（导入脚本自检，无告警）。
- `pnpm validate:data`：ming-qing 154 事件 / 142 路线段；全库 11 专题 / 2036 事件 / 1129 路线段。
