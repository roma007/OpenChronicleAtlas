## 1. 问题

用户指出地图上有一条线从阳泉直接走到昆明。

核查确认：这是 `china-resistance` 实体（「中国抗战力量」）的 **order 19「华北—云南（远征军）」**，
坐标 `阳泉 [113.58, 37.86] → 重庆 [106.55, 29.56] → 昆明 [102.83, 24.88]`，
日期 `1940-08-21 → 1942-02-01`，全长约 1765 km。

它不是任何一支部队的行军路线，而是 2026-11-05 M21 首发时为了把
「中国抗战力量」画成一条贯穿十四年的连续叙事线而加的 **转场连接线**。
同类的跨战区连接线还有：

这些线把不同战区、不同番号的部队串成了一条线，读起来像一支部队从华北打到云南，
与史实不符。**正确的做法不是删线，而是把「哪支部队、从哪里来、到哪里去」补成独立战史线。**

## 2. 方法

以战役为入口，回答四个问题：

1. 这场战役是谁打的（番号、隶属、主官）？
2. 战前从哪里来（驻地、集结地、调动路线）？
3. 战后去了哪里（追击、撤退、整补、转用）？
4. 一路上经过哪些地点、发生哪些事件（可作为路线端点锚点）？

只画有史料依据的调动；无法确证的标 `schematic` 并在描述中注明。
现有 `kmt-forces`、`kmt-group-armies`、`eighth-route-army`、`allied-forces`
已经有大量营级/集团军级路线与事件，优先复用，不重复造线。

## 4. 建议的重建方案

### 方案 A（推荐）：拆掉 `china-resistance` 叙事链，改为「部队战史线」

1. 删除 `china-resistance` 的 10 段跨战区转场线（上表 order 3/5/7/10/11/13/19/24/27/29）。
2. 把 `china-resistance` 现有战役事件按参战部队改挂：
   - 淞沪、南京、兰封、武汉、随枣、长沙、上高、鄂西、常德、豫湘桂、衡阳、湘西 → `kmt-forces` / `kmt-group-armies`；
   - 平型关、百团大战 → `eighth-route-army`；
   - 远征军入缅、滇西反攻、松山 → `allied-forces` / `kmt-forces`；
   - 九一八、一·二八、察哈尔同盟军 → 需要新增少量 `kmt-forces` 路线，或保留 `china-resistance` 作为「非正规/民众武装」层。
3. 新增上表「关键部队战史线」共约 20 段，放在对应实体。
4. `china-resistance` 若保留，只放察哈尔民众抗日同盟军等无法归入正规军的部队，并在图例改名「民众抗日武装」。

### 方案 B（保守）：保留 `china-resistance`，只把 10 段转场线替换成部队战史线

- 不改事件归属，只在 `china-resistance` 层新增第74军、第5军、第10军、第33集团军、第18军的战史线；
- 转场线删除后，靠这些战史线覆盖原有事件；
- 图例仍叫「中国抗战力量」，但路线名称改为「第74军：长沙—上高」等。

### 方案 C（最小）：只删「阳泉—昆明」，补第5军入缅线

- 删除 order 19；
- 新增「第5军：昆仑关—昆明」「第5军：昆明—同古」两段；
- 其余转场线暂不动，记入待办。
