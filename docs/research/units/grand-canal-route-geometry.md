# 京杭大运河航道几何细化（M283）

- **日期**：2026-11-23
- **批次**：M283
- **对象**：`data/atlases/grand-canal/routes/canal.geojson` 19 段航道
- **问题**：原来多数航段只有起终点两个坐标，地图上是一条直线，看不出运河走向。

> **M284 更新（2026-11-23）**：现存运河段（7—18）已改用 OpenStreetMap 关系 1112801 的
> 航道中心线，见 [grand-canal-osm-geometry.md](grand-canal-osm-geometry.md)。
> 本文档的城镇连线表只适用于隋唐通济渠、永济渠、汴河（1—6）与黄河改道影响段（19）。

## 1. 做法

1. 把每段航道按**运河沿线主要城镇**拆成多个节点，再连成折线。
2. 坐标取现代城镇 WGS84 点位，只表示「运河经过这些地方」，**不表示实测河道中心线**。
3. 新增 `segmentType: "canal"`，图例显示「运河 / 航道」，不再用「进攻 / 前进」。
4. 所有航段保留 `extensions.precision: "schematic"`，并加 `geometryBasis: "canal-towns"`。

## 4. 精度说明

- 这是**示意折线**，不是实测河道。历史运河河道多次变迁，部分河段已湮没，无法用一条现代水系复原。
- 隋唐通济渠、永济渠的局部走向有异说，本批只取通行说法的主线，不画支渠。
- 1855 年黄河改道后的兰考—济宁段只表示受影响方向，不表示新河道。
- 各节点取现代城镇中心附近，误差在数公里级；如需更精确，应接入历史水系 GIS 数据。
