# 抗日战争 · 海外事件坐标符号修正（M256）

- **日期**：2026-11-22
- **批次**：M256 坐标修正（质量批次，不改日期、不改主体、不改正文）
- **触发**：地图上「美国租借法案援华」出现在**新疆喀什附近**，用户提问「那里有节点的理由是什么」。

## 1. 问题

`lend-lease-china-1941-03`「美国租借法案援华」：

| 字段 | 修正前 | 修正后 |
| --- | --- | --- |
| `place.zh` | 美国华盛顿 | 美国华盛顿（不变） |
| `lng` | **77.04** | **-77.04** |
| `lat` | 38.9 | 38.9（不变） |

华盛顿经度为**西经 77.04°**，数据里漏了负号。地图按 WGS84 渲染时，
`77.04°E, 38.9°N` 正好落在**新疆喀什—阿图什一带**，于是出现一个「美国租借法案」的节点。
历史与史料上并无新疆节点，纯粹是坐标符号错误。

同类问题另查出一处：`pearl-harbor-1941-12`「珍珠港事件」`lng` 为 **157.86**（应为 **-157.86**，
西经），修正前落在太平洋中部，不在夏威夷。

## 2. 排查方法

对全部 11 个专题扫描「地点名含海外地名、但经度为正」的事件：

```js
const kw = /美国|加拿大|夏威夷|旧金山|纽约|华盛顿|珍珠港|南美|巴西|秘鲁/;
arr.filter(e => kw.test(e.location.place.zh) && e.location.lng > 0)
```

结果：只有抗日专题这两条为真错；`long-march`「巴西会议」是四川若尔盖巴西镇（假阳性），
其余亚洲地点（东京、香港、河内、仰光、曼德勒、印度等）经度本就为正，均正确。

## 3. 影响面

- 两条事件均 `routeEvent: false`，不参与路线端点与 `check:routes` 距离校验。
- 事件数 1026、路线 563、地区 862 均不变；仅坐标与地图落点改变。
- 修正后「美国租借法案援华」落在华盛顿，「珍珠港事件」落在夏威夷珍珠港。

## 5. 教训

境外事件在本专题里是少数（东京、华盛顿、珍珠港、河内、仰光、曼德勒、印度），
录入时容易沿用「中国境内经纬度全为正」的直觉，漏掉西经负号。
以后新增境外事件，落点必须同时核对 `place.zh` 与经纬度半球；建议在
`pnpm validate:data` 里加一条「海外地名 + 正东经」告警（本次先人工扫描，未改脚本）。
