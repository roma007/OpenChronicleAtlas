# 抗日战争 · 东北抗日义勇军与东北抗日联军（M266）

- **日期**：2026-11-22
- **批次**：M266，新增 2 个实体、9 个事件、1 段路线
- **起因**：用户提问「当时是不是东北抗日联军？」核对后发现本专题 1931—1945 年东北只有日军进攻层
  （沦陷、失守、惨案），**中国一方没有主体**：抗联 0 条事件，义勇军 0 条，马占山江桥抗战连一条都没有。
  这比省界画错更严重——那是画错，这是整块缺席。

## 1. 先把名字理清（这是最容易出错的地方）

| 时期 | 主体 | 说明 |
| --- | --- | --- |
| 1931-09—1933 | **东北抗日义勇军** | 马占山（江桥）、李杜/冯占海（哈尔滨）、邓铁梅、王德林、黄显声等；1932 年号称 30 万人，成分复杂、无统一指挥，1932 年底基本溃散 |
| 1932—1936 | **东北人民革命军** | 中共领导的南满、东满、吉东、北满四片游击区；杨靖宇、赵尚志、周保中、李兆麟等 |
| **1936-02 起** | **东北抗日联军** | 1936-02-20《统一军队建制宣言》；至 1937 年秋 11 个军；1940 后缩编支队；1942-08-01 教导旅；1945-08 配合苏军 |

所以「当时是抗联」不能一概而论：1931—1935 年那五年是义勇军和人民革命军，
恰恰是江桥抗战、哈尔滨保卫战、赵一曼这些事发生的时期。数据层因此拆成两个实体，
不把 1931 年的马占山写成「抗联」。

## 3. 路线

只画一段：**江桥—大兴—三间房防线**（`segmentType: defense`，1931-11-04～11-18），
按洮昂铁路沿线三处阵地连线，`precision: schematic`。

不画哈尔滨保卫战路线，理由：该轴已有日军进攻层「双城堡—哈尔滨」段（1932-01-31～02-05），
再画一条中国守军同轴撤退线会完全重叠；且双城失守日期本身有 2-01／2-02 异说，
不宜据此画精确端点。事件正文已写明「不另绘路线」。

抗联其余 7 个事件全部 `routeEvent: false`：游击战没有连续进攻轴线，硬画就是编。
