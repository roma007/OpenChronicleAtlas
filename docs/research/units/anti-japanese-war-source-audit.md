### 1.2 处理方式

1. **标题内含作者/机构**：拆成 `author` + `title`。
   例：`海南史志网《琼崖日伪政权》` → author `海南史志网`，title `《琼崖日伪政权》`。
2. **标题内含媒体与日期**：拆出媒体名。
   例：`《宁波日报》2014-04-14《日军入侵大事年表》` → author `《宁波日报》`，
   title `《日军入侵大事年表》`。
3. **纯书名**：按通行版本补编者/作者。
   例：`《中国抗日战争史》` → `张宪文等`；`《广东省志·军事志》` → `广东省地方志编纂委员会`。
4. **官方文件**：`《开罗宣言》`、`《波茨坦公告》` → `中、美、英三国政府`；
   `《日本投降书》` → `日本政府`。
5. **同事件内重复来源**：按 `title + author` 去重，保留首条。

> **口径说明**：本批只补书目字段，不改任何事件日期、地点、主体与正文。
> 补出的作者来自标题自带信息或通行版本，未逐页核对版权页；后续做页码级核对时再校正。

## 3. M254 收口口径

1. **本表此后视为结案清单**。标注「结案：史料不足 / 冲突未决 / 月份级」的县城，
   在没有新增**县志、档案、当时报刊**级史料前，不再逐批重启网搜；如需重启，
   必须先在本表补「新增来源」一列。
2. **「暂不录入」不等于否认沦陷**。这些县绝大多数确有沦陷事实，只是无法落到可核查的
   具体日期，按「宁可少一条，不可错一条」不写入事件层。
3. **空袭类转专题**。云南、川渝各县空袭不属「县城沦陷」，统一转空袭专题处理，
   不再挂在分省补县清单下。
4. **已合并/已覆盖项**列入「并入已有事件」（如沙市→荆州、唐山/秦皇岛→1935 年即日控），
   不计入待考。
