### 1.2 处理方式

1. **标题内含作者/机构**：拆成 `author` + `title`。
   例：`海南史志网《琼崖日伪政权》` → author `海南史志网`，title `《琼崖日伪政权》`。
2. **标题内含媒体与日期**：拆出媒体名。
   例：`《宁波日报》2014-04-14《日军入侵大事年表》` → author `《宁波日报》`，
   title `《日军入侵大事年表》`。
3. **纯书名**：按通行版本补编者/作者。
   例：`《中国抗日战争史》` → `张宪文等`；`《广东省志·军事志》` → `广东省地方志编纂委员会`。
4. **官方文件**：`《开罗宣言》`、`《波茨坦公告》` → `中、美、英三国政府`；
   `《日本投降书》` → `日本政府`。
5. **同事件内重复来源**：按 `title + author` 去重，保留首条。

> **口径说明**：本批只补书目字段，不改任何事件日期、地点、主体与正文。
> 补出的作者来自标题自带信息或通行版本，未逐页核对版权页；后续做页码级核对时再校正。
