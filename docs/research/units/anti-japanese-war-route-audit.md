## 4. 教训

1. **删路线必须先重建 regionIndex**。本次删 #15 后未先重建，`validate:data` 报
   `regionIndex 引用了不存在的路线`，并把该专题统计为 0 事件，容易被误判为数据损坏。
2. **删粗线前先确认事件覆盖**。删 #15 后「日军进攻中条山（1938）」立即失去活动路线
   （`check:routes` 报 547km），故改为「收紧时间跨度」而非删除；删 #23/#77 前已确认
   #289、#203/#204 覆盖对应事件日期。
3. **总览线与分段线并存是允许的，但必须标注**，否则时间轴插值会把几个月的位置漂移
   画成一条直线——这正是规则 §4.10 点名的郑和反例。
