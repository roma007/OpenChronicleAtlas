# 抗日战争 · 民国省界换源（M257）

- **日期**：2026-11-22
- **批次**：M257 省界数据换源（质量批次，事件/路线不变）
- **触发**：用户指出「有一条省界线横跨整个四川省」。核查为川康界被画成 102.1°E 的直线，
  累计约 550 km；另有「1931 年就有西康省」的时代错误。

## 1. 旧数据的问题

旧的 `territories/roc-provinces.geojson` 来自 `DeanChensj/jiangshan-map`（GPL-3.0）的手绘 region 层，
文件自述「手工绘制，非精确勘界」。实测：

| 问题 | 实测 |
| --- | --- |
| 川康界过直 | 四川西界由 6 段近乎共线的竖边组成，经度 102.04–102.21°E，北起 33.14°N、南到 26.27°N，累计约 550 km |
| 西康提前建省 | 1931、1937、1938 三帧即标「西康省」；实际 1939-01-01 才建省 |
| 东界偏西 | 1939 年后西康辖康属、宁属（西昌）、雅属（雅安），东界应在 100–103°E 之间，旧图压到 102.1°E |

## 2. 新数据源

**ENP-China（ERC 788476, Aix-Marseille）"Provinces in Republican China (boundaries)"**
Christian Henriot 制作，**CC0 1.0 Universal**（可自由再分发），
Virtual Shanghai 数据集 198：<https://www.virtualshanghai.net/Data/Tables?ID=198>

- 5 套分期面：1912–1921、1922–1928、**1928–1945**、**1945–1946**、1947–1949
- 字段按分期给出省名（`p_28_45_nz`、`p_45_46_nz` 等），天然支持「同一张图、分期取面」
- 坐标系统为 `WGS_1984_Web_Mercator_Auxiliary_Sphere`，需反算到经纬度

## 3. 处理流程

新增 `scripts/import-roc-provinces-enp.py`（可复现）：

1. 读取 `Prov_1928_1945/1928_1945.shp` 与 `Prov_1945_1946/1945_1946.shp`；
2. Web Mercator → WGS84（`lon = x/R·180/π`，`lat = 2·atan(exp(y/R)) − π/2`）；
3. RDP 抽稀，容差 0.008°（约 0.9 km）；丢弃面积 < 0.002°²（约 20 km²）的碎环；
4. 环闭合、取面积最大环的形心作 `labelPoint`；
5. **分五帧**：1931、1937、1938、1939—1944、1945；
   前三帧西康标「西康特别行政区」，1939 起标「西康省」；
6. 1945 帧取 1945–1946 套面，含台湾省（源数据台湾中文名为空，按拼音兜底）。

产物：146 个要素（29+29+29+29+30），1006 KB（旧文件 565 KB）。

## 4. 同时修的一处检查

`scripts/check-region-index.ts` 原先用「边长 > 170km 即判跨省直线」的粗糙规则。
新数据里有两段**真实**长直边界：

- 宁夏—蒙古沙漠界 174 km（1929 年宁夏省含阿拉善、额济纳旗）
- 新疆—苏联界 194 km（塔城—阿勒泰段）

规则改为**只看几何**：取边中点两侧各 20 km，两点都落在本省环内才算「横穿」。
真实边界总有一侧在本省之外，因此不再误报；而海南三角形、陕西/甘肃斜线这类真问题仍会被抓到
（三角形任一边的两侧 20 km 都在环内）。

视觉复核：四川西界已沿大渡河—贡嘎山一线呈锯齿状，102.1°E 的直线消失。

## 6. 遗留

1. 源数据把 1928—1945 年画成同一套面，因此 1931/1937 帧的省界实际是
   「1928—1945 年的某一年」的近似；本批用改名（西康特别行政区）纠正最明显的时代错误，
   其余省份的逐年微调未做。
2. 西康西界在源数据中伸到 91.79°E（含昌都以西），与部分民国勘界图不同；这是源数据取舍，
   本批不擅改，如需另据档案校订应另开批次。
3. 民国县界仍无公开可再分发数据，本期继续不绘制。
