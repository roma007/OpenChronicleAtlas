## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 数据版本 | 构建期根据全部专题数据生成 `dataVersion` |
| F2 | 共享类型与判断 | `AtlasIndex.dataVersion`、`isDataVersionNewer` |
| F3 | Web 提示 | 定时/回到前台检查，显示更新横幅 |
| F4 | 移动端提示 | 首页检查，显示更新横幅并可清缓存重载 |
| F5 | 文档与版本 | `v0.36.0-m36` |

不在本轮范围：增量数据下载、后台自动更新、服务端推送、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 构建期生成内容哈希 | 只有数据变化才提示，文档/代码构建不误报 |
| D2 | 写入 `index.json` 与 `search-index.json` | 首页与搜索页都能读取 |
| D3 | 采用“版本不同即提示” | 回滚时也提示刷新到服务器版本 |
| D4 | Web 定时 + 回到前台检查 | 覆盖长时间打开的标签页 |
| D5 | 移动端清缓存后重载首页 | 避免继续使用旧缓存数据 |

## 4. 验收

- `index.json` 与 `search-index.json` 含 `dataVersion`；
- 数据变化时版本变化，仅文档变化时版本不变；
- Web 与移动端能显示更新提示；
- 共享判断函数有单测；
- 版本 `0.36.0`，双仓 tag `v0.36.0-m36`。
