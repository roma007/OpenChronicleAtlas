## 2. 本轮范围

| 编号 | 战役 | 路线 |
| --- | --- | --- |
| F1 | 淞沪会战 | 上海—宝山—罗店—大场—苏州河 |

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 只精修 4 个重点战役 | 控制范围，先验证精度提升流程 |
| D2 | 保留其余段「示意简化」 | 不夸大未校订部分 |
| D3 | 精修段描述改为「战役路线（据常见战史地图整理，待页码核对）」 | 区分精度层级 |
| D4 | 事件-路线抽查仍要求 0 个 >30km | 不破坏时间对齐 |
| D5 | 不新增事件 | 本轮只改路线节点与描述 |

## 4. 验收

- 4 个战役路线节点增加；
- 精修段描述不再写「示意简化」；
- 其余段保留「示意简化」；
- 事件-路线抽查 0 个 >30km；
- `pnpm validate:data` 通过；
- 版本 `0.23.0`，双仓 tag `v0.23.0-m23`。
