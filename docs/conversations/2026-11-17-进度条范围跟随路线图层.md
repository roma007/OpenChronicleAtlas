# 对话档案：进度条范围跟随筛选出的路线图层

- **日期**：2026-11-17
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M167 方案](../plans/2026-11-17-M167-进度条范围跟随路线图层-design.md)、[M167 计划](../plans/2026-11-17-M167-进度条范围跟随路线图层-plan.md)、[M166 七次下西洋拆线](../plans/2026-11-17-M166-郑和专题七次下西洋拆线-design.md)

## 1. 需求

郑和专题拆成 7 个航次图层后，用户提出：

> 进度起止日期应该等于用户筛选的路线图层的最小和最大日期

## 2. 理解与决策

| 编号 | 议题 | 结论 |
| --- | --- | --- |
| D1 | 统计对象 | 当前选中且有图例的路线图层 |
| D2 | 范围 | 最小 `startDate` 到最大 `endDate` |
| D3 | 背景线 | `legend: false` 的海防线不参与范围计算 |
| D4 | 无路线 | 回退到专题 `manifest.timeRange` |
| D5 | 当前时间 | 切换图层后 clamp 到新范围 |
| D6 | 影响面 | 进度条、刻度、事件标记、播放、日期输入 |
| D7 | 事件筛选 | 类别/日期筛选不改变路线范围 |

## 3. 实现

- `packages/shared/src/timeline/core.ts` 新增 `routeDateRange(routes, isIncluded)`；
- Web / 移动端 store 在 `loadAtlas`、`setActiveEntities`、`toggleEntity`、`soloEntity`、`showAllEntities` 后重算 `timeline`；
- 计算时排除未选中的实体与 `extensions.legend === false` 的背景实体；
- `currentTime` 夹到新 `timeline` 的起止之间；
- 补充单元测试。

## 4. 验证

- 全选：`1405-07-11` → `1433-07-22`；
- 独显第四次：`1413-12-01` → `1415-08-12`，当前时间自动变为 `1413-12-01`；
- 独显第七次：`1431-01-01` → `1433-07-22`；
- `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过。
