## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 共享 QA 模块 | 事件-路线时间匹配与距离计算 |

| F3 | 命令入口 | `pnpm check:routes` |
| F4 | 测试 | 距离、无活动路线、`routeEvent: false` |
| F5 | 文档与版本 | `v0.31.0-m31` |

不在本轮范围：自动修复路线、地图可视化 QA、CI 接入、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 逻辑放入 shared | Web / 移动端 / 脚本可复用 |
| D2 | 使用局部切平面距离 | 30km 级别检查足够，且实现稳定 |
| D3 | 事件与路线按日期区间重叠匹配 | 支持多日事件 |
| D4 | 跳过 `extensions.routeEvent = false` | 政治/外交事件本就不画路线 |
| D5 | 默认阈值 30km，可命令行覆盖 | 与既有 QA 口径一致 |
