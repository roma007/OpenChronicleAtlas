## 1. 原始需求

用户：

> 继续

M13 已让时间轴显示事件点，但事件点只表示起点。数据契约支持 `endDate`，本轮进入 M14：事件持续时间与时间轴区间。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 多日事件补 `endDate` | 数据 | 共用 |
| F2 | 时间轴显示持续时间条 | ✅ | ✅ |
| F3 | 当前事件区间高亮 | ✅ | ✅ |
| F4 | 详情显示日期范围 | 已有 | 已有 |
| F5 | 共享标记计算兼容区间 | ✅ | 共用 |

不在本轮范围：事件时长统计、动画按区间推进、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 只给史料明确的多日事件补 `endDate` | 避免臆测 |
| D2 | 持续时间条画在事件点下方 | 不遮挡事件点点击 |
| D3 | 零时长事件不画条 | 避免视觉噪音 |
| D4 | 当前事件区间使用朱红 | 与事件点高亮一致 |
| D5 | 筛选仍按事件起点 | 保持现有行为 |
