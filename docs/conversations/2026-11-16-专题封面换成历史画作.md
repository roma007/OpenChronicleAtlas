## 1. 需求

> 专题封面换成照片或者画

## 3. 处理

- 每张原图按构图裁切为 16:9，缩放为 1600×900，转 JPEG（q4），11 张合计约 3.2 MB；
- 西路军照片降饱和至 0.55，贴近站内宣纸色调；
- manifest 与 `index.json` 的 cover 改为 `assets/cover.jpg`，西路军补上封面；
- 删除旧的 `cover.png` / `cover.svg`（此前是占位图形，且 svg 不进移动端映射）；
- `data/atlases/ATTRIBUTION.md` 新增「封面图来源与许可」表，逐张列作者、馆藏、Commons 链接与许可；
- 关于页新增「来源与许可」链接，指向 `/data/atlases/ATTRIBUTION.md`。

## 4. 验证

- `pnpm validate:data`：11 专题 / 911 事件 / 654 路线段；
- `pnpm build:mobile-data --check`：映射已是最新（53 个文本 / 11 个图片）；
- `pnpm typecheck`、`pnpm lint` 通过；
- 浏览器检查首页 11 张封面全部 1600×900 加载成功；
- ATTRIBUTION 中 11 条 Commons 链接逐条 curl，均返回 200。
