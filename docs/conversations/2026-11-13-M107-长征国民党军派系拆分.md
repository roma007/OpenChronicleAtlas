## 1. 原始需求

用户：

> 国民党追堵部队太笼统了，当时有各地的部队和中央军。

## 2. 结论

原数据只有一个实体 `kmt-army`，16 段追堵路线共用一个灰色。M45/M46 只在文字里写了「湘军、桂军、滇军……」等派系，地图与图例仍是「一锅粥」。

本轮直接拆实体：中央军 + 湘、桂、黔、滇、川、东北、晋绥、甘宁青共 9 个，16 段路线与 14 个事件按派系重新归属。

## 3. 派系与路线归属

| 实体 | 路线 |
| --- | --- |
| 中央军（嫡系） | 中央军追击（赣—湘—黔）；中央军等追堵红二十五军（豫—陕—甘） |
| 湘军 | 湘江封锁线（湘军）；湘军“围剿”湘鄂川黔；湘军、中央军追击红二、六军团 |
| 桂军 | 湘江封锁线（桂军） |
| 黔军 | 乌江防线（黔军） |
| 滇军 | 金沙江防线（滇军） |
| 川军 | 川军堵截红四方面军；大渡河防线（川军） |
| 东北军 | 东北军西安—延安（第三次“围剿”）；六盘山骑兵追击；直罗镇进攻 |
| 晋绥军 | 晋绥军追堵东征（太原—石楼） |
| 甘宁青部队 | 腊子口防线（鲁大昌部）；马鸿逵等部堵截西征（银川—盐池） |

## 4. 关键决策

| 议题 | 结论 |
| --- | --- |
| 是否保留 `kmt-army` | 不保留，避免旧口径回流 |
| 多派系走廊（红二十五军、红二/六军团） | 按主责部队入库，名称与描述列全参战部队，不复制几何 |
| 配色 | 统一低饱和冷色系，与红军暖色形成阵营区分 |
| 文件命名 | `kmt-army.geojson` → `kmt-forces.geojson`，因为内容已不是一个实体 |
| 图例变长 | 桌面图例限高 `calc(100vh - 16rem)` + 滚动，避免压住时间轴 |
| 版本 | 不升，交由发布窗口统一处理（沿用 M105/M106 约定） |
