## 1. 起因

用户问：「当时是不是东北抗日联军？」

这是一个史实问题，但一查就发现是**数据事故**：本专题 1931—1945 年的东北，
只有日军进攻层（齐齐哈尔沦陷、海拉尔失守、平顶山惨案……），
中国一方**一条主体都没有**——抗联 0 条事件，义勇军 0 条，马占山江桥抗战连一条都没有。

地图上只有日军在动，中国人不存在。这比省界画错严重：那是画错，这是整块缺席。

## 2. 先把名字理清

| 时期 | 主体 |
| --- | --- |
| 1931-09—1933 | 东北抗日义勇军（马占山、李杜、冯占海、邓铁梅、王德林、黄显声） |
| 1932—1936 | 东北人民革命军（中共领导，杨靖宇、赵尚志、周保中、李兆麟） |
| 1936-02 起 | 东北抗日联军（1936-02-20 统一建制宣言；1942-08-01 教导旅；1945-08 反攻） |

所以「当时是抗联」不能一概而论。1931—1935 那五年是义勇军和人民革命军，
恰恰是江桥抗战、哈尔滨保卫战、赵一曼这些事发生的时期。数据层因此拆成两个实体。

## 4. 查证时改掉的两个错

1. **八女投江不是 11-22**。原计划草案写 11-22，查证后是 **1938-10-20**
   （黑龙江日报据林口县于春芳考证；新华社 2024 作 10 月上旬、解放军报 2025 作 10 月下旬，正文并列）。
2. **「萝北梧桐河」的县属错了**。1942 年该地属伪满鹤立县（今汤原），
   1937 年框架下是汤原县；赵尚志牺牲地吕家菜园子今属鹤北林业局。
   同样，八女投江的刁翎 1938 年属**勃利县**，林口县 1939-06-01 才设。

另外**删掉了两条自己编的来源**（《东北抗日联军名录》《黑龙江省志·军事志》相关章节），
全部换成可点开的页面：黑龙江史志网、吉林地方志、人民网、新华社、中国军网、赵尚志纪念馆、
中华英烈网。宁可少一条考证细节，不能留一条假出处。
