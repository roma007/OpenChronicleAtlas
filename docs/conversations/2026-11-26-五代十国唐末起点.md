# 五代十国：为什么一开始只有吴越，以及补唐

- **日期**：2026-11-26
- **触发**：用户问「五代十国专题，为什么一开始只有吴越一国？」
- **诊断**：
  1. 时间轴范围由当前激活图层的路线与事件最早/最晚日期决定
     （`apps/web/src/stores/useAtlasStore.ts:45-55`），加载时 `currentTime = timeline.start`；
     本专题最早数据是 `wu-yue-founded-893`（0893-01-01）。
  2. 疆域面按 `startDate <= currentTime <= endDate` 显示
     （`apps/web/src/components/map/MapCanvas.tsx:231-235`）；893 年只有吴越面，
     杨吴要 902、后梁/前蜀要 907、闽 909、辽 916、南汉 917……
  3. 更关键的是：唐朝没有被建模——没有「唐」实体，也没有唐疆域面。893—906 年中原与江南
     大部分仍属唐朝，但图上没有唐，于是除吴越外整张图是空的。
  4. 附带发现：`manifest.json` 的 `timeRange.start` 是 0893-01-01，`index.json` 却写 0907-01-01；
     893 年事件原题「钱镠据两浙」、正文「任浙江节度使」也不准确——893 年钱镠只是镇海军节度使、
     润州刺史，据浙西；浙东仍在董昌手中，896 年才兼镇东军。
- **决策**：给出「起点改到 907」与「补唐朝」两个方案，用户选择后者。
- **处理**：
  - 新增实体 `tang-chao`（唐，order 0，色 `#8b1e3f`），无路线/事件，仅作为疆域背景；
  - 唐面复用隋唐专题的 Cliopatria `Tang Dynasty` 900—910 切片，做差集：
    893-01-01—902-04-30 减吴越面，902-05-01—0907-05-31 再减杨吴面；
    两段都写入 `extensions.derivation` 与 `note`，标识点落长安 [108.94, 34.34]；
  - 修正 `wu-yue-founded-893`：改名「钱镠任镇海军节度使」，正文改为镇海军节度使、
    润州刺史、据浙西、浙东属董昌，出处补《新五代史》卷六十七、《旧五代史》卷一百三十三、
    《十国春秋》卷七十七；
  - 吴越实体描述改为「893 据浙西，896 兼镇东军后有两浙」；
  - 吴越 893—947 疆域面加注：893—896 实仅据浙西，早期段仍按两浙范围近似；
  - `index.json` 的 `timeRange` 对齐为 0893-01-01 → 0979-06-30；
  - manifest 描述补「唐末前史」分期。
- **校验**：
  - `pnpm validate:data` 通过（87 事件 / 25 路线）；
  - `pnpm build:search-index` 通过，数据版本 `2026-11-26-38b4cc380468`；
  - `pnpm check:heads --atlas wu-dai-shi-guo`：25 段路线，0 个无来由端点；
  - 用 shapely 复核同时段跨政权重叠：除吴越/杨吴边界的 801 km² 历史遗留外，新增唐面与吴越、
    杨吴重叠均为 0；
  - 开发服务器实测：893 年显示「唐 + 吴越」，902 年杨吴加入后唐面自动扣除淮南，
    907-05 唐面仍在，907-06 换成后梁，无空月；
  - `pnpm check:routes --atlas wu-dai-shi-guo` 仍报告 131 条「事件无活动路线」等告警，
    为专题原有状态（87 事件仅 25 段路线），本次未新增。
- **未做 / 存疑**：
  - 893—896 吴越仍按两浙范围近似，未拆董昌（浙东威胜军）与湖州（忠国军）；
    需要 CHGIS 镇海军/威胜军界线或现代地级市边界，本轮边界来源不足，已在研究笔记登记；
  - 907 年 5 月不再空档：唐面延至 907-05-31，与后梁面（907-06-01）首尾相接；唐哀帝禅位与
    朱温即位的具体公历日期待考，未改事件日期。
