# 对话档案：郑和专题明朝海防线

- **日期**：2026-11-17
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M165 方案](../plans/2026-11-17-M165-郑和专题明朝海防线-design.md)、[M165 计划](../plans/2026-11-17-M165-郑和专题明朝海防线-plan.md)、[M164 台湾注记](../plans/2026-11-17-M164-郑和专题台湾注记-design.md)

## 1. 需求修正

M164 上线“东番（台湾）：明朝海防要地，未设府县”的说明后，用户指出：

> 不对，我是说把台湾加入当时明朝的海防范围，换句话说画出当时明朝的海防线。

即：不是只加一句“未设府县”的注记，而是把台湾、澎湖纳入明朝海防范围，并把这条海防线画出来。

## 2. 理解与决策

| 编号 | 议题 | 结论 |
| --- | --- | --- |
| D1 | 表达对象 | 明朝东南海防范围，不是行政疆域 |
| D2 | 表达方式 | 新实体“明朝海防线”+ 两段 `defense` 路线 |
| D3 | 大陆段 | 辽东 → 山东 → 南直隶 → 浙江 → 福建 → 广东 → 海南 |
| D4 | 台澎段 | 福建沿海 → 澎湖 → 环台湾本岛 → 返回福建 |
| D5 | 时间轴 | `static: true`，起点即整段显示，不逐段生长 |
| D6 | 东番标注 | 保留不填充示意面，标签改为“东番（台湾）· 海防范围” |
| D7 | 说明文字 | “东番（台湾）：明朝东南海防范围，未设府县。” |

## 3. 史实边界

- 台湾本岛没有明朝府县、常驻行政官员与编户征税；
- 明朝把台澎纳入东南海防视野，并在台湾本岛多次用兵；
- 因此地图表达的是“海防范围”，不是“行政疆域”；
- 海防线为示意线，综合明初沿海卫所、巡检司、水寨与明中后期台澎海防，不代表某一年份的精确布防。

## 4. 本轮产出

- 东番标签与 manifest 说明改为“海防范围”；
