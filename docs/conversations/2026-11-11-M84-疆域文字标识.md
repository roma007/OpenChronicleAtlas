## 1. 原始需求

用户：

> 这个时代疆域遮罩有没有可能增加文字标识？比如三国的魏、汉、吴等等

即：在时代疆域半透明遮罩上增加政权文字标识，并支持中英文切换。

## 2. 本轮范围

| 类型 | 新增 |
| --- | --- |
| 数据契约 | `label`、`labelPoint`（均可选） |
| Web 地图 | `AMap.Text` 疆域文字标识，随疆域显隐 |
| 专题数据 | 隋唐 5、宋元 6、三国 4，共 15 个标识 |
| 文档 | 计划、方案、发布说明、schema 章节 |

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 标识放在疆域面数据里，而不是硬编码 | 数据驱动，便于校订与多语言 |
| D2 | `label` 可选，缺省用疆域 `name`，再缺省用实体名 | 兼容已有数据 |
| D3 | `labelPoint` 可选，缺省取外环顶点平均值 | 复杂形状可手动指定位置 |
| D4 | 三国使用「魏 / 汉 / 吴 / 晋」简称 | 符合用户示例与地图习惯 |
| D5 | 标识与面同时显隐 | 避免出现无面的孤立文字 |

## 4. 验收

- 三国地图显示「魏」「汉」「吴」，西晋时段显示「晋」；
- 隋唐、宋元各政权显示对应标识；
- 中英文切换后标识同步切换；
- 关闭「时代疆域遮罩」后文字一并隐藏；
- 版本 `0.84.0`，双仓 tag `v0.84.0-m84`。
