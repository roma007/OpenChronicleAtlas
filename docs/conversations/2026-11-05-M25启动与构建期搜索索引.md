## 1. 原始需求

用户：

> 继续

平台已有 4 个专题，搜索页仍在运行时加载全部专题数据并构建索引。本轮进入 M25：构建期搜索索引，降低搜索页网络与计算开销。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 构建脚本 | 生成 `data/atlases/search-index.json` |
| F2 | 共享加载器 | `loadSearchIndex` |
| F3 | Web 搜索页 | 直接读取索引 |
| F4 | 移动端搜索页 | 直接读取索引 |
| F5 | 构建集成 | Vercel build 前生成索引 |
| F6 | 索引文件 | 中英标题 + 拼音字段 |

不在本轮范围：增量索引、服务端搜索、分词、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 索引在构建期生成 | 搜索页只加载一个 JSON |
| D2 | 索引包含完整事件对象 | 搜索结果可直接展示，无需再取专题数据 |
| D3 | `atlasTitle` 改为多语言对象 | 英文界面显示英文专题名 |
| D4 | 拼音在构建期生成 | 运行时不再加载 pinyin-pro |
| D5 | 保留 `buildSearchIndex` 供脚本使用 | 共享逻辑不变 |
| D6 | 索引文件提交到仓库 | 静态部署无需额外服务 |

## 4. 验收

- `pnpm build:search-index` 生成索引；
- Web / 移动端搜索页只请求 `search-index.json`；
- 中英文、拼音、类型、时间段搜索仍可用；
- 索引文件包含 4 个专题、103 个事件；
- 版本 `0.25.0`，双仓 tag `v0.25.0-m25`。
