## 1. 原始需求

用户：

> 目前在地图上的表现是两点一线这样的表现，有其他更好的表现方式吗？

AI 给出「数据补点、军事符号、交互、面状控制带」四层建议后，用户回复：

> 好

确认先做「番号牌 + 据点端点 + 防御齿线」这一版原型。

## 2. 需求拆解

| 编号 | 需求点 | 类型 | 优先级 |
| --- | --- | --- | --- |
| R1 | 路线显示番号，不再只有颜色 | 数据 / UI | 高 |
| R2 | 封锁线/防御线用齿线符号，而不是普通点虚线 | UI | 高 |
| R3 | 防线首尾加据点符号 | UI | 高 |
| R4 | 符号不要随缩放变形 | UI | 高 |
| R5 | 不影响其他专题 | 约束 | 高 |
| R6 | 图例能解释新符号 | UI | 中 |
| R7 | 中英文标签同步 | UI | 中 |

## 3. 讨论与决策

| 编号 | 议题 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 先做哪一层 | 先做番号牌、据点、齿线 | 用户确认「好」 |
| D2 | 齿线怎么画 | 用 Marker + CSS 旋转，固定屏幕像素 | 公里折线放大后变「梯子」 |
| D3 | 是否所有防御线都加齿线 | 只对写了 `label` 的防御线启用 | 避免其他专题 marker 激增 |
| D4 | 番号牌何时显示 | 缩放 ≥ 6 且进度 ≥ 45% | 总览时避免 21 个标签重叠 |
| D5 | 国民党军线是否降低视觉权重 | 是，线宽减一档、透明度 0.6/0.65 | 突出红军主线 |
| D6 | 是否同时补真实路径点 | 本轮不做 | 先验证符号方向，再决定数据精修 |
| D7 | 移动端是否同步 | 本轮不做 | 原型先在 Web 验证 |

## 4. 实现要点

### 4.1 数据契约

- `AtlasRouteProperties` 新增可选 `label` / `labelPoint`；
- `routeFeatureSchema` 同步补充，保持向后兼容；
- 21 段长征国民党军路线补中英文短标签。

### 4.2 渲染

- 番号牌：`AMap.Text`，中点向法线偏移约 7 km，羊皮纸底 + 实体色文字；
- 防御齿线：每 24 km 一个 `AMap.Marker`，内部 span 为 12×2 px 横条，按路线法线旋转；
- 据点：首尾各一个 9×9 px 方块 Marker；
- 时间轴：齿线只显示已画到的部分；起点据点随路线出现，终点据点在线走完后出现；
- 番号牌：缩放 ≥ 6、进度 ≥ 45% 显示；实体关闭、路线未发生、语言切换时同步更新。

### 4.3 图例

- 「防御 / 驻守」样例改为「细线 + 三道垂直齿」；
- 增加说明「齿线与方块表示封锁阵地与据点（放大后显示）。」；
- 仅在存在带 label 的防御线时显示，其他专题保持原样。
