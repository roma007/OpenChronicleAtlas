## 1. 原始需求

用户：

> 继续

原始需求 §9 要求「无障碍：键盘可操作时间轴，对比度达标；移动端支持系统字体缩放」。时间轴已支持键盘，但还缺少跳转链接、详情焦点管理与屏幕阅读器提示。本轮进入 M16：无障碍与键盘体验。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 跳到主要内容链接 | ✅ | — |
| F2 | 详情打开时焦点进入/关闭后恢复 | ✅ | — |
| F3 | 时间轴当前事件屏幕阅读器提示 | ✅ | ✅ |
| F4 | 事件点 `aria-current` | ✅ | ✅ |
| F5 | 卡片/按钮可访问标签 | ✅ | ✅ |
| F6 | 更新提示状态语义 | ✅ | — |

不在本轮范围：完整焦点陷阱、屏幕阅读器全量测试、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 使用 Skip Link 而非全局焦点陷阱 | 详情是侧栏而非模态对话框 |
| D2 | 详情打开聚焦关闭按钮，关闭恢复原焦点 | 键盘用户不迷失 |
| D3 | 时间轴当前事件使用 `aria-live="polite"` | 只在事件变化时播报，不逐帧播报日期 |
| D4 | 事件点使用 `aria-current="true"` | 屏幕阅读器可识别当前事件 |
| D5 | 不改变视觉设计 | 无障碍增强不引入新布局 |

## 4. 验收

- Tab 首次聚焦显示「跳到主要内容」；
- 激活后焦点进入主内容；
- 点击事件点打开详情后焦点进入详情，Escape 关闭后焦点回到事件点；
- 当前事件点有 `aria-current`；
- 时间轴事件变化有礼貌播报；
- 中英文案正确；
- 共享测试、Lint、Typecheck、Web 构建通过；
- 版本 `0.16.0`，双仓 tag `v0.16.0-m16`。
