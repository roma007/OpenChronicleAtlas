## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 索引事件摘要 | 新增 `SearchEvent`，只保留搜索与结果展示字段 |
| F2 | 构建改造 | `buildSearchIndex` 不再写入完整事件对象 |
| F3 | 类型收敛 | `eventStart`、`collectCategories` 接受更窄类型 |
| F4 | 测试 | 断言索引不含 description/sources 等字段 |
| F5 | 版本与 tag | `v0.34.0-m34` |

不在本轮范围：增量索引、服务端搜索、分词、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 索引只存事件摘要 | 搜索结果与跳转不需要完整 description/sources |
| D2 | 保留 `fields.description` | 维持描述文本的搜索召回 |
| D3 | 不改变搜索 API | `searchEvents` 入参与返回结构保持兼容 |
| D4 | 目标体积 ≤ 260 KB | 从当前 323.7 KB 明显下降 |
| D5 | 版本升至 0.34.0 | 保持里程碑版本与 tag 一致 |

## 4. 验收

- 索引事件对象不含 description/sources/images/relatedIds；
- 搜索结果、专题筛选、分类、日期筛选行为不变；
- 索引体积明显下降；
- 共享测试与 Web 构建通过；
- 版本 `0.34.0`，双仓 tag `v0.34.0-m34`。
