## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | ADR-0009 | 评估公元前日期、事件别名、路线分段类型 |
| F2 | 事件别名 | 可选 `aliases`，进入搜索索引 |
| F3 | 路线分段类型 | 可选 `segmentType` 枚举 |
| F4 | Schema v1.1 | 新增数据契约文档，manifest 升到 1.1.0 |
| F5 | 测试与版本 | schema 单测、别名搜索测试、`v0.35.0-m35` |

不在本轮范围：公元前日期的实际实现、路线分段类型的 UI 样式、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 别名与分段类型作为可选字段 | 向后兼容，旧数据无需修改 |
| D2 | 别名进入搜索 `fields.name` | 无需新增字段即可提升召回 |
| D3 | 公元前日期暂缓到 v2.0 | 涉及日期解析、时间轴、格式化与数据迁移 |
| D4 | manifest 升到 1.1.0 | 明确契约已扩展 |
| D5 | 分段类型先只定义枚举 | 样式与图例后续再接入 |
