## 1. 原始需求

用户：

> 继续

M7 完成了双语，但移动端语言状态只在会话内保持；M8 完成了移动端数据缓存，但没有缓存状态提示与清理入口。本轮进入 M11：移动端体验收尾。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 语言持久化 | AsyncStorage 保存 `atlas-locale`，启动时恢复 |
| F2 | 缓存状态提示 | 数据来自缓存时显示「离线缓存」徽标 |
| F3 | 清除离线缓存 | 首页底部提供清除入口，带确认 |
| F4 | 缓存命中检测 | 数据源记录是否使用了缓存 |
| F5 | 文案双语 | 新增缓存/离线相关文案 |

不在本轮范围：APK/IPA 打包、新增专题、iOS 真机、商店提审。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 语言持久化复用已有 AsyncStorage | M8 已引入，无需新增原生依赖 |
| D2 | 缓存命中用模块级标记 + 消费函数 | 不改变 shared 数据源接口 |
| D3 | 清除缓存只删 `atlas-cache:v1:` 前缀键 | 不影响语言与其他存储 |
| D4 | 缓存状态显示在专题页与首页 | 用户能感知当前是否离线数据 |
| D5 | 清除前使用系统 Alert 确认 | 避免误操作 |

## 4. 验收

- 切换英文后重启应用仍为英文；
- 断网进入已缓存专题时显示「离线缓存」徽标；
- 首页可清除缓存，清除后再次进入需要联网；
- 中英文文案正确；
- 移动端 typecheck、Lint、共享测试通过；
- 版本 `0.11.0`，双仓 tag `v0.11.0-m11`。
