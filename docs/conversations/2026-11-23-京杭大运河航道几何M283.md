# 2026-11-23 京杭大运河航道几何细化（M283）

- **日期**：2026-11-23
- **参与者**：用户（项目负责人）、AI 开发助手
- **关联版本**：v1.0.265
- **关联文档**：[航道几何核对表](../research/units/grand-canal-route-geometry.md)、[CHANGELOG](../changelog/CHANGELOG.md)

## 1. 用户的问题

「运河的航道就是两点一线这样吗？太粗糙了吧？」

## 2. 原因

`grand-canal` 的 19 段路线里，多数只有起终点两个坐标，地图上就是一条直线。数据本身是 M75 的示例初稿，只标了「示意简化」，没有把沿线城镇补进去。

## 3. 改法

- 19 段全部改成多节点折线，按运河沿线主要城镇连线。
- 主航道「北京—杭州」从 8 个点扩到 **30 个点**：北京、通州、天津、沧州、德州、临清、聊城、济宁、徐州、宿迁、淮安、扬州、镇江、常州、无锡、苏州、嘉兴、杭州。
- 通济渠、永济渠、江南河、汴河、会通河、通惠河、南运河等分段也补到 3—17 个点。
- 新增 `segmentType: "canal"`，图例显示「运河 / 航道」，不再显示「进攻 / 前进」。
- 所有航段加 `geometryBasis: "canal-towns"`，明确是「按沿线城镇连线」，不是实测河道。

## 4. 几个判断

### 为什么不用现代水系线

京杭大运河今天仍在使用，但隋唐通济渠、永济渠大部分已湮没，黄河改道后线路也变了。用一条现代水系线会假装历史河道没变。按沿线城镇连线，至少能看出「从哪到哪、经过哪些地方」。

### 为什么主航道要 30 个点

主航道跨北京、天津、河北、山东、江苏、浙江，只用 8 个点会把德州—临清—济宁、徐州—宿迁、淮安—扬州这些弯折拉直。30 个点能看出运河的大致走向，又不至于密到像实测图。

### 为什么新增 `canal` 类型

原来的 `advance` 是军事术语，运河不是军队在进攻。新增 `canal` 后，图例、路线详情、时间轴都显示「运河 / 航道」，语义正确。
