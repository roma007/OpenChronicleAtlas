# 五代十国：把纯政治事件从路线检查里摘出去

- **日期**：2026-11-28
- **触发**：用户要求「单开一轮把纯政治事件标注清楚」。
- **诊断**：`pnpm check:routes --atlas wu-dai-shi-guo` 报 140 条「无活动路线」。
  本专题 91 个事件、25 段路线，绝大多数事件是即位、册封、改制、文化一类，本就不该画线；
  因未标 `extensions.routeEvent = false`，检查把它们当成缺线，掩盖了真正的军事缺线。
- **口径**：
  1. 标 `routeEvent: false`：即位、建号、受封、进封、禅让、纳土、割地、大分封、外交、羁縻、
     官制/税制/抑佛/扩军方针/杯酒释兵权、文化词学水利、荒淫、诸子争位，以及同一事件的政治叙述副本；
  2. 不标：有军队行动的战役、征伐、围城、南侵、平叛。即使尚未画线也保留告警，
     下一轮补攻方行军线或守方防御线，不用标记掩盖。
- **处理**：给 56 个事件加 `extensions.routeEvent = false`，其余字段不动。
- **结果**：`check:routes` 问题 140 → 58。
  剩余 58 条全部是 34 个军事事件：
  - 23 个事件攻方有线段、守方没有（后唐灭前蜀、后周征南唐、北宋灭后蜀/南汉/南唐/北汉等）；
  - 11 个事件双方都没有线段（后梁晋争潞州、胡柳陂、后唐灭后梁、辽澶州之战、南唐灭闽、
    南唐攻福州、刘言复湖南、高平之战、高梁河之战等）。
- **校验**：`validate:data`、`build:search-index`、`build:mobile-data`、`typecheck`、`lint`、`test` 通过。
- **下一步**：为上述 34 个军事事件补路线（攻方行军线、守方防御/撤退线），
  史料锚点与 `precision: schematic` 规则同前几轮。
