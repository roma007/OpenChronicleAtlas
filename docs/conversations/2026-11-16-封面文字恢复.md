# 对话档案：封面文字恢复

- **日期**：2026-11-16
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[专题封面换成历史画作](2026-11-16-专题封面换成历史画作.md)、[数据来源说明](../../data/atlases/ATTRIBUTION.md)

## 1. 需求

> 原先在封面上的文字恢复回来，不要去掉

上一轮换封面时只保留了画作/照片，旧封面上的标题、年代、关键词与品牌文字被一并去掉。本轮把这些文字按原版式重新叠回新封面。

## 2. 原封面有两套版式

| 版式 | 专题 | 文字内容 |
| --- | --- | --- |
| 简版 | 长征、郑和下西洋、抗日战争 | 大标题、年代、品牌行（抗战为「十四年抗战 · 时空地图」）、底部「示意图 · 数据待史料校订」 |
| 详版 | 三国、隋唐、宋元、明清、京杭大运河、徐霞客游记、玄奘西行 | 大标题、英文名 + 年代、中文关键词、英文关键词、底部 `OPENCHRONICLE ATLAS · 史迹 · 时空地图` |

西路军此前没有封面，本轮按简版补：西路军 / 1936 — 1937 / 史迹 · 时空地图。

## 3. 实现

- 用 Swift + AppKit 在 1600×900 的新封面上重新排版文字（`STSongti-SC-Bold` 标题、`Georgia` 拉丁文）；
- 文字后加左侧宣纸色渐层（#F7F1E3，alpha 0.92 → 0），既保留画作/照片，又保证墨色文字可读；
- 简版保留底部细线与「示意图 · 数据待史料校订」；详版保留底部品牌行；
- 所有封面重新导出 JPEG，11 张合计约 6.7 MB；
- ATTRIBUTION 补一句：封面文字为本站叠加的版式，不属于原图。

## 4. 验证

- `pnpm build:mobile-data --check` 通过（53 文本 / 11 图片）；
- 浏览器检查首页 11 张封面全部加载，标题、年代、关键词、品牌行清晰可读；
- `data/atlases/ATTRIBUTION.md` 图片链接与许可未变。

## 5. 提交与发布

版本由钩子从 `1.0.77` 升到 `1.0.78`，tag `v1.0.78`，提交后立即 `pnpm release`。
