## 1. 原始需求

用户：

> 继续

M8 的 PWA 使用 `autoUpdate`，新版本会静默接管；用户看不到更新提示，也没有 Web 端缓存管理入口。本轮进入 M15：PWA 更新提示、关于页与 Web 缓存管理。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 新版本提示 | Service Worker 更新时显示「新版本可用」 |
| F2 | 手动刷新 | 点击刷新后激活新版本 |
| F3 | 关于页 | 版本、数据契约、地图服务、仓库链接 |
| F4 | Web 缓存管理 | 显示缓存占用与条目数，支持清除 |
| F5 | 隐私页/首页入口 | 页脚增加「关于」入口 |
| F6 | 中英文案 | 新增关于/更新/缓存文案 |

不在本轮范围：服务端版本检查、强制更新、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | PWA 改为 `registerType: 'prompt'` | 让用户决定何时刷新 |
| D2 | 使用 `virtual:pwa-register/react` | 官方 React 集成，避免手写 SW 生命周期 |
| D3 | 关于页放 `/about` | 与隐私页同级，便于页脚链接 |
| D4 | 缓存管理使用 `caches` + `storage.estimate()` | 浏览器原生能力，无新增依赖 |
| D5 | 清除缓存后自动刷新 | 避免 Service Worker 立即重新填充造成困惑 |

## 4. 验收

- 新版本构建后，旧页面出现「新版本可用」提示；
- 点击刷新后加载新版本；
- `/about` 显示版本、数据契约、地图服务与仓库链接；
- 缓存占用与条目数可见；
- 清除缓存后页面刷新，缓存为空；
- 中英文案正确；
- 共享测试、Lint、Typecheck、Web 构建通过；
- 版本 `0.15.0`，双仓 tag `v0.15.0-m15`。
