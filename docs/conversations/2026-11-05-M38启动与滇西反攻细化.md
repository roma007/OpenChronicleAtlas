## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 以龙陵为事件地点 | 三条路线都经过龙陵，避免距离检查误报 |
| D2 | 中国与盟军路线分东西两轴 | 表现腾冲与松山两个方向 |
| D3 | 日军路线表现畹町—腾冲防御线 | 与反攻方向区分 |
| D4 | 复用既有松山事件为关联 | 避免重复建事件 |
| D5 | 搜索索引重新生成 | 事件数变化 |
