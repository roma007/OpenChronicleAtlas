## 1. 原始需求

用户：

> 继续

M12 已完成分享链接增强。当前时间轴只有刻度和当前事件文字，用户看不到事件在时间轴上的分布，也无法直接点击事件跳转。本轮进入 M13：时间轴事件标记。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 时间轴显示事件点 | ✅ | ✅ |
| F2 | 当前事件高亮 | ✅ | ✅ |
| F3 | 点击事件点跳转并打开详情 | ✅ | ✅ |
| F4 | 缩放后只显示视口内事件 | ✅ | ✅ |
| F5 | 与筛选/图层联动 | ✅ | ✅ |
| F6 | 共享事件标记计算 | ✅ | 共用 |

不在本轮范围：事件持续时间条、事件聚合、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 标记计算放 shared | Web / 移动端共用 |
| D2 | 标记只显示事件起点 | 当前数据没有 endDate |
| D3 | 标记随筛选与图层过滤 | 与地图 Marker 一致 |
| D4 | 缩放后只渲染视口内标记 | 避免溢出与拥挤 |
| D5 | 点击标记暂停播放并选中事件 | 与地图交互一致 |

## 4. 验收

- 时间轴出现事件点；
- 当前事件点高亮；
- 点击事件点跳到对应时间并打开详情；
- 缩放后只显示视口内事件；
- 切换图层/筛选后事件点同步变化；
- 共享测试、Lint、Typecheck、Web 构建通过；
- 版本 `0.13.0`，双仓 tag `v0.13.0-m13`。
