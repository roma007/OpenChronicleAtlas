## 1. 原始需求

用户：

> 继续

M44 已补国民党军追堵路线，但仍是笼统的「国民党军」。本轮补派系、部队与追击细节。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 路线命名 | 6 段 KMT 路线加派系/部队标注 |
| F2 | 事件命名 | 5 个 KMT 事件加派系/部队标注 |
| F3 | 新增事件 | 国民党军六盘山骑兵追击 |
| F4 | 新增路线 | 六盘山骑兵追击、赣—湘—黔追击路线 |
| F5 | 索引与版本 | `v0.45.0-m45` |

不在本轮范围：完整战斗序列、师级以下单位、页码级来源、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 派系写在路线/事件名中 | 地图与时间轴可直接看到 |
| D2 | 不新增派系实体 | 避免图例膨胀，保持 KMT 单层 |
| D3 | 新增六盘山追击事件 | 补 1935 年 10 月空档 |
| D4 | 新增赣—湘—黔追击路线 | 表现战略追击方向 |
| D5 | 番号标注待校订 | 避免把未核实部队写死 |

## 4. 验收

- 6 段 KMT 路线名称含派系/部队；
- 5 个 KMT 事件名称含派系/部队；
- 新增 1 个事件、2 段路线；
- 事件-路线抽查 0 个 >30km；
- 长征 37 事件 / 41 路线段；
- 全项目 133 事件 / 135 路线段；
- 版本 `0.45.0`，双仓 tag `v0.45.0-m45`。
