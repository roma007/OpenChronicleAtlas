## 1. 原始需求

用户提供 OpenReel 项目 Logo，并要求：

> 这是另一个 OpenReel 项目的 logo，现在根据这个 logo 开始设计本项目的 logo，颜色可以变，中间的三角播放图换成本项目的特点，其他不变。

第一版中心符号（细路线 + 三个小节点 + 小定位针）出稿后，用户反馈：

> 等等，路线和定位太细了，作为 logo 不合适，看不到那么多细节的。

## 2. 需求拆解

| 编号 | 需求点 | 类型 | 优先级 |
| --- | --- | --- | --- |
| R1 | 沿用 OpenReel 构图：深色圆角方底 + 右侧开口 C 环 + 内嵌徽章 | 视觉 | P0 |
| R2 | 中心播放三角替换为本项目「地图 + 时间轴」特征 | 视觉 | P0 |
| R3 | 配色可改，需适配史迹品牌 | 视觉 | P1 |
| R4 | 中心符号必须极简、够粗，缩小后仍可辨识 | 视觉 | P0 |
| R5 | 定稿后替换 Web / Tauri / iOS / Android 全端图标 | 落地 | P1 |

## 3. 讨论与决策

| 编号 | 议题 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 中心符号第一版 | 细路线 + 3 个事件节点 + 小定位针 | 信息完整，但缩小后细节丢失 |
| D2 | 用户反馈后的方向 | 去掉节点、描边与细线，改为「46px 粗路线 + 大定位针」单一剪影 | 仅保留针孔一个细节，32px 可读 |
| D3 | 画面结构 | C 环保留 OpenReel 的形态与开口方向 | 满足「其他不变」，形成家族感 |
| D4 | 配色 | 三选一：青铜·朱砂 / 青瓷·朱砂 / 靛蓝·鎏金；用户选定**青铜·朱砂** | 与项目既有暖色（深墨、青铜、朱砂）一致 |
| D5 | 图标落地 | Web 用直角全出血方图（PWA maskable）；iOS / Android 同样使用直角方图，由系统裁切；Android adaptive 用透明前景 + `#17120E` 背景 | 各平台裁切规则不同 |
| D6 | 用户真机反馈 | Logo 四角改为直角，不预制圆角；避免与系统圆角不一致造成边缘缺白 | 用户 2026-11-12 反馈 |
