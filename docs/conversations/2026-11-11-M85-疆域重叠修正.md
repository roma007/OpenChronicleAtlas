## 1. 原始需求

用户：

> 从图上看各国遮罩是重叠的，为什么？

需要解释重叠原因，并修正示意疆域数据，避免同一时期不同政权的面互相覆盖。

## 2. 原因

1. 早期疆域面按各政权独立绘制，未共用边界线；
2. 部分政权的时间区间重叠（如金 1115 起、北宋 1127 止；蒙古 1206 起、金 1234 止）；
3. 三国魏、汉、吴在荆州一带的粗略多边形互相侵入；
4. 唐与吐蕃在青藏高原东缘的边界未对齐；
5. 安史叛军控制区是唐境内的占领区，属于有意叠加。

## 3. 本轮范围

| 类型 | 修正 |
| --- | --- |
| 三国 | 魏、汉、吴、晋改用共享边界节点 |
| 宋元 | 北宋/辽、金/南宋、蒙古/金、元/南宋 对齐边界 |
| 隋唐 | 唐前期/后期与吐蕃边界分离 |
| 渲染 | 略提高描边不透明度，便于分辨相邻政权 |

## 4. 验收

- 同一时期不同政权不再出现明显重叠；
- 三国 230 年魏、汉、吴边界相接不重叠；
- 宋元 1120 年北宋与辽不重叠；
- 隋唐 640 年唐与吐蕃不重叠；
- 安史控制区仍作为唐境内占领区叠加，保留说明；
- 版本 `0.85.0`，双仓 tag `v0.85.0-m85`。
