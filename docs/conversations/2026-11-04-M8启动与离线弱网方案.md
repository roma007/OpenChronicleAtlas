## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | Web 使用 `vite-plugin-pwa` 生成 Service Worker | 避免手写缓存清单，构建期自动注入哈希资源 |
| D2 | 应用壳预缓存，数据与图片运行时缓存 | 数据包会更新，运行时缓存更灵活 |
| D3 | 数据用 `StaleWhileRevalidate` | 先显示缓存，再后台更新，弱网体验最好 |
| D4 | 地图瓦片 `CacheFirst` 且限制数量 | 已浏览区域离线可看，避免无限占用 |
| D5 | 移动端用 AsyncStorage 缓存原始 JSON | 不改变 shared 加载器，失败时回退 |
| D6 | 移动端不新增离线提示 | 避免再引入网络状态原生依赖，先保证可用 |

## 4. 验收

- Web 首次访问后断网，刷新仍能打开首页、专题页与已缓存数据；
- Web 离线时显示提示条；
- 移动端断网后可从缓存加载专题（逻辑与 typecheck 验证）；
- 缓存不会缓存高德 Key 或用户隐私数据；
- 版本 `0.8.0`，双仓 tag `v0.8.0-m8`。
