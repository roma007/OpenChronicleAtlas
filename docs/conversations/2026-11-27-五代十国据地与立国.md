# 五代十国：把「占据地方」与「立国」分开

- **日期**：2026-11-27
- **触发**：补完唐面后，用户指出「没有国家归属只是占据地方，与立国是两回事，在地图上的表现要区分开」。
- **诊断**：
  1. 此前疆域面只有「某政权 × 某时间段」，没有「是否已立国」这一维。结果是两个方向的错误：
     - 马殷 896 年已据湖南、刘隐 905 年已据岭南，但楚、南汉实体要到 907、917 年才出现，
       896—906 年湖南、905—916 年岭南在地图上没有任何归属；
     - 若简单把建国年提前到据地年，就等于把藩镇据地说成「立国」，同样失真。
  2. 907 年后的空白还有第二个来源：大量政权从未建模——岐、晋（河东）、燕、定难军、朔方军、
     归义军、甘州回鹘、吐蕃诸部、静海军、南诏系、播州、牂牁。榆林、银川、兰州、西宁、敦煌、
     贵阳、昆明、河内、太原、北京因此长期是空的。
  3. Cliopatria 对本时段只有粗切片（911—921、911—946、926—935、947—969、960—969），
     且不含晋、燕、定难、归义、静海，无法直接补齐。
- **决策**：
  1. 新增 `properties.extensions.polityStatus`：`state`（立国）/ `regime`（藩镇据地）/ `tribal`（部族羁縻），
     缺省为 `state`，不破坏既有 40 余个面。
  2. 立国口径取《十国春秋》与通行十国表的建国年（受封王爵、实际独立、国号见于史籍）；
     未入十国表的藩镇一律记为 `regime`，只有刘守光 911 年称大燕皇帝单列 `state`。
  3. 缺失政权用现代省/市/县界与唐面做交、差推导，全部标 `precision: schematic` 并逐面写 `note`；
     南诏—大理五面跨期借用 Cliopatria 大理 960—969 面，明确写「非当时实际疆界」。
- **处理**：
  - **样式层**：新增 `packages/shared/src/territory-style.ts`（`territoryPolityStatus`、
    `territoryVisualStyle`），立国实线、据地虚线且填充 ×0.55、部族点线浅填充中性灰；
    Web `MapCanvas`、移动端 `AtlasMap` 共用；标识斜体区分据地。
  - **图例**：`Legend.tsx` 在「时代疆域遮罩」下新增「疆域状态」三行说明（有非立国面时才出现），
    中英文案写入 `packages/shared/src/i18n/messages.ts`。
  - **标识防拥挤**：新增 `extensions.minLabelZoom`，定难、朔方、归义、甘州、吐蕃、播州、牂牁、
    静海、交趾、南诏系在缩放 < 5 时只显示面、不显示标识。
  - **据地切片**：吴越 893—906、杨吴 893—901、闽 893—908、前蜀 893—906、楚 896—906、
    南汉 905—916、荆南 907—923；吴越实线面起点由 893 改为 907，马楚由 927 改为 907。
    清源军、武平、福州（李仁达）标为 `regime`。
  - **新增实体与面**：岐、晋（河东，两段）、燕（据地 + 大燕）、定难军、朔方军、归义军、甘州回鹘、
    吐蕃诸部、静海军、交趾、南诏、大长和、大天兴、大义宁、大理、播州（杨氏）、牂牁诸部。
    疆域面 42 → 73，实体 21 → 38；唐末自专的岐（893）、晋（893）、燕（895 刘仁恭）、静海（905）也先按据地画出。
  - **唐面重切**：按 896（楚）、905（南汉）两个据地起点，把唐面由 2 段切成 4 段，每段减去同期
    所有非唐面，只留唐廷直接控制区，并写 `extensions.clipNote`；893 段约 170 万 km²、896/902 段约 132 万 km²、
    905 段约 103 万 km²。
  - **南汉补海南**：Cliopatria 南汉切片不含海南，按现代海南省主岛并入南汉面（含据地段）。
  - **凤翔府与秦州**：924 年岐国除后凤翔府（宝鸡）并入后唐、后晋、后汉、后周、北宋面；
    秦州（天水）属岐，前蜀面扣除；893—894 年幽州（李匡筹）名义属唐并入唐首段，895 年起由燕面覆盖。

  2. 南诏、大长和、大天兴、大义宁、大理共用一张大理国面，与 9—10 世纪实际疆界有出入。
