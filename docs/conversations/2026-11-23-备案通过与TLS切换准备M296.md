## 3. 域名与证书的区别（用户此问的直接答复）

| | 域名 | 证书 |
| --- | --- | --- |
| 是什么 | 地址，解析到 IP | CA 签发的身份证明文件 |
| 解决 | 能找到你 | 不报「不安全」、内容加密、地址栏出锁 |
| 依赖 | 注册商 | 绑定具体域名；一张单域名证书只能绑一个 |
| 缺失后果 | 打不开 | https 打不开；**Service Worker 无法注册**，PWA 离线能力失效 |

买了域名 = 有了地址；没有证书 = 没有 https，也没有 PWA。

### 4.2 请求单：TLS 切换（服务器）

`/srv/ops/requests/2026-11-23-atlas-to-quizgo-enable-443-tls.md`（255 行，可直接执行），要点：

| 项 | 内容 |
| --- | --- |
| 挂载 | `web.volumes` 增 `/srv/nginx/certs:/etc/nginx/certs:ro` |
| 兜底 | 新增 `conf.d/00-default.conf`：80 跳 Atlas，443 `ssl_reject_handshake on` |
| conf | `atlas.conf` / `quiz.conf` 全文给出（80→301、443 TLS、保留 8081/8082 调试口） |
| 顺序 | 改仓库 → 证书就位 → 只 recreate `web` → `nginx -t` → 同步 conf |
| 判据 | 切换时写 `state/exposure.json`（80/443=allowed，其余 blocked） |
| 红线 | 不开 HSTS（先跑 24h）、不删 8081/8082、证书不进仓库、只 recreate web |

为什么「先挂载后改 conf」：新 conf 引用 `/etc/nginx/certs/...`，挂载不存在时 `nginx -t` 直接失败。

### 4.3 状态脚本：自探判据可切换（服务器）

原 `status.sh` 把「80/443 超时」写死为正常。备案后这个判据必然长期告警，
`pnpm release` 的漂移闸门会被自己拦住。改为：

- 期望值从 `/srv/ops/state/exposure.json` 读，文件缺失时按全部 `blocked`（行为与之前一致）；
- 判据从 `curl` 改为 TCP 连接：`124`=拦、`0/1`=放行。原实现用 http 探 443，在 TLS 下会误判；
- 切换时由执行方写 `exposure.json`，不需要再改脚本。
