# 五代十国：给 34 个军事事件补攻方与守方路线

- **日期**：2026-11-28
- **触发**：上一轮把 56 个纯政治事件标为 `routeEvent: false` 后，`check:routes` 还剩 58 条告警，
  全部是 34 个军事事件的真实缺线。用户要求「给这 34 个军事事件补攻方行军线与守方防御/撤退线」。
- **做法**：
  1. 先按「事件 × entityId」列出每个事件缺的是攻方还是守方；
  2. 攻方补行军线（`advance` / `naval` / `counterattack`），守方补防线或撤退线（`defense` / `retreat`）；
  3. 同一次行动的路线首尾共用锚点，保持 `check:heads` 连续；
  4. 全部新线标 `precision: schematic`，只按史实地名与进军方向连点，不冒充实测。
- **新增**：`data/atlases/wu-dai-shi-guo/routes/military-extra.geojson` 35 段，manifest 已登记。
- **结果**：
  - `check:routes --atlas wu-dai-shi-guo`：58 → **0**；
  - `check:heads`：0 个无来由端点；
  - `check:land`：0 段穿越陆地（吴越援福州海路改为沿海航线）。
- **顺带勘误**（补线时发现，不改会把错误固化）：
