# 对话档案：郑和专题台湾注记

- **日期**：2026-11-17
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M164 方案](../plans/2026-11-17-M164-郑和专题台湾注记-design.md)、[M164 计划](../plans/2026-11-17-M164-郑和专题台湾注记-plan.md)、[M163 图例调整](../plans/2026-11-17-M163-郑和专题图例只保留两条航线-design.md)

## 1. 需求

用户看到郑和专题的明疆域面没有覆盖台湾本岛，问：

> 明朝时台湾不属于明吗？

并强调“这个是大问题”，要求查中国历史后确认。

## 2. 查证结论

| 层面 | 结论 |
| --- | --- |
| 正式行政疆域 | 台湾本岛不属于明；明朝没有在台湾设府县、派官、编户、征税 |
| 海防与对外主张 | 明朝把台澎视为东南海防要地，多次派兵入台追剿海盗倭寇，并在对外交涉中把台湾视为中国地方 |
| 澎湖 | 元设澎湖巡检司；明初沿置，1387/1388 废，1563 复设，1597 设澎湖游击；与台湾本岛分开 |
| 台湾正式设治 | 1661 年郑成功设承天府、天兴县、万年县；明郑是南明/明遗民政权，不是明朝本身 |
| 清朝 | 1683 年统一台湾，1684 年设台湾府 |

关键史料：

- 《明史》卷 45《地理六·福建》：福建布政使司领八府一州五十七县，海中有彭湖屿，无台湾府县；
- 明崇祯年间给事中何楷奏疏：台湾“中国版图所不载”；
- 清《续修台湾府志》：“台湾，古未隶中国版图”；
- 《道光福建通志台湾府》：“台湾府 康熙二十三年始入版图，立府”。

## 3. 决策

| 编号 | 议题 | 结论 |
| --- | --- | --- |
| D1 | 是否把台湾涂成明色 | 不涂；与正式行政疆域不符 |
| D2 | 是否完全不管 | 要说明明朝海防经营，避免误解为“明朝完全不知道台湾” |
| D3 | 表现形式 | 图例加“说明”块 + 地图上台湾本岛灰色描边与标识，不填充 |
| D4 | 数据实现 | 新增 `dongfan` 实体与 `opacity: 0` 的示意面；不进入图例 |
| D5 | 通用性 | `manifest.extensions.notes` 作为通用说明字段，Web 与移动端都读取 |

## 4. 本轮产出

- 新增 `dongfan` 实体与东番示意面；
- manifest 增加 `extensions.notes`；
- Web 图例、移动端筛选面板增加“说明”块；
- `scripts/build-zheng-he-territories.py` 支持按规则覆盖 `opacity`；
- `ATTRIBUTION.md` 记录东番为示意标注、不表示明朝疆域；
- 重建搜索索引与移动端生成物。

## 5. 验证

- 图例显示：“东番（台湾）：明朝海防要地，未设府县。”；
- 地图缩放至台湾可见灰色描边与“东番（台湾）· 未设府县”标识；
- 台湾本岛无明朝填充色；
- `pnpm validate:data`、`pnpm typecheck`、`pnpm lint` 通过。
