## 1. 原始需求

> 抗日战争，各事件和路线可以分省份和市县来展示吗？跨省/市的线路把起终点都显示即可，用户可以筛选省市县，另外能显示当时的省市县名称并绘制相应的地界吗？
>
> 按你的想法来做，做好完整的实施计划再开始实施。

## 2. 需求拆解

| 编号 | 需求点 | 类型 | 优先级 |
| --- | --- | --- | --- |
| R1 | 事件按省/市/县筛选 | 功能 | P0 |
| R2 | 路线按地区筛选 | 功能 | P0 |

| R4 | 显示当时省/市/县名称 | 数据/功能 | P0 |

## 3. 讨论与决策

| 编号 | 议题 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 是否按今天的地级市建层级 | 否；1930—1940 年代没有地级市 | 历史行政层级 |
| D2 | 省界数据来源 | 江山时序 `region` 图层（GPL-3.0，手工示意），不用 CHGIS 县界 | 许可与年代 |
| D3 | 县界是否绘制 | 本期不画；没有可自由再分发的民国县界矢量数据 | 数据许可 |
| D4 | 跨省路线是否裁剪 | 不裁剪；整条保留，6 级以上标端点 | 路线端点铁律 |
| D5 | 筛选是并集还是层级 | 最具体者优先；选县时省 id 被覆盖 | 避免按县退化为按省 |
| D6 | 地区归属在何时计算 | 构建期生成 `region-index.json`，运行时只做 Set 交集 | 性能/可复现 |
| D7 | 院辖市如何处理 | 单列一级地区，事件按地名归属；不画市界 | 数据可用性 |
