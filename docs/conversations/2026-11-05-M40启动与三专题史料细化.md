## 1. 原始需求

用户：

> 继续

M39 已完成抗日战争专题的史料细化，本轮把同样的方法应用到长征、郑和、玄奘三个专题。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 长征事件排序 | `events.json` 按日期稳定排序 |
| F2 | 别名补充 | 三个专题的主要事件补充通行别名 |
| F3 | 校订报告 | 覆盖 74 个事件的三专题报告 |
| F4 | 索引与版本 | `v0.40.0-m40` |

不在本轮范围：新增事件、页码级原文核对、图片、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 只补通行别名 | 不引入未经验证的异名 |
| D2 | 长征事件数组排序 | 修正永坪会师位置错位 |
| D3 | 三专题报告统一格式 | 与 M39 抗战报告一致 |
| D4 | 不修改坐标 | 本轮抽查未发现明显偏差 |
| D5 | 搜索索引重新生成 | 别名进入名称字段 |

## 4. 验收

- 长征事件数组按日期排序；
- 三专题别名可被搜索命中；
- 报告覆盖 74 个事件；
- 版本 `0.40.0`，双仓 tag `v0.40.0-m40`。
