## 3. 结构

```
桑植 → 陈家河 → 桑植
龙山 → 忠堡 → 龙山
龙山 → 板栗园 → 龙山
永顺 → 桑植 → 龙山
```

三次出击各从最近的根据地落点出发，回师线只保留战场至出击据点的一段，由苏区线（永顺—桑植、桑植—龙山）完成回到桑植、永顺的行程。十万坪不再是三条支线的共同起点。

## 4. 依据

- 陈家河在桑植县境，从桑植出击；
- 忠堡在咸丰县境，忠堡战斗本身就是围困龙山时的打援，从龙山出击；
- 板栗园在宣恩县境，从龙山北上；
- 桑植、龙山、永顺、来凤是 1935 年湘鄂川黔苏区的主要活动区域。
