# 2026-11-23 运河长时段航线不再慢速爬行（M290）

- **日期**：2026-11-23
- **参与者**：用户（项目负责人）、AI 开发助手
- **关联版本**：v1.0.272
- **关联文档**：[CHANGELOG](../changelog/CHANGELOG.md)、[京杭大运河人物工程 M289](2026-11-23-京杭大运河人物工程M289.md)

## 1. 用户看到的现象

「隋唐大运河 611 年后一直有两条线在慢慢沿着运河走，然后到 955 年一条走到开封一条到南京。」

这不是数据错位，是**航线日期语义**和**动画语义**不一致。

## 2. 哪两条线

- **洛阳—开封（汴河）**：`startDate 0611`、`endDate 0960`。
- **淮安—扬州（邗沟）**：`startDate 0605`、`endDate 0907`。

这两段的数据含义是「**使用期**」：

- 汴河从隋唐一直用到北宋；
- 邗沟从隋代一直用到唐末。

但地图的 `routeProgress` 把 `startDate → endDate` 当作「行进 / 施工进度」，于是：

- 汴河用 349 年从洛阳「走」到开封；
- 邗沟用 302 年从淮安「走」到扬州（扬州离南京很近，看起来就像走到南京）。

到 955 年，汴河接近开封、邗沟接近扬州，正好对应你看到的两条线。

## 3. 修法

1. `routeProgress` 增加 `staticUntilEnd`：
   - `static: true` 仍表示「起点后长期显示」；
   - `static: true, staticUntilEnd: true` 表示「只在起止日期内整段显示」。
2. 运河的**使用期航线**统一标 `staticUntilEnd`：
   - 4 汴河、5 开封—淮安、6 杭州—镇江、9—18 京杭大运河各段、19 黄河改道影响、20 邗沟。
3. **施工期航线**仍保留动画，因为它们是真正的工程过程：
   - 1 通济渠、2 永济渠、3 江南河、7 会通河、8 通惠河、21 济州河。

## 4. 效果

- 611 年通济渠、永济渠、江南河建成后，不再有长线慢慢爬行；
- 汴河、邗沟等使用期航线在起始年整段出现，在结束年整段消失；
- 1289—1293 年会通河、通惠河仍按施工过程逐段出现；
- 时间轴事件与航线不再「一边说 611 年贯通、一边画到 955 年」。
