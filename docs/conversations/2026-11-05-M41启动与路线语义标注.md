## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | `segmentType` 全量标注 | 让 M35 契约真正被数据使用 |
| D2 | 精度用 `extensions.precision` | 不新增 schema 字段，保持 v1.1 兼容 |
| D3 | 战役路线标 `campaign` | 与「战役路线」描述一致 |
| D4 | 示意路线标 `schematic` | 与「示意简化」描述一致 |
| D5 | 不改变几何与日期 | 只加语义元数据 |
