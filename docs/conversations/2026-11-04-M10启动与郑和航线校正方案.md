## 2. 抽查结果

使用与长征相同的脚本（优先当前活动段，其次最近完成段），发现 26 个事件中 **21 个偏差超过 50km**，典型问题：

| 问题 | 例子 | 原因 |
| --- | --- | --- |
| 返航事件不在航线上 | 第一次返航偏差 9342km | 航线只有去程，没有返程 |
| 出发事件不在起点 | 第二次下西洋偏差 4369km | 航段起始日期与事件日期不一致 |
| 港口事件偏离 | 占城 990km、满剌加 721km、锡兰山 976km | 单段跨度过长，线性插值偏离 |
| 分䑸事件绑定主船队 | 榜葛剌事件同时绑定 ming-fleet | 主船队未访问榜葛剌 |
| 政策事件被当作航行 | 仁宗停止下西洋（北京） | 非路线事件 |

## 3. 修正方案

| 编号 | 决策 | 说明 |
| --- | --- | --- |
| D1 | 每次航行拆为去程 + 返程 | 返航事件回到太仓 |
| D2 | 在事件日期处切段 | 占城、满剌加、锡兰山、古里、忽鲁谟斯、麻林地、阿丹等 |
| D3 | 第二、三次航行起始日期改为事件日期 | 1408-10-01、1410-01-01 |
| D4 | 榜葛剌事件只绑定分䑸 | 主船队未访问榜葛剌 |
| D5 | 仁宗停止下西洋标记为非路线事件 | `extensions.routeEvent = false` |
| D6 | 航线补充返程节点 | 古里—锡兰山—满剌加—占城—泉州—太仓 |
