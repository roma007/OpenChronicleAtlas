## 1. 原始需求

用户先问「陕甘边第一次反“围剿”算是长征的部分吗」，随后指出：

> 你确定第一次反“围剿”的意义在于：它让陕北、陕甘边苏区活了下来吗？哪个文献里说的？

确认这句是没有原文依据的概括后，用户要求：

> 那就把陕甘边的历史充分补上，做个实施计划，按计划执行

（后经用户澄清：目标是补全陕北红军从第一次反围剿到长征结束的全部历史，见 [陕北红军全史补全](2026-11-16-陕北红军全史补全.md)。）

## 2. 先改口：那句话错在哪

- 「活了下来」是通俗概括，文献原文是「粉碎 / 挫败围剿」「巩固并扩大根据地」「解放十几个县」，没有一本说「苏区因此得以生存」。
- 把「陕北、陕甘边」并称也不准确：1934 年这轮围剿是两个战场——陕甘边 2—6 月（刘志丹、红 42 师），陕北 7—8 月（谢子长、陕北游击队），陕北方向到 8 月才进入高潮。

## 4. 改了什么

- order 1 改为「照金—包家寨—南梁（重心北移）」1933-10-12—1934-11-06，类型 advance；
- 新增 order 7「南梁—西华池—三里塬—南梁（第一次反“围剿”外线）」1934-03-01—05-31；
- 新增 order 8「南梁—安定（红三团北上陕北）」1934-07-23—08-15；
- 新增 5 个事件：包家寨会议、陕甘边区革命委员会、西华池战斗、三里塬战斗、陕北苏区第一次反“围剿”；
- 「陕甘边第一次反“围剿”」事件移到南梁、改正表述与战果，并指向陕北方向的事件；
- 南梁坐标统一为 `108.34,36.40`；实体描述补 1931—1935 年脉络与落脚点定位；
- order 2、3 描述按周家硷会议、第二次反“围剿”重写。

劳山、榆林桥原已挂在 `red-15-army` 条下（事件 `laoshan-1935-10`、`yulinqiao-1935-10`），本批不重复建，避免同一战果记在两个实体上。

## 5. 顺手发现的问题（未在本批改线）

order 5「永坪—吴起」、order 6「吴起—直罗镇」描述原为「陕北红军由吴起镇南下直罗镇」，但没有直接史料：永坪会师后陕北红军编入红十五军团，主力由永坪南下甘泉、富县，红十五军团只派郭洪涛、程子华前往迎接中央红军，军团并未开往吴起。

本批把 order 5 描述改为「时间轴示意衔接线，不代表陕北红军主力开往吴起」，并在台账 L6-6 记为待办；重划或删除留待下一批（需同时处理吴起、直罗镇两个事件的实体归属）。
