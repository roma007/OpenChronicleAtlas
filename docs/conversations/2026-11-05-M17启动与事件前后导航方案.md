## 1. 原始需求

用户：

> 继续

时间轴可以点击事件点，但打开详情后只能关闭再找下一个事件。本轮进入 M17：事件前后导航。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 详情内「上一事件 / 下一事件」 | ✅ | ✅ |
| F2 | 按当前筛选与图层排序 | ✅ | ✅ |
| F3 | 键盘快捷键 | ✅ | — |
| F4 | 首尾事件禁用 | ✅ | ✅ |
| F5 | 共享邻居计算与单测 | ✅ | 共用 |

不在本轮范围：事件自动播放、关联事件图、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 邻居按事件日期排序 | 与时间轴顺序一致 |
| D2 | 使用当前筛选后的集合 | 导航不跳出用户当前上下文 |
| D3 | 当前事件不在筛选集合时回退全量 | 避免无导航 |
| D4 | Web 使用 Alt+← / Alt+→ | 不与时间轴方向键冲突 |
| D5 | 点击后暂停并跳到事件日期 | 与事件点行为一致 |

## 4. 验收

- 详情显示上一/下一事件；
- 点击后跳转并更新详情；
- 首尾事件按钮禁用；
- 键盘 Alt+← / Alt+→ 可用；
- 筛选后导航只走当前筛选集合；
- 共享测试、Lint、Typecheck、Web 构建通过；
- 版本 `0.17.0`，双仓 tag `v0.17.0-m17`。
