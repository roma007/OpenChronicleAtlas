## 1. 原始需求

用户：

M6 已完成地图聚合与时间轴缩放。按原始需求 §6.6「多语言：中文为主，预留 i18n（英文），数据字段支持多语言对象」，本轮进入 M7：中英双语。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 中 / 英界面切换 | ✅ | ✅ |
| F2 | 界面文案双语化 | ✅ | ✅ |
| F3 | 专题、实体、事件、地点英文字段 | ✅ | 共用数据 |
| F4 | 日期按语言格式化 | ✅ | ✅ |
| F5 | 英文检索（名称/摘要/地点/类型） | ✅ | ✅ |
| F6 | 英文隐私政策 | ✅ | 隐私同意页 |

不在本轮范围：APK/IPA 打包、离线缓存、新增专题、商店提审。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 语言状态放共享类型，各端各自持有 | Web 用 localStorage 持久化；移动端先会话内切换 |
| D2 | 文案字典放 `packages/shared/src/i18n/messages.ts` | 三端共用，避免两套翻译 |
| D3 | 数据翻译直接写入数据包 `en` 字段 | 保持数据自包含，不依赖运行时翻译 |
| D4 | 检索索引继续合并所有语言 | 中英文关键词都能命中，无需切换语言再搜 |
| D5 | 英文缺失时回退中文 | 渐进翻译，不出现空白 |
| D6 | 分类名使用映射表 | 数据里的 category 保持稳定中文键，展示层翻译 |
