## 2. 一个容易被抹平的差别

这五个军当时**不都叫「人民革命军」**：

| 军 | 当时番号 |
| --- | --- |
| 第一、二、三、六军 | 东北人民革命军 |
| **第四军** | 东北抗日**同盟军**第四军 |
| **第五军** | 东北**反日联合军**第五军 |

三套名字分别对不同的统战对象：人民革命军对中共游击队，同盟军对救国军余部，
反日联合军对义勇军与山林队。名字本身就是统战工具。

所以第五军按当时番号写「东北反日联合军第五军」，1936-02 才改称抗联第五军；
不为了整齐提前统一。

## 3. 第四军为什么没做

东北抗日同盟军第四军（李延禄）成立于 1934 年，但各源只到月份，没有确切日期。
按纪律不硬填，留待下一批。

## 4. 一个小事故

第一版脚本把 `description` 写成 `{zh, en}`，与 `ev()` 读取的 `descZh/descEn` 不一致，
validate 直接报 5 条 `description: Invalid input`。修正 `ev()` 后重跑，数据无残留。

这也说明流水线的价值：写错了不会静默入库。
