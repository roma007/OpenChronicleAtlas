# 对话档案：M153 苏区三战回师

- **日期**：2026-11-16
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M153 计划](../plans/2026-11-16-M153-苏区三战回师-plan.md)、[M153 方案](../plans/2026-11-16-M153-苏区三战回师-design.md)

## 1. 原始需求

用户：

> 红二方面军，忠堡大捷、板栗园大捷、陈家河战斗这三个节点为什么都是从十万坪大捷节点长出来然后就都断头，而同时还有一条线从十万坪大捷节点继续走？

## 2. 原因

三段是 M52（2026-11-06）加的「苏区支线」，只画了从永顺出击的一段，回师路线没画；「继续走」的那条是苏区主线「永顺—桑植」。

三段都从永顺起，是因为 M52 用永顺作苏区锚点统一起画，并没有按各自最近的根据地落点分线。

## 3. 史实

1935 年 2—8 月反「围剿」期间，三次战斗都是**从苏区出击、战后回师**：

- 陈家河（4/13，桑植县境）→ 回师桑植，恢复桑植县城；
- 忠堡（6/12，咸丰县境）→ 经龙山县境回师桑植、永顺；
- 板栗园（8/3，宣恩县境）→ 经鹤峰县境回师桑植、永顺。

## 4. 修法

新增三段 `retreat` 回师线：

| order | 路线 | 日期 |
| --- | --- | --- |
| 13 | 陈家河—桑植 | 4/14 |
| 14 | 忠堡—龙山—桑植 | 6/13—6/15 |
| 15 | 板栗园—鹤峰—桑植 | 8/4—8/6 |

三段回师线与出击线、苏区主线形成闭环：

```
永顺 → 陈家河 → 桑植 → 永顺
永顺 → 忠堡 → 龙山 → 桑植 → 永顺
永顺 → 板栗园 → 鹤峰 → 桑植 → 永顺
```

## 5. 保留的简化

出击线仍从永顺（十万坪）起画，这是 M52 的苏区锚点简化。严格按地理，陈家河应从桑植出击、忠堡应从龙山、板栗园应从鹤峰；要这样改需要先补「桑植—龙山」「桑植—鹤峰」两条苏区内部机动线，属于下一步的苏区网络细化。
