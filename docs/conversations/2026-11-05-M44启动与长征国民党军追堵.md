## 1. 原始需求

用户：

> 还是太少了，比如长征国民党围堵部队的一个都没有

长征专题已有 `kmt-army` 实体，但没有路线与事件。本轮补齐国民党军追堵、封锁线及对应事件。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | KMT 路线文件 | 新增 `routes/kmt-army.geojson`，6 段封锁/进攻线 |
| F2 | KMT 事件 | 湘江封锁、乌江防线、金沙江封锁、大渡河防线、腊子口封锁 |
| F3 | 直罗镇事件 | 加入 `kmt-army` 实体 |
| F4 | 实体描述 | 更新国民党军实体说明 |
| F5 | 索引与版本 | `v0.44.0-m44` |

不在本轮范围：国民党军师级序列、详细战斗序列、页码级来源、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | KMT 路线用独立文件 | 与红军路线分色、分图层 |
| D2 | 5 个封锁/追堵事件 | 对应长征关键节点 |
| D3 | 直罗镇复用既有事件 | 避免重复建事件 |
| D4 | 路线标为示意简化 | 缺乏精确部队行军图 |
| D5 | 搜索索引重新生成 | 事件数变化 |

## 4. 验收

- 6 段 KMT 路线、5 个 KMT 事件；
- 直罗镇事件包含 `kmt-army`；
- 事件-路线抽查 0 个 >30km；
- 长征 36 事件 / 39 路线段；
- 全项目 132 事件 / 133 路线段；
- 版本 `0.44.0`，双仓 tag `v0.44.0-m44`。
