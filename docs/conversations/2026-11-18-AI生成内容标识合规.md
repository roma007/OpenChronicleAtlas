# 对话档案：AI 生成内容标识合规

- **日期**：2026-11-18
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：
  - [AI 生成内容标识与提审口径](../guides/ai-content-labeling.md)
  - [决策：AI 生成内容标识口径](../decisions/2026-11-18-AI生成内容标识口径.md)
  - [用户协议 AI 内容条款草案](../legal/user-agreement.draft.md)
  - [来源与许可](../../data/atlases/ATTRIBUTION.md)

## 1. 需求

用户给出《人工智能生成合成内容标识办法》
（https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm），要求检查项目是否有相关内容，
并按 **P0 + P1 + P2** 全部落地。

## 2. 审计结论

项目原有内容：

- 11 张专题封面由豆包 AI 生成，图片右下角保留「豆包 AI 生成」水印；
- `data/atlases/ATTRIBUTION.md` 写明封面为 AI 生成示意插画；
- Web 关于页可打开 `ATTRIBUTION.md`。

缺口：

- 界面没有文字标识，只有图片小水印；
- 移动端没有「关于/来源」入口；
- 封面 JPEG 没有 AIGC 隐式元数据；
- 商店材料没有回答「是否提供 AI 生成合成服务」；
- 专题文本的 AI 参与未披露；
- 没有用户协议或未来 AI 功能条款。

适用性判断：本项目是静态历史地图，不提供生成式 AI 服务，不直接适用《标识办法》
第四条、第五条的主要义务；但含 AI 生成封面，需按第七条向商店如实声明，并主动标识。

## 3. 落地内容

### P0

- Web `AtlasCard` 与移动端 `GalleryScreen` 封面左下角增加「AI 生成示意图」角标；
- Web 关于页新增「人工智能生成内容说明」一节；
- `ATTRIBUTION.md` 新增 AIGC 专节；
- 商店中文/英文元数据与提交指南补「不提供生成服务、包含 AI 生成封面」口径；
- 新增 `docs/guides/ai-content-labeling.md`。

### P1

- 新增 `scripts/aigc-labels.ts`、`pnpm check:aigc` / `pnpm apply:aigc`；
- 11 张封面写入 XMP `TC260:AIGC`，字段：
  `Label=1`、`ContentProducer=豆包（字节跳动）`、
  `ContentPropagator=史迹 · 时空地图（OpenChronicle Atlas）`；
- 写入后按内容 MD5 重命名，manifest、`index.json`、搜索索引、移动端内置数据同步重建；
- 新增 `data/atlases/ai-content.json` 封面登记表；
- 移动端新增 `AboutModal`，可从首页页脚打开版本、AI 说明与来源链接。

### P2

- README 第八节补 AI 生成内容说明；
- `docs/legal/user-agreement.draft.md` 起草 AI 内容条款，覆盖标识义务、分享保留标识、
  未来生成功能与日志要求；
- 发布检查清单补 AI 声明、水印、元数据与登记表校验项。

## 4. 验证

- `pnpm validate:data`：11 专题 / 981 事件 / 641 路线段，AIGC 校验通过；
- `pnpm typecheck`：通过；
- `pnpm lint`：通过；
- `pnpm test`：通过；
- `pnpm build`：Web 构建通过；
- `pnpm build:mobile-data --check`：移动端内置数据映射为最新；
- 11 张封面均为 1600×900，文件名与 MD5 一致，XMP 字段解析正确；
- 打开《长征》封面确认「豆包 AI 生成」水印仍在。

## 5. 发布

版本由钩子从 `1.0.111` 升到 `1.0.112`，提交后执行 `pnpm release`。
