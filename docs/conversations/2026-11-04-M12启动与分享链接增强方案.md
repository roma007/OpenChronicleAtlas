## 1. 原始需求

用户：

> 继续

M11 已完成移动端收尾。当前分享链接只保存专题、时间点、事件与地图视野，打开后语言、图层与筛选状态会丢失。本轮进入 M12：分享链接增强。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 分享链接保存语言 | ✅ | ✅ |
| F2 | 分享链接保存图层开关 | ✅ | ✅ |
| F3 | 分享链接保存事件类型筛选 | ✅ | ✅ |
| F4 | 分享链接保存时间段筛选 | ✅ | ✅ |
| F5 | 打开链接后恢复上述状态 | ✅ | ✅ |
| F6 | 非法参数安全忽略 | ✅ | ✅ |

不在本轮范围：服务端短链、二维码、分享统计、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 新增 `locale`、`entities`、`categories`、`from`、`to` 参数 | 覆盖当前可分享的视图状态 |
| D2 | 实体与类型使用逗号分隔 | URL 短、易读、易校验 |
| D3 | 恢复时与专题实际实体/类型取交集 | 防止旧链接注入不存在的 ID |
| D4 | 语言只接受 `zh` / `en` | 与现有 Locale 一致 |
| D5 | 日期参数复用现有日期校验 | 防止非法日期 |
| D6 | 移动端复用同一 `decodeShareState` | 保持三端一致 |

## 4. 验收

- 分享链接包含语言、图层、类型、时间段；
- 打开链接后语言、图层、筛选与时间点正确恢复；
- 非法实体/类型/日期被忽略，不导致崩溃；
- 现有分享链接仍可打开；
- 共享测试、Lint、Typecheck、Web 构建通过；
- 版本 `0.12.0`，双仓 tag `v0.12.0-m12`。
