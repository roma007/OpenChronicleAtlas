## 1. 原始需求

本轮聚焦抗日战争专题的史料与坐标细化，不新增战役。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 事件排序 | `events.json` 按日期稳定排序 |
| F2 | 坐标修正 | 平型关事件坐标改为 113.75, 39.34 |
| F3 | 别名补充 | 为主要战役补充通行别名 |
| F4 | 校订报告 | 新增史料与坐标校订文档 |
| F5 | 索引与版本 | `v0.39.0-m39` |

不在本轮范围：新增战役、页码级原文核对、图片、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 只修正有把握的坐标 | 避免用推测替换现有近似值 |
| D2 | 别名采用通行史称 | 提升搜索召回，不改变正式名 |
| D3 | 事件数组按日期排序 | 便于人工审阅，加载器仍会排序 |
| D4 | 校订报告列出全部 44 个事件 | 形成可追溯的检查基线 |
| D5 | 页码级来源继续标注待核对 | 无原书情况下不虚构页码 |

## 4. 验收

- 平型关坐标修正且事件-路线检查通过；
- 事件数组按日期排序；
- 主要战役别名可被搜索命中；
- 校订报告覆盖全部事件；
- 版本 `0.39.0`，双仓 tag `v0.39.0-m39`。
