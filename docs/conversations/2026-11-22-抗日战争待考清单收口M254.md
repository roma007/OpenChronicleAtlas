## 1. 为什么收口

M236—M253 逐批销号后，剩下来的县已经全部落在三类：

1. 只有月份级记载（南伞、片马、罗城/天河、思恩/宜北、桦甸/磐石、富锦/穆棱…）；
2. 只有单一来源（芮城、武陟、太康/陈留/偃师、南伞…）；
3. 两说或三说冲突（昌图、敦化、宁安、绥化、青龙、丰宁、嵩县、融县长安镇、来宾县城）。

再逐批网搜，只会把同一批网页再查一遍，不会产生可核查的新日期。按「宁可少一条，不可错一条」，
把清单从「待考」改成「结案」，并写明**已查来源 + 冲突点 + 结论**，比继续挂着更有用。

## 2. 口径

| 标记 | 含义 |
| --- | --- |
| 结案：史料不足 | 月份级或单一来源，暂不录入；拿到县志/档案/当时报刊再开 |
| 结案：冲突未决 | 两条以上来源但日期互斥，暂不录入，不选边、不改日期凑好看 |
| 结案：不按县城处理 | 渡口（风陵渡）、1935 年即日控（唐山、秦皇岛）、并入已有事件（沙市） |
| 结案：不单独立事件 | 属战役战场（渔洋关、都镇湾） |
| 转空袭专题 | 空袭不属「县城沦陷」，另设专题 |
