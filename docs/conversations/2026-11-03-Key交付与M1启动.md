## 1. 原始需求

用户完成三端 Key 申请，并把控制台信息发给开发助手：

> 申请完了，拿去用吧：web / iOS / android 三个 Key，以及 Web 端安全密钥。

用户意图：**把 Key 交给项目使用，开始 M1 开发**。

## 2. 安全处理（重要）

| 事项 | 处理 |
| --- | --- |
| Key 明文 | **不写入仓库、不写入任何 docs、不写入 CHANGELOG** |
| 存放位置 | 仅写入本地 `apps/web/.env.local`、`apps/mobile/.env.local`（已 gitignore） |
| 聊天暴露 | 用户在对话中粘贴过 Key；建议上线前在高德控制台**重置 Web 安全密钥**，必要时重建 Key |
| 文档记录 | 只记录「已配置」状态与变量名，不记录值 |
| 备份 | release keystore 与口令仍需离线备份（见 `docs/guides/amap-setup.md` §4） |

> 本档案及后续提交中出现的 Key 一律以「已配置」描述；如发现任何文档含明文 Key，视为安全事故，需立即重置并清理历史。
