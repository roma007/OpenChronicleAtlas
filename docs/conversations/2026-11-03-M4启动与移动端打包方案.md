## 3. 讨论与决策

| 编号 | 议题 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 移动端地图库 | `expo-gaode-map`（Expo Modules + Config Plugin） | ADR-0004 / ADR-0007 |
| D2 | 导航 | React Navigation native-stack | ADR-0007 |
| D3 | 数据来源 | 远端 `/data/atlases` URL，与 Web 同一套数据；不打包副本 | 需求 §三 |
| D4 | 时间轴 | 复用 shared `timeline`，RN 用 PanResponder + rAF | 架构一致性 |
| D5 | 详情 | 底部抽屉 + Markdown（RN 渲染器） | 交互一致性 |
| D6 | 分享 | `Share.share` + deep link；M5 再做 universal link | 需求 §六 |
| D7 | Android 打包 | 本地 prebuild + Gradle（keystore 在仓库外）；EAS 作为备选 | 环境已具备 |
| D8 | iOS 打包 | 本地 Xcode + 签名；无 Apple 账号时先出模拟器包/未签名 archive | 环境已具备 Xcode 26.6 |
| D9 | 隐私 | 首次启动隐私同意后再初始化地图 SDK；不申请定位权限（M4 无定位） | 合规 |
| D10 | 文档先行 | 先提交 M4 plan/design/ADR-0007，确认后编码 | 铁律 |

## 6. 实施结果（2026-11-04）

| 项 | 结果 |
| --- | --- |
| 移动端页面 | React Navigation：专题列表 / 地图 / 搜索 |
| 地图 | `expo-gaode-map`：底图、路线、Marker、当前事件高亮 |
| 时间轴 | 拖动、播放/暂停、倍速、日期输入、刻度 |
| 详情/筛选 | 底部抽屉、Markdown、分享、实体/类型/时间段筛选 |
| Android | release APK 构建成功，release keystore 签名，API 34 模拟器安装运行；地图/时间轴/搜索/详情可用 |
| iOS | 模拟器构建编译成功（x86_64），但 AMap iOS SDK 无 arm64 模拟器切片，arm64 Mac 模拟器无法安装运行 |
| 检查 | typecheck / lint / test / build / validate:data 通过 |

**环境与偏差**：

- Gradle 9.4.1 从 services.gradle.org/GitHub 下载超时，改用华为镜像并本地运行。
- `pod install` 在中文路径下 hermes podspec 编码报错，设置 `HERMES_ENGINE_TARBALL_PATH` 绕过。
- 开发期 HTTP 数据：Android 开启 `usesCleartextTraffic`，iOS 允许本地网络。
- RN 不支持 SVG 封面，新增 JPEG 版本。
- Hermes 缺少中文 locale，shared 中文日期改为手动格式化。
- Android 详情/筛选 Modal 改为全屏（iOS 仍 pageSheet）。
- iOS IPA 仍受 Apple Developer 账号与 AMap SDK 模拟器限制。
