## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 错误边界 | 捕获渲染异常，显示可恢复的兜底页 |
| F2 | 错误记录 | 生成错误编号，写入 console 与 sessionStorage |
| F3 | 全局监听 | `error` 与 `unhandledrejection` |
| F4 | 中英文案 | 兜底页与错误编号文案 |
| F5 | 测试与版本 | 纯函数单测、`v0.33.0-m33` |

不在本轮范围：服务端上报、第三方监控 SDK、移动端错误边界、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 仅本地记录，不联网上报 | 避免隐私与合规风险 |
| D2 | sessionStorage 最多保留 20 条 | 便于用户复现，不长期占用 |
| D3 | 生成可读错误编号 | 方便用户反馈与日志定位 |
| D4 | 兜底页提供「重新加载 / 返回专题」 | 让用户可自行恢复 |
| D5 | 全局监听与 ErrorBoundary 共用记录函数 | 统一格式 |

## 4. 验收

- 渲染异常时显示兜底页，不白屏；

- 中英文兜底文案完整；
- lint / typecheck / test / build 通过；
- 版本 `0.33.0`，双仓 tag `v0.33.0-m33`。
