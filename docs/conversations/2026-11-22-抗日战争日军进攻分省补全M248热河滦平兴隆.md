## 1. 本批目标

M231 留下滦平、青龙、兴隆、丰宁。本批滦平、兴隆补到可核查来源，
补 2 个事件、2 段路线；青龙、丰宁因日期三说冲突继续待考。

## 2. 实施

### 2.1 事件（新增 2，日军 769 → 771）

- **滦平** 1933-03-05：日军占承德后沿平热大道追击，上午 11 时占滦平县城喀喇河屯；
  同日青石梁阻击战打响，为古北口长城抗战第一枪。
- **兴隆** 1933-04-21：日军侵占兴隆县城，04-27 被萧之楚部克复，29 日夜县府被焚。

### 2.2 路线（2，#382—#383）

承德—滦平（趋古北口）、承德—兴隆。

### 2.3 地区索引

增加滦平县、兴隆县。地区 853 → 855 个。

## 3. 史料与主体核对

- 滦平取 03-05（网信滦平、双滦事、高思文，三源一致）。
- 兴隆取 04-21（兴隆县人民政府《历史沿革》），《申报》1933-05-03 专电与郭廷以日志
  记 04-27 克复，可相印证；高思文记 03-21，异说并存。
- **主体**：全部为日军进攻/占领，统一挂 `japanese-invasion`；萧之楚部只作背景。
- **归属**：兴隆 1933 年属河北省，伪满 07-01 划归热河省承德县；按伪满区划归热河，
  正文注明 1933 年属河北，避免归属错乱。
- **不硬录**：青龙（03-05 轰炸 / 03-08 侵占 / 3 月底占领三说）、丰宁（03-27 与 04-02 冲突）。
