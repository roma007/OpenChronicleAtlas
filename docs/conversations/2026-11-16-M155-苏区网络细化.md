## 1. 原始需求

用户：

> 继续

承接 M154 末尾的提议：继续细化苏区网络。

## 2. 核对发现

继续核对点位时发现两处战斗坐标偏差较大：

| 事件 | 原坐标 | 实际点位 | 偏差 |
| --- | --- | --- | --- |
| 忠堡大捷 | 109.15, 29.55 | 忠堡镇 109.273, 29.676 | 约 15km |
| 板栗园大捷 | 109.49, 29.99（宣恩县城） | 板栗园村 109.408, 29.66 | 约 38km |

原坐标是县域代表点，事件还没有标 `locationPrecision`，所以地图上忠堡偏西南、板栗园直接落在宣恩县城。

## 3. 修法

- 忠堡、板栗园坐标改为 OSM 镇/村点，补 `locationPrecision: approx`；
- 两次出击改从来凤出发，回师回来凤；
- 新增「龙山—来凤」苏区内部机动线，把来凤接回桑植—龙山—永顺苏区。

结构：

```
永顺 → 桑植 → 龙山 → 来凤
来凤 → 忠堡 → 来凤
来凤 → 板栗园 → 来凤
桑植 → 陈家河 → 桑植
```

## 4. 验证

- 来凤 → 忠堡、来凤 → 板栗园 0.00km；
- 忠堡、板栗园事件在出击线终点 0.00km；
- `validate:data` 11 专题 / 844 事件 / 641 路线段；`check:routes` 0 问题；
- 数据版本 `2026-11-16-acdfe43ae376`。
