# 明清疆域细切片（M299）

- **日期**：2026-11-23
- **触发**：用户提问「明清专题，清军入关前的疆域为什么只有明的？」
- **结论**：不是渲染问题，是数据取法问题——原疆域面只取了 Cliopatria 的
  1400/1500/1600/1700/1800/1900 六个百年快照，1600 快照里没有后金，
  最早含清的切片是 1700，M89 又把它的起点定在 1644-05-01。

## 排查

1. `data/atlases/ming-qing/territories/territories.geojson` 原只有 6 个要素：
   明 1400/1500/1600，清 1700/1800/1900。
2. `apps/web/src/components/map/MapCanvas.tsx` 的 `applyTerritoryVisibility`
   只按 `startDate ≤ currentTime ≤ endDate` 开关，没有最近快照兜底，
   所以 1616—1644 年图上没有任何清的疆域面。
3. 1600 明快照 bbox 北界 42.8°N、东界 124.7°E，本身也不含满洲腹地，
   于是赫图阿拉、盛京一带在图上完全空白。
4. 事件层已有 `houjin-1616`、`sarhu-1619`、`shengjing-chushi-1644`，
   但疆域层没有对应面，形成「有事无地」的矛盾。

## 处理

- 下载并核对 Cliopatria `cliopatria_polities_only_v021.geojson`，
  确认源数据有 `Later Jin Dynasty` 1619—1644 与 `Qing Dynasty` 1645—1911 的逐年段切片，
  还有 `Southern Ming` 1645—1658。
- 在 `scripts/import-cliopatria-territories.py` 增加 `MING_QING_SERIES` 与
  `ming_qing_rules()`，按实体与时段生成规则，并加 `--atlas=ming-qing` 过滤。
- 重跑生成 99 个疆域面；新增 `houjin`、`nanming` 两个实体。
- 1636—1644 的源数据切片仍叫 Later Jin Dynasty，按史实挂 `qing` 并加注。
- 不采用 Southern Ming 1662—1672（台湾，属明郑）与 1673—1682（三藩之乱范围）。
- 南明 1653—1658 落在清全国面内，`MapCanvas` 疆域面改为按 `properties.order` 抬 `zIndex`，
  南明三段 `order = 1`，保证叠色可见。
- 详细出处与不采用理由见 `docs/research/units/ming-qing-territories.md`。

## 验证

- `pnpm validate:data` / `typecheck` / `lint` / `test` / `build` /
  `build:search-index` / `build:mobile-data --check` 全部通过。
- 逐实体时段连续；99 个 `labelPoint` 均在面内。

## 遗留

- 南明 1653—1658 与清 1653—1658 在云南重叠约 20 万 km²，源数据自身矛盾；
  南明三段 `order = 1`，渲染时压在清面之上以叠色显示。
- 明清路线仍为示意简化，端点核查另见 `docs/research/route-endpoints/ming-qing.md`。
