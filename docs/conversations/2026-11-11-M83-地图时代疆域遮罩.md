## 1. 原始需求

用户：

> 这个留作待办，现在在地图上增加当时代的地理分布半透明遮罩

即：把此前讨论的待办留档，本轮优先在地图上增加随时间变化、半透明的时代地理分布（疆域）遮罩。

## 2. 本轮范围

| 类型 | 新增 |
| --- | --- |
| 数据契约 | `manifest.territories`、`AtlasTerritoryFeature`（Polygon / MultiPolygon） |
| 共享层 | 类型、schema、loader、跨文件校验、单元测试 |
| Web 地图 | 疆域多边形图层、时间/实体过滤、显示开关 |
| 专题数据 | 隋唐 5 面、宋元 6 面、三国 4 面 |
| 文档 | schema 文档、计划、方案、发布说明 |

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 用可选 `territories` 扩展而不是改既有 routes | 保持数据契约 1.1.0，向后兼容 |
| D2 | 面按 `entityId` 取实体色，默认透明度 0.16 | 与路线、图例视觉统一 |
| D3 | 面只作背景，不参与事件-路线距离校验 | 避免示意边界影响既有 QA |
| D4 | 时间轴 + 实体开关双重过滤 | 遮罩随时代演进，且可与图层联动 |
| D5 | 先接入隋唐、宋元、三国 | 政权地理明确；其余专题实体为人物/船队/运河，暂不铺面 |
| D6 | 新增「时代疆域遮罩」开关 | 用户可一键隐藏，避免遮挡路线 |
