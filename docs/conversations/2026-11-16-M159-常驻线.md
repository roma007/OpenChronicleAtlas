# 对话档案：M159 常驻线

- **日期**：2026-11-16
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M159 计划](../plans/2026-11-16-M159-常驻线-plan.md)、[M159 方案](../plans/2026-11-16-M159-常驻线-design.md)

## 1. 原始需求

用户：

> 龙山县出发去了忠堡大捷和板栗园大捷两个节点，但问题是红二方面军为什么突然从龙山县冒出来？

## 2. 原因

不是缺线，是渲染方式：

- 桑植—龙山（order 16）、龙山—来凤（order 17）是 1934-11-16 至 1935-11-19 的苏区内部机动线；
- 地图按日期线性推进每段路线，到 1935-06-12 时 order 16 只画到约 56%，还没到龙山；
- 于是忠堡、板栗园从龙山起画时，桑植—龙山还没画到龙山，看起来就是凭空出现。
- 永顺—桑植（order 2）同理，6 月只画了一半。

## 3. 修法

- 路线扩展新增 `static: true`；渲染时常驻线进入起始日后整段显示，不再按日期截断；
- 标记 order 2、16、17 为常驻线。

## 4. 效果

1935-06-12 与 1935-08-03 时，永顺—桑植—龙山—来凤整段完整显示，龙山、来凤都有清楚的来路。

## 5. 验证

- `check:heads` 121 段路线，0 个无来由端点；
- `check:routes` 0 问题；
