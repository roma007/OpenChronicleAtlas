# 对话档案：M149 路线图层显示控制

- **日期**：2026-11-15
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M149 计划](../plans/2026-11-15-M149-路线图层显示控制-plan.md)、[M149 方案](../plans/2026-11-15-M149-路线图层显示控制-design.md)

## 1. 原始需求

用户：

> 给路线图层菜单栏里的每条路线增加2个按钮，一个是显示/隐藏按钮（目前是直接点击路线进行切换，但是门槛高了），一个是独显（就是隐藏其他所有路线），再在路线图层菜单栏右上角增加一个全显按钮（就是显示所有路线）

## 2. 实现

### 每行右侧两个按钮

| 按钮 | 图标 | 行为 |
| --- | --- | --- |
| 显示/隐藏 | 眼睛（隐藏时带斜线） | 切换该主体；按下态朱红底色 |
| 独显 | 准星 | 只保留该主体；再次点击恢复独显前的选择 |

行内的颜色圆点 + 名称仍然可点，保留原来的切换方式作为大目标；新增的两个图标按钮是显式入口。

### 标题右侧全显

「路线图层」标题改成 flex 两端对齐，右侧加「全显」小按钮；全部主体都显示时按钮禁用，避免无意义的点击。

### store

- 新增 `preSoloEntityIds` 快照、`soloEntity(id)`、`showAllEntities()`；
- `toggleEntity`、`setActiveEntities`、`loadAtlas` 清空快照，防止恢复过期选择。

## 3. 验证

- 浏览器 DOM 实测：
  - 独显中央红军后，只有它的 `aria-pressed=true`，其余为 false；
  - 再点一次独显，恢复为独显前的「除红二方面军外全部显示」；
  - 点全显后全部为 true，全显按钮 `disabled=true`；
  - 点红二方面军的眼睛按钮，该行变为 false，其余保持 true。
- `pnpm typecheck`、`pnpm lint`、`pnpm test` 通过。
