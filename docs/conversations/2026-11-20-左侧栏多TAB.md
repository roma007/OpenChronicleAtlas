## 1. 原始需求

> 左侧栏做多TAB模式

## 2. 背景

左侧栏 `Legend` 原来是一个连续长面板：图层开关 → 地区筛选 → 实体列表 → 路线样式 → 说明 → 分类筛选 → 日期范围。内容超过一屏，桌面上滑到「筛选」就看不到「图层」，移动端弹层更明显。

## 3. 方案

拆成四个 TAB：

| TAB | 内容 |
| --- | --- |
| 图层 | 时代疆域、历史省界、地区标注；各实体显隐 / 独显 / 全显 |
| 地区 | 地区光圈、搜索、省→县→地点树、本区事件 / 路线、复制链接 / 定位 / 搜本区 |
| 筛选 | 事件分类、起止日期、重置 |
| 说明 | 路线样式图例、齿线与线头说明、专题备注 |

实现要点：

- `Legend.tsx` 增加本地 `tab` 状态，四个 `role="tabpanel"` 面板用 `hidden` 控制显隐（内容不卸载，地区搜索词等状态保留）；
- 使用 `useId()` 生成唯一 DOM id，避免桌面版与移动弹层同时挂载时 id 冲突；
- 切换 TAB 时把面板 `scrollTop` 归零；
- 已选地区、或分类/日期筛选生效时，对应 TAB 显示小红点；
- `RegionFilter` 增加 `embedded` 参数，嵌入 TAB 时去掉上边距与分隔线。

## 4. 取舍

| 选项 | 结论 | 原因 |
| --- | --- | --- |
| 继续加折叠面板 | 不采纳 | 嵌套折叠层级太深，仍要滚动 |
| 只在桌面做 TAB | 不采纳 | 移动端同一个组件，顺带受益 |
| 四 TAB + 隐藏面板不卸载 | **采纳** | 状态保留，逻辑简单 |
| 用路由切换 TAB | 不采纳 | 会污染 URL，且无分享需求 |
