## 6. 去掉封面白色遮罩

用户要求：

> 把封面上的白色半透明遮罩去掉我看看效果

处理：

- Web 删除 `SCRIM` 渐层，移动端删除左侧五条半透明分条；
- 文字改为浅色描边阴影（`text-shadow` / `textShadow`），在深色画面上仍有轮廓，但不再整片压白；
- 封面图完整露出。

代价：深色画面（三国、明清、抗日战争、长征）上标题对比度明显下降。若接受不了，可改为「只保留文字后的小范围渐变」或「文字移到图片下方」。

## 7. 恢复遮罩并调高不透明度

用户反馈无遮罩效果差，要求恢复之前的半透明遮罩，并把透明度再调高一些。

最终取值（Web 横向渐层）：

| 位置 | 不透明度 |
| --- | --- |
| 0% | 0.97 |
| 32% | 0.92 |
| 52% | 0.70 |
| 72% | 0.25 |
| 90% | 0 |

比 `1.0.81` 的原遮罩（0.96 / 0.90 / 0.62 / 0.18 / 88%）略强，右侧仍保留约 40% 的画面；移动端用六条 12% 宽的分条近似同一渐变。文字保留浅色描边阴影。

## 8. 临时遮罩滑杆

用户要自己试遮罩透明度，首页「历史专题」标题右侧加了临时滑杆：

- 范围 0—100%，默认 97%；
- `scrimGradient(max)` 把 5 个渐层停靠点按同一比例缩放（0.95 / 0.72 / 0.26 / 0）；
- 取值写入 `localStorage`（`atlas-cover-scrim`），刷新后保留；
- 「重置」回到 97%；
- 仅 Web，用于确定最终数值；确定后移除滑杆并把数值写死。

## 8. 验证

- `typecheck`、`lint` 通过。

## 9. 副文字加粗与临时字号滑杆

用户要求：

> 再弄个临时的文字大小调节，我用来试一下封面上除了主标题之外的其他字体的大小。另外直接给封面上除了主标题之外的其他字体都加粗，这个不用弄临时配置。

- 所有非主标题文字（年代、英文名、中文关键词、英文关键词、品牌行、底部注记）统一 `font-weight: 600`（Web `font-semibold`，移动端 `fontWeight: '600'`），此项为永久改动；
- 首页新增第二个临时滑杆「副文字」：60%—200%，默认 100%，按比例缩放上述所有非标题文字与行距，取值存 `localStorage`（`atlas-cover-subscale`），带重置；
- 主标题字号不随滑杆变化；
- 150% 时品牌行会换行并与注记重叠，属预期的越界提示，实际取值建议 100%—120%。

## 10. 专题卡只保留封面

用户要求去掉专题卡下半部分，只留封面，封面上的文字保留。

- Web `AtlasCard` 删除标题、副标题、标签与「进入专题」区块，只保留 16:9 封面与 `coverText` 叠加文字；链接加 `aria-label={title}`。
- 移动端 `GalleryScreen` 删除 `cardBody`，卡片只剩封面；`accessibilityLabel` 原本就是标题，保持不变。
- 卡片变为纯图块，点击整张图进入专题。

## 11. 临时遮罩模式切换

为对比不同文字可读性方案，首页控件区加了四选一：

| 模式 | 做法 |
| --- | --- |
| 整图 | 横向渐层覆盖整张封面（当前默认） |
| 局部 | 以左上为圆心的径向渐层，只压文字所在的左侧区域 |
| 毛玻璃 | 左侧 56% 宽度加 `backdrop-filter: blur(10px)` 与淡宣纸底色，文字落在磨砂带上 |
| 描边 | 不加任何底色，只给文字更强的浅色描边阴影 |

- 取值存 `localStorage`（`atlas-cover-mode`）；
- 「封面遮罩」滑杆在整图/局部模式下控制渐层强度，在毛玻璃模式下控制底色浓度，描边模式无效；
- 仅 Web 临时对比用，确定方案后移除切换器与未采用的实现。
