# 对话档案：封面换成项目提供的 AI 插画

- **日期**：2026-11-16
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[封面文字恢复](2026-11-16-封面文字恢复.md)、[数据来源说明](../../data/atlases/ATTRIBUTION.md)

## 1. 需求

> 我给每个专题弄了封面图，放在桌面，拿去替换掉现在的，每张图3M，如果不需要那么清晰的，就先缩小再替换

桌面共 11 张，命名与专题一一对应：

`长征`、`郑和下西洋`、`丝绸之路：玄奘西行`、`抗日战争`、`徐霞客游记`、`京杭大运河`、`三国`、`宋元`、`隋唐`、`明清`、`西路军`。

## 2. 处理

- 原图均为 **2047×1152（16:9）**，无需裁切，直接缩放到 **1600×900**；
- 统一转 JPEG（q4），11 张合计 **2.8 MB**（原图合计约 39 MB）；
- 文件名继续带内容哈希（`cover-<hash>.jpg`），换图自动绕过旧缓存；
- 封面文字**不写入图片**，仍由 `coverText` 字段在 Web/移动端叠加渲染；
- 图片右下角保留生成工具的「豆包 AI 生成」水印，未裁剪、未抹除。

## 3. 来源说明

`data/atlases/ATTRIBUTION.md` 的封面章节改为：

- 封面由项目负责人提供（豆包 AI 生成），是示意插画，不对应具体史实场景；
- 此前的公有领域画作/老照片封面于 `1.0.81` 停用，来源记录保留在 git 历史与 CHANGELOG（`1.0.77`—`1.0.80`）。

## 4. 验证

- `validate:data`：11 专题 / 911 事件 / 654 路线段；
- `build:mobile-data --check` 通过（53 文本 / 11 图片）；
- 首页 11 张封面全部 1600×900 加载，文字叠加正常；
- 总封面体积 2.8 MB（此前公有领域版 3.2 MB，烘焙文字版 6.7 MB）。

## 5. 提交与发布

版本由钩子从 `1.0.80` 升到 `1.0.81`，tag `v1.0.81`，提交后立即 `pnpm release`。

## 6. 去掉封面白色遮罩

用户要求：

> 把封面上的白色半透明遮罩去掉我看看效果

处理：

- Web 删除 `SCRIM` 渐层，移动端删除左侧五条半透明分条；
- 文字改为浅色描边阴影（`text-shadow` / `textShadow`），在深色画面上仍有轮廓，但不再整片压白；
- 封面图完整露出。

代价：深色画面（三国、明清、抗日战争、长征）上标题对比度明显下降。若接受不了，可改为「只保留文字后的小范围渐变」或「文字移到图片下方」。

## 7. 恢复遮罩并调高不透明度

用户反馈无遮罩效果差，要求恢复之前的半透明遮罩，并把透明度再调高一些。

最终取值（Web 横向渐层）：

| 位置 | 不透明度 |
| --- | --- |
| 0% | 0.97 |
| 32% | 0.92 |
| 52% | 0.70 |
| 72% | 0.25 |
| 90% | 0 |

比 `1.0.81` 的原遮罩（0.96 / 0.90 / 0.62 / 0.18 / 88%）略强，右侧仍保留约 40% 的画面；移动端用六条 12% 宽的分条近似同一渐变。文字保留浅色描边阴影。
