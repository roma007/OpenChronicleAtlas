## 1. 原始需求

用户：

> 红二、六方面军在1935年11月19日之前啥都没有吗？

核实结果：数据中此前只有 1935-11-19 的国民党军追堵事件和一条 1935-11-19 起的红二方面军示意路线，红二、六军团自身的西征、会师、苏区反“围剿”与长征节点均缺失。

同时澄清术语：1935 年 11 月前为红二、六军团；红二方面军于 1936 年 7 月成立。

## 2. 本轮范围

| 类型 | 新增 |
| --- | --- |
| 红六军团 | 遂川西征出发、木黄会师 |
| 红二、六军团 | 十万坪、陈家河、忠堡、板栗园、桑植出发、乌蒙山、石鼓渡江、甘孜会师、红二方面军成立 |
| 国民党军 | 湘鄂川黔苏区“围剿” |
| 实体 | 新增 `red-6-army` |
| 路线 | 新增红六军团线，拆分红二军团线并补苏区支线 |

共 12 个事件，新增 1 条红六军团路线、拆分 1 条红二军团路线、新增 1 段国民党军路线。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 新增 `red-6-army` 实体 | 红六军团西征是独立主线 |
| D2 | 把单段红二路线拆成 6 段 | 让 1935-11 前后的节点都有对应路线 |
| D3 | 补 3 段苏区支线 | 忠堡、板栗园、陈家河不在主线上 |
| D4 | 时间范围前移到 1934-08-07 | 覆盖红六军团西征 |
| D5 | 修正会宁会师表述 | 红二方面军实际在将台堡会师 |
| D6 | 搜索索引重新生成 | 事件数变化 |
