## 3. 讨论与决策

| 编号 | 议题 | 结论 | 依据 |
| --- | --- | --- | --- |
| D1 | 第二专题选题 | **郑和下西洋（1405—1433）** | 时间跨度清晰、航线多、史料丰富、日期为正年份 |
| D2 | 数据规模 | 6 条航线（7 次航行合并）+ 24 个事件 + 3 个实体 | 满足 20–30 事件要求 |
| D3 | 是否改代码接入 | 只新增数据包 + 更新索引；不改加载逻辑 | 验证「专题可插拔」 |
| D4 | 部署平台 | Vercel 为主，Cloudflare Pages 备选 | 静态站点 + 环境变量简单 |
| D5 | 数据托管 | 与 Web 同域 `/data/atlases`，移动端指向部署域名 | 同一套数据 |
| D6 | 图标/启动图 | 自制 SVG → PNG，庄重历史风 | 不引入版权风险 |
| D7 | 隐私政策 | Web `/privacy` 页面；移动端同意页链接到该页面 | 合规 |
| D8 | iOS | 仍受 AMap SDK 模拟器切片限制；M5 只准备真机/IPA 清单 | 需 Apple 账号 |
| D9 | 商店上架 | 准备元数据/截图/隐私说明；实际提交需账号 | 外部依赖 |
| D10 | 文档先行 | 先提交 M5 plan/design/ADR-0008，确认后实施 | 铁律 |
