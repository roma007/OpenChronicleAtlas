## 1. 原始需求

> 抗日战争历史省界，察哈尔省、甘肃省、河北省、河南省、湖北省、吉林省、辽宁省、陕西省、浙江省，这几个省都有一些横跨该省的直线，怎么回事？

## 2. 原因

`roc-provinces.geojson` 来自江山时序 `region` 图层。源数据里有相当多的环把**边界碎段**接在了环的末尾或中间，再用两条长直线连回主轮廓。渲染出来就是横跨全省的直线：

| 省 | 最长直线 | 结构 |
| --- | --- | --- |
| 陕西 | 884km | 主轮廓 + 7 点碎段，用 846/884km 连回 |
| 甘肃 | 1140km | 主轮廓 + 3 段碎段，用 756/1140/594km 连回 |
| 宁夏 | 1134km | 同上，1021/1134km |
| 青海 | 1094km | 1076/1094/411km |
| 湖北 | 697km | 三段大弧用 473/697/316km 相连 |
| 河南 | 537km | 395/537/162km |
| 河北 | 460km | 268/460/226km |
| 浙江 | 382km | 355/382km |
| 吉林 | 773km | 679/773/139km |
| 辽宁 | 490km | 281/490/363km |
| 察哈尔 | 610km | 610/548km |

上一轮只修了海南岛，用的是「切开长跳跃、保留最大闭合子环」，无法处理这类碎段错位。

## 3. 方案

新增 `scripts/roc_ring_repair.py`，对每个环通用处理：

1. 按 **50km** 切开环，得到真正的边界碎段；
2. 从最大碎段出发，每次接上**端点最近**的未用碎段，串成闭环；
3. 若某碎段让接缝总长比直接相连多出 **150km** 以上（典型是海南岛重复的北岸弧），丢弃它；
4. 固定环起点，保证重复运行稳定。

关键点：真实的长直边界（川康界 102°E、新疆界、察哈尔—热河等）在切开后端点重合，会被原样接回，不会被当成病态直线删除。

## 4. 落地

- `repair-roc-provinces.py`：对全部省界要素生效，四张快照一次修复；
- `import-roc-provinces.py`：简化后调用同一缝合逻辑，重新导入不复发；
- `check-region-index.ts`：海南专项检查升级为通用回归检查——线段 >170km，或中点两侧 20km 都在省域内，即报错。

## 5. 验证

| 检查 | 结果 |
| --- | --- |
| 旧数据（HEAD）跑新检查 | ❌ 29 处横跨直线（4 张快照合计） |
| 新数据跑新检查 | ✅ 0 处 |
| `check:heads` / `check:land` | 0 个无来由端点 / 0 段穿越陆地 |
| `validate:data` | 通过 |

| 几何自交 | 湖北、河南、陕西、甘肃、宁夏、青海、察哈尔、辽宁、吉林均降为 0 |
| 地图截图 | 湖北、河南、陕西、甘肃、河北、察哈尔、辽宁—吉林、浙江均无跨省直线 |

剩余 >80km 的线段全部是真实长直边界：川康界 165km、察哈尔—热河 118km、辽宁—热河 101km、新疆界 113km、海南北岸 96km 等。

## 6. 取舍

| 选项 | 结论 | 原因 |
| --- | --- | --- |
| 继续按省写特例 | 不采纳 | 已出现 11 个省，特例不可维护 |
| 手动画一遍省界 | 不采纳 | 工作量大、无史料依据 |
| 删掉所有 >100km 线段 | 不采纳 | 会破坏川康界等真实直线 |
| 切开 + 最近端点重建 + 丢弃重复弧 | **采纳** | 可复现，保留真实边界 |
| 用现代省界替代 | 不采纳 | 年代不符，违背史实 |
