M41 已为 127 段路线补 `segmentType`，本轮把它接入地图线型与图例。

## 2. 本轮范围

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 共享样式 | `routeStyleForSegmentType` 与 `segmentTypeLabel` |
| F2 | Web 线型 | 实线/虚线/点线、线宽与透明度 |
| F3 | Web 图例 | 「路线样式」区块 |
| F4 | 移动端 | 线宽/虚线 + 筛选面板图例 |
| F5 | 版本与 tag | `v0.42.0-m42` |

不在本轮范围：新增数据、箭头方向、动画、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 样式由共享函数统一 | Web / 移动端一致 |
| D2 | 反击用较粗实线 | 强调反攻方向 |
| D3 | 撤退/航行用虚线 | 与进攻区分 |
| D4 | 防御用点线 | 表示驻守/防线 |
| D5 | 图例只列当前专题存在的类型 | 避免空项 |
