# 把「疆域状态」说明从图例 tab 移到说明 tab

- **日期**：2026-11-28
- **触发**：用户问「为什么疆域状态说明不放说明 tab 里？」。上一轮（v1.0.291）把三行说明放在
  「图例」tab 的疆域开关下方，而路线线型图例在「说明」tab，同类视觉编码被拆成两处。
- **决定**：方案 A，整块移到说明 tab。
- **改动**：
  - `apps/web/src/components/layout/Legend.tsx`：
    - 图例 tab 移除三行色块，只在疆域开关下保留一行提示（`legend.polityStatus.hint`）；
    - 说明 tab 顶部新增「疆域状态」小节，与路线线型同样式（`h2` + 色块列表），
      顺序为「面样式（疆域状态）→ 线样式（路线类型）→ manifest 注记」。
  - `packages/shared/src/i18n/messages.ts`：新增中英文 `legend.polityStatus.hint`。
- **不变**：`polityStatus` 取值（`state` / `regime` / `tribal`）、`territoryVisualStyle` 渲染逻辑、
  移动端（未使用该图例块）均未改动。
- **校验**：`pnpm typecheck`、`pnpm lint`、`pnpm test` 通过；`check:versions` 由提交钩子升至 1.0.294。
