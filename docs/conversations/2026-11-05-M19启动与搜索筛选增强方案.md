## 1. 原始需求

用户：

> 继续

搜索页目前只支持关键词 + 专题筛选，不能按事件类型和时间段过滤。`searchEvents` 已支持 `category/from/to`，本轮进入 M19：搜索筛选增强。

## 2. 本轮范围

| 编号 | 功能 | Web | 移动端 |
| --- | --- | --- | --- |
| F1 | 事件类型筛选 | ✅ | ✅ |
| F2 | 时间段筛选 | ✅ | ✅ |
| F3 | 重置筛选 | ✅ | ✅ |
| F4 | 结果计数与空状态 | ✅ | ✅ |
| F5 | 中英文案 | ✅ | ✅ |

不在本轮范围：实体筛选、分词、纠错、APK/IPA 打包。

## 3. 关键决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 复用 `searchEvents` 的 `category/from/to` | 共享逻辑已存在 |
| D2 | 类型 chips 使用 `collectCategories` | 与专题筛选一致 |
| D3 | 时间段用日期输入 | 与筛选面板一致 |
| D4 | 非法日期忽略 | 不阻塞搜索 |
| D5 | 重置只清筛选，不清关键词 | 用户可保留搜索词 |
