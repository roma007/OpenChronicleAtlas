## 3. 调研结论

现有 `data/atlases/xuanzang`：37 条事件（行军 35 / 外交 2）、20 段路线，
`check:routes` 与 `check:heads` 均为 0 问题。缺的不是零散地点，而是四段主线：

1. **怎么活着走出大唐边境**：莫贺延碛失水、野马泉、伊吾全缺；
2. **中亚怎么走**：凌山之后直接到碎叶，缺大清池；碎叶之后直接到撒马尔罕，缺怛罗斯、赭时；
3. **印度怎么学**：迦湿弥罗两年被压成 10 天；缺北印度游学的至那仆底、阇烂达罗；
   缺那烂陀五年求学、王舍城巡礼、曲女城大会、钵罗耶伽无遮大会；
4. **怎么回来**：归途只有「启程归国 / 于阗 / 归抵长安」三点，缺信度河失经、活国、
   朅盘陀、疏勒、敦煌；且现有归途路线穿喜马拉雅、绕经高昌，与史实不符。

此外还有时间线硬伤：

- 曲女城大会写在 633 年（通行年表为 643，一说 641/642）；
- 启程归国写在 635 年（应在 643 年曲女城、钵罗耶伽之后）；
- 于阗写在 643 年（应在 644 年）；
- 那烂陀入寺写在 632 年（通行年表为 633/634）。

不修时间线，新补的事件会与旧日期互相矛盾。

### 3.1 关键约束

- `manifest.timeRange` = 629-08-01 → 645-01-24，轴外事件只能 warning 且无法在进度条定位；
- `check:routes` 默认 30km，且事件日期必须落在活动路线区间内；
- `check:heads` 默认 10km，相邻段必须共用锚点；
- 事件 id 内嵌日期，改日期就要改 id，旧分享链接会失效；
- 数据、索引、移动端生成物必须同一次提交。
