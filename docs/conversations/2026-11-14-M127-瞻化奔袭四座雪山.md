## 2. 结论

1936 年 4 月 1—4 日，红四军第十师从道孚出发，四天连续翻越四座海拔 4000 米以上雪山，4 月 4 日夜十时攻破瞻化（今新龙）县城。本轮把这段过程拆成 4 个行军事件 + 1 个战斗事件，并新增道孚—瞻化支线路线。

| 类型 | 新增 / 修正 |
| --- | --- |
| 事件 | 新增 5 个（4 垭口 + 1 破城） |
| 路线 | 新增红四方面军 order 5 支线 |
| 搜索索引 | 778 → 783 事件 |
| 版本 | 提交时钩子从 1.0.20 升到 1.0.21 |

> 版本说明：M125 发布的是 1.0.18，期间另一轮「备案前共享面收口」文档提交把版本推到 1.0.20（M126 编号已被占用），因此本批数据顺延为 M127、版本 1.0.21。

四个垭口事件类别为「行军」，夺取瞻化为「战斗」，坐标均取代表点并标 `approx`。

## 4. 路线修正

新增红四方面军 order 5：

**道孚 → 麻孜 → 亚洛阔 → 沙拥 → 伊涅阿 → 拉日马 → 扎巴加 → 甲拉西 → 瞻化**

- 与 order 4（丹巴—道孚—炉霍—甘孜）并行，是奔袭瞻化的支线；
- 时间范围 1936-04-01 → 1936-04-04；
- long-march 路线段 97 → 98。

## 5. 表述口径

- 垭口名称有两套系统：周军记为亚洛阔、沙拥、伊涅阿、扎巴加；四川日报等记为决益涅阿、伊则涅阿、伊涅阿、俄里涅阿。除伊涅阿外对应关系未定，标题用周军系统，描述注明另一套「尚待考证」；
- 陈伯钧日记的「麻子沟、热里科、甲子孔、腊科」作为日程与里程写入，不与现代地名强行对应；
- 不写「全歼守敌」，只写「夜十时攻破县城」；
- 红军自身伤亡写「有一定伤亡，具体数字待核」；
- 4 月 4 日的两个事件（翻越扎巴加山、夺取瞻化）按顺序分列，同一天。
