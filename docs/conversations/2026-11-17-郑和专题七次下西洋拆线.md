# 对话档案：郑和专题七次下西洋拆线与海防线降为背景

- **日期**：2026-11-17
- **参与者**：用户（项目负责人）、AI 开发助手（DeepSeek V4.1 Flash / OpenCode）
- **关联**：[M166 方案](../plans/2026-11-17-M166-郑和专题七次下西洋拆线-design.md)、[M166 计划](../plans/2026-11-17-M166-郑和专题七次下西洋拆线-plan.md)、[M165 明朝海防线](../plans/2026-11-17-M165-郑和专题明朝海防线-design.md)

## 1. 需求

M165 上线后，用户提出三点调整：

> 1、把明朝宝船队线拆分为7次下西洋，每一次一条线路。
> 2、去掉明朝海防线这条线路，但是保留在地图上的划线，因为它不是线路，而是防线。
> 3、分䑸不单独成一条线路，而是融入那7次下西洋线路中

## 2. 理解与决策

| 编号 | 议题 | 结论 |
| --- | --- | --- |
| D1 | 拆线粒度 | 每次下西洋一个实体、一条完整往返 `LineString` |
| D2 | 分䑸 | 删除独立实体，几何与事件并入第六次 |
| D3 | 天方支线 | 并入第七次，不再单独成段 |
| D4 | 海防线 | 实体与路线保留，标记 `extensions.legend = false`，只作地图背景 |
| D5 | 海防线开关 | 不进入图例；独显航次时仍显示，始终可见 |
| D6 | 路线样式 | 只统计图例内路线，因此不再显示「防御 / 驻守」 |
| D7 | 事件归属 | 按日期归入对应航次；1424 年停航事件归第六次 |

## 3. 实现要点

- `routes/voyages.geojson`：20 段船队路线 + 2 段分䑸合并为 7 条航次路线，保留 2 段海防线；
- `manifest.json`：删除 `ming-fleet`、`detached-squadron`，新增 `voyage-1` 至 `voyage-7`；海防线实体加 `legend: false`；
- `events.json`：41 个事件改挂 7 个航次实体；
- `AtlasEntity` 增加 `extensions`；
- Web 图例、Web 地图、移动端筛选面板、移动端地图同步；
- 移动端补上 `extensions.static` 的进度处理，海防线不再随时间逐段生长。

## 4. 验证

- 图例：7 个航次，各 1 段；无「明朝宝船队」「分䑸」「明朝海防线」；
- 地图：7 条航线按航次显示，第六次含榜葛剌支线，第七次含天方支线；
- 海防线：图例不列，但沿海红色点线与台湾环线仍显示；独显某航次时保留；
- `pnpm validate:data`、`pnpm check:heads --atlas zheng-he`、`pnpm typecheck`、`pnpm lint`、`pnpm test` 通过。
