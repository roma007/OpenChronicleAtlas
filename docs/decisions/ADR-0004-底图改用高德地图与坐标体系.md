## 背景（Context）

原方案使用 MapLibre GL JS / maplibre-react-native，底图走 OSM / MapTiler / 天地图。
用户在实际申请底图服务时选择**高德地图（AMap）**，并已开始申请 Android 平台 Key。
高德在国内访问稳定、有中文注记与合规资质，但其坐标体系、Key 体系、SDK 与 MapLibre 完全不同，必须重新定案。

## 选项（Options）

| 选项 | 优点 | 缺点 |
| --- | --- | --- |
| A. 维持 MapLibre + OSM/天地图 | 已有设计、矢量样式自由、无厂商锁定 | 国内访问与配额不稳定；天地图需单独 key；用户已倾向高德 |
| B. MapLibre + 高德栅格瓦片 URL | 保留 MapLibre 动画能力 | 瓦片 URL 非官方公开接口，违反服务条款风险高；GCJ-02 瓦片与 WGS84 数据错位；不可用于正式产品 |
| **C. 高德官方 JS API + 高德 Android/iOS SDK** | 国内稳定、中文底图、合规、官方支持自定义样式 | 放弃 MapLibre；需处理 GCJ-02 偏移；Key 分平台；商用需技术服务许可 |
| D. 高德底图 + 自绘图层（Canvas/WebGL） | 完全控制渲染 | 工作量大，等于自研地图引擎，M1 无法交付 |

## 决策（Decision）

1. **Web**：使用 **高德地图 JS API 2.0**（`@amap/amap-jsapi-loader`），申请「Web 端 (JS API)」Key + 安全密钥 `securityJsCode`。
   - 开发环境允许明文配置 `window._AMapSecurityConfig`；生产环境改为服务端代理转发（见高德官方文档）。
2. **移动端**：使用 **`expo-gaode-map`**（Expo Modules + Config Plugin，支持新架构），替代 `maplibre-react-native`。
   - 该库覆盖地图、Marker、Polyline、Cluster、自定义样式与定位，符合本项目需求。
   - M4 前做一次 PoC 验证；若与 Expo SDK 版本不兼容，回退候选为 `react-native-amap3d`（维护模式，需自行适配）。
3. **坐标体系**：
   - **数据包一律存储 WGS84**（GeoJSON / 事件经纬度），保持与其他 GIS 工具、公开史料的互操作。
   - 渲染到高德地图前，在 **shared** 中统一转换为 **GCJ-02**（火星坐标）；用户点击地图取点时再转回 WGS84。
   - 转换使用离线算法（WGS84 ↔ GCJ-02），不依赖高德 `convertFrom` 网络接口，避免配额与网络依赖；误差约 1–2 米，历史地图尺度可接受。
   - 时间轴、距离计算等逻辑仍基于 WGS84，避免坐标系污染业务层。
4. **应用标识**（Key 绑定，一经申请不要随意变更）：
   - Android `applicationId` / iOS `Bundle Identifier`：**`com.openchronicle.atlas`**
   - Android Key 名称：`atlas-android`；Web Key 名称：`atlas-web`；iOS Key 名称：`atlas-ios`
5. **Key 管理**：
   - 所有 Key 通过环境变量 / 本地配置文件注入，**不入库**。
   - Android 发布版与调试版 SHA1 分别登记；iOS 绑定 Bundle ID；Web 配置域名白名单。
   - 具体申请与配置步骤见 [`../guides/amap-setup.md`](../guides/amap-setup.md)。
6. **地图风格**：在高德控制台创建「自定义地图样式」，调成低饱和、暗红/土黄/墨色，Web 通过 `mapStyle: 'amap://styles/<styleId>'` 引用，移动端通过 SDK 对应接口引用；样式 ID 走配置。
7. **合规**：
   - 隐私政策必须列出高德 SDK 提供者、SDK 名称、收集的个人信息类型、使用目的与《高德地图开放平台隐私权政策》链接。
   - Android 必须在使用地图前完成隐私合规声明（`MapsInitializer.updatePrivacyShow/updatePrivacyAgree`，Expo 插件需确认已处理）。
   - 未购买技术服务许可时，Key 与配额仅限短期少量测试；上架/商用前需评估购买许可。

## 后果（Consequences）

### 正面
- 国内网络下底图稳定，中文注记完整，适合历史地图的中文用户。
- 官方 SDK 的 Marker / Polyline / Cluster 能力可直接满足路线与节点展示。
- 合规资质清晰，便于后续上架。

### 负面 / 代价
- **放弃 MapLibre**：原设计中的矢量样式、`line-gradient` 生长动画需改用高德 Polyline 的 `setPath` 分段更新实现；M2 动画方案需重新验证。
- **坐标转换**：所有渲染点都要转 GCJ-02，新增 shared 模块与测试；若遗漏会出现数百米偏移。
- **厂商锁定**：底图样式、配额、商用授权受高德约束；切换回 MapLibre 需重写地图适配层（但 shared 数据层不受影响）。
- **Key 体系复杂**：Android（SHA1 + 包名）、iOS（Bundle ID）、Web（域名白名单 + 安全密钥）分别申请，配置错误表现为地图空白。
- **Expo 生态风险**：`expo-gaode-map` 相对小众，需在 M4 做兼容性验证。
