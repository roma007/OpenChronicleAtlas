## 背景（Context）

M1–M3 已完成 Web 端。M4 要交付 Android APK/AAB 与 iOS IPA（或模拟器包），
并保证与 Web 使用同一套 shared 逻辑与同一套 `/data/atlases` 数据。
需要确定：导航方案、地图库、数据来源、详情交互、打包方式、签名与合规。

## 选项（Options）

### 导航

| 选项 | 优点 | 缺点 |
| --- | --- | --- |
| **A. React Navigation native-stack** | 成熟、原生转场、依赖少 | 与 Web React Router 不同，需要各自维护 |
| B. Expo Router | 文件路由、与 Expo 集成好 | 引入文件路由约定；对 M4 页面量偏重 |
| C. 单页状态切换 | 零依赖 | 无返回栈、深链与转场差 |

### 地图

| 选项 | 优点 | 缺点 |
| --- | --- | --- |
| **A. expo-gaode-map** | Expo Modules + Config Plugin，支持新架构，功能全 | 相对小众，需 T1 PoC |
| B. react-native-amap3d | 社区成熟、文档多 | 维护模式，Expo/新架构适配成本高 |
| C. WebView 套 Web 地图 | 复用 Web | 性能/手势/原生分享差，不符合「原生」预期 |

### 数据

| 选项 | 优点 | 缺点 |
| --- | --- | --- |
| **A. 远端同一套 `/data/atlases`** | 零副本、与 Web 完全一致、更新即时 | 依赖网络；真机需可访问开发机/域名 |
| B. 打包进 App | 离线可用 | 需要生成副本，违背「禁止各端维护副本」；包体增大 |
| C. 远端 + 本地缓存 | 兼顾 | M4 工作量大，M5 再评估 |

### 构建

| 选项 | 优点 | 缺点 |
| --- | --- | --- |
| **A. 本地 prebuild + Gradle/Xcode** | 完全可控、无需云账号、便于调试 | 依赖本机环境与签名 |
| B. EAS Build | 环境标准化、易出包 | 需 Expo 账号与云构建时间；密钥上传 |
| C. 混合（本地优先，EAS 备选） | 灵活 | 文档需维护两套流程 |

## 决策（Decision）

1. **导航**：React Navigation `native-stack`，页面：Gallery / Atlas / Search。
2. **地图**：`expo-gaode-map`，先做 T1 PoC；不兼容则回退 `react-native-amap3d` 或自定义 Expo Module。
3. **数据**：远端同一套 `/data/atlases`，通过 `EXPO_PUBLIC_DATA_BASE_URL` 配置；M4 不打包副本。
4. **详情/筛选**：使用 RN `Modal` 底部抽屉，暂不引入 `@gorhom/bottom-sheet`，减少原生依赖。
5. **分享/深链**：`Share.share` + `expo-linking`，scheme `atlas`；M5 再做 Universal Links / App Links。
6. **构建**：本地 `expo prebuild` + Gradle/Xcode 为主，EAS Build 作为备选；签名/证书全部在仓库外。
7. **合规**：首次启动隐私同意后再渲染地图；M4 不申请定位权限；隐私政策列出高德 SDK。

## 后果（Consequences）

### 正面
- shared 逻辑与数据完全复用，三端行为一致。
- 本地构建可控，便于快速迭代与排障。
- 不引入 WebView，地图手势与性能接近原生。

### 负面 / 代价
- `expo-gaode-map` 兼容性风险，需要 PoC 与回退预案。
- 原生模块不能用 Expo Go，必须 dev build/prebuild。
- iOS IPA 依赖 Apple Developer 账号与证书；无账号时只能交付模拟器包/未签名 archive。
- 远端数据依赖网络；离线能力缺失。
- React Navigation 与 Web Router 两套路由，深链需要分别处理。

### 后续行动
- T1 先验证 `expo-gaode-map`，记录实际 API 与版本。
- T10/T11 产出 APK/AAB 与 IPA（或模拟器包），在 `docs/releases/` 记录构建命令与产物校验值。
- M5 评估离线数据、Universal Links、底部抽屉库与商店素材。
