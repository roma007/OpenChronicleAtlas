# ADR-0011：地区索引与历史省界

- **状态**：已采纳
- **日期**：2026-11-20
- **关联**：
  - [Atlas Schema v1.2.0](../schema/atlas-schema-v1.2.0.md)
  - [M209 design](../plans/2026-11-20-M209-抗战按地区浏览-design.md)
  - [M209 plan](../plans/2026-11-20-M209-抗战按地区浏览-plan.md)

## 背景

抗日战争专题有 529 个事件、308 段路线。用户希望按省、市、县浏览，跨省路线保留起终点，并看到当时的名称与省界。

现状：

- 事件地点是自由文本 `location.place`，没有行政区编码；
- 路线只有坐标，没有经过的行政区；
- 320 个不同地名，仅 24 个明确含“县”；
- 1930—1940 年代没有今天的“地级市”层级；
- 民国县界没有可自由再分发的公开矢量数据。

## 决策

### 1. 采用“地区字典 + 构建期索引”，不在运行时解析文本

- `regions.json` 存历史行政区/地点树；
- `region-index.json` 存事件/路线归属，构建期生成；
- 运行时只做 Set 交集，不跑点面判断；
- 新增字段全部可选，旧客户端忽略。

### 2. 层级采用“省/院辖市 → 县市/地点”

- 不虚构今天的地级市；
- 有把握的挂县，否则直接挂省并标为“地点”；
- 县级只做筛选和名称，不画县界。

### 3. 省界用四张历史快照，只描边不填充

- 1931、1932—1937、1938—1944、1945；
- 来源为江山时序 `region` 图层（GPL-3.0，手工绘制）；
- 不使用 CHGIS 的 `prefecture` 图层；
- 界面标注“历史省界（示意）”，选中省时高亮，低缩放隐藏省名。

### 4. 跨省路线不裁剪

- 只要路线命中选区，整条保留；
- 在 6 级以上显示起终点标签；
- 不做几何裁剪，避免产生假线头，符合路线端点铁律。

### 5. 选区“最具体者优先”

- 同时选中省和县时，只保留县；
- 避免事件同时带省 id 时，按县筛选退化为按省筛选；
- 选中省时清掉其下县/地点，选中县/地点时去掉祖先。

## 备选方案

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 运行时解析 `place` 文本 | 未采纳 | 县级覆盖低、易错、不可复现 |
| 手工给 529 个事件写行政区 | 未采纳 | 难维护，易漂移 |
| 用现代县界套历史名称 | 未采纳 | 界线是现代、名字是当时，误导 |
| 用 CHGIS 1911 县界 | 未采纳 | 许可禁止再分发，年代不符 |
| 跨省路线裁剪到省内 | 未采纳 | 产生假线头，违背数据铁律 |
| 只做省级筛选 | 未采纳 | 用户明确要求市县；地名表可覆盖大部分 |
| 使用江山时序省界（GPL-3.0） | **采纳** | 有 1931—1945 快照，手工示意，可注明来源 |

## 后果

### 正面

- 省界可靠、可复现，事件/路线归属可自动重建；
- 省、县市、地点三级筛选可用，跨省路线保持完整；
- 新增字段可选，旧专题不受影响；
- 县界缺失被明确标注，不伪造精度。

### 负面 / 风险

- 县域覆盖不完整：320 个地点中约 2/3 能挂县，其余为“地点”；
- 省界为手工示意，不能作为精确边界；
- 江山时序数据为 GPL-3.0，需在 ATTRIBUTION 中单独声明；
- 院辖市没有面，只有点与事件归属；
- 伪满/汪伪/根据地仍按名义省区，需在文案中说明。

## 验收

- `pnpm validate:data` 输出地区索引检查通过；
- 529 事件、308 路线全部有地区归属；
- 选河北、上海、海外、清苑县，事件数正确；
- 跨省路线整条保留，6 级以上显示起终点；
- 省界可开关，选中省高亮，低缩放不堆叠省名。
